# 修改状态栏颜色
> 继续我们的vim魔改, 下面应该是完整的statusbar定义. 你看能否修改为配置状态栏颜色时只修改vim拓展的这部分颜色.

可以，而且我更建议这么改。

你现在这份代码的问题就在 `updateColor()`：

```ts
workbenchConfiguration.update('colorCustomizations', colorCustomizations, true);
```

它实际上是在修改 VSCode 的**全局 `workbench.colorCustomizations`**，所以：

* Vim 状态栏变色 ✅
* 其他扩展的 StatusBarItem 也可能跟着变色 ❌
* VSCode 整个 status bar 的背景/前景也可能被改掉 ❌
* 用户原本在 `settings.json` 里配置的颜色还会被运行时覆盖/污染 ❌

而 `this.statusBarItem` 本身就支持：

```ts
this.statusBarItem.backgroundColor
this.statusBarItem.color
```

所以完全没必要碰 `workbench.colorCustomizations`。

### 推荐改法

把 `updateColor()` 改成**直接设置 Vim 自己的 `StatusBarItem`**：

```ts
private updateColor(mode: Mode) {
  let foreground: string | undefined;
  let background: string | undefined;

  const colorToSet = (
    configuration.statusBarColors as unknown as Record<
      string,
      string | string[] | undefined
    >
  )[Mode[mode].toLowerCase()];

  if (colorToSet !== undefined) {
    if (typeof colorToSet === 'string') {
      background = colorToSet;
    } else {
      [background, foreground] = colorToSet;
    }
  }

  // 只修改 VSCodeVim 自己的 StatusBarItem。
  // 不再修改 workbench.colorCustomizations，
  // 因此不会影响 VSCode 其他状态栏项目。
  this.statusBarItem.backgroundColor = background;
  this.statusBarItem.color = foreground;
}
```

然后**整个删除**下面这一大段：

```ts
const workbenchConfiguration = configuration.getConfiguration('workbench');
const currentColorCustomizations: {
  [index: string]: string;
} = workbenchConfiguration.get('colorCustomizations') ?? {};

const colorCustomizations = { ...currentColorCustomizations };

if (background !== undefined) {
  colorCustomizations['statusBar.background'] = background;
  colorCustomizations['statusBar.noFolderBackground'] = background;
  colorCustomizations['statusBar.debuggingBackground'] = background;
  colorCustomizations['statusBarItem.prominentBackground'] = background;
}

if (foreground !== undefined) {
  colorCustomizations['statusBar.foreground'] = foreground;
  colorCustomizations['statusBar.debuggingForeground'] = foreground;
  colorCustomizations['statusBarItem.prominentForeground'] = foreground;
}

if (currentColorCustomizations !== colorCustomizations) {
  void workbenchConfiguration.update('colorCustomizations', colorCustomizations, true);
}
```

### 最终 `updateColor()` 就这么简单

```ts
private updateColor(mode: Mode) {
  let foreground: string | undefined;
  let background: string | undefined;

  const colorToSet = (
    configuration.statusBarColors as unknown as Record<
      string,
      string | string[] | undefined
    >
  )[Mode[mode].toLowerCase()];

  if (colorToSet !== undefined) {
    if (typeof colorToSet === 'string') {
      background = colorToSet;
    } else {
      [background, foreground] = colorToSet;
    }
  }

  this.statusBarItem.backgroundColor = background;
  this.statusBarItem.color = foreground;
}
```

**这样你的 `settings.json` 里的 `workbench.colorCustomizations` 就完全不需要被 VSCodeVim 动了。**

而且还有一个好处：你之前一直在折腾 Everforest 配色的话，现在可以放心给 Vim 自己搞一套，比如：

```json
    "insert": ["#7FBBB3", "#2D353B"],
    "visual": ["#D699B6", "#2D353B"],
    "replace": ["#E67E80", "#2D353B"]
}
```

这只会影响 **VSCodeVim 创建的那个 `primary` StatusBarItem**，不会再把 Git、语言模式、行列号、其他插件的东西一起染色。

另外，你现在 `statusBarText()` 里的这些图标：
