# 第八章：性能优化

## 8.1 延迟优化

### 8.1.1 延迟组成

端到端延迟包括：

```
总延迟 = 采集延迟 + 编码延迟 + 网络延迟 + 解码延迟 + 播放延迟
```

#### 各阶段延迟目标

- **采集延迟**：< 10ms
- **编码延迟**：< 50ms
- **网络延迟**：< 150ms（理想）
- **解码延迟**：< 20ms
- **播放延迟**：< 50ms
- **总延迟**：< 400ms（可接受）

### 8.1.2 采集优化

#### 设备选择

- **低延迟设备**：选择延迟低的采集设备
- **驱动优化**：使用优化的设备驱动
- **缓冲区设置**：减少设备缓冲区

#### 采集参数

```javascript
// 优化采集参数
const constraints = {
  audio: {
    sampleRate: 48000,        // 采样率
    channelCount: 1,          // 单声道（减少数据量）
    echoCancellation: true,   // 回声消除
    noiseSuppression: true,   // 降噪
    autoGainControl: true     // 自动增益
  },
  video: {
    width: 640,               // 降低分辨率
    height: 480,
    frameRate: 30,            // 帧率
    latency: 0                // 低延迟模式
  }
};
```

### 8.1.3 编码优化

#### 编码参数

- **低延迟模式**：使用低延迟编码配置
- **减少B帧**：B帧增加延迟
- **降低GOP**：提高I帧频率
- **硬件编码**：使用硬件编码器

#### 编码配置示例

```javascript
// H.264低延迟配置
const encoderConfig = {
  profile: 'baseline',        // Baseline profile（低延迟）
  level: '3.1',
  bitrate: 1000000,           // 码率
  framerate: 30,              // 帧率
  keyFrameInterval: 30,       // 关键帧间隔（1秒）
  latencyMode: 'realtime'     // 实时模式
};
```

### 8.1.4 网络优化

#### 传输优化

- **UDP传输**：使用UDP而非TCP
- **减少MTU**：使用较小的数据包
- **优先级队列**：音频优先于视频
- **快速重传**：关键帧快速重传

#### 路由优化

- **就近接入**：选择最近的服务器
- **智能路由**：选择最优路径
- **CDN加速**：使用CDN加速

### 8.1.5 播放优化

#### 缓冲策略

- **最小缓冲**：减少播放缓冲
- **动态缓冲**：根据网络状况调整
- **预加载**：提前加载关键帧

#### 播放参数

```javascript
// 优化播放参数
videoElement.playbackRate = 1.0;  // 播放速度
videoElement.buffered;            // 缓冲管理
```

## 8.2 带宽优化

### 8.2.1 自适应码率（ABR）

根据网络状况动态调整码率。

#### 实现原理

1. **网络监控**：监控带宽、丢包率、延迟
2. **质量评估**：评估当前网络质量
3. **码率调整**：根据质量调整码率

#### 码率阶梯

```javascript
const bitrateLadder = [
  { resolution: '320x240', bitrate: 200000 },   // 低质量
  { resolution: '640x480', bitrate: 500000 },   // 中等质量
  { resolution: '1280x720', bitrate: 1500000 }, // 高质量
  { resolution: '1920x1080', bitrate: 3000000 } // 超高质量
];
```

### 8.2.2 分辨率自适应

根据网络状况和屏幕大小调整分辨率。

#### 策略

- **网络好**：高分辨率
- **网络差**：低分辨率
- **小屏幕**：降低分辨率（节省带宽）

### 8.2.3 帧率自适应

根据网络状况和内容复杂度调整帧率。

#### 策略

- **静态场景**：降低帧率
- **动态场景**：提高帧率
- **网络差**：降低帧率

### 8.2.4 智能码率控制

#### 内容感知

- **简单场景**：降低码率
- **复杂场景**：提高码率
- **关键帧**：提高码率

#### 用户感知

- **人脸区域**：提高码率
- **背景区域**：降低码率
- **ROI编码**：感兴趣区域编码

## 8.3 网络质量监控

### 8.3.1 监控指标

#### 延迟（Latency）

```javascript
// 计算RTT
const rtt = receiveTime - sendTime;

// 目标：< 150ms
if (rtt > 150) {
  // 网络质量差，降低码率
  adjustBitrate('down');
}
```

#### 丢包率（Packet Loss）

```javascript
// 计算丢包率
const packetLoss = lostPackets / totalPackets;

// 目标：< 1%
if (packetLoss > 0.01) {
  // 丢包率高，降低码率
  adjustBitrate('down');
}
```

#### 抖动（Jitter）

```javascript
// 计算抖动
const jitter = calculateJitter(packetArrivalTimes);

// 目标：< 30ms
if (jitter > 30) {
  // 抖动大，增加缓冲
  increaseBuffer();
}
```

#### 带宽（Bandwidth）

```javascript
// 估算可用带宽
const availableBandwidth = calculateBandwidth(
  bytesReceived,
  timeInterval
);

// 根据带宽调整码率
if (availableBandwidth < currentBitrate) {
  adjustBitrate('down');
}
```

### 8.3.2 质量评估

#### 网络质量等级

```javascript
function assessNetworkQuality(rtt, packetLoss, jitter, bandwidth) {
  let score = 100;
  
  // 延迟评分
  if (rtt > 400) score -= 30;
  else if (rtt > 200) score -= 15;
  else if (rtt > 150) score -= 5;
  
  // 丢包率评分
  if (packetLoss > 0.05) score -= 30;
  else if (packetLoss > 0.01) score -= 15;
  else if (packetLoss > 0.005) score -= 5;
  
  // 抖动评分
  if (jitter > 50) score -= 20;
  else if (jitter > 30) score -= 10;
  
  // 带宽评分
  if (bandwidth < requiredBandwidth * 0.5) score -= 20;
  else if (bandwidth < requiredBandwidth * 0.8) score -= 10;
  
  // 质量等级
  if (score >= 80) return 'excellent';
  if (score >= 60) return 'good';
  if (score >= 40) return 'fair';
  return 'poor';
}
```

### 8.3.3 实时调整

```javascript
// 实时监控和调整
setInterval(async () => {
  const stats = await getNetworkStats();
  const quality = assessNetworkQuality(
    stats.rtt,
    stats.packetLoss,
    stats.jitter,
    stats.bandwidth
  );
  
  switch(quality) {
    case 'excellent':
      increaseQuality();
      break;
    case 'good':
      maintainQuality();
      break;
    case 'fair':
      decreaseQuality();
      break;
    case 'poor':
      decreaseQualitySignificantly();
      break;
  }
}, 1000); // 每秒检查一次
```

## 8.5 编码优化

### 8.5.1 编码参数优化

#### 码率控制

```javascript
// 自适应码率控制
class AdaptiveBitrateController {
  constructor() {
    this.currentBitrate = 1000000; // 1Mbps
    this.minBitrate = 200000;      // 200kbps
    this.maxBitrate = 5000000;     // 5Mbps
  }
  
  adjustBitrate(networkQuality) {
    if (networkQuality === 'excellent') {
      this.currentBitrate = Math.min(
        this.currentBitrate * 1.2,
        this.maxBitrate
      );
    } else if (networkQuality === 'poor') {
      this.currentBitrate = Math.max(
        this.currentBitrate * 0.8,
        this.minBitrate
      );
    }
  }
}
```

#### 分辨率自适应

```javascript
// 分辨率自适应
const resolutionLevels = [
  { width: 320, height: 240 },
  { width: 640, height: 480 },
  { width: 1280, height: 720 },
  { width: 1920, height: 1080 }
];

function adjustResolution(networkQuality, currentLevel) {
  if (networkQuality === 'excellent' && currentLevel < resolutionLevels.length - 1) {
    return currentLevel + 1;
  } else if (networkQuality === 'poor' && currentLevel > 0) {
    return currentLevel - 1;
  }
  return currentLevel;
}
```
