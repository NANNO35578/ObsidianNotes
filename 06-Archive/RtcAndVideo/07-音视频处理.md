# 第七章：音视频处理

## 7.1 音频处理

### 7.1.1 音频采集

#### 采集流程

```
麦克风 → 音频驱动 → 应用层 → 处理 → 编码
```

#### 采集参数

- **采样率**：8kHz - 48kHz
- **位深度**：16bit、24bit
- **声道**：单声道、立体声
- **格式**：PCM

### 7.1.2 音频预处理

#### 自动增益控制（AGC）

自动调整音量，保持稳定的输出音量。

**应用场景**：
- 说话距离变化
- 环境噪音变化
- 不同设备音量差异

**实现原理**：
- 检测输入音量
- 动态调整增益
- 避免削波失真

#### 噪声抑制（NS）

降低环境噪音，提高语音清晰度。

**应用场景**：
- 办公室环境
- 户外环境
- 设备噪音

**实现原理**：
- 频谱分析
- 噪声模型建立
- 噪声过滤

#### 回声消除（AEC）

消除扬声器声音被麦克风采集的回声。

**应用场景**：
- 免提通话
- 视频会议
- 直播连麦

**实现原理**：
- 参考信号（播放的音频）
- 自适应滤波
- 回声信号估计和消除

#### 静音检测（VAD）

检测是否有语音活动，用于：
- 节省带宽（静音时不发送）
- 降低噪音
- 提高通话质量

### 7.1.3 音频后处理

#### 混音

将多路音频混合成一路。

**应用场景**：
- 多人会议
- 背景音乐
- 音效叠加

**实现原理**：
- 多路音频叠加
- 防止削波（归一化）
- 音量平衡

#### 音频特效

- **变声**：改变音调
- **混响**：添加空间感
- **均衡器**：调整频率响应

### 7.1.4 音频播放

#### 播放流程

```
解码 → 后处理 → 音频驱动 → 扬声器
```

#### 播放优化

- **缓冲管理**：减少延迟，避免卡顿
- **音量控制**：动态调整播放音量
- **同步处理**：与视频同步

## 7.3 音视频同步

### 7.3.1 同步原理

音视频同步需要：
- **时间戳**：每个数据包的时间戳
- **时钟同步**：统一的时钟基准
- **缓冲管理**：合理的缓冲策略

### 7.3.2 同步策略

#### 音频为主

以音频时间戳为基准，调整视频播放速度。

**优点**：
- 音频对延迟更敏感
- 用户体验好

**缺点**：
- 视频可能轻微跳帧

#### 视频为主

以视频时间戳为基准，调整音频播放速度。

**优点**：
- 视频流畅

**缺点**：
- 音频可能变调

#### 系统时钟

使用系统时钟作为统一基准。

**优点**：
- 同步准确

**缺点**：
- 需要精确的时钟同步

### 7.3.3 同步实现

```javascript
// 伪代码示例
class AVSync {
  constructor() {
    this.audioTime = 0;
    this.videoTime = 0;
    this.syncThreshold = 40; // 40ms
  }
  
  updateAudioTime(timestamp) {
    this.audioTime = timestamp;
    this.checkSync();
  }
  
  updateVideoTime(timestamp) {
    this.videoTime = timestamp;
    this.checkSync();
  }
  
  checkSync() {
    const diff = Math.abs(this.audioTime - this.videoTime);
    if (diff > this.syncThreshold) {
      // 调整视频播放速度
      this.adjustVideoSpeed();
    }
  }
}
```
