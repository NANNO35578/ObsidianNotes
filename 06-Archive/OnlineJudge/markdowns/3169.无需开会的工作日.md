[3169. 无需开会的工作日](https://leetcode.cn/problems/count-days-without-meetings/)

##### 排序
- 按照**第一元素优先**，**第二元素作为次要比较**. 即`std::sort`默认规则
- 然后对于当前天数，进行处理若为区间前，增加工作天数，若在区间内或右侧，更新当前天数

```cpp
    int countDays(int days, vector<vector<int>>& meetings) {
        sort(meetings.begin(), meetings.end(),
             []( vector<int>& a,  vector<int>& b) {
                 return (a[0] < b[0]) ;
             });

        int ans = 0;
        int currentDay = 0;
        for (vector<int>& vec : meetings) {
            int beg = vec[0];
            int end = vec[1];

            if (currentDay < beg) {
                ans += beg - currentDay - 1;
                currentDay = end;
            } else if (currentDay < end) {
                currentDay = end;
            } else if (currentDay > end) {
                continue;
            }
        }

        if (days > currentDay) {
            ans += days - currentDay;
        }

        return ans;
    }
```

##### 差分
*对于此题数据量太大，超出内存*

- 初始化差分数组`{1,0,0,0...}`
- 可将区间更新减小到$O(1)$时间复杂度, 遍历会议容器
- 对于每个区间，更新l与r
- 求出每天的偏移，若为1即工作时间，否则为会议时间

时间复杂度$O(n+m)$ 空间复杂度$O(n)$


```cpp
    int countDays(int days, vector<vector<int>>& meetings) {
        int ans = 0;
        std::vector<int> dif(days, 0);
        dif[0] = 1;

        for (vector<int>& vec : meetings) {
            int beg = vec[0] - 1;
            int end = vec[1] - 1;

            dif[beg] -= 1;
            if (days > end + 1) dif[end + 1] += 1;
        }

        int sum = 0;
        for (int i : dif) {
            sum += i;
            if (sum == 1) {
                ++ans;
            }
        }

        return ans;
    }
```
