[146. LRU 缓存](https://leetcode.cn/problems/lru-cache/)

*可不将缓存的`key`与`value`存储到一起*
##### 哈希表和双向链表
### 1. 数据结构选择
1. 首先考虑到我们要存储数据的key与value，同时要记录优先级
2. 其次，添加删除等操作要尽量小
- **哈希表（Hash Map）**：
    - 用于快速存储和访问缓存中的键值对
    - 允许 O(1) 的时间复杂度来检索缓存值
- **双向链表（Doubly Linked List）**：
    - 用于维护缓存的访问顺序
    - 最近访问的节点放在链表的头部，最久未访问的节点放在链表的尾部
    - 允许在 O(1) 的时间复杂度内插入和删除节点

### 2. 核心操作
#### 获取 (get) 操作
1. **查找**：
    - 使用哈希表查找键。
    - 如果找到，获取对应的节点。
2. **移动到头部**： 将该节点移动到链表的头部，表示最近使用。
3. **返回值**： 返回节点的值。如果未找到，返回 -1。

#### 插入 (put) 操作

1. **查找**： 使用哈希表检查键是否存在。
2. **更新或插入**：
    - 如果存在，更新节点的值并将其移动到头部。
    - 如果不存在，创建一个新节点并插入到链表的头部，同时添加到哈希表中。
3. **容量检查**：
    - 每次插入后检查缓存的大小。
    - 如果超出容量，调用弹出尾部节点的函数，删除最久未使用的节点，并从哈希表中删除相应的条目。

### 3. 具体操作流程
- **初始化**： 创建一个虚拟头部和尾部节点，以方便管理链表的插入和删除操作。
- **移动节点**： 定义一个函数来将指定节点移动到链表头部，涉及移除节点，然后重新插入到头部。
- **移除尾部节点**： 定义一个函数来移除链表尾部的节点，这个节点是最久未使用的，删除后更新哈希表。

### 4. 时间复杂度
- `get` 和 `put` 操作都可以在 O(1) 的时间复杂度内完成：
    - 哈希表提供了 O(1) 的查找时间。
    - 双向链表的插入和删除操作也为 O(1)。

```cpp
#include <unordered_map>

class LRUCache {
private:
    struct Node {
        int key;
        int value;
        Node* prev;
        Node* next;
        Node(int k, int v) : key(k), value(v), prev(nullptr), next(nullptr) {}
    };

    std::unordered_map<int, Node*> cache;
    Node* head;
    Node* tail;
    int capacity;
    int size;

    void moveToHead(Node* node) {
        // Remove node from its current position
        removeNode(node);
        // Insert node at head
        node->next = head->next;
        node->prev = head;
        head->next->prev = node;
        head->next = node;
    }

    void removeNode(Node* node) {
        Node* prevNode = node->prev;
        Node* nextNode = node->next;
        prevNode->next = nextNode;
        nextNode->prev = prevNode;
    }

    void popTail() {
        Node* node = tail->prev;
        removeNode(node);
        cache.erase(node->key);
        delete node;
    }

public:
    LRUCache(int capacity) : capacity(capacity), size(0) {
        head = new Node(0, 0); // Dummy head
        tail = new Node(0, 0); // Dummy tail
        head->next = tail;
        tail->prev = head;
    }

    ~LRUCache() {
        Node* current = head;
        while (current) {
            Node* next = current->next;
            delete current;
            current = next;
        }
    }

    int get(int key) {
        if (cache.find(key) != cache.end()) {
            Node* node = cache[key];
            moveToHead(node);
            return node->value;
        }
        return -1; // Not found
    }

    void put(int key, int value) {
        if (cache.find(key) != cache.end()) {
            Node* node = cache[key];
            node->value = value;
            moveToHead(node);
        } else {
            Node* newNode = new Node(key, value);
            cache[key] = newNode;
            moveToHead(newNode);
            size++;

            if (size > capacity) {
                popTail();
                size--;
            }
        }
    }
};
```
