- **归并排序基础**：
    - 归并排序的核心是将数组分成两半，分别进行排序，然后将两个已排序的数组合并成一个排序好的数组。
- **统计逆序对**：
    - 在合并的过程中，我们可以统计逆序对。当我们从左边的子数组中取一个元素时，如果这个元素大于右边子数组中的某个元素，那么这个元素及其右边的所有元素都与该元素形成逆序对。
    - 假设左边子数组的当前元素是 `L`，右边子数组的当前元素是 `R`，如果 `L > R`，那么 `L` 与右边子数组中所有尚未合并的元素都形成逆序对。
- **实现细节**：
    - 使用一个辅助数组来存储合并后的结果。
    - 递归地对数组进行分割和合并，同时在合并的过程中统计逆序对的数量。
- **时间复杂度与空间复杂度**：
    - 时间复杂度为 O(n log n)，因为归并排序的分割和合并过程都是 O(n log n)。
    - 空间复杂度为 O(n)，用于存储辅助数组。
```cpp
    int mergeAndCount(vector<int>& arr, vector<int>& temp, int left, int mid,
                      int right) {
        int i = left;     // 左边子数组的起始索引
        int j = mid + 1;  // 右边子数组的起始索引
        int k = left;     // 合并后数组的起始索引
        int invCount = 0;
 
        while (i <= mid && j <= right) {
            if (arr[i] <= arr[j]) {
                temp[k++] = arr[i++];
            } else {
                temp[k++] = arr[j++];
                invCount += (mid - i + 1);  // 统计逆序对
            }
        }
 
        while (i <= mid) {
            temp[k++] = arr[i++];
        }
 
        while (j <= right) {
            temp[k++] = arr[j++];
        }
 
        for (i = left; i <= right; i++) {
            arr[i] = temp[i];
        }
 
        return invCount%1000000007;
    }
 
    // 归并排序并计数逆序对
    int mergeSortAndCount(vector<int>& arr, vector<int>& temp, int left,
                          int right) {
        int invCount = 0;
        if (left < right) {
            int mid = (left + right) / 2;
 
            invCount += mergeSortAndCount(arr, temp, left, mid);
            invCount += mergeSortAndCount(arr, temp, mid + 1, right);
            invCount += mergeAndCount(arr, temp, left, mid, right);
        }
        return invCount % 1000000007;
    }
    int InversePairs(vector<int>& nums) {
        // write code here
        if (nums.empty()) return 0;
        vector<int> temp(nums.size());
        return mergeSortAndCount(nums, temp, 0, nums.size() - 1);
    }
```

##### 1. 树状数组（Fenwick Tree）
使用树状数组可以在 O(n log n) 的时间复杂度内统计逆序对。基本思路是从右到左遍历数组，维护一个树状数组来记录已处理元素的频率。

##### 2. 线段树
类似于树状数组，线段树也可以用于动态统计逆序对。你可以在遍历时更新和查询频率。

##### 3. 排序 + 二分查找
可以先对数组进行排序，然后使用二分查找来查找每个元素在已处理元素中的位置，从而计算逆序对。

##### 树状数组的实现示例
- **树状数组类** (`FenwickTree`):
    - 提供 `update` 和 `query` 方法，用于更新和查询频率。
- **`countInversions` 函数**:
    - 首先进行坐标压缩，然后从后向前遍历数组，利用树状数组统计逆序对。
- **`main` 函数**:
    - 提供一个示例数组，计算逆序对，并输出结果对 `1000000007` 取模。
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class FenwickTree {
public:
    FenwickTree(int size) : tree(size + 1, 0) {}

    void update(int index, int value) {
        while (index < tree.size()) {
            tree[index] += value;
            index += index & -index;
        }
    }

    int query(int index) {
        int sum = 0;
        while (index > 0) {
            sum += tree[index];
            index -= index & -index;
        }
        return sum;
    }

private:
    vector<int> tree;
};

int countInversions(vector<int>& arr) {
    int n = arr.size();
    // 对数组进行坐标压缩
    vector<int> sortedArr = arr;
    sort(sortedArr.begin(), sortedArr.end());
    
    for (int i = 0; i < n; ++i) {
        arr[i] = lower_bound(sortedArr.begin(), sortedArr.end(), arr[i]) - sortedArr.begin() + 1;
    }

    FenwickTree fenwickTree(n);
    int invCount = 0;

    // 从右到左遍历
    for (int i = n - 1; i >= 0; --i) {
        invCount += fenwickTree.query(arr[i] - 1); // 查询当前值左边的元素数量
        fenwickTree.update(arr[i], 1); // 更新当前值的频率
    }

    return invCount;
}

int main() {
    vector<int> arr = {5, 3, 4, 2, 1};
    int result = countInversions(arr) % 1000000007;
    cout << result << endl;
    return 0;
}
```
