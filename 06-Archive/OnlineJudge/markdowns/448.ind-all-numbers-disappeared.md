[找到所有数组中消失的数](https://leetcode.cn/problems/find-all-numbers-disappeared-in-an-array/description/)
- 用STL
```cpp
    vector<int> findDisappearedNumbers(vector<int>& nums) {
        vector<bool> tab(nums.size(), 0);
        for (int i : nums) 
            tab[i - 1] = 1;
        
        vector<int> ans;
        for (int i = 0; i < tab.size(); ++i) 
            if (tab[i] == false) ans.push_back(i + 1);
        
        return ans;
    }
```
# 原地修改
 - 由于 nums 的数字范围均在 [1,n] 中，我们可以利用这一范围之外的数字，来表达「是否存在」的含义。
 - 具体来说，遍历 nums，每遇到一个数 x，就让 nums[x−1] 增加 n。由于 nums 中所有数均在 [1,n] 中，增加以后，这些数必然大于 n。最后我们遍历 nums，若 nums[i] 未大于 n，就说明没有遇到过数 i+1。这样我们就找到了缺失的数字。
 - 注意，当我们遍历到某个位置时，其中的数可能已经被增加过，因此需要对 n 取模来还原出它本来的值。
```cpp
    const int mod = 998244353;
    vector<int> findDisappearedNumbers(vector<int>& nums) {
        int n = nums.size();
        for (auto& num : nums) {
            int x = (num - 1) % n;
            if (nums[x] <= n) {
                nums[x] += n;
            }
        }
        vector<int> ret;
        for (int i = 0; i < n; i++) {
            if (nums[i] <= n) {
                ret.push_back(i + 1);
            }
        }
        return ret;
    }
```
