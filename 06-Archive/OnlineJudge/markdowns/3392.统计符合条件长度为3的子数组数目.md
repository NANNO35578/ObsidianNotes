[3392. 统计符合条件长度为 3 的子数组数目](https://leetcode.cn/problems/count-subarrays-of-length-three-with-a-condition/)

- **定义子数组**：对于长度为 3 的子数组 `nums[i], nums[i+1], nums[i+2]`，我们需要检查是否满足条件：
    $nums[i] + nums[i+2] = 2 \times nums[i+1]$
    这个条件可以转化为：
    $nums[i] + nums[i+2] - 2 \times nums[i+1] = 0$
- **遍历数组**：我们可以通过遍历数组，从索引 0 到 `n-3`（n 为数组长度），检查每个长度为 3 的子数组。
- **计数有效子数组**：如果满足条件，就增加计数器。

```cpp
int countValidSubarrays(const std::vector<int>& nums) {
    int count = 0;
    int n = nums.size();
    
    // 遍历数组，检查每个长度为3的子数组
    for (int i = 0; i <= n - 3; ++i) {
        if (nums[i] + nums[i + 2] == 2 * nums[i + 1]) {
            count++;
        }
    }
    
    return count;
}
```
