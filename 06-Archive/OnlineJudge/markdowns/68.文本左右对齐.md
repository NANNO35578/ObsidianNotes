[68. 文本左右对齐](https://leetcode.cn/problems/text-justification/)

这是一个经典的文本排版问题，可以通过贪心算法来解决。以下是实现代码的思路和代码：
##### 思路
1. **按行分组**：首先需要将单词按行分组，每行尽可能多地放置单词，但总长度不能超过 `maxWidth`。
2. **处理每行的空格**：
   - **非最后一行**：单词之间的空格需要均匀分配，如果不能均匀分配，则左侧的空格数多于右侧。
   - **最后一行**：左对齐，单词之间只有一个空格，剩余的空格填充到行尾。
3. **特殊情况**：如果一行只有一个单词，该单词左对齐，剩余的空格填充到行尾。
##### 实现代码
以下是用 C++ 实现的代码：
```cpp
#include <vector>
#include <string>
using namespace std;

vector<string> fullJustify(vector<string>& words, int maxWidth) {
    vector<string> result;
    int n = words.size();
    int start = 0;

    while (start < n) {
        int end = start;
        int totalChars = 0;

        // 尽可能多地往当前行添加单词
        while (end < n && totalChars + words[end].size() + (end - start) <= maxWidth) {
            totalChars += words[end].size();
            ++end;
        }

        int numWords = end - start;
        int totalSpaces = maxWidth - totalChars;

        string line;
        if (end == n || numWords == 1) {
            // 最后一行或当前行只有一个单词，左对齐
            for (int i = start; i < end; ++i) {
                line += words[i];
                if (i < end - 1) line += " ";
            }
            line += string(maxWidth - line.size(), ' ');
        } else {
            // 非最后一行，单词间均匀分配空格
            int spacesBetweenWords = totalSpaces / (numWords - 1);
            int extraSpaces = totalSpaces % (numWords - 1);

            for (int i = start; i < end; ++i) {
                line += words[i];
                if (i < end - 1) {
                    line += string(spacesBetweenWords, ' ');
                    if (i < start + extraSpaces) {
                        line += " ";
                    }
                }
            }
        }

        result.push_back(line);
        start = end;
    }

    return result;
}
```

##### 代码解释
1. **外层循环**：
   - 使用 `start` 和 `end` 指针来标记当前行的单词范围。
   - 每次循环处理一行，直到所有单词都被处理。
1. **内层循环**：
   - 尽可能多地往当前行添加单词，直到行的总长度（包括单词和空格）达到 `maxWidth`。
1. **处理最后一行或单个单词的行**：
   - 如果是最后一行或当前行只有一个单词，直接左对齐，单词之间只有一个空格，剩余的空格填充到行尾。
1. **处理非最后一行**：
   - 计算单词之间的空格数量，尽量均匀分配。
   - 如果不能均匀分配，左侧的空格数多于右侧。
1. **结果存储**：
   - 每处理完一行，将该行的结果存储到 `result` 中。
