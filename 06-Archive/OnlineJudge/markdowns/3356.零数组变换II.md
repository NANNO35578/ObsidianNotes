[3356. 零数组变换 II](https://leetcode.cn/problems/zero-array-transformation-ii/)

1. **理解问题**：
   - 我们需要通过一系列查询对数组 `nums` 进行调整，使其最终变成一个零数组。
   - 每个查询可以在指定范围内减少元素的值，最多减少一个给定的值。
2. **使用差分数组**：
   - 为了有效地应用查询，我们使用差分数组来记录每个查询对数组的影响。差分数组可以在 O(1) 时间内记录范围更新。
3. **二分查找**：
   - 由于我们需要找到最小的 `k`（查询的数量），可以使用二分查找来高效地寻找最小满足条件的 `k`。
   - 设定二分查找的范围为 `0` 到 `m`（查询的总数）。
4. **验证每个 `k`**：
   - 对于每个中间值 `mid`，模拟应用前 `mid` 个查询，更新差分数组，然后计算每个元素的最终值。
   - 检查最终结果是否为零数组。
5. **更新搜索范围**：
   - 如果当前 `mid` 能使 `nums` 变成零数组，则尝试更小的 `k`（更新右边界）；否则，增大 `k`（更新左边界）。
6. **返回结果**：
   - 最后，返回找到的最小 `k` 或者 `-1`（如果没有满足条件的 `k`）。
   
```cpp
    int minZeroArray(vector<int>& nums, vector<vector<int>>& queries) {
        int n = nums.size();
        int m = queries.size();
        
        // 二分查找的范围
        int left = 0, right = m;
        int result = -1;

        // 二分查找
        while (left <= right) {
            int mid = left + (right - left) / 2;

            // 创建一个差分数组
            std::vector<int> diff(n + 1, 0);
            for (int i = 0; i < mid; ++i) {
                int li = queries[i][0];
                int ri = queries[i][1];
                diff[li] -= queries[i][2];
                if (ri + 1 < n) {
                    diff[ri + 1] += queries[i][2];
                }
            }

            // 应用差分数组
            std::vector<int> temp(nums);
            int currentDecrease = 0;
            for (int j = 0; j < n; ++j) {
                currentDecrease += diff[j];
                temp[j] += currentDecrease;
            }

            // 检查是否为零数组
            if (std::all_of(temp.begin(), temp.end(), [](int x) { return x <= 0; })) {
                result = mid;  // 找到满足条件的 k
                right = mid - 1; // 尝试更小的 k
            } else {
                left = mid + 1; // 尝试更大的 k
            }
        }

        return result;
    }
```
##### 方法二：双指针

> 仍然按照单调的思路，我们先不预计算出整个 `deltaArray` 数组，而是只在有需要的时候处理一些 `queries`。那什么时候是有需要的时候呢，就是我们从左往右遍历 `nums` 的时候，发现已经处理过的 `queries` 不能使当前的 `nums[i]` 变成 0，则需要多考虑一些 `queries`。依次按顺序处理当前没有处理过的 `queries`，并更新前缀和，一满足要求就停止，直到遍历完 `queries` 或者 `nums`，并返回结果。

```cpp
class Solution {
public:
    int minZeroArray(vector<int>& nums, vector<vector<int>>& queries) {
        int n = nums.size();
        vector<int> deltaArray(n + 1, 0);
        int operations = 0;
        int k = 0;
        for (int i = 0; i < n; ++i) {
            int num = nums[i];
            operations += deltaArray[i];
            while (k < queries.size() && operations < num) {
                int left = queries[k][0];
                int right = queries[k][1];
                int value = queries[k][2];
                deltaArray[left] += value;
                deltaArray[right + 1] -= value;
                if (left <= i && i <= right) {
                    operations += value;
                }
                k++;
            }
            if (operations < num) {
                return -1;
            }
        }
        return k;
    }
};
```
