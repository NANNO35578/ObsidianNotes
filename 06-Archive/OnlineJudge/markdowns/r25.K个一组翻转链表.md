
[25. K 个一组翻转链表](https://leetcode.cn/problems/reverse-nodes-in-k-group/) 

----
##### 按需模拟

- 首先题目要求将长度为K的子链表反转, 因此, 我们至少需要一个能够反转链表的函数.
- 其次, 反转链表函数是否为只需要头部即可, 返回新头部就行呢, 考虑到子链表或许只是遍历到了K的长度, 但并没有从尾部断开
- 因此, 可以将该函数设置为链表起点以及终点确定的反转, 将起点到终点(不包含)中间的节点反转即可.
	 *反转单链表有很多方法*:
	1. 将链表节点存储到`{cpp}std::stack`中, 当遍历到`nullptr`时, 即可一个个弹出并连接.
	2. 可以将内存栈转化为函数栈, 即递归调用, 将递归函数设置*头, 返回头, 返回尾* 三个参数即可
	3. *头插* 即变量迭代, 即使用`previous, current, rear`, 通过不断连接`{cpp}current->previous`, 并进行赋值替换即可.
	
我们发现, 我们进行反转链表的这个函数中, 参数head最终是链表尾, 而返回值是反转后的链表头. 因此, 我们在K个一组遍历反转的时候就可以标记当前已处理部分末尾节点为哪一个, 然后与反转后的新链表头相连就能将反转后的各组合并到一起, 而参数head就将成为新的已处理末尾节点.


*具体流程:*
1. 创建`dummy`节点, 初始时, 已处理的尾节点`appendPos`就是dummy.
2. 遍历链表, 记录遍历长度, 将newHead新的待处理头往后偏移
3. 直到已遍历长度steps为K时, 我们的oldHead就是待反转的子链表头, 而newHead就是子链表终点.
	*反转函数调用*:
	1. 变量迭代, 不断更新curt, last, 以及prev的指向, 达到反转的目的.
	2. 初始设置dummy节点. last表示当前节点curt的上一个节点, prev表示下一个节点.
	3. 若当前链表长度小于等于三, 单独处理. 否则, 初始化`{cpp}last->next`为空, 因为*成为末尾节点*.
	4. 在循环中, 当prev还未到达end, 即可将`{cpp}curt->last`后, 将curt赋值给last, prev赋值给curt, prev向下移动.
	5. 最终`{cpp}prev==end`, 我们还需再连接一次`{cpp}curt->last`. 然后返回`{cpp}dummy->next`.即子链表的新链表头
4. 将`{cpp}appendPos->next`即已处理链表末尾节点指向子链表新表头, 就将这K个节点处理好了
5. 再次迭代遍历, 准备下一次更新: appendPos赋值为接上来的子链表的旧表头即可, 对于oldHead, 我们应当赋值为newHead, 因为就是开启了新的一轮反转, 与开始一样, 在同一个起点, steps更新为0.
6. 循环结束, 即最终不足K个, 题目要求不在处理, 当我们的反转函数中, 将已处理与未处理部分拆分了, 我们应当将appendPos再接上旧表头.


`[!!bug:不可优化的地方]` 直接在反转函数中将`{cpp}oldHead = newHead;`, 因为最后还用到了oldHead.

```cpp title:"K个一组翻转链表"
class Solution {
 public:
  ListNode* reverseList(ListNode* head, ListNode* end) {
    ListNode  var(0);
    ListNode* dummy = &var;
    dummy->next     = head;

    ListNode* last = nullptr;
    ListNode* curt = nullptr;
    ListNode* prev = nullptr;

    if (head == end) {
      return nullptr;
    } else if (head->next == end) {
      head->next = nullptr;
      return head;
    } else if (head->next->next == end) {
      dummy->next      = head->next;
      head->next->next = head;
      head->next       = nullptr;
      return dummy->next;
    }

    last = head;
    curt = head->next;
    prev = head->next->next;

    last->next = nullptr;
    while (prev != end) {
      curt->next = last;
      last       = curt;
      curt       = prev;
      prev       = prev->next;
    }
    curt->next = last;
    return curt;
  }

  ListNode* reverseKGroup(ListNode* head, int k) {
    ListNode  var(0);
    ListNode* dummy = &var;
    dummy->next     = head;

    int       steps     = 0;
    ListNode* appendPos = dummy;
    ListNode* oldHead   = head;
    ListNode* newHead   = head;
    while (newHead != nullptr) {
      newHead = newHead->next;
      ++steps;

      if (steps == k) {
        appendPos->next = reverseList(oldHead, newHead);
        appendPos       = oldHead;
        oldHead         = newHead;
        steps           = 0;
      }
    }

    appendPos->next = oldHead;
    return dummy->next;
  }
};
```

##### 递归

- 解法更简短:
1. 用 **头插法** 局部反转 k 个节点
2. 如果不足 k 个节点，就再反转回去
3. 递归处理剩余部分

```cpp
  ListNode* reverseKGroup(ListNode* head, int k) {
    if (head == nullptr) return nullptr;

    ListNode* pre   = head;
    ListNode* index = head->next;  // 双指针操纵反转
    int       m     = 0;

    while (++m < k && index != nullptr) {
      pre->next   = index->next;
      index->next = head;
      head        = index;
      index       = pre->next;
    }
    if (m < k) 
      // 不足k个元素，反转回去
      return reverseKGroup(head, m);
    
    pre->next = reverseKGroup(index, k);  // index位置翻转下一个窗口
    return head;
  }
```
