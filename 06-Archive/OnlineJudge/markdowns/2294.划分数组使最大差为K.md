[2294. 划分数组使最大差为 K](https://leetcode.cn/problems/partition-array-such-that-maximum-difference-is-k/)

---  

## 方法一：排序 + 贪心扫描  
 
1. 把 `nums` 排序；  
2. 用一个变量 `start` 记录当前子序列的最小值（也就是这一批子序列最左边的元素），初始取 `nums[0]`
3. 从头到尾遍历排序后的 `nums`，如果 `nums[i] - start > k`，说明当前元素装不进「以 start 为最小值」的子序列，必须启动一个新子序列，令 `start = nums[i]`，子序列数 `ans++`
4. 最后别忘了算上最后一个子序列
  
```cpp
int partitionArray(vector<int>& nums, int k) {
    if (nums.empty()) return 0;
    sort(nums.begin(), nums.end());
    int ans = 1;            // 至少要一个子序列
    int start = nums[0];    // 当前子序列的最小值
    for (int i = 1; i < (int)nums.size(); i++) {
        if (nums[i] - start > k) {
            // 启动新子序列
            ans++;
            start = nums[i];
        }
        // 否则 nums[i] 可以并入当前子序列
    }
    return ans;
}
```

## 方法二：哈希/有序 Map 统计 + 区间覆盖  
 
1. 用 `map<int,int>` 或 `unordered_map<int,int>` 统计每个值出现的次数；  
2. 转为有序结构（`map` 本身有序），每次取当前最小的键 `x`，它开始一个新的子序列：`ans++`；  
3. 这个子序列可以覆盖所有值在 `[x, x+k]` 范围内的元素——把这段区间内的键统统从 `map` 中删掉；  
4. 重复 2–3，直到 `map` 为空

这样其实是在「值域」上做了一个经典的“最少区间覆盖”贪心：  
每次选最左端的点 `x`，放一个长度为 `k` 的段 `[x, x+k]`，尽可能覆盖后面的点 

```cpp
int partitionArray(vector<int>& nums, int k) {
    // 1) 统计频次
    map<int,int> freq;
    for (int x : nums) {
        freq[x]++;
    }

    int ans = 0;
    // 2) 贪心区间覆盖
    while (!freq.empty()) {
        ans++;
        // 取当前最小的键作为子序列的最小值
        int start = freq.begin()->first;
        int endv = start + k;

        // 把 map 中所有 key <= endv 的都删掉
        // 注意不能在遍历中直接 ++it 并 erase(it)，要先取下个迭代器
        auto it = freq.begin();
        while (it != freq.end() && it->first <= endv) {
            auto it2 = next(it);
            freq.erase(it);
            it = it2;
        }
    }
    return ans;
}
```

把整个数域当作一个巨大的位图（bitmap）来「排序＋遍历」，配合一个 De Bruijn 序列的 bit-scan hack 来快速找出每次的最小（低位）那一位 1，从而完成了「桶排序＋线性扫描」的效果，最后再做和方法一一模一样的贪心分组

关键点拆解：

1. 位图（bitmap）  
   • `unsigned int bitVec[3126]` 一共能表示 3126×32≈100 032 个整数（假设 nums 中的值都 ≤100 000）。  
   • `bitVec[val/32] |= 1u << (val%32)` 把每个出现过的数字在 bitmap 上打一个“1”

2. De Bruijn 序列 + 查表  
   • `lg2_power_of_two(x)` 用了经典的 De Bruijn «×0x077CB531u >>27» trick，把一个只有最低位为 1 的 32-bit 数映射到它那一位的下标(0…31)
   • 这样就能在 O(1) 时间里完成类似 `ffs` / `__builtin_ctz` 的功能

3. 扫描 & 贪心  
   • 先在 bitmap 上找到第一个 1（最小的那条数），设为 `bitPrev`，子序列计数 `res=1`
   • 然后不断地「取出当前 bitmap 中最低位的 1 → 位置即下一个数 → 清零那位」，得到下一个升序的数 `position`
   • 若 `position - bitPrev > k`，就说明又要开新子序列 `res++`，并把 `bitPrev=position`

这样，整个流程是 O(U/32 + n)（U 是数域大小，n 是 nums 长度），免去了比较排序的 O(n log n)，适合 n 还行但数域较小、且对常数要求极高的场景
