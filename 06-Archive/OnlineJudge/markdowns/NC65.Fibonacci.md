[求斐波那契值](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=456677439)
- 基础动态规划 压缩空间
```cpp
    int Fibonacci(int n) {
        // write code here
        if (n == 1 || n == 2) return 1;
        int fib_1 = 1;
        int fib_2 = 1;
        int ans;
        n-=2;
        while (n--) {
            ans = fib_1 + fib_2;
            fib_2 = fib_1;
            fib_1 = ans;
        }
        return ans;
    }
```
