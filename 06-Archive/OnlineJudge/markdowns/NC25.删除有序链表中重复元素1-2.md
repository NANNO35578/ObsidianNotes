[删除链表中重复元素1](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457457082)
- **检查边界条件**：如果链表为空（`head == nullptr`）或只有一个节点（`head->next == nullptr`），直接返回原链表。
- **初始化指针**：使用两个指针：`memory`（用于存储当前处理的节点）和`p`（用于遍历链表）。
- **遍历链表**：
    - `while (p != nullptr)`：循环遍历链表，直到链表结束。
    - 在内层循环中，使用`p`跳过所有与`memory->val`相同的节点，以找到下一个不同的节点。
- **链接不同的节点**：
    - 将`memory->next`指向`p`（即下一个不同的节点）。
    - 更新`memory`指针为`p`，继续处理下一个节点。
- **返回结果**
```cpp
    ListNode* deleteDuplicates(ListNode* head) {
        // write code here
        if(head==nullptr||head->next==nullptr)return head;
        ListNode* memory=head;
        ListNode* p=head;
        while(p!=nullptr){
            p=p->next;
            while (p!=nullptr&&p->val == memory->val) {
                p=p->next;
            }
          memory->next=p;
          memory=p;
        }
        return head;
    }
```

[删除链表中重复元素2](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457457548)
- 使用一个虚拟头节点 `dummy` 来简化操作。
- 通过 `prev` 指针保存当前无重复元素部分的尾节点。
- 当发现重复元素时，跳过这些元素。
```cpp
    ListNode* deleteDuplicates(ListNode* head) {
        // write code here
    // 创建一个虚拟头节点
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy; // 指向当前无重复元素的最后一个节点
 
    while (head) {
        // 检查当前节点是否是重复的
        if (head->next && head->val == head->next->val) {
            // 找到所有重复元素
            while (head->next && head->val == head->next->val) {
                head = head->next;
            }
            // 跳过所有重复元素
            prev->next = head->next;
        } else {
            // 如果没有重复，移动prev指针
            prev = prev->next;
        }
        // 移动到下一个节点
        head = head->next;
    }
 
    return dummy.next;
    }
```
