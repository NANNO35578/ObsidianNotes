[2410. 运动员和训练师的最大匹配数](https://leetcode.cn/problems/maximum-matching-of-players-with-trainers/) 

`[!!example:题目概述]`  给定两个数组 `players` 和 `trainers`，分别表示运动员和训练师的能力值. 每个运动员可以匹配一个训练师，条件是 $运动员能力值 ≤ 训练师能力值$ 求 最大匹配数

---

##### 方法一：双指针+贪心

1. 将运动员和训练师按能力值升序排序
2. 使用两个指针遍历数组：
   * 如果当前运动员能力值 ≤ 当前训练师能力值，则匹配成功，两个指针都向前移动
   * 否则训练师能力不足，移动训练师指针寻找更强的训练师

$O(n \times log_2(n) + m \times log_2(m))$

```cpp title:"排序_双指针"
int matchPlayersAndTrainers(std::vector<int>& players, std::vector<int>& trainers) {
    std::sort(players.begin(), players.end());
    std::sort(trainers.begin(), trainers.end());

    int playerIndex = 0, trainerIndex = 0;
    int matches = 0;

    while (playerIndex < players.size() && trainerIndex < trainers.size()) {
        if (players[playerIndex] <= trainers[trainerIndex]) {
            matches++;
            playerIndex++;
            trainerIndex++;
        } else {
            trainerIndex++;
        }
    }
    return matches;
}
```

##### 方法二：排序 + 二分查找

1. 将运动员和训练师按能力值升序排序
2. 对每个运动员，用二分查找找到第一个能力值 ≥ 运动员的训练师：
   * 找到后匹配并将该训练师从“可用列表”中移除（移动索引）

$O(n \times log_2(n) + m \times log_2(m))$

```cpp title:"排序_二分"
int matchPlayersAndTrainers(std::vector<int>& players, std::vector<int>& trainers) {
    std::sort(players.begin(), players.end());
    std::sort(trainers.begin(), trainers.end());

    int matches = 0;
    int trainerIndex = 0;

    for (int player : players) {
        while (trainerIndex < trainers.size() && trainers[trainerIndex] < player) {
            trainerIndex++;
        }
        if (trainerIndex < trainers.size()) {
            matches++;
            trainerIndex++;
        }
    }

    return matches;
}
```

##### 方法三：动态规划（DP）

1. 先将运动员和训练师按能力值升序排序。
2. 定义状态： $dp[i][j] = \text{前 i 个运动员和前 j 个训练师的最大匹配数}$
3. 状态转移：
   * 如果运动员 i 能匹配训练师 j：$dp[i][j] = \max(dp[i-1][j-1]+1, dp[i-1][j], dp[i][j-1])$
   * 否则：                       $dp[i][j] = \max(dp[i-1][j], dp[i][j-1])$
最终答案为 `dp[n][m]`

同时, 二维数组可以压缩成一维数组，因为我们每次计算 `dp[i][j]` 只依赖 **上一行** (`i-1`) 的值

---

*时间复杂度*: $O(n * m)$ 超时

```cpp title:"超时了"
int matchPlayersAndTrainers(std::vector<int>& players, std::vector<int>& trainers) {
    int n = players.size(), m = trainers.size();
    std::sort(players.begin(), players.end());
    std::sort(trainers.begin(), trainers.end());

    std::vector<int> dp(m + 1, 0);

    for (int i = 1; i <= n; i++) {
        int prev = 0; // dp[i-1][j-1] 对应上一行上一列
        for (int j = 1; j <= m; j++) {
            int temp = dp[j]; // 暂存 dp[i-1][j]，用于下一个循环
            if (players[i - 1] <= trainers[j - 1]) {
                dp[j] = std::max({prev + 1, dp[j], dp[j - 1]});
            } else {
                dp[j] = std::max(dp[j], dp[j - 1]);
            }
            prev = temp;
        }
    }

    return dp[m];
}
```
