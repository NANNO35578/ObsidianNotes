[缺失的第一个正整数](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=456750599) 
- - **数组的范围**：对于一个长度为 `n` 的数组，最小的正整数应该在 `1` 到 `n + 1` 之间。因为如果数组包含 `1` 到 `n` 的所有正整数，那么最小的缺失正整数就是 `n + 1`。    
- **原地哈希**：可以利用数组的索引来标记数字。具体的方法是将每个数字放在它该在的位置上（例如，数字 `1` 应该放在索引 `0`，数字 `2` 应该放在索引 `1`，以此类推）。    
- **遍历数组**：在调整完数组后，再次遍历数组，找到第一个不符合条件的位置，即为缺失的最小正整数。
```cpp
 int minNumberDisappeared(vector<int>& nums) {
     // write code here
     int n = nums.size();

     // 将数字放到合适的位置
     for (int i = 0; i < n; ++i) {
         // 只处理在 [1, n] 范围内的正整数
         while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
             std::swap(nums[i], nums[nums[i] - 1]);
         }
     }

     // 找到第一个缺失的正整数
     for (int i = 0; i < n; ++i) {
         if (nums[i] != i + 1) {
             return i + 1;
         }
     }

     return n + 1;  // 如果数组是 [1, 2, ..., n]
 }
```

##### 哈希表

思路：𝑛个长度的数组，没有重复，则如果数组填满了1～𝑛，那么缺失n+1，如果数组填不满1～n，那么缺失的就是1～n中的数字。对于这种快速查询某个元素是否出现过的问题，还是可以使用哈希表快速判断某个数字是否出现过。
```cpp
class Solution {
public:
    int minNumberDisappeared(vector<int>& nums) {
        int n = nums.size();
        unordered_map<int, int> mp;
        //哈希表记录数组中出现的每个数字
        for(int i = 0; i < n; i++) 
            mp[nums[i]]++;
        int res = 1;
        //从1开始找到哈希表中第一个没有出现的正整数
        while(mp.find(res) != mp.end()) 
            res++;
        return res;
    }
};
```
