[1552. 两球之间的磁力](https://leetcode.cn/problems/magnetic-force-between-two-balls/)
### 思路
1. **排序**: 首先，将篮子的 `position` 数组进行排序，以便我们可以使用贪心算法来放置球。
2. **二分搜索**:
    - 我们需要找到一个最大化的最小磁力值。这可以通过在 `position` 数组的最小差（0）和最大差（`position.back() - position.front()`）之间进行二分搜索来实现。
    - 对于每个中间值 `mid`，我们需要检查能否在篮子中放置 `m` 个球，使得任意两个球间的最小磁力至少为 `mid`。
3. **贪心算法**:
    - 从第一个篮子开始放置第一个球，然后逐个检查后续的篮子，只有当当前篮子的距离大于等于 `mid` 时，才放置下一个球。
4. **更新搜索范围**:
    - 如果能够放置 `m` 个球，则说明可以尝试更大的 `mid`，否则减少 `mid`。
```cpp

bool canPlaceBalls(const vector<int>& position, int m, int minDist) {
    int count = 1; // 第一个球放在第一个篮子里
    int lastPosition = position[0];

    for (int i = 1; i < position.size(); i++) {
        if (position[i] - lastPosition >= minDist) {
            count++;
            lastPosition = position[i];
            if (count == m) return true; // 成功放置 m 个球
        }
    }
    return false;
}

int maximizeMinMagnetism(vector<int>& position, int m) {
    sort(position.begin(), position.end());

    int left = 0, right = position.back() - position.front();
    int best = 0;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (canPlaceBalls(position, m, mid)) {
            best = mid; // 找到一个可行解，尝试更大
            left = mid + 1;
        } else {
            right = mid - 1; // 不可行，尝试更小
        }
    }

    return best;
}
```
