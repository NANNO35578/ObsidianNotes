[907. 子数组的最小值之和](https://leetcode.cn/problems/sum-of-subarray-minimums/)

使用单调栈来高效地计算每个元素在子数组中的最小值的贡献。具体思路如下：

1. **定义贡献**：每个元素 `arr[i]` 在其作为子数组最小值的情况下，贡献值为 `arr[i] * 贡献的子数组数量`
2. **确定贡献的子数组数量**：
    - 使用单调栈来找到 `arr[i]` 左侧和右侧第一个小于 `arr[i]` 的元素的索引。
    - 设 `left[i]` 为 `arr[i]` 左侧第一个小于 `arr[i]` 的元素的索引，`right[i]` 为右侧第一个小于 `arr[i]` 的元素的索引。
    - `arr[i]` 作为最小值的子数组个数为 `(i - left[i]) * (right[i] - i)`。
3. **计算总和**：对每个元素计算其贡献并求和

```cpp
    const int MOD = 1e9 + 7;
    int sumSubarrayMins(vector<int>& arr) {
        int n = arr.size();
        std::vector<int> left(n), right(n);
        std::stack<int> s;

        // 找到每个元素左边第一个小于它的元素的索引
        for (int i = 0; i < n; ++i) {
            while (!s.empty() && arr[s.top()] >= arr[i]) {
                s.pop();
            }
            left[i] = s.empty() ? -1 : s.top();
            s.push(i);
        }
        
        // 清空栈以便下一次使用
        while (!s.empty()) {
            s.pop();
        }

        // 找到每个元素右边第一个小于它的元素的索引
        for (int i = n - 1; i >= 0; --i) {
            while (!s.empty() && arr[s.top()] > arr[i]) {
                s.pop();
            }
            right[i] = s.empty() ? n : s.top();
            s.push(i);
        }

        long long result = 0;

        // 计算每个元素的贡献
        for (int i = 0; i < n; ++i) {
            long long leftCount = i - left[i];
            long long rightCount = right[i] - i;
            result = (result + arr[i] * leftCount % MOD * rightCount % MOD) % MOD;
        }

        return result;
    }
```

#### 方法二：动态规划


设 $s[j][i]$ 表示子数组 $[arr[j],arr[j+1],⋯,arr[i]]$ 的最小值，则可以推出所有连续子数组的最小值之和为 $i=0∑n−1​j=0∑i​s[j][i]$。对于每个以 i 为最右的子数组最小值之和为 $j=0∑i​s[j][i]$。我们只需要求出以每个元素 $arr[i] 为最右的子数组最小值之和，即可求出所有的子数组的最小值之和。每当我们减少 j 时，子序列的最小值可能会有关联，事实上我们可以观察到 $s[j−1][i]=min(s[j][i],arr[j−1])$。  
假设当前数组为: $arr=[1,7,5,2,4,3,9]$，当 i=5 时，所有以索引 j 为起点且以 i 结尾的连续子序列为:

​$j=5,[3]$
$j=4,[4,3]$
$j=3,[2,4,3]$
$j=2,[5,2,4,3]$
$j=1,[7,5,2,4,3]$
$j=0,[1,7,5,2,4,3]$​

上述序列的最小值分别为 $[3,3,2,2,2,1]$，可以发现重要点是 $j=5,j=3,j=0$，分别是 j 从 i 开始向左移动遇到的最小值的位置。如下图所示:

具体解法过程如下：

从左向右遍历数组并维护一个单调递增的栈，如果栈顶的元素大于等于当前元素 arr[i] 则弹出栈，此时栈顶的元素即为左边第一个小于小于当前值的元素；

我们求出以当前值为最右且最小的子序列的长度 k，根据上述递推公式求出 dp[i]，最终的返回值即为  
$i=0∑n−1​dp[i]$
```cpp
class Solution {
public:
    int sumSubarrayMins(vector<int>& arr) {
        int n = arr.size();
        long long ans = 0;
        long long mod = 1e9 + 7;
        stack<int> monoStack;
        vector<int> dp(n);
        for (int i = 0; i < n; i++) {
            while (!monoStack.empty() && arr[monoStack.top()] > arr[i]) {
                monoStack.pop();
            }
            int k = monoStack.empty() ? (i + 1) : (i - monoStack.top());
            dp[i] = k * arr[i] + (monoStack.empty() ? 0 : dp[i - k]);
            ans = (ans + dp[i]) % mod;
            monoStack.emplace(i);
        }
        return ans;
    }
};
```
