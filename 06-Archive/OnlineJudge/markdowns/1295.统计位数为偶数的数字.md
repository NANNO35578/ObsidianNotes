[1295. 统计位数为偶数的数字](https://leetcode.cn/problems/find-numbers-with-even-number-of-digits/)

- **countNumbersWithEvenDigits** 函数接受一个整数数组 `nums`，然后遍历每个数字。
- 对于每个数字，计算其位数（处理负数情况）。
- 如果位数是偶数，则计数加1。
- 最后返回偶数位数数字的总个数。
```cpp
bool isPalindrome(const std::string& s, int start, int end) {
    while (start < end) {
        if (s[start] != s[end]) {
            return false;
        }
        start++;
        end--;
    }
    return true;
}
```

#### 方法一：枚举 + 字符串
- 我们枚举数组 nums 中的整数，并依次判断每个整数 x 是否包含偶数个数字。  
- 一种简单的方法是使用语言内置的整数转字符串函数，将 x 转换为字符串后，判断其长度是否为偶数即可
```cpp
    int findNumbers(vector<int>& nums) {
        int ans = 0;
        for (int num: nums) {
            if (to_string(num).size() % 2 == 0) {
                ++ans;
            }
        }
        return ans;
    }
```
#### 方法二：枚举 + 数学
- 我们也可以使用语言内置的以 10 为底的对数函数 $log10 ​()$ 来得到整数 x 包含的数字个数。  
- 一个包含 k 个数字的整数 x 满足不等式 10^k−1≤x<10^k。将不等式取对数，得到 k−1≤log10​(x)<k，因此我们可以用 k=⌊log10​(x)+1⌋ 得到 x 包含的数字个数 k，其中 ⌊a⌋ 表示将 a 进行下取整，例如 ⌊5.2⌋=5。

```cpp
    int findNumbers(vector<int>& nums) {
        int ans = 0;
        for (int num: nums) {
            if ((int)(log10(num) + 1) % 2 == 0) {
                ++ans;
            }
        }
        return ans;
    }

```
