[208. 实现 Trie (前缀树)](https://leetcode.cn/problems/implement-trie-prefix-tree/)


### 结构体定义
```cpp
struct node {
    std::vector<node*> sub;
    int cnt;

    node() : sub(26, nullptr), cnt(0) {}
    ~node() {}
};
```
- `node` 结构体表示 Trie 的每个节点。
- `sub` 是一个大小为 26 的向量，用于存储指向子节点的指针（每个字母对应一个指针）。
- `cnt` 用于记录以该节点为结尾的单词的数量。

### Trie 类
1. **构造函数**
   ```cpp
   Trie() { root = new node(); }
   ```
   - 初始化 Trie，创建一个根节点。
2. **插入单词**
   ```cpp
   void insert(std::string word) {
       node* point = root;
       for (char c : word) {
           if (point->sub[c - 'a'] == nullptr) {
               point->sub[c - 'a'] = new node();
           }
           point = point->sub[c - 'a'];
       }
       ++point->cnt;
   }
   ```
   - 遍历单词的每个字符，检查当前节点的子节点是否存在。
   - 如果不存在，则创建一个新的子节点。
   - 最后，增加当前节点的计数，表明有一个单词以此节点为结尾。

3. **搜索单词**
   ```cpp
   bool search(std::string word) {
       node* point = root;
       for (char c : word) {
           if (point->sub[c - 'a'] == nullptr) return false;
           point = point->sub[c - 'a'];
       }
       return point->cnt > 0;
   }
   ```
   - 遍历单词的每个字符，检查路径是否存在。
   - 如果遍历结束时计数大于 0，则表示字典中存在该单词。

4. **前缀查询**
   ```cpp
   bool startsWith(std::string prefix) {
       node* point = root;
       for (char c : prefix) {
           if (point->sub[c - 'a'] == nullptr) return false;
           point = point->sub[c - 'a'];
       }
       return true;
   }
   ```
   - 类似于搜索方法，但不检查计数。
   - 只需确认是否可以从根节点到达指定的前缀。
