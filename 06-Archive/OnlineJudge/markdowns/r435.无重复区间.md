问题: [无重复区间](https://leetcode.cn/problems/non-overlapping-intervals/description/)  
- 给定一个区间的集合 `intervals` ，其中 `intervals[i] = [starti, endi]` 。返回 _需要移除区间的最小数量，使剩余区间互不重叠_ 。
- **注意** 只在一点上接触的区间是 **不重叠的**。例如 `[1, 2]` 和 `[2, 3]` 是不重叠的。


----

##### 方法一: 排序 + 贪心
 - 求最少的移除区间个数，等价于尽量多保留不重叠的区间
 - 在选择要保留区间时，*区间的结尾*十分重要：
	 - 选择的区间结尾越小，余留给其它区间的空间就越大，就越能保留更多的区间
	 - 因此，我们采取的贪心策略为，优先保留结尾小且不相交的区间
具体实现方法为，先把区间按照结尾的大小进行增序排序，每次选择结尾最小且和前一个选择的区间不重叠的区间
使用C++ 的Lambda，结合 `std::sort()` 函数进行自定义排序

```cpp title:"r435_排序+贪心"
  int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    std::sort(intervals.begin(), intervals.end(), [](vector<int>& a, vector<int>& b) { return a[1] < b[1]; });

    int curPos = intervals[0][0];
    int ans    = 0;
    for (vector<int>& terv : intervals) {
      if (curPos <= terv[0])
        curPos = terv[1];
	  else
        ++ans;
    }
    return ans;
  }
```

##### 方法二: $O(n\times log_2(n) )$「`LIS-like`」DP 利用二分优化

将「删除最少区间」转化为「保留最多互不重叠区间」，即  `{c}ans = intervals.size() – maxNonOverlapCount`  


- 令 `dp[i]` 表示以第 i 个区间作为「结尾」时，能组成的最多不重叠区间数
- 先按右端点升序或左端点升序都可以，以左端点升序为例;  

- 同时维护一个数组 `ends`，其中  
```
ends[k] = 能够组成 k+1 个不重叠区间时，所能取得的最小“结尾右端点” 
```  
这样 `ends` 始终是单调递增的. 对每个新区间 `[s,e]`：  
1. 在 `ends` 中二分找到第一个大于 `s` 的位置 `idx`（即 `upper_bound(ends, s)`）  
2. 若 `idx == ends.size()`，说明可以把它加到末尾，`ends.push_back(e)`  
   否则用更小的 `e` 更新 `ends[idx] = min(ends[idx], e)`  

最终 `ends.size()` 就是「最多不重叠区间数」

```cpp title:"DP + 二分优化"
int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    int n = intervals.size();
    if (n <= 1) return 0;

    // 必须先按“右端点”升序，或者按左端点升序皆可；这里按右端点升序
    sort(intervals.begin(), intervals.end(),
         [](auto &a, auto &b){
             if (a[1] != b[1]) return a[1] < b[1];
             return a[0] < b[0];
         });

    vector<int> ends;  
    ends.reserve(n);

    for (auto &in : intervals) {
        int s = in[0], e = in[1];
        // 找到第一个 > s 的位置
        auto it = upper_bound(ends.begin(), ends.end(), s);
        int idx = it - ends.begin();
        if (idx == (int)ends.size()) {
            ends.push_back(e);
        } else {
            // 用更小的 e 替换，保持 ends 单调
            ends[idx] = min(ends[idx], e);
        }
    }

    int maxKeep = ends.size();
    return n - maxKeep;
}
```
