[两个栈实现队列](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=456750772) 
- 队列特征: 先进先出 一头只可进 一头只可出 ; 栈特征: 先进后出 只有一头 可进可出
- 栈中元素一次出为逆序 两次出则为正序 因此 可将一个栈作为push栈 另一个作为pop栈
- push时 检测pop是否为空
- pop时 检测push是否为空
```cpp
class Solution {
   public:
    void push(int node) {
        while (!stack2.empty()) {
            stack1.push(stack2.top());
            stack2.pop();
        }
        stack1.push(node);
    }

    int pop() {
        while (!stack1.empty()) {
            stack2.push(stack1.top());
            stack1.pop();
        }
        int p = stack2.top();
        stack2.pop();
        return p;
    }

private:
    stack<int> stack1;// push
    stack<int> stack2;// pop
};
```
