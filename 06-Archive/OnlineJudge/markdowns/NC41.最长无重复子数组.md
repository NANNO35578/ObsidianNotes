[最长无重复子数组](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457918255)

> 要找出给定数组中最长无重复元素子数组的长度，可以使用滑动窗口的技巧。基本思路是维护一个窗口，其中包含当前无重复元素的子数组。可以使用一个哈希集合来快速检查当前窗口内的元素是否重复
- **初始化**：
    - 使用两个指针，`start` 和 `end`，都指向数组的开始。
    - 创建一个哈希集合 `charSet` 用于存储当前窗口内的元素。
    - 初始化 `maxLength` 为 0，用于记录最长子数组的长度。
- **移动窗口**：
    - 使用 `end` 指针逐步扩展窗口：
        - 如果 `arr[end]` 不在 `charSet` 中，说明没有重复元素，将其添加到集合中并更新 `maxLength`。
        - 如果 `arr[end]` 已经存在于 `charSet` 中，说明有重复元素，需要移动 `start` 指针，直到窗口内没有重复元素为止。
- **更新最大长度**：
    - 在每次成功扩展窗口后，更新 `maxLength`。
- **返回结果**：
    - 最后返回 `maxLength`。

```cpp
    int maxLength(vector<int>& arr) {
        // write code here
        unordered_set<int> charSet;
        int maxLength = 0;
        int start = 0;

        for (int end = 0; end < arr.size(); ++end) {
            // 如果有重复元素，移动start指针
            while (charSet.find(arr[end]) != charSet.end()) {
                charSet.erase(arr[start]);
                start++;
            }
            // 添加当前元素到集合
            charSet.insert(arr[end]);
            // 更新最大长度
            maxLength = max(maxLength, end - start + 1);
        }

        return maxLength;
    }
```
