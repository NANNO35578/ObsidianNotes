[单链表的排序](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457454517)
- **遍历链表**：创建一个空的 `vector<int> nums`，然后通过一个指针 `p` 遍历整个链表，将每个节点的值 (`p->val`) 存储到 `nums` 中。
- **排序**：使用标准库中的 `sort` 函数对 `nums` 进行排序。
- **将排序结果赋值回链表**：再次使用指针 `p` 遍历链表，将排序后的值依次赋值回原来的链表节点。
- **返回头节点**：最后返回排序后的链表的头节点 `head`。
```cpp
     ListNode* sortInList(ListNode* head) {
         // write code here
         vector<int> nums;
         ListNode* p = head;
         while (p) {
             nums.push_back(p->val);
             p = p->next;
         }
         sort(nums.begin(), nums.end());
         p = head;
         for (int i : nums) {
             p->val = i;
             p = p->next;
         }
         return head;
     }
```



##### 归并排序


```cpp
        ListNode* sortInList(ListNode* head) {
        if (!head || !head->next) {
            return head;
        }
 
        // 使用快慢指针找到中间节点
        ListNode *slow = head, *fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
 
        // 切割链表
        ListNode *mid = slow->next;
        slow->next = nullptr;
 
        // 递归排序
        ListNode *left = sortInList(head);
        ListNode *right = sortInList(mid);
 
        // 合并两个有序链表
        return merge(left, right);
    }
 
private:
    ListNode* merge(ListNode* left, ListNode* right) {
        ListNode dummy(0);
        ListNode *current = &dummy;
 
        while (left && right) {
            if (left->val < right->val) {
                current->next = left;
                left = left->next;
            } else {
                current->next = right;
                right = right->next;
            }
            current = current->next;
        }
 
        // 如果有剩余节点
        if (left) {
            current->next = left;
        } else if (right) {
            current->next = right;
        }
 
        return dummy.next;
    }
```
