[3291. 形成目标字符串需要的最少字符串数 I](https://leetcode.cn/problems/minimum-number-of-valid-strings-to-form-target-i/)

### 思路分析

1. **Trie 数据结构**：    
    - 使用 Trie 来存储所有的有效单词，以便快速检查子串是否是有效的前缀。
2. **动态规划**：    
    - 使用 `dp[i]` 表示形成 `target` 前 `i` 个字符所需的最少有效字符串数量。初始化为无穷大（`INF`）。
    - `dp[0]` 初始化为 0，因为形成空字符串不需要任何有效字符串。
3. **状态转移**：    
    - 遍历 `target` 的每个字符，从当前起始点 `l` 开始，尝试扩展到 `r`。如果当前字符在 Trie 中存在，则更新 `dp[r]`。
    - 若当前字符不在 Trie 中，终止这个扩展过程。
4. **返回结果**：    
    - 如果 `dp[m]` 仍为无穷大，则返回 -1，表示无法形成目标字符串。

```cpp

const int N = 100010, INF = numeric_limits<int>::max();
int dp[N];

class TrieNode {
public:
    TrieNode* nxt[26];

    TrieNode() {
        fill(begin(nxt), end(nxt), nullptr);
    }
};

class Solution {
public:
    TrieNode* root;

    Solution() {
        root = new TrieNode();
    }

    int minValidStrings(vector<string>& words, string target) {
        int n = words.size(), m = target.size();
        fill(dp, dp + m + 1, INF);
        dp[0] = 0; // 基础情况

        // 插入所有单词到 Trie 中
        for (const string& word : words) {
            insert(word);
        }

        // 动态规划状态转移
        for (int l = 0; l < m; l++) {
            TrieNode* cur = root;
            for (int r = l; r < m; r++) {
                int index = target[r] - 'a';
                if (cur->nxt[index]) {
                    // 更新 dp[r + 1]
                    dp[r + 1] = min(dp[r + 1], dp[l] + 1);
                    cur = cur->nxt[index];
                } else {
                    break; // 当前字符不在 Trie 中，终止
                }
            }
        }

        return dp[m] == INF ? -1 : dp[m];
    }

    void insert(const string& word) {
        TrieNode* cur = root;
        for (char c : word) {
            int index = c - 'a';
            if (!cur->nxt[index]) {
                cur->nxt[index] = new TrieNode();
            }
            cur = cur->nxt[index];
        }
    }
};
```


##### KMP dp
### 思路分析

1. **前缀数组 `p` 的构建**：    
    - 遍历每个单词，构建一个前缀数组 `p`，其中 `p[i]` 表示能够从 `target[0..i]` 匹配到的最长有效前缀的长度。
    - 对于每个单词，使用 KMP 算法的部分匹配表（`next` 数组）来加速匹配过程。
2. **KMP 部分匹配表**：    
    - 对于每个单词，计算其 KMP 部分匹配表 `next`，用于快速找到下一个匹配的位置。
    - 该表用于在匹配失败时，不必从头开始，而是可以跳到下一个可能的匹配位置。
3. **动态规划数组 `dp`**：    
    - 创建一个动态规划数组 `dp`，其中 `dp[i]` 表示形成 `target[0..i]` 所需的最少有效字符串数量。
    - 初始化 `dp` 数组，依据前缀数组 `p` 的值更新 `dp`。
4. **状态转移**：    
    - 对于每个 `i`，如果 `p[i]` 为 0，表示没有有效的前缀，赋值为 -1。
    - 如果 `i < p[i]`，说明当前字符可以通过一个有效字符串匹配，赋值为 1。
    - 否则，根据 `p[i]` 计算出需要的字符串数量，如果前一个状态 `dp[j]` 为 -1，则返回 -1；否则将其加一。
5. **返回结果**：    
    - 返回 `dp[m-1]`，即形成完整目标字符串所需的最少字符串数量，如果无法形成则返回 -1。

### 代码流程

1. **构建前缀数组 `p`**： 对每个单词进行 KMP 匹配，更新 `p` 数组。
2. **动态规划计算**： 使用 `p` 数组更新 `dp`，计算每个位置所需的最少有效字符串数量。
3. **结果输出**： 返回 `dp[m-1]`，即最后一个字符形成所需的字符串数量。

```cpp
    int minValidStrings(std::vector<std::string>& words, std::string target) {
        int m = target.size();
        std::vector<int> p(m, 0);

        // 遍历每个单词
        for (const auto& word : words) {
            int n = word.size();
            std::vector<int> next(n + 1, 0);

            // 构建 KMP 部分匹配表
            for (int i = 0, j = 1; j < n;) {
                if (word[i] == word[j]) {
                    ++i;
                    ++j;
                    next[j] = i;
                } else if (i == 0) {
                    ++j;
                } else {
                    i = next[i];
                }
            }

            // 更新前缀数组 p
            for (int i = 0, j = 0; i < m;) {
                if (j < n && target[i] == word[j]) {
                    p[i] = std::max(p[i], j + 1);
                    ++i;
                    ++j;
                } else if (j == 0) {
                    ++i;
                } else {
                    j = next[j];
                }
            }
        }

        // 动态规划数组
        std::vector<int> dp(m, -1);
        for (int i = 0; i < m; ++i) {
            if (p[i] == 0) {
                dp[i] = -1; // 无法形成
            } else if (i < p[i]) {
                dp[i] = 1; // 可以通过一个有效字符串匹配
            } else {
                int j = i - p[i];
                if (dp[j] != -1) {
                    dp[i] = dp[j] + 1; // 更新最少有效字符串数量
                }
            }
        }

        return dp[m - 1]; // 返回结果
    }
```
