[2446. 判断两个事件是否存在冲突](https://leetcode.cn/problems/determine-if-two-events-have-conflict/)
#### 方法一：直接比较字符串😎
```cpp
    bool haveConflict(vector<string>& event1, vector<string>& event2) {
        return !(event1[1] < event2[0] || event2[1] < event1[0]);
    }
```


#### 转换为数字
```cpp
    bool haveConflict(vector<string>& event1, vector<string>& event2) {
	    // 解析事件1的开始和结束时间
	    int start1 = stoi(event1[0].substr(0, 2)) * 100 + stoi(event1[0].substr(3, 2));
	    int end1 = stoi(event1[1].substr(0, 2)) * 100 + stoi(event1[1].substr(3, 2));
	
	    // 解析事件2的开始和结束时间
	    int start2 = stoi(event2[0].substr(0, 2)) * 100 + stoi(event2[0].substr(3, 2));
	    int end2 = stoi(event2[1].substr(0, 2)) * 100 + stoi(event2[1].substr(3, 2));
	
	    // 检查是否有冲突
	    return !(end1 < start2 || end2 < start1);
    }
```
