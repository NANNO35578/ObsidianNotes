[2614. 对角线上的质数](https://leetcode.cn/problems/prime-in-diagonal/)


- **质数检查**：`isPrime` 函数用于检查一个整数是否为质数。
- **对角线最大质数**：`maxPrimeOnDiagonals` 函数遍历主对角线和副对角线，查找最大质数。
- **返回结果**：如果没有找到质数，返回 0；否则返回找到的最大质数。

```cpp
bool isPrime(int num) {
    if (num <= 1) return false;
    for (int i = 2; i <= std::sqrt(num); ++i) {
        if (num % i == 0) return false;
    }
    return true;
}

int maxPrimeOnDiagonals(const std::vector<std::vector<int>>& nums) {
    int maxPrime = 0;
    int n = nums.size();

    for (int i = 0; i < n; ++i) {
        // 主对角线
        if (isPrime(nums[i][i])) {
            maxPrime = std::max(maxPrime, nums[i][i]);
        }
        // 副对角线
        if (isPrime(nums[i][n - i - 1])) {
            maxPrime = std::max(maxPrime, nums[i][n - i - 1]);
        }
    }

    return maxPrime;
}
```
