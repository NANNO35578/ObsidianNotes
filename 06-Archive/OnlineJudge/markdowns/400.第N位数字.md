[400. 第 N 位数字](https://leetcode.cn/problems/nth-digit/)

- **理解问题**： 我们需要找到无限整数序列中第 `n` 位上的数字。例如，在序列 `123456789101112...` 中，第 10 位是 `1`，第 11 位是 `0`。
- **分位数处理**：
    - 数字可以分为不同的位数段：
        - 1 位数（1-9）：总共 9 个数字。
        - 2 位数（10-99）：总共 90 个数字。
        - 3 位数（100-999）：总共 900 个数字。
    - 每个位数段的数字个数和总位数可以用公式计算：
        - 1 位数：9 * 1 = 9
        - 2 位数：90 * 2 = 180
        - 3 位数：900 * 3 = 2700
    - 以此类推。
- **找到 `n` 所在的位数**：
    - 通过累加各个位数段的总位数，直到 `n` 小于当前位数段的总位数。
    - 这时就找到了 `n` 所在的位数。
- **确定具体数字**：
    - 计算出在该位数段中，`n` 对应的具体数字。
    - 计算出该数字的值，并获取其中的目标位。
- **返回结果**

```cpp
int findNthDigit(int n) {
    if (n < 10) return n; // 直接返回 0-9 的数字

    long long len = 1; // 当前数字的位数
    long long count = 9; // 当前位数的数字个数
    long long start = 1; // 当前位数的起始数字

    // 找到 n 所在的数字位数
    while (n > len * count) {
        n -= len * count;
        len++;
        count *= 10;
        start *= 10;
    }

    // 找到具体的数字
    start += (n - 1) / len; // 找到目标数字
    string num = to_string(start);
    
    return num[(n - 1) % len] - '0'; // 返回目标数字中的某一位
}

```

##### 二分
- 为了找到无限整数序列中第 `n` 位的数字，需要确定这个数字所属的整数以及该整数的具体位数。使用二分查找可以高效地找到该整数的位数。

1. **位数定义**：
    - 假设该数字所在的整数是 `d` 位数。
    - 所有不超过 `d-1` 位数的整数的位数之和小于 `n`，而所有不超过 `d` 位数的整数的位数之和大于等于 `n`。
2. **二分查找**：
    - 设定 `low = 1`，`high = 9`（因为最多 9 位数）。
    - 通过二分查找确定 `d` 的值。
    - 对于某个 `x`，如果所有不超过 `x` 位数的整数的位数之和小于 `n`，则更新 `low`，否则更新 `high`
3. **计算位数和**：
    - 定义函数 `totalDigits(length)` 来计算所有不超过 `length` 位数的整数的位数之和。
4. **计算目标数字**：
    - 使用 `prevDigits` 表示不超过 `d-1` 位数的总位数。
    - 计算 `index = n - prevDigits - 1`（0-based）。
    - 计算 `start = 10^(d-1)`，找到 `d` 位数的起始数字。
    - 计算目标数字 `num = start + index / d` 和目标位 `digitIndex = index % d`。
    - 最终得到目标数字的第 `digitIndex` 位。

```cpp
    int findNthDigit(int n) {
        int low = 1, high = 9;
        while (low < high) {
            int mid = (high - low) / 2 + low;
            if (totalDigits(mid) < n) {
                low = mid + 1;
            } else {
                high = mid;
            }
        }
        int d = low;
        int prevDigits = totalDigits(d - 1);
        int index = n - prevDigits - 1;
        int start = (int) pow(10, d - 1);
        int num = start + index / d;
        int digitIndex = index % d;
        int digit = (num / (int) (pow(10, d - digitIndex - 1))) % 10;
        return digit;
    }

    int totalDigits(int length) {
        int digits = 0;
        int curLength = 1, curCount = 9;
        while (curLength <= length) {
            digits += curLength * curCount;
            curLength++;
            curCount *= 10;
        }
        return digits;
    }

```
