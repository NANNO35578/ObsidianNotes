[2588. 统计美丽子数组数目](https://leetcode.cn/problems/count-the-number-of-beautiful-subarrays/)


> 一个子数组可以通过题目中成对减 `2^k` 的操作全部变成 0，当且仅当该子数组内对于每一位二进制 1 的个数都是偶数
> 换句话说，子数组的按位 XOR 应该是 0


---

## 方法一：哈希表记录前缀 XOR 频次
1. 先把 `cnt[0]=1`，意味着「从开头到第 i XOR = 0 的子数组」也被统计进来
2. 遍历到位置 i 时，令 `prefix = XOR(nums[0..i])`
	- 若之前已有 `cnt[prefix]` 个位置 j（j < i）使得 `XOR(nums[0..j]) = prefix`，那么区间 (j, i] 的 XOR 就是 0，恰好是一段美丽子数组

时间复杂度 O(n)，空间 O(n)

```cpp
long long beautifulSubarrays(vector<int>& nums) {
    unordered_map<int, long long> cnt;
    cnt.reserve(nums.size() * 2);
    cnt[0] = 1;      // 空前缀的 XOR = 0，方便统计从 0 开始到某 i 的子数组
    long long ans = 0;
    int prefix = 0;
    for (int x : nums) {
        prefix ^= x;
        // 所有之前前缀 XOR 与当前相同的位置 j，都能和当前 i 组成一个 XOR 为 0 的子数组 (j, i]
        if (auto it = cnt.find(prefix); it != cnt.end()) {
            ans += it->second;
        }
        cnt[prefix]++;
    }
    return ans;
}
```

## 方法二：前缀 XOR 数组 + 排序


1. 首先计算出大小为 n+1 的前缀异或数组 `prefix`，第 `i` 个元素表示 `XOR(nums[0..i-1])`
2. 对 `prefix` 排序后，相同值的区间长度记为 `run`，每两两配对就对应一个异或为 0 的子数组，贡献 `C(run,2)`

时间复杂度 O(n log n)，空间 O(n)

```cpp
#include <bits/stdc++.h>
using namespace std;

// 返回美丽子数组的个数
long long beautifulSubarrays(vector<int>& nums) {
    int n = nums.size();
    // 构造前缀 xor，长度 n+1，prefix[0]=0
    vector<int> prefix(n+1, 0);
    for (int i = 0; i < n; i++) {
        prefix[i+1] = prefix[i] ^ nums[i];
    }
    // 排序
    sort(prefix.begin(), prefix.end());
    // 连续相同的有 m 个，就能从中选两两配对 C(m,2) 个子数组
    long long ans = 0;
    long long run = 1;
    for (int i = 1; i <= n; i++) {
        if (prefix[i] == prefix[i-1]) {
            run++;
        } else {
            ans += run * (run - 1) / 2;
            run = 1;
        }
    }
    ans += run * (run - 1) / 2;
    return ans;
}
```
