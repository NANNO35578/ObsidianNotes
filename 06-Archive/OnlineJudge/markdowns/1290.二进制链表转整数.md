[1290. 二进制链表转整数](https://leetcode.cn/problems/convert-binary-number-in-a-linked-list-to-integer/)

##### 模拟
- 每读取链表的一个节点值，可以认为读到的节点值是当前二进制数的最低位；
- 当读到下一个节点值的时候，**需要将已经读到的结果乘以 2**，再将新读到的节点值当作当前二进制数的最低位；
- 如此进行下去，直到读到了链表的末尾。

```cpp
    int getDecimalValue(ListNode* head) {
        ListNode* cur = head;
        int ans = 0;
        while (cur != nullptr) {
            ans = ans * 2 + cur->val;
            cur = cur->next;
        }
        return ans;
    }
```

##### 字符串

- 遍历链表，拼接成字符串
- 使用`stoi(src,dst,base)`可将`std::string`转化为int
```cpp
    int getDecimalValue(ListNode* head) {
        int cnt = 0;
        std::string num;
        num.reserve(40);
        ListNode* point = head;
        while (point != nullptr) {
            num += (char)(point->val+48);
            ++cnt;
            point = point->next;
        }

        return stoi(num,nullptr,2);
    }
```

##### 栈
- 利用栈将数位存储，遍历完链表，栈顶即为最低位数值
- 遍历栈，求和
```cpp
    int getDecimalValue(ListNode* head) {
        std::stack<int> stk;

        ListNode* point = head;
        while (point != nullptr) {
            stk.push(point->val);
            point = point->next;
        }

        int base = 1;
        int ans = 0;
        while (!stk.empty()) {
            ans += (stk.top() ? base : 0);
            stk.pop();
            base *= 2;
        }

        return ans;
    }
```

##### 递归
- 若当前节点为最后一位，记`ans`为当前节点`val`，将基数置为1
	- 若不为最后一位，遍历后一节点
	- 将当前`ans`增加`base * val` ，同时`base*=2`

```cpp
    void ret(ListNode* head, int* curbase,int * ans) {
        if (head->next == nullptr) {
            *curbase = 1;
            *ans+=head->val;
            return;
        }

        ret(head->next, curbase, ans);
        *curbase *= 2;

        *ans += head->val * *curbase;
    }

        int ans = 0;
        int base = 0;

        ret(head, &base, &ans);

        return ans;
    }
```
