$A \land B = B$ 
$A \lor B$ 
$0 \oplus B = B$ 
$1 \oplus A = 1$ 

- `n | 0` → 不变
- `n | 1` → 最低位变 1
- `n & 0` → 永远是 0
- `n & 1` → 取最低位
- `n ^ 0` → 不变
- `n ^ 1` → 翻转最低位

----


- 题目要求只使用常量空间, 即不可使用类似`std::map`等关系型容器存储
- 考虑到, 如果我们能够在遍历时对第一次出现的数进行对结果加操作, 第二次出现的进行减操作, 最终就可以获得结果
- 此过程中, 初始值应当设置为0, 否则会出现偏差
- 基于这些条件, 可以使用*异或*操作, 因为一个数与自己异或得到0, 0与$x$异或得到$x$ 
- **解法**: 遍历, 将所有数与0 异或

##### 实现一: 手动遍历

```cpp
  int singleNumber(vector<int>& nums) {
    int ans = 0;
    for (int i : nums) ans ^= i;

    return ans;
  }
```


##### 实现二: STL `std::accumulate`
```cpp
int signalNumber(std::vector<int>& nums) {
	return std::accumulate(nums.begin(), nums.end(), 0, [](int ans, int other) { return ans ^ other; });
}
```
