# 迭代器主要有哪几种类型

1. **输入迭代器 (Input Iterator)**  
    只能读取数据，不能修改。支持单向遍历。
    
2. **输出迭代器 (Output Iterator)**  
    只能写入数据，不能读取。也支持单向遍历。
    
3. **前向迭代器 (Forward Iterator)**  
    既可以读取也可以写入数据，支持单向遍历，可以多次访问同一个元素。
    
4. **双向迭代器 (Bidirectional Iterator)**  
    既可以读取也可以写入数据，支持双向遍历（可以向前和向后移动）。
    
5. **随机访问迭代器 (Random Access Iterator)**  
    具有随机访问能力，可以在 O(1) 时间内访问任意元素，支持双向遍历。

# C++设计模式中代理模式和适配器模式区别
代理模式和适配器模式在设计模式中有不同的目的和应用场景。以下是它们的主要区别：

##### 代理模式 (Proxy Pattern)
- **定义**：通过一个代理对象控制对另一个对象的访问。代理对象可以在客户端和目标对象之间提供一个替代品。
- **目的**：用于控制访问、延迟加载、权限检查、日志记录等。
- **实现方式**：代理对象持有目标对象的引用，客户端通过代理对象与目标对象交互。
- **示例**：虚拟代理（延迟加载），保护代理（权限控制）。

##### 适配器模式 (Adapter Pattern)
- **定义**：将一个接口转换成客户端所期待的另一个接口，使得原本因接口不兼容而无法一起工作的类能够一起工作。
- **目的**：用于解决不同接口之间的兼容性问题。
- **实现方式**：适配器类实现目标接口，并持有一个需要适配的类的实例，通过适配器将调用转发到被适配的对象。
- **示例**：将一个旧的类接口适配到新的接口，使得旧代码可以与新系统协同工作。
## 总结
- **代理模式**关注的是对对象的控制和访问，而**适配器模式**关注的是接口的转换和兼容性。
- 使用代理时，目标对象是可以被代理的，而使用适配器时，通常是为了让不同接口的对象能够互相协作。

# `advance`函数介绍一下
`advance` 函数是 C++ STL 中用于迭代器的一个重要工具。它的主要作用是移动迭代器到指定的位置。
##### 基本语法
```cpp
template< class ForwardIt, class Distance >
void advance( ForwardIt& it, Distance n );
```

##### 参数
- **ForwardIt**：迭代器类型，支持前进迭代（如 `std::vector`、`std::list` 的迭代器）。
- **Distance**：可以是整数类型，表示要移动的距离。可以是正数（向前移动）或负数（向后移动）。

##### 功能
- 将迭代器 `it` 移动 `n` 个位置。
- 如果 `n` 为正数，迭代器向前移动；如果为负数，向后移动。

##### 注意事项
- `advance` 适用于所有支持前进迭代的迭代器，不适用于反向迭代器或随机访问迭代器（在这些情况下，可以直接使用加法操作）。
- 使用时要确保移动的范围在容器的有效范围内，以避免未定义行为。
