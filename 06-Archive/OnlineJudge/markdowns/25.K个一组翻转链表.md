[25. K 个一组翻转链表](https://leetcode.cn/problems/reverse-nodes-in-k-group/)

- **虚拟头节点**：创建一个 `dummy` 节点，方便处理头节点的翻转。
- **循环遍历**：用 `while (true)` 不断处理每一组。
    - **判断组大小**：检查当前组是否有 k 个节点。
    - **翻转节点**：如果有 k 个节点，翻转之。
- **连接组**：翻转后，连接翻转后的组与前一组和下一组。
- **更新指针**：更新 `preGroup` 为当前组的起始节点。

```cpp
    ListNode* reverseKGroup(ListNode* head, int k) {
        ListNode dummy(0); // 创建一个虚拟头节点
        dummy.next = head;
        ListNode* preGroup = &dummy; // 记录当前组的前一个节点

        while (true) {
            ListNode* groupStart = preGroup->next; // 当前组的起始节点
            ListNode* curr = groupStart;
            int count = 0;

            // 检查当前组是否有 k 个节点
            while (curr && count < k) {
                curr = curr->next;
                count++;
            }
            if (count < k) break; // 不足 k 个节点，结束

            // 翻转 k 个节点
            ListNode* prev = nullptr;
            curr = groupStart;
            for (int i = 0; i < k; i++) {
                ListNode* nextTemp = curr->next;
                curr->next = prev;
                prev = curr;
                curr = nextTemp;
            }

            // 连接翻转后的组和下一组
            preGroup->next = prev; // 连接前一组和翻转后的组
            groupStart->next = curr; // 连接翻转后的组和下一组
            preGroup = groupStart; // 更新 preGroup 为当前组的起始节点
        }

        return dummy.next; // 返回修改后的链表
    }
```
