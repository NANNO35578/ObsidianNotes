[1373. 二叉搜索子树的最大键值和](https://leetcode.cn/problems/maximum-sum-bst-in-binary-tree/)

### 方法一：递归

#### 思路与算法

题目给定的是一颗二叉树，并不保证是二叉搜索树。因此，我们需要独立判断每个子树是否是一个二叉搜索树。以 `root` 为根的子树是一颗二叉搜索树当且仅当以下条件满足：
1. **左子树**：
    - 左子树为空，或者
    - 左子树是一颗二叉搜索树，并且左子树的最大值小于 `root.val`。
2. **右子树**：
    - 右子树为空，或者
    - 右子树是一颗二叉搜索树，并且右子树的最小值大于 `root.val`。
为了实现这一判断，我们使用一个结构体来描述子树的基本情况，包含以下元素：

- `isBST`：表示该子树是否为二叉搜索树。
- `minValue`：表示该子树中的最小值。
- `maxValue`：表示该子树中的最大值。
- `sumValue`：表示该子树中所有节点的键值之和，用于求解答案。
#### 递归过程

1. **判断子树**：
    - 首先递归判断左子树是否是二叉搜索树。
    - 然后递归判断右子树是否是二叉搜索树。
2. **条件检查**：
    - 用 `left` 和 `right` 分别表示左子树和右子树的基本信息。
    - 当且仅当以下条件都满足时，以 `root` 为根的子树是二叉搜索树：
        - `left.isBST` 为真；
        - `right.isBST` 为真；
        - `left.maxValue < root.val`；
        - `right.minValue > root.val`。

#### 特殊处理

- 对于空子树，我们用 `-∞` 表示最大值，用 `∞` 表示最小值，并且将 `isBST` 设置为真，`sumValue` 设置为 0。这保证了在父节点判断时，即使左或右子树为空，也不会影响条件判断。
#### 更新子树信息

- 在确定以 `root` 为根的子树是二叉搜索树后，设置其基本信息：
    - `isBST` 设置为真；
    - `minValue` 设置为 `min(left.minValue, root.val)`（考虑左子树为空的情况）；
    - `maxValue` 设置为 `max(right.maxValue, root.val)`（考虑右子树为空的情况）；
    - `sumValue` 设置为 `left.sumValue + right.sumValue + root.val`。
- 同时，用 `sumValue` 更新题目答案，取所有二叉搜索树中的最大值。

#### 遍历要求

本题需要遍历所有节点，因为每个子树都有成为二叉搜索树的可能。即使某个节点的左子树不是二叉搜索树，也需要遍历该节点的右子树，因为其右子树及其子树仍有可能成为二叉搜索树。

```cpp
class Solution {
public:
    static constexpr int inf = 0x3f3f3f3f;
    int res;
    struct SubTree {
        bool isBST;
        int minValue;
        int maxValue;
        int sumValue;
        SubTree(bool isBST, int minValue, int maxValue, int sumValue) : isBST(isBST), minValue(minValue), maxValue(maxValue), sumValue(sumValue) {}
    };

    SubTree dfs(TreeNode* root) {
        if (root == nullptr) {
            return SubTree(true, inf, -inf, 0);
        }
        auto left = dfs(root->left);
        auto right = dfs(root->right);

        if (left.isBST && right.isBST &&
                root->val > left.maxValue && 
                root->val < right.minValue) {
            int sum = root->val + left.sumValue + right.sumValue;
            res = max(res, sum);
            return SubTree(true, min(left.minValue, root->val), 
                           max(root->val, right.maxValue), sum);
        } else {
            return SubTree(false, 0, 0, 0);
        }
    }

    int maxSumBST(TreeNode* root) {
        res = 0;
        dfs(root);
        return res;
    }
};

```
