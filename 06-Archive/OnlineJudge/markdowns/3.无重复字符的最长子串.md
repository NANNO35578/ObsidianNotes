[3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

1. **使用两个指针**: 定义两个指针 `left` 和 `right`，分别表示当前窗口的开始和结束位置。
2. **使用一个集合**: 用一个 `unordered_set` 来存储当前窗口中的字符，以便快速检查是否有重复字符。
3. **滑动窗口**:
    - 通过 `right` 指针向右扩展窗口，逐个添加字符到集合中。
    - 如果添加的字符已经存在于集合中，则移动 `left` 指针向右，直到窗口中不再有重复字符。
4. **更新最长子串的长度**: 在每次扩展窗口后，检查并更新最长子串的长度。
5. **遍历结束**: 当 `right` 指针到达字符串末尾时，结束遍历。

```cpp
    int lengthOfLongestSubstring(string s) {
        std::unordered_set<char> charSet;
        int left = 0, longest = 0;

        for (int right = 0; right < s.size(); ++right) {
            // 如果字符存在，移动左指针
            while (charSet.find(s[right]) != charSet.end()) {
                charSet.erase(s[left]);
                left++;
            }
            // 添加当前字符到集合
            charSet.insert(s[right]);
            // 更新最长子串长度
            longest = std::max(longest, right - left + 1);
        }

        return longest;
    }
```
