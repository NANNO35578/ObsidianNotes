[55. 跳跃游戏](https://leetcode.cn/problems/jump-game/)
##### 贪心
1. **初始化一个变量 `maxReach`**，表示当前能到达的最远距离，初始值为 0。
2. **遍历数组**，对于每一个下标 `i`：
    - 如果 `i` 大于 `maxReach`，说明不能到达这个下标，直接返回 `false`。
    - 更新 `maxReach` 为 `max(maxReach, i + nums[i])`，表示更新能达到的最远距离。
    - 如果 `maxReach` 达到或超过最后一个下标，返回 `true`。
3. **结束遍历后**，如果没有返回 `true`，则返回 `false`。

```cpp
    int maxProfit(vector<int>& prices) {
        int maxProfit = 0; // 初始化最大利润为 0
        int minPrice = INT_MAX; // 初始化最低价格为最大整数

        for (int price : prices) {
            // 更新最低价格
            if (price < minPrice) {
                minPrice = price;
            }
            // 计算当前利润并更新最大利润
            int profit = price - minPrice;
            if (profit > maxProfit) {
                maxProfit = profit;
            }
        }
        return maxProfit; // 返回最大利润
    }
```
