[139. 单词拆分](https://leetcode.cn/problems/word-break/)

----
### 方法 1：动态规划
1. 通过一个布尔数组 `dp` 来记录当前子串是否可以被字典中的单词拼接. 
2. `dp[i]` 表示字符串 `s` 的前 `i` 个字符是否可以通过字典中的单词拼接得到.
3. 从 `i = 1` 到 `i = n`（字符串的长度），对于每一个 `i`，尝试用每个可能的 `j` 来查看前缀是否符合字典中的单词.
4. 如果 `dp[j]` 为真，并且从 `j` 到 `i` 之间的子串在字典中，说明 `dp[i]` 可以是 `true`，即从 `0` 到 `i` 的子串可以拼接出.

```cpp 
bool wordBreak(std::string s, std::vector<std::string>& wordDict) {
    std::unordered_set<std::string> wordSet(wordDict.begin(), wordDict.end());
    std::vector<bool> dp(s.size() + 1, false);
    dp[0] = true; // 空字符串可以被拼接

    for (int i = 1; i <= s.size(); ++i) {
        for (int j = 0; j < i; ++j) {
            if (dp[j] && wordSet.count(s.substr(j, i - j))) {
                dp[i] = true;
                break;
            }
        }
    }
    return dp[s.size()];
}
```

### 方法 2：回溯
1. 尝试从字符串的每一个位置开始分割，判断是否能通过字典中的单词拼接出字符串 `s`
2. 使用递归尝试每一个可能的分割. 如果从某个位置到某个位置的子串在字典中，继续检查接下来的部分
3. 如果找到一个有效的分割路径，返回 `true`
4. 使用一个 `visited` 集合来避免重复计算，防止陷入死循环


```cpp
bool wordBreakHelper(const std::string& s, int start, std::unordered_set<std::string>& wordSet, std::unordered_set<int>& visited) {
    if (start == s.size()) return true;
    if (visited.count(start)) return false; // 防止重复计算

    for (int end = start + 1; end <= s.size(); ++end) {
        if (wordSet.count(s.substr(start, end - start)) && wordBreakHelper(s, end, wordSet, visited)) {
            return true;
        }
    }
    
    visited.insert(start); // 记录已访问的起始位置
    return false;
}

bool wordBreak(std::string s, std::vector<std::string>& wordDict) {
    std::unordered_set<std::string> wordSet(wordDict.begin(), wordDict.end());
    std::unordered_set<int> visited;
    return wordBreakHelper(s, 0, wordSet, visited);
}
```

### Tire + 回溯

##### 1. **Trie 树实现**

- `TrieNode` 结构体表示 Trie 树的节点，其中 `children` 用来存储当前节点的子节点，`isEndOfWord` 用来标记是否为一个完整单词的结尾
- `Trie` 类包含 `insert` 方法，遍历每个字符并将其插入到 Trie 树中

##### 2. **回溯方法**

- `backtrack` 函数是核心的递归函数，它通过不断尝试不同的子串来判断是否可以拼接出完整的单词
- 从 `start` 开始，向后遍历字符串 `s`，尝试匹配 Trie 树中的单词。如果找到一个单词结尾（`isEndOfWord == true`），就递归检查剩下的部分。如果整个字符串匹配完成，则返回 `true`
- 通过 `visited` 集合记录已经访问的起始位置，避免重复计算

##### 3. **优化**
- **提前结束：** 如果当前字符不在 Trie 树中，直接 `break` 退出，避免不必要的查找
- **避免重复计算：** 使用 `visited` 集合避免重新从相同的起始位置进行计算，提高效率


```cpp
class Solution {
public:
    struct TrieNode {
        std::unordered_map<char, TrieNode*> children;
        bool isEndOfWord = false;
    };

    class Trie {
    public:
        TrieNode* root;

        Trie() { root = new TrieNode(); }

        void insert(const std::string& word) {
            TrieNode* node = root;
            for (char c : word) {
                if (!node->children.count(c)) {
                    node->children[c] = new TrieNode();
                }
                node = node->children[c];
            }
            node->isEndOfWord = true;
        }
    };

    bool wordBreak(std::string s, std::vector<std::string>& wordDict) {
        Trie trie;
        for (const std::string& word : wordDict) {
            trie.insert(word);
        }

        std::unordered_set<int> visited;
        return backtrack(s, 0, trie.root, visited);
    }

private:
    bool backtrack(const std::string& s, int start, TrieNode* node,
                   std::unordered_set<int>& visited) {
        if (start == s.size())
            return true; // 成功匹配整个字符串
        if (visited.count(start))
            return false; // 防止重复计算

        TrieNode* currentNode = node;
        for (int end = start; end < s.size(); ++end) {
            char c = s[end];
            if (currentNode->children.count(c)) {
                currentNode = currentNode->children[c];
                if (currentNode->isEndOfWord) {
                    if (backtrack(s, end + 1, node, visited)) {
                        return true;
                    }
                }
            } else {
                break; // 如果没有这个字符，提前结束
            }
        }

        visited.insert(start); // 记录已访问的起始位置
        return false;
    }
};
```
