[3046. 分割数组](https://leetcode.cn/problems/split-the-array/)
- 统计每次出现数量
- 使用哈希表
```cpp
    bool isPossibleToSplit(vector<int>& nums) {
        unordered_map<int, int> frequency;
        
        // 统计每个元素的出现次数
        for (int num : nums) {
            frequency[num]++;
            if(frequency[num]==3)return false;
        }

        return true;
    }
```
