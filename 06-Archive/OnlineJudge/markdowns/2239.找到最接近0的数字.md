[2239. 找到最接近 0 的数字](https://leetcode.cn/problems/find-closest-number-to-zero/)
- 遍历 取绝对值更小的
- 若绝对值相等 取最大的

```cpp
    int findClosestNumber(vector<int>& nums) {
        int ans=nums[0];
        for(int i:nums){
            if(abs(i)<abs(ans)){
                ans=i;
            }else if(abs(i)==abs(ans)){
                ans=max(ans,i);
            }
        }
        return ans;
    }
```

##### 使用lambda表达式
```cpp
    int findClosestNumber(vector<int>& nums) {
        return *std::min_element(nums.begin(), nums.end(), [](int a, int b) {
            if (std::abs(a) == std::abs(b)) {
                return a > b; // 如果绝对值相同，返回较小的值
            }
            return std::abs(a) < std::abs(b); // 返回绝对值较小的值
        });
    }
```

```cpp
    int findClosestNumber(vector<int>& nums) {
        return ranges::min(nums, {}, [](int i) { return abs(i) << 1 | (i < 0); });
    } 
```
- **自定义比较函数**：
    - 使用 lambda 表达式来定义比较逻辑。
    - `abs(i) << 1` 将绝对值左移一位，确保绝对值较小的数优先。
    - `| (i < 0)` 用于处理负数。对于同样的绝对值，负数将被认为更大（因为在比较中会加 1）。
- **使用 `ranges::min`**：
    - `ranges::min` 会根据自定义的比较函数找到最小值。
    - 这样可以直接得到绝对值最小的数，并在绝对值相同的情况下优先返回较大的数。
