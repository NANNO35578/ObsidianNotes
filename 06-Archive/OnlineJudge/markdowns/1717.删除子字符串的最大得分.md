[1717. 删除子字符串的最大得分](https://leetcode.cn/problems/maximum-score-from-removing-substrings/)


##### 贪心
- **确定优先级**：首先确定删除 "ab" 和 "ba" 的优先级。如果 `x >= y`，优先删除 "ab"；否则，优先删除 "ba"
- **使用栈来处理删除**：使用栈来删除子字符串。遍历时，将字符入栈。如果栈顶的两个字符形成目标子字符串（"ab" 或 "ba"），则弹出这两个字符并累加分数
- **反复遍历**：在处理完一个优先级的子字符串后，需要再次遍历字符串，以处理剩余的字符中可能形成的另一种子字符串

```cpp
int maximumGain(string s, int x, int y) {
    int score = 0;
    stack<char> st;
    
    // Determine which substring to prioritize
    if (x >= y) {
        // Prioritize "ab"
        for (char c : s) {
            if (c == 'b' && !st.empty() && st.top() == 'a') {
                st.pop(); // Remove "ab"
                score += x;
            } else {
                st.push(c);
            }
        }

        // process "ba"
        string remaining;
        while (!st.empty()) {
            remaining += st.top();
            st.pop();
        }
        reverse(remaining.begin(), remaining.end());

        for (char c : remaining) {
            if (c == 'a' && !st.empty() && st.top() == 'b') {
                st.pop(); // Remove "ba"
                score += y;
            } else {
                st.push(c);
            }
        }
    } else {
        // Prioritize "ba"
        for (char c : s) {
            if (c == 'a' && !st.empty() && st.top() == 'b') {
                st.pop(); // Remove "ba"
                score += y;
            } else {
                st.push(c);
            }
        }

        // process "ab"
        string remaining;
        while (!st.empty()) {
            remaining += st.top();
            st.pop();
        }
        reverse(remaining.begin(), remaining.end());

        for (char c : remaining) {
            if (c == 'b' && !st.empty() && st.top() == 'a') {
                st.pop(); // Remove "ab"
                score += x;
            } else {
                st.push(c);
            }
        }
    }

    return score;
}
```

##### 优化
- **优先级设置**： 如果 `x < y`，则交换它们的值及对应的字符 `highChar`（得分高的字符）和 `lowChar`（得分低的字符）
- **初始化计数器**：    
    - 使用两个计数器：
        - `aCount`：记录未处理的 `highChar`（即 `a` 或 `b`）的数量
        - `bCount`：记录未处理的 `lowChar`（即 `b` 或 `a`）的数量
    - 使用 `totalScore` 来累加最终得分
- **遍历字符串**： 使用一个循环遍历字符 `c`：
    - 如果 `c` 是 `highChar`，则增加 `aCount`
    - 如果 `c` 是 `lowChar`：
        - 如果 `aCount` 大于零，说明可以形成 "ab"（或 "ba"），则加上得分 `x` 并减少 `aCount`
        - 如果 `aCount` 为零，说明没有可匹配的 `highChar`，于是增加 `bCount`
    - 如果字符既不是 `highChar` 也不是 `lowChar`，则表示当前段结束
        - 计算未处理的 `aCount` 和 `bCount` 的得分，使用 `min(aCount, bCount) * y`
        - 重置 `aCount` 和 `bCount` 为零，准备处理下一个段落
- **处理最后一段**： 在循环结束后，可能还有一段未处理的 `aCount` 和 `bCount`，需要再次计算得分并加到 `totalScore` 中

```cpp
    int maximumGain(string s, int x, int y) {
        char highChar = 'a', lowChar = 'b';
        if (x < y) {
            swap(x, y);
            swap(highChar, lowChar);
        }

        int totalScore = 0, aCount = 0, bCount = 0;

        for (char c : s) {
            if (c == highChar) {
                aCount++;
            } else if (c == lowChar) {
                if (aCount > 0) {
                    totalScore += x; // Form "ab"
                    aCount--;
                } else {
                    bCount++; // Count unmatched 'b'
                }
            } else {
                totalScore += min(aCount, bCount) * y;
                aCount = 0;
                bCount = 0;
            }
        }

        totalScore += min(aCount, bCount) * y;
        return totalScore;
    }
```

##### 栈删除元素
- `helper` 处理给定字符串 `s` 中的特定模式（如 "ab" 或 "ba"），并计算通过删除该模式所获得的得分
- **使用栈处理字符**：函数中，使用栈来逐个处理字符串字符
    - 当栈顶字符与当前字符形成目标模式（如 "ab" 或 "ba"）时，从栈中弹出栈顶字符，并增加得分
    - 如果不形成目标模式，则将当前字符压入栈中
- **重组字符串**：在处理完字符串后，栈中剩余的字符会重新组合成新的字符串，清空原字符串并将栈中的字符按顺序保存
- **主函数逻辑**：
    - 在 `maximumGain` 函数中，首先计算两种情况的得分：
        - **情况1**：先删除 "ab"，然后删除 "ba"
        - **情况2**：先删除 "ba"，然后删除 "ab"
    - 通过调用 `helper` 函数，分别计算这两种情况下的得分
    - 使用 `max` 函数返回两种情况中的最大得分
- **字符串复制**： 在第二种情况中，复制原始字符串 `s` 为 `s2`，以确保每次处理都是从同一初始状态开始

```cpp
class Solution {
public:
    int helper(string& s, const string& pattern, int score) {
        stack<char> st;
        int res = 0;
        for (char c : s) {
            if (!st.empty() && st.top() == pattern[0] && c == pattern[1]) {
                st.pop();
                res += score;
            } else {
                st.push(c);
            }
        }
        // 重组字符串
        s.clear();
        while (!st.empty()) {
            s += st.top();
            st.pop();
        }
        reverse(s.begin(), s.end());
        return res;
    }

    int maximumGain(string s, int x, int y) {
        // 情况1：先删 "ab"，再删 "ba"
        int score1 = helper(s, "ab", x);
        score1 += helper(s, "ba", y);

        // 情况2：先删 "ba"，再删 "ab"
        string s2 = s; // 复制原始字符串
        int score2 = helper(s2, "ba", y);
        score2 += helper(s2, "ab", x);

        return max(score1, score2);
    }
};
```
