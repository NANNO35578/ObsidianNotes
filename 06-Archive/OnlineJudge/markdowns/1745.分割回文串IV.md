[1745. 分割回文串 IV](https://leetcode.cn/problems/palindrome-partitioning-iv/)
- **定义回文检查函数**：
    - 创建一个函数 `isPalindrome`，接受字符串的起始和结束索引，逐字符检查是否为回文。
- **预处理回文信息**：
    - 创建一个二维布尔数组 `isPal`，大小为 `n x n`，其中 `n` 是字符串的长度。
    - 填充这个数组，记录所有子字符串是否为回文：
        - 使用双重循环遍历字符串的所有可能的起始和结束索引。
        - 如果子字符串是回文，则在 `isPal[start][end]` 位置标记为 `true`。
- **检查分割条件**：
    - 使用两个嵌套循环来尝试分割字符串：
        - 第一个循环选定第一个分割点 `i`，确保前面部分是非空。
        - 第二个循环选定第二个分割点 `j`，确保中间部分也是非空。
    - 在每次循环中，检查以下三个条件是否同时成立：
        - `s[0..i]` 是回文（使用 `isPal[0][i]`）。
        - `s[i+1..j]` 是回文（使用 `isPal[i+1][j]`）。
        - `s[j+1..n-1]` 是回文（使用 `isPal[j+1][n-1]`）。
    - 如果以上条件满足，返回 `true`。
- **返回结果**：
    - 如果所有可能的分割都检查完毕且未找到满足条件的分割，返回 `false`。
```cpp
bool isPalindrome(const string& s, int start, int end) {
    while (start < end) {
        if (s[start] != s[end]) {
            return false;
        }
        start++;
        end--;
    }
    return true;
}

vector<vector<bool>> preprocessPalindrome(const string& s) {
    int n = s.length();
    vector<vector<bool>> isPal(n, vector<bool>(n, false));

    for (int i = 0; i < n; ++i) {
        for (int j = i; j < n; ++j) {
            if (isPalindrome(s, i, j)) {
                isPal[i][j] = true; // 记录 s[i..j] 是否为回文
            }
        }
    }
    
    return isPal;
}

bool canSplitIntoThreePalindromes(const string& s) {
    int n = s.length();
    if (n < 3) return false; // 至少需要三个字符

    vector<vector<bool>> isPal = preprocessPalindrome(s);
    
    for (int i = 0; i < n - 2; ++i) { // 第一个分割点
        for (int j = i + 1; j < n - 1; ++j) { // 第二个分割点
            if (isPal[0][i] && isPal[i + 1][j] && isPal[j + 1][n - 1]) {
                return true;
            }
        }
    }
    
    return false;
}
```


##### 动态规划
- 设字符串的长度为 n，首先我们用动态规划算出 s 的任意一个子字符串是否为回文串，并将结果保存在二维数组中。这一步中，我们使用双重循环来计算，第一层循环遍历长度 length，从短到长；第二层循环遍历子字符串的起始位置。判断某个子字符串是否为回文时，如果长度为 1，则一定为回文；如果长度为 2，则判断这两个字符是否相同；如果长度为 3，则需要首尾两个字符相同并且剩余的字符串也为回文。每次判断长串时，直接查询已存储的短串状态，避免了重复计算。遍历完成后，所有子串的回文状态均已确定，可在常数时间内查询任意子串是否为回文。

- 接下来需要判断是否存在三个非空回文子串，拼接起来可以构成完整的 s。我们只需要遍历中间子字符串的起始位置和终点位置，这两个位置确定后，三个子串都确定了。如果三个子串都是回文，则返回 true，否则返回 false。
```cpp
    bool checkPartitioning(string s) {
        int n = s.size();
        vector<vector<bool>> isPalindrome(n, vector<bool>(n));
        for (int length = 1; length < n; length++) {
            for (int start = 0; start <= n - length; start++) {
                int end = start + length - 1;
                if (length == 1) {
                    isPalindrome[start][end] = true;
                } else if (length == 2) {
                    isPalindrome[start][end] = s[start] == s[end];
                } else {
                    isPalindrome[start][end] = s[start] == s[end] && isPalindrome[start + 1][end - 1];
                }
            }
        }
        for (int start = 1; start < n - 1; start++) {
            if (!isPalindrome[0][start - 1]) {
                continue;
            }
            for (int end = start; end < n - 1; end++) {
                if (isPalindrome[start][end] && isPalindrome[end + 1][n - 1]) {
                    return true;
                }
            }
        }
        return false;
    }

```
