[1035. 不相交的线](https://leetcode.cn/problems/uncrossed-lines/)
可以将其视为寻找在两条线段上可以连接的最大公共子序列。具体来说，需要找到两个数组 `nums1` 和 `nums2` 中相同元素的最大个数，同时保证这些元素的顺序是相同的。以下是解决方案的思路：
- **动态规划**：我们可以使用动态规划来解决这个问题。创建一个二维数组 `dp`，其中 `dp[i][j]` 表示在 `nums1[0...i-1]` 和 `nums2[0...j-1]` 中可以连接的最大线条数。
- **状态转移**：
    - 如果 `nums1[i-1] == nums2[j-1]`，则 `dp[i][j] = dp[i-1][j-1] + 1`（连接此元素）。
    - 否则，`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`（不连接当前元素）。
- **初始化**：`dp[0][j]` 和 `dp[i][0]` 都初始化为 0，因为没有元素时无法连接。
- **结果**：最终的结果将保存在 `dp[len(nums1)][len(nums2)]` 中。

```cpp
int maxConnectedLines(const std::vector<int>& nums1, const std::vector<int>& nums2) {
    int m = nums1.size();
    int n = nums2.size();
    std::vector<std::vector<int>> dp(m + 1, std::vector<int>(n + 1, 0));

    // 动态规划填充 dp 表
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (nums1[i - 1] == nums2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1; // 连接此元素
            } else {
                dp[i][j] = std::max(dp[i - 1][j], dp[i][j - 1]); // 不连接
            }
        }
    }

    return dp[m][n]; // 返回最大连线数
}
```
