[链表中倒数最后k个结点](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457293324)
- 类似滑动窗口 当前指针移动足够步长后开始移动目标指针
```cpp
    ListNode* FindKthToTail(ListNode* pHead, int k) {
        // 如果链表为空或k小于等于0，返回nullptr
        if (pHead == nullptr || k <= 0) return nullptr;
 
        ListNode* pE = pHead;
        ListNode* pF = pHead;
 
        // 首先移动pE，直到它前进k个节点
        for (int i = 0; i < k; ++i) {
            if (pE == nullptr)
                return nullptr;  // 如果链表长度小于k，返回nullptr
            pE = pE->next;
        }
 
        // 然后同时移动pE和pF，直到pE到达链表末尾
        while (pE != nullptr) {
            pE = pE->next;
            pF = pF->next;
        }
 
        // pF此时指向倒数第k个节点
        return pF;
    }
```
