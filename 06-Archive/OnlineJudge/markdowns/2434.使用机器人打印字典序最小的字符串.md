[2434. 使用机器人打印字典序最小的字符串](https://leetcode.cn/problems/using-a-robot-to-print-the-lexicographically-smallest-string/)

- 题目即给出入栈顺序，求出栈顺序的字典序最小字符串

遍历当前字符串，统计每个字符频率
理论字符 `a` 最小，第二次遍历s 时根据频率是否为0 更新最小字符

- 若当前字符大于最小字符，应当入栈
- 若小于等于，将栈顶出栈，后续会更新最小字符

```cpp
    string robotWithString(string s) {
        std::stack<char> t;
        std::string result;
        std::vector<int> count(26, 0);

        // 计数每个字符的出现次数
        for (char c : s) {
            count[c - 'a']++;
        }

        int minc = 0;

        for (char c : s) {
            t.push(c);
            count[c - 'a']--;

            while (minc != 26 && count[minc] == 0) { // 更新最小字符，即栈尾
                minc++;
            }

            // 尝试从 t 中写出字符
            while (!t.empty() && (t.top() <= minc + 'a')) {
                result.push_back(t.top());
                t.pop();
            }
        }
        return result;
    }
```


---
##### 1.. 计算后缀最小字符
- **`minCharToEnd` 数组**：该数组用于记录从当前位置到字符串末尾的最小字符。通过从右往左遍历字符串 `s`，逐步更新 `minChar`，并将其存入 `minCharToEnd` 数组。
- 这样，我们可以快速知道在当前字符后面还有哪些字符是最小的。

##### 2. 使用栈来管理字符
- **`stackChar`**：用来模拟机器人的操作，将字符暂时存储在栈中。栈的后进先出特性允许我们在合适的时机写出字符。

##### 3. 构建结果字符串
- 遍历字符串 `s` 的每个字符：
    - 在每次添加字符到栈后，检查栈顶字符是否可以写入结果字符串 `ans`。条件是栈顶字符小于等于当前位置的后缀最小字符 `minCharToEnd[i]`。如果可以写入，就将其添加到 `ans` 并从栈中移除。
    - 最后，将当前字符添加到 `stackChar` 中。

##### 4. 处理剩余字符
- 在遍历完字符串 `s` 后，可能仍有字符在 `stackChar` 中。需要继续将这些字符写入 `ans`，直到栈为空。


```cpp
    string robotWithString(string s) {
        int n = s.length();
        vector<char> minCharToEnd(n);
        char minChar = 'z';
        for (int i = n-1; i >= 0; i--) {
            minChar = min(minChar, s[i]);
            minCharToEnd[i] = minChar;
        }

        vector<char> stackChar;
        string ans;
        for (int i = 0; i < n; i++) {
            while (stackChar.size() > 0 && stackChar.back() <= minCharToEnd[i]) {
                ans.push_back(stackChar.back());
                stackChar.pop_back();
            }
            stackChar.push_back(s[i]);
        }
        while (stackChar.size() > 0) {
            ans.push_back(stackChar.back());
            stackChar.pop_back();
        }

        return ans;
    }
```
