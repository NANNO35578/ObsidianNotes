[2094. 找出 3 位偶数](https://leetcode.cn/problems/finding-3-digit-even-numbers/)

1. **目标**：
    - 从给定的整数数组 `digits` 中生成所有满足以下条件的三位偶数：
        - 由数组中的三个不同元素组成。
        - 不含前导零。
        - 最后一位必须是偶数。
2. **数据结构**：
    - 使用一个 `set` 来存储生成的三位偶数，以保证结果的唯一性。
3. **遍历组合**：
    - 使用三重循环遍历数组中的每个元素：
        - 外层循环选择第一位数字。
        - 中间循环选择第二位数字，确保不与第一位重复。
        - 内层循环选择第三位数字，确保不与前两位重复。
4. **条件检查**：
    - 在生成三位数之前，检查首位是否为零（避免前导零）。
    - 检查最后一位是否为偶数，以确保生成的数字是偶数。
5. **生成数字**：
    - 使用公式 `number = digits[i] * 100 + digits[j] * 10 + digits[k]` 将三个数字组合成一个三位数。
6. **结果处理**：
    - 将生成的数字插入到 `set` 中，保证唯一性。
    - 最后，将 `set` 转换为向量并返回，结果将是按递增顺序排列的。

```cpp
    vector<int> findEvenNumbers(vector<int>& digits) {
	    set<int> uniqueNumbers; // 用于存放唯一的整数
	    int n = digits.size();
	
	    // 遍历所有可能的三位数
	    for (int i = 0; i < n; ++i) {
	        for (int j = 0; j < n; ++j) {
	            if (j == i) continue; // 确保不重复使用
	            for (int k = 0; k < n; ++k) {
	                if (k == i || k == j) continue; // 确保不重复使用
	
	                // 确保不含前导零
	                if (digits[i] == 0) continue;
	
	                // 检查最后一位是否为偶数
	                if (digits[k] % 2 == 0) {
	                    // 组合成数字
	                    int number = digits[i] * 100 + digits[j] * 10 + digits[k];
	                    uniqueNumbers.insert(number); // 插入集合以去重
	                }
	            }
	        }
	    }
	
	    // 将集合转化为结果向量
	    vector<int> result(uniqueNumbers.begin(), uniqueNumbers.end());
	    
	    return result; // 返回结果
    }
```

# 计数

1. **目标**：
    - 从给定的整数数组 `digits` 中生成所有满足条件的三位偶数，并返回这些数字。
2. **计数数组**：
    - 使用一个大小为 11 的数组 `c` 来记录每个数字（0-9）在 `digits` 中出现的次数。数组索引对应数字，值表示该数字的出现次数。
3. **填充计数数组**：
    - 遍历 `digits` 数组，将每个数字的出现次数存入计数数组 `c`。
4. **遍历三位数**：
    - 使用一个循环遍历所有三位数（从 100 到 999）：
        - 通过整除和取余运算提取三位数的每一位数字 `x`（百位）、`y`（十位）和 `z`（个位）。
5. **条件检查**：
    - 在检查数字 `z` 是否为偶数以确保生成的数字是偶数。
    - 检查 `c[x]`、`c[y]` 和 `c[z]` 是否均大于或等于 0，确保所需的数字在原数组中存在且未被重复使用。
6. **生成结果**：
    - 如果以上条件满足，则将该三位数添加到结果向量 `res` 中。
7. **恢复计数**：
    - 在每次检查后，将计数数组中的相应数字的计数恢复，以便在下一次循环中继续正确判断。
8. **返回结果**：
    - 最后返回结果向量 `res`，其中包含所有符合条件的三位偶数。

```cpp
    int count[11] = { 0 }; // 计数数组
    vector<int> res; // 结果向量
    
    // 填充计数数组
    for (auto& digit : digits) {
        ++count[digit];
    }

    // 遍历所有三位数
    for (int i = 100; i < 1000; ++i) {
        int x = i / 100;         // 百位
        int y = (i % 100) / 10;  // 十位
        int z = i % 10;          // 个位
        
        // 暂时减少计数
        --count[x];
        --count[y];
        --count[z];

        // 检查是否满足条件
        if (z % 2 == 0 && count[x] >= 0 && count[y] >= 0 && count[z] >= 0) {
            res.emplace_back(i); // 添加到结果
        }

        // 恢复计数
        ++count[x];
        ++count[y];
        ++count[z];
    }

    return res; // 返回结果
```

#### 遍历所有可能的 3 位偶数

**思路与算法**

我们也可以从小到大遍历所有 3 位偶数（即 `[100,999]` 闭区间内的所有偶数），并判断对应的三个整数位是否为 digits 数组中三个不同元素。如果是，则该偶数为目标偶数；反之亦然。

具体地，我们首先用哈希表 freq 维护 digits 数组中每个数出现的次数。在遍历偶数时，我们同样用哈希表 freq1​ 维护每个偶数中每个数位出现的次数。此时，该偶数能够被数组中不重复元素表示的**充要条件**即为：

freq1​ 中每个元素的出现次数都不大于它在 freq 中的出现次数。

我们按照上述条件判断每个偶数是否为目标偶数，并按顺序统计这些偶数。最终，我们返回目标偶数的数组作为答案。

```cpp
class Solution {
public:
    vector<int> findEvenNumbers(vector<int>& digits) {
        vector<int> res;   // 目标偶数数组
        unordered_map<int, int> freq;   // 整数数组中各数字的出现次数
        for (const int digit: digits){
            ++freq[digit];
        }
       // 枚举所有三位偶数，维护整数中各数位的出现次数并比较判断是否为目标偶数
        for (int i = 100; i < 1000; i += 2){
            unordered_map<int, int> freq1;
            int tmp = i;
            while (tmp){
                ++freq1[tmp%10];
                tmp /= 10;
            }
            if (all_of(freq1.begin(), freq1.end(), [&](const auto& x){
                    return freq[x.first] >= freq1[x.first]; 
                })){
                res.push_back(i);
            }
        }
        return res;
    }
};
```
