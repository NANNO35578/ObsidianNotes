[2901. 最长相邻不相等子序列 II](https://leetcode.cn/problems/longest-unequal-adjacent-groups-subsequence-ii/)


### 问题总结
我们需要从字符串数组 `words` 和其对应的 `groups` 数组中找到一个最长的子序列，满足以下条件：
1. 相邻元素在 `groups` 中的值不同。
2. 相邻元素在 `words` 中的长度相等。
3. 相邻元素之间的汉明距离为 1。
### 解题思路
1. **动态规划数组**：
    - 使用一个数组 `dp` 来记录以每个字符串结尾的最长子序列的长度。
    - 使用一个数组 `prev` 来记录构成最长子序列的前一个索引，以便后续追踪。
2. **初始化**：
    - 将 `dp` 数组初始化为 1，因为每个单词自身可以单独形成一个子序列。
    - `prev` 数组初始化为 -1，表示没有前驱。
3. **双重循环**：
    - 使用两个嵌套循环，外层遍历每个单词 `words[i]`，内层遍历之前的单词 `words[j]`。
    - 检查以下条件：
        - `groups[i]` 和 `groups[j]` 不同。
        - `words[i]` 和 `words[j]` 长度相等。
        - `words[i]` 和 `words[j]` 的汉明距离为 1。
    - 如果满足这些条件，更新 `dp[i]` 和 `prev[i]`。
4. **寻找最大长度**： 在内层循环结束后，检查是否更新最大长度和对应的索引。
5. **反向追踪**：
    - 从最大索引开始，通过 `prev` 数组追踪到完整的子序列。
    - 由于追踪是从后往前的，因此需要反转结果数组以得到正确顺序。
```cpp
class Solution {
public:
    // 计算汉明距离为1的函数
    bool isHammingDistanceOne(const string &a, const string &b) {
        int distance = 0;
        for (size_t i = 0; i < a.size(); ++i) {
            if (a[i] != b[i]) {
                distance++;
                if (distance > 1) return false; // 超过1就返回false
            }
        }
        return distance == 1; // 只有一个不同
    }

    vector<string> getWordsInLongestSubsequence(vector<string>& words, vector<int>& groups) {
        int n = words.size();
        if (n == 0) return {};

        vector<int> dp(n, 1);         // dp[i] 表示以 words[i] 结尾的最长子序列长度
        vector<int> prev(n, -1);      // prev[i] 用于追踪最大 dp[i] 的前一索引

        int maxLength = 1;            // 最大长度
        int maxIndex = 0;             // 最大长度的索引

        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                // 检查条件
                if (groups[i] != groups[j] && words[i].size() == words[j].size() &&
                    isHammingDistanceOne(words[i], words[j])) {
                    if (dp[j] + 1 > dp[i]) {
                        dp[i] = dp[j] + 1; // 更新 dp[i]
                        prev[i] = j;       // 记录前一个索引
                    }
                }
            }
            // 更新最大长度和索引
            if (dp[i] > maxLength) {
                maxLength = dp[i];
                maxIndex = i;
            }
        }

        // 追踪最长子序列
        vector<string> result;
        for (int i = maxIndex; i != -1; i = prev[i]) {
            result.push_back(words[i]);
        }
        reverse(result.begin(), result.end()); // 反转结果

        return result;
    }
};
```


- 题目要求找到 `[0,1,...,n−1]` 中的**最长子序列**，该子序列中满足前后相邻**下标**对应的 groups 值不同，且相邻**下标**对应的 words 的汉明距离为 1。与「[最长相邻不相等子序列 I](https://leetcode.cn/problems/longest-unequal-adjacent-groups-subsequence-i/)」题目类似，我们仍可采用动态规划来解决该问题。

- 设 `dp[i]` 表示以下标 i 为结尾的**最长子序列**长度，设 `HammingDistance(s,t)` 表示两个字符 s,t 的「[**汉明距离**](https://leetcode.cn/link/?target=https%3A%2F%2Fbaike.baidu.com%2Fitem%2F%E6%B1%89%E6%98%8E%E8%B7%9D%E7%A6%BB%2F475174)」。子序列中如果下标 i 可以添加在下标 j 之后，则此时一定满足`groups[i]=groups[j],j<i` 且 `HammingDistance(words[i],words[j])=1`，此时下标 i 可以添加到下标 j 之后，此时以下标 i 为结尾的**最长子序列**长度为 `dp[i]=dp[j]+1`，我们可以得到动态规划递推公式如下：

$dp[i]=max(dp[i],dp[j]+1) if     groups[i]!=groups[j],HammingDistance(words[i],words[j])=1$

- 对于下标 i，我们可以枚举 i 之前的小标，即可求得以 i 为结尾的**最长子序列**的长度，依次求出以每个下标为结尾的**最长子序列**长度即可找到 `[0,1,...,n−1]`  中的**最长子序列**长度。为了方便计算，我们用 `prev[i]` 记载以下标 i 为结尾的**最长子序列**中 i 的上一个下标。当我们找到**最长子序列**的结尾下标 i 时，沿着 i 往前即可找到整个序列的下标，并将每个下标对应的字符串加入到数组中，对整个数组反转后的结果即为答案。



##### 优化
### 代码思路

1. **数据结构**：
    - 使用 `unordered_map<long long, pair<int, int>> f_map` 来存储每个字符串的哈希值以及它对应的最大子序列长度和索引。
    - `from` 数组用于追踪从哪个索引到达当前索引，以便后续反向构建结果。
2. **反向遍历**： 从后往前遍历 `words` 数组。这样可以确保在计算 `f` 时，所有可能的后继单词都已经被处理。
3. **哈希计算**： 对每个字符串计算一个唯一的哈希值，用于标识其字符组合。哈希值是通过将字符左移并结合位运算生成的。
4. **查找最长子序列**：
    - 对于每个字符串，遍历其所有字符位置，构造不同的哈希值（通过在哈希中添加位标志）。
    - 对于每个构造的哈希值，从 `f_map` 中查找对应的最大子序列长度 `max_f` 和索引 `j`，并检查是否可以更新当前的最长子序列长度 `f`。
5. **更新全局最大长度**： 在每次更新 `f` 后，检查是否需要更新全局最大长度 `gloal_max_f` 和对应的索引 `max_i`。
6. **记录新哈希值**： 在处理完每个字符串后，更新 `f_map` 中的哈希值和对应的最大长度与索引。
7. **构建结果**： 从 `max_i` 开始，使用 `from` 数组反向追踪，以构建最终的字符串数组 `ans`。

```cpp
    vector<string> getWordsInLongestSubsequence(vector<string>& words,
                                                vector<int>& groups) {
        int n = words.size();
        unordered_map<long long, pair<int, int>> f_map; // 哈希表
        vector<int> from(n); // 追踪前一个索引
        int gloal_max_f = 0, max_i = 0; // 全局最大长度和索引

        // 反向遍历
        for (int i = n - 1; i >= 0; --i) {
            string& w = words[i];
            int g = groups[i];
            long long hash = 0;
            // 计算字符串的哈希值
            for (char ch : w) {
                hash = (hash << 5) | (ch & 31);
            }
            int f = 0; // 当前字符串的最大长度

            // 遍历字符位置，构造哈希
            for (int k = 0; k < w.size(); ++k) {
                long long h = hash | (31LL << (k * 5));
                auto& [max_f, j] = f_map[h];
                // 选择合适的前驱
                if (max_f > f && groups[j] != g) {
                    f = max_f;
                    from[i] = j;
                }
            }
            ++f; // 更新当前字符串的长度
            // 更新全局最大值
            if (f > gloal_max_f) {
                gloal_max_f = f;
                max_i = i;
            }

            // 更新哈希表
            for (int k = 0; k < w.size(); ++k) {
                long long h = hash | (31LL << (k * 5));
                auto& [max_f, j] = f_map[h];
                if (f > max_f) {
                    max_f = f;
                    j = i;
                }
            }
        }

        // 构建结果数组
        vector<string> ans(gloal_max_f);
        int i = max_i;
        for (int k = 0; k < gloal_max_f; ++k) {
            ans[k] = words[i];
            i = from[i];
        }
        return ans;
    }
```
