[1742. 盒子中小球的最大数量](https://leetcode.cn/problems/maximum-number-of-balls-in-a-box/)

- **初始化一个数组**:
    - 创建一个数组 `boxCount` 用于统计每个盒子中小球的数量。盒子的编号最大为 `9 * d`，其中 `d` 是小球编号的位数。对于 `highLimit`，我们可以估计它的位数大约为 `log10(highLimit)`，所以最坏情况下，盒子的数量是 `9 * 6 = 54`（因为 `highLimit` 最多为 999999）。
- **遍历小球编号**:
    - 使用一个循环遍历从 `lowLimit` 到 `highLimit` 的每个小球编号。
    - 对于每个小球编号，将其转换为字符串或逐位提取数字，计算各位数字之和，得到对应的盒子编号。
- **更新盒子计数**:
    - 将小球计入对应的盒子中，更新 `boxCount` 数组。
- **找出最大值**:
    - 在 `boxCount` 数组中找到最大值，并返回该值。

```cpp
    int countBalls(int lowLimit, int highLimit) {
        std::vector<int> boxCount(55, 0); // 盒子编号范围是 1 到 54
        for (int ball = lowLimit; ball <= highLimit; ++ball) {
            int boxNumber = 0;
            int temp = ball;
            // 计算各位数字之和
            while (temp > 0) {
                boxNumber += temp % 10;
                temp /= 10;
            }
            boxCount[boxNumber]++;
        }
        // 找到最大值
        return *std::max_element(boxCount.begin(), boxCount.end());
    }
```

##### 方法一：哈希表
遍历所有的小球，对于编号为 i 的小球，计算它应该放入的盒子编号 box，使用哈希表 count 记录每个盒子中的小球数量，返回遍历结束后 count 中小球数量最大的盒子对应的小球数量即可。

```cpp
    int countBalls(int lowLimit, int highLimit) {
        unordered_map<int, int> count;
        int res = 0;
        for (int i = lowLimit; i <= highLimit; i++) {
            int box = 0, x = i;
            while (x) {
                box += x % 10;
                x /= 10;
            }
            count[box]++;
            res = max(res, count[box]);
        }
        return res;
    }
```

##### 动态规划 深度优先搜索DFS

1. **数字和的上界**:
    - 首先，计算 `highLimit` 的数字个数 `n`，并确定数字和的上界 `m`。这个上界是通过 `high_s[0] - '0' + (n - 1) * 9` 得到的，表示在最高位取最大值 9 时，其他位也为 9 的情况下的最大数字和。
2. **字符串处理**:
    - 将 `lowLimit` 和 `highLimit` 转换为字符串，并通过在 `lowLimit` 前面补零来使其与 `highLimit` 对齐，以便于逐位比较。
3. **记忆化搜索**:
    - 使用一个二维数组 `memo` 来记录已经计算过的状态，避免重复计算。
    - 定义一个 DFS 函数，该函数接受当前位索引 `i`、当前数字和 `j` 以及两个布尔值 `limit_low` 和 `limit_high`，分别表示是否受限于 `lowLimit` 和 `highLimit`。
4. **递归条件**:
    - 当到达字符串的末尾时，如果当前数字和 `j` 为 0，则说明成功找到一种组合。
    - 根据 `limit_low` 和 `limit_high` 确定当前位可以填的数字范围。
5. **枚举当前位的数字**:
    - 对于当前位，枚举可以填入的数字 `d`，并递归调用 DFS 进行下一位的计算。
    - 如果不受低限和高限的限制，则将结果存入 `memo` 中以便后续使用。
6. **统计最大值**:
    - 外层循环遍历所有可能的数字和 `j`（从 1 到 `m`），并采用 DFS 计算能形成的有效数字组合的数量，最终返回最大的组合数。

##### 复杂度分析

- **时间复杂度**: 主要取决于 DFS 的状态数和每个状态的计算，通常是 O(n * m)，其中 n 是数字位数，m 是数字和的上界。
- **空间复杂度**: O(n * m)，用于存储 `memo` 数组。

```cpp
    int countBalls(int lowLimit, int highLimit) {
        string high_s = to_string(highLimit);
        int n = high_s.size();
        string low_s = to_string(lowLimit);
        low_s = string(n - low_s.size(), '0') + low_s; // 补前导零，和 high_s 对齐

        int m = high_s[0] - '0' + (n - 1) * 9; // 数位和的上界
        vector memo(n, vector<int>(m + 1, -1)); // -1 表示没有计算过

        auto dfs = [&](this auto&& dfs, int i, int j, bool limit_low, bool limit_high) -> int {
            if (i == n) { // 填完了
                return j == 0;
            }
            if (!limit_low && !limit_high && memo[i][j] != -1) { // 之前计算过
                return memo[i][j];
            }

            int lo = limit_low ? low_s[i] - '0' : 0;
            int hi = limit_high ? high_s[i] - '0' : 9;

            int res = 0;
            for (int d = lo; d <= min(hi, j); d++) { // 枚举当前数位填 d，但不能超过 j
                res += dfs(i + 1, j - d, limit_low && d == lo, limit_high && d == hi);
            }

            if (!limit_low && !limit_high) {
                memo[i][j] = res; // 记忆化
            }
            return res;
        };

        int ans = 0;
        for (int j = 1; j <= m; j++) {
            ans = max(ans, dfs(0, j, true, true));
        }
        return ans;
    }
```
