- **使用栈存储数字**：通过两个栈 `num1` 和 `num2` 将两个链表中的数字压入栈中。这样可以逆序访问链表中的数字，便于从最低位开始相加。
- **初始化结果链表**：创建一个指针 `ansHead` 初始化为 `nullptr`，用于构建结果链表。同时，初始化一个 `carry` 变量用于处理进位。
- **进行加法运算**：
    - 使用 `while` 循环，直到两个栈都为空且没有进位。
    - 从栈中弹出顶部的数字并累加到 `sum` 中，如果栈不为空。
    - 计算当前位的值和进位：`carry = sum / 10`，当前节点的值为 `sum % 10`。
    - 创建新节点并将其插入到结果链表的头部。
- **返回结果链表**：最后返回构建好的结果链表的头节点 `ansHead`。
```cpp
    ListNode* addInList(ListNode* head1, ListNode* head2) {
        // write code here
        std::stack<int> num1, num2;
 
        // 将链表的数字压入栈中
        while (head1) {
            num1.push(head1->val);
            head1 = head1->next;
        }
        while (head2) {
            num2.push(head2->val);
            head2 = head2->next;
        }
 
        ListNode* ansHead = nullptr;
        int carry = 0;
 
        // 开始进行加法运算
        while (!num1.empty() || !num2.empty() || carry) {
            int sum = carry;
            if (!num1.empty()) {
                sum += num1.top();
                num1.pop();
            }
            if (!num2.empty()) {
                sum += num2.top();
                num2.pop();
            }
 
            // 计算进位和当前位的值
            carry = sum / 10;
            ListNode* newNode = new ListNode(sum % 10);
            newNode->next = ansHead;  // 新节点指向当前结果链表头
            ansHead = newNode;        // 更新结果链表头
        }
 
        return ansHead;  // 返回结果链表头
    }
```
