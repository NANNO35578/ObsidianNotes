[3270. 求出数字答案](https://leetcode.cn/problems/find-the-key-of-the-numbers/)
- **输入处理**：程序首先接收三个正整数。
- **字符串转换与补齐**：将每个整数转换为字符串，并使用前导零补齐到四位。
- **计算最小值**：逐位比较三个数字的每位，取最小值。
- **去除前导零**：通过转换为整数再转换回字符串的方式去除前导零。
- **输出结果**：打印最终结果。

```cpp
int getKey(int num1, int num2, int num3) {
    // 将数字转换为字符串，补齐至四位数
    std::vector<std::string> nums = {
        std::to_string(num1),
        std::to_string(num2),
        std::to_string(num3)
    };

    for (auto& num : nums) {
        num = std::string(4 - num.length(), '0') + num; // 补齐前导0
    }

    std::string key;
    for (int i = 0; i < 4; ++i) {
        // 找到每个数位的最小值
        char minDigit = std::min({nums[0][i], nums[1][i], nums[2][i]});
        key += minDigit;
    }

    // 返回去除前导0的整数
    return std::stoi(key);
}


```

- 我们可以从低到高枚举三个数的数位，三者的最小值就是答案 key 对应数位上的值。无需补充前导 0，因为当某个数在当前枚举的数位上没有值时，后续数位的最小值都为 0，对于答案 key 就是需要删去的前导 0。

```cpp
    int generateKey(int num1, int num2, int num3) {
        int key = 0;
        for (int p = 1; num1 && num2 && num3; p *= 10) {
            key += min({num1 % 10, num2 % 10, num3 % 10}) * p;
            num1 /= 10;
            num2 /= 10;
            num3 /= 10;
        }
        return key;
    }
```
