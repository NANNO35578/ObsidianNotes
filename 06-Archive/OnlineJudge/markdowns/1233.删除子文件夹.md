[1233. 删除子文件夹](https://leetcode.cn/problems/remove-sub-folders-from-the-filesystem/)

- **排序文件夹**：首先对文件夹进行排序，这样可以确保子文件夹总是在其父文件夹之后
- **使用集合存储有效文件夹**：创建一个集合来存储剩下的文件夹，以便快速查找
- **遍历文件夹列表**：逐个检查文件夹，判断当前文件夹是否是前一个文件夹的子文件夹。如果是，则跳过；如果不是，则将其添加到集合中

```cpp
vector<string> removeSubfolders(vector<string>& folder) {
    std::sort(folder.begin(), folder.end());
    
    std::set<string> result;
    
    for (const std::string& f : folder) {
        // Check if the current folder is a subfolder of any folder already in the result
        if (result.empty() || f.find(*result.rbegin() + "/") != 0) {
            result.insert(f);
        }
    }
    
    return std::vector<string>(result.begin(), result.end());
}
```

##### `Tire`
- **Trie 数据结构**： `Trie` 结构体包含一个 `unordered_map` 来存储子节点，以及一个 `int ref` 用于指向文件夹的索引（如果该节点代表一个文件夹的话）
- **构造函数**： `Trie()` 初始化 `ref` 为 -1，表示该节点不是文件夹的终点
- **文件夹路径分割**： 使用 `split` 函数将文件夹路径按 `/` 分割成多个部分，返回一个字符串向量
- **构建 Trie**：
    - 遍历文件夹列表，对于每个文件夹路径，使用 `split` 函数分割路径。
    - 在 Trie 中插入每个部分，如果当前节点没有该子节点，则创建一个新的 Trie 节点。
    - 当路径的最后一部分插入完成时，将 `cur->ref` 设置为当前文件夹在原始列表中的索引。
- **深度优先搜索 (DFS)**：
    - 定义一个递归函数 `dfs`，用于遍历 Trie
    - 如果当前节点的 `ref` 不为 -1，说明该节点代表一个有效的文件夹，加入到答案 `ans` 中
    - 遍历所有子节点，递归调用 `dfs`

```cpp
struct Trie {
    Trie() : ref(-1) {}
    unordered_map<string, Trie*> children;
    int ref;
};

class Solution {
public:
    vector<string> removeSubfolders(vector<string>& folder) {
        // Helper function to split the folder path
        auto split = [](const string& s) -> vector<string> {
            vector<string> ret;
            string cur;
            for (char ch : s) {
                if (ch == '/') {
                    ret.push_back(move(cur));
                    cur.clear();
                } else {
                    cur.push_back(ch);
                }
            }
            ret.push_back(move(cur));
            return ret;
        };

        Trie* root = new Trie();
        
        // Build the Trie from folder paths
        for (int i = 0; i < folder.size(); ++i) {
            vector<string> path = split(folder[i]);
            Trie* cur = root;
            for (const string& name : path) {
                if (!cur->children.count(name)) {
                    cur->children[name] = new Trie();
                }
                cur = cur->children[name];
            }
            cur->ref = i; // Mark the end of the folder path
        }

        vector<string> ans;

        // Depth-first search to collect valid folders
        function<void(Trie*)> dfs = [&](Trie* cur) {
            if (cur->ref != -1) {
                ans.push_back(folder[cur->ref]);
                return;
            }
            for (auto&& [_, child] : cur->children) {
                dfs(child);
            }
        };

        dfs(root);
        return ans;
    }
};
```

##### 哈希优化


- **排序**： 使用 `std::sort` 按照文件夹路径的长度进行排序，确保父文件夹在子文件夹之前
- **哈希集合**： `std::unordered_set<ULL> alls;` 用于存储文件夹路径的哈希值，帮助快速查找
- **遍历和哈希计算**： 对于每个文件夹 `s`，计算其哈希值：
        - 初始化哈希值为路径的第一个字符
        - 遍历路径的每个字符，并使用多项式哈希公式更新哈希值
        - 在遍历过程中，检查当前字符是否为路径的最后一个字符或是 `/`，如果是，则检查这个哈希值是否已经存在于 `alls` 中
        - 如果哈希值存在，说明该路径是某个已存在路径的子文件夹，标记 `flag` 为 `false`
- **存储有效路径**： 如果 `flag` 仍为 `true`，说明当前路径不是子文件夹，将其哈希值存入集合 `alls`，并将路径加入结果 `res` 中

```cpp
class Solution {
public:
    vector<string> removeSubfolders(vector<string>& folder) {
        // 增加对空输入的处理
        if (folder.empty()) {
            return {};
        }

        // --- 改进1: 双哈希，提升稳健性 ---
        using ULL = unsigned long long;
        const int P1 = 911, P2 = 131; // 使用两个不同的质数

        // 按字符串长度从小到大排序
        sort(folder.begin(), folder.end(), [](const string& a, const string& b) {
            return a.size() < b.size();
        });

        // 存储根目录的哈希对
        unordered_set<ULL> rootFolderHashes;
        vector<string> rootFolders;

        for (const string& path : folder) {
            bool isSubfolder = false;
            ULL hash1 = 0, hash2 = 0;

            // --- 改进2: 简化核心逻辑，只检查真前缀 ---
            // 循环只检查到倒数第二个字符，因为父路径必然以'/'结尾
            for (int i = 0; i < path.size() - 1; ++i) {
                hash1 = hash1 * P1 + path[i];
                hash2 = hash2 * P2 + path[i];

                // 如果下一个字符是'/'，说明形成了一个父路径，进行检查
                if (path[i + 1] == '/') {
                    // 将两个哈希值合并成一个，存入集合
                    ULL combinedHash = (hash1 << 32) | hash2;
                    if (rootFolderHashes.count(combinedHash)) {
                        isSubfolder = true;
                        break;
                    }
                }
            }

            // 如果遍历完所有父路径都不是子文件夹
            if (!isSubfolder) {
                // 计算当前路径完整的哈希值
                ULL fullHash1 = 0, fullHash2 = 0;
                for(char c : path) {
                    fullHash1 = fullHash1 * P1 + c;
                    fullHash2 = fullHash2 * P2 + c;
                }
                
                ULL fullCombinedHash = (fullHash1 << 32) | fullHash2;
                rootFolderHashes.insert(fullCombinedHash);
                rootFolders.push_back(path);
            }
        }
        return rootFolders;
    }
};
```
