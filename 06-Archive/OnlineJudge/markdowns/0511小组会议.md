##### C++深浅拷贝
1. **深拷贝 (Deep Copy)**：深拷贝复制对象及其所指向的所有数据，确保每个对象都有独立的内存空间。
- **特点**：
    - 每个对象有自己的内存，互不影响。
    - 适用于复杂数据类型，尤其是动态分配的内存。
2. **浅拷贝 (Shallow Copy)**：浅拷贝只复制对象的字段值，对于指针类型的成员，复制的是指针本身的地址。
- **特点**：
    - 多个对象指向同一块内存。
    - 对其中一个对象的修改可能影响到其他对象。
    - 适用于存储简单数据类型。

##### 构造函数为什么不能是虚函数
1. **构造过程** :  当一个对象被创建时，构造函数负责初始化对象的状态。如果构造函数是虚的，调用哪个构造函数的决定是在运行时进行的，这与对象的创建过程相悖。
2. **对象的类型** :  在调用构造函数时，派生类的构造函数还未完成，因此无法确定对象的完整类型。虚函数的机制依赖于对象的动态类型，但在构造过程中，只有静态类型可用。
3. **性能和复杂性** :  如果构造函数是虚的，系统需要额外的开销来管理虚函数表（vtable），这会增加构造时间和复杂性。
4. **设计意图** :  构造函数的设计目的是为了初始化对象，而虚函数通常用于实现多态性。将这两者结合起来会导致设计上的混乱，降低代码的可读性和可维护性。
---

##### 哪些函数不能声明为虚函数 
1. **构造函数** :  构造函数用于初始化对象，不能是虚函数，因为在对象创建时，动态类型尚未确定。
2. **析构函数（在某些情况下）** :  虽然析构函数可以是虚函数，但在基类中应该声明为虚的，以确保派生类的析构函数被正确调用。
3. **静态成员函数** :  静态成员函数属于类而不是类的实例，无法使用虚函数机制。
4. **友元函数** :  友元函数不是类的成员，不能声明为虚函数。
5. **常量成员函数和非常量成员函数** :  虚函数可以是常量或非常量的，但不能将同一个函数同时声明为虚和常量。
6. **模板函数** :  虽然模板函数可以是虚的，但特化的版本不能直接声明为虚函数。需要在类中进行虚函数的声明。

##### 迭代器何时会失效
1. **容器修改** :  
	- **插入操作**：在某些容器（如 `std::vector`）中，插入元素可能导致重新分配内存，从而使所有现有迭代器失效。
	- **删除操作**：删除元素会使指向被删除元素的迭代器失效。对于某些容器，删除操作可能使后续元素的迭代器也失效。
	- **清空容器**：调用 `clear()` 函数会使所有迭代器失效。
 2. **容器类型** :  
	- **`std::vector`** 和 **`std::deque`**：在插入或删除元素时，迭代器可能失效。
	- **`std::list`**：插入和删除操作一般不使迭代器失效，但如果迭代器指向被删除的节点，则会失效。
	- **`std::map`** 和 **`std::set`**：插入和删除操作不会使其他迭代器失效，但指向被删除元素的迭代器会失效。
 3. **范围变化** :  如果在迭代过程中，容器的大小发生变化（例如，添加或删除元素），则所有指向容器的迭代器可能失效。
 4. **使用无效迭代器** :  如果迭代器已失效，再次使用它会导致未定义行为。

##### C++中的`auto`和`decltype`
### `auto`
- **用途**：`auto`用于自动推导变量的类型。
- **特点**：
    - 在声明变量时，根据初始化表达式的类型自动决定变量的类型。
    - 需要在声明时初始化。
- **示例**：
    ```cpp
    auto x = 10;          // x 的类型为 int
    auto y = 3.14;       // y 的类型为 double
    auto str = "Hello";  // str 的类型为 const char*
    ```
### `decltype`
- **用途**：`decltype`用于获取表达式的类型。
- **特点**：
    - 不需要初始化，可以用于获取任何表达式的类型。
    - 可以用于复杂的类型推导，包括函数返回类型和类型别名。
- **示例**：
    ```cpp
    int a = 5;
    decltype(a) b = 10; // b 的类型为 int
    
    decltype(a + 1.0) c = 3.14; // c 的类型为 double
    ```
### 主要区别

|特性|`auto`|`decltype`|
|---|---|---|
|用途|类型推导|获取表达式类型|
|初始化要求|必须初始化|不需要初始化|
|适用范围|用于变量声明|用于任何表达式|

##### `decltype` 是 C++11 引入的一个关键字，用于获取一个表达式的类型。它在类型推导和模板编程中非常有用。以下是 `decltype` 的详细介绍：
```cpp
decltype(expression)
```
- **expression**：可以是任意有效的 C++ 表达式。
### 特性
1. **类型推导**：
    - `decltype` 根据给定的表达式推导出相应的类型，而不需要对表达式进行求值。
2. **不要求初始化**：
    - 使用 `decltype` 不需要初始化，可以用于任何有效的表达式。

### 示例

#### 基本示例

```cpp
int a = 5;
decltype(a) b = 10; // b 的类型为 int

double c = 3.14;
decltype(c) d = 2.71; // d 的类型为 double
```

#### 表达式的类型

```cpp
int x = 10;
double y = 5.5;

decltype(x + y) result = x + y; // result 的类型为 double
```

#### 引用类型

`decltype` 也能正确处理引用类型：

```cpp
int a = 5;
int& ref = a;

decltype(ref) another_ref = a; // another_ref 的类型为 int&
```

### 复杂使用场景

#### 结合 `auto`

`decltype` 可以与 `auto` 结合使用，以实现更复杂的类型推导：

```cpp
#include <vector>
#include <iostream>

std::vector<int> vec = {1, 2, 3};

// 使用 decltype 获取迭代器类型
decltype(vec.begin()) it = vec.begin();

int main() {
    std::cout << *it << std::endl; // 输出 1
    return 0;
}
```

#### 函数返回类型

可以使用 `decltype` 来推导函数的返回类型：

```cpp
auto add(int a, int b) -> decltype(a + b) {
    return a + b; // 返回类型为 int
}
```

### 特殊情况

1. **左值与右值**：
    
    - 如果表达式是一个左值，`decltype` 返回的是左值引用类型。
    - 如果是右值，则返回的是值类型。
2. **表达式为 `void`**：
    
    - 如果表达式的类型为 `void`，则 `decltype` 会返回 `void`。
