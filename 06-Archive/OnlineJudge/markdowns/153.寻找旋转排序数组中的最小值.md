[153. 寻找旋转排序数组中的最小值](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)

- 容易证明，左侧有序序列最小值大于右侧有序序列最大值
![['attachments/153.png]]
```cpp
    int findMin(vector<int>& nums) {
        int l = 0, r = nums.size() - 1, mid;
        while (l < r) { // 修改为 l < r
            mid = l + (r - l) / 2;
            if (nums[mid] > nums[r]) {   // 如果中间元素大于右边元素，最小值在右半部分
                l = mid + 1; // 更新左边界
            } else { // 如果中间元素小于或等于右边元素，最小值在左半部分或中间
                r = mid; // 更新右边界
            }
        }
        return nums[l]; // 返回左边界的值
    }
```
