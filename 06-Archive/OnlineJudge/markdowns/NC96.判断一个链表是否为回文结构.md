[判断一个链表是否为回文结构](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457455756)
- **使用快慢指针找到中间点**：
    - 初始化两个指针：`pSlow`（慢指针）和 `pFast`（快指针），都指向链表的头部。
    - 使用 `while` 循环遍历链表，快指针每次走两步，慢指针每次走一步。
    - 在每次迭代中，将慢指针的值压入栈 `half`，以便后续比较。
- **确定中间节点**：
    - 当快指针到达链表末尾时，检查慢指针的位置。
    - 如果链表长度为奇数，弹出栈顶元素（中间节点的值），然后将慢指针移动到下一个节点；如果长度为偶数，直接将慢指针移动到下一个节点。
- **比较后半部分与栈中的前半部分**：
    - 使用 `while` 循环遍历后半部分链表，逐个比较节点的值与栈顶部的值。
    - 如果有任何不匹配，返回 `false`。
```cpp
    bool isPail(ListNode* head) {
        // write code here
        // 快慢指针找到中间点
        if (head == nullptr || head->next == nullptr) return true;
        if (head->next->next == nullptr) {
            return head->val == head->next->val;
        }
 
        stack<int> half;
        ListNode* pSlow = head;
        ListNode* pFast = head;
        ListNode* pMid = nullptr;
        while (pFast != nullptr) {
            half.push(pSlow->val);
            if (pFast->next == nullptr) {
                pMid = pSlow;
                break;
            } else if (pFast->next->next == nullptr) {
                break;
            }
 
            pFast = pFast->next->next;
            pSlow = pSlow->next;
        }
        if (pMid) {
            half.pop();
            pMid = pMid->next;
        } else {
            pMid = pSlow->next;
        }
        while (pMid != nullptr) {
            if (pMid->val != half.top()) return false;
            pMid = pMid->next;
            half.pop();
        }
        return true;
    }
```
