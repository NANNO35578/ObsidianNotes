[2145.统计隐藏数组数目](https://leetcode.cn/problems/count-the-hidden-sequences/)

- **计算隐藏数组的可能范围**：
    - 从 `differences` 数组中推导出隐藏数组的值。我们从第一个元素开始，逐步累加 `differences`，记录当前的和（即隐藏数组的元素）。
    - 同时，维护当前的最小值和最大值。
- **确定有效范围**：
    - 计算出隐藏数组的最小值和最大值后，我们需要判断这些值是否在给定的 `lower` 和 `upper` 范围内。
    - 具体来说，我们需要检查以下两个条件：
        - 最小值 (`min_value`) 应该大于等于 `lower`。
        - 最大值 (`max_value`) 应该小于等于 `upper`。
- **计算符合条件的隐藏数组数目**：
    - 如果有效范围存在（即 `min_value` 和 `max_value` 都在 `lower` 和 `upper` 之间），则计算符合条件的数目。
    - 符合条件的数目可以通过 `(max_value - min_value + 1)` 来计算。

```cpp
int countValidHiddenArrays(vector<int>& differences, int lower, int upper) {
    long long min_value = 0, max_value = 0, current_sum = 0;

    for (int diff : differences) {
        current_sum += diff;
        min_value = min(min_value, current_sum);
        max_value = max(max_value, current_sum);
    }

    // Calculate the valid range
    long long valid_min = lower - min_value;
    long long valid_max = upper - max_value;

    // Count the number of valid starting points
    if (valid_min > valid_max) {
        return 0; // No valid hidden arrays
    }

    return valid_max - valid_min + 1; // Number of valid starting points
}
```

 - 记最终的数组为 $a_0​,a_1​,⋯,a_n​$。我们可以发现，如果数组 a 满足要求，那么：`a0​+k,a1​+k,⋯,an​+k`也一定满足要求。这里的「要求」指的是相邻元素的差值对应着给定的数组 differences。因此我们就可以任意指定 $a_0​$，为了方便不妨直接令 $a_0​=0$ 我们就可以还原出数组 $a_0​,a_1​,⋯,a_n$​ 了 如果我们继续考虑数组元素都在 `[lower,upper]` 范围内的要求，不妨记数组中最小的元素为 $a_i$  ，最大的元素为 $a_j$ ，显然需要满足$lower≤ai​≤aj​≤upper$ 
 - 那么$a_i$ 的取值下界即为$lower$,上界为$upper-(a_j-a_i)$,即需要保证最大值$a_j$不能超过 $upper$。这里的aj-ai实际上与ai,aj本身的值无关,它就等于: $k=\sum_i(j−1​) differences[k]$
 - 因此符合要求的隐藏数组的数目即为 $upper-(a_j-a_i)-lower+1$,整理可得:$(upper- lower)-(a_j-a_i)+1$

 - 实际上就是规定的数组元素的区间长度,减去数组元素最大值与最小值的差值,再加上1。我们可以将其看成是一个长度为$a_j-a_i$的小窗口在长度为$upper-lower$的大窗口中滑动时,能够放置的位置数量。

细节

 - 在还原数组a的过程中,我们无需记录整个数组,而是只需要记录最大值和最小值即可。如果某一时刻最大值与最小值的差值大于 $upper-lower$,我们可以直接返回0。

```cpp
class Solution {
public:
    int numberOfArrays(vector<int>& differences, int lower, int upper) {
        int x = 0, y = 0, cur = 0;
        for (int d: differences) {
            cur += d;
            x = min(x, cur);
            y = max(y, cur);
            if (y - x > upper - lower) {
                return 0;
            }
        }
        return (upper - lower) - (y - x) + 1;
    }
};
```
