[169. 多数元素](https://leetcode.cn/problems/majority-element/)

##### 抵消法 (Boyer-Moore 投票算法)
- 由于多数元素占比一半以上，可以完全抵消掉非多数元素，最终剩余的一定是多数元素
- 初始化一个计数器 `count` 和一个候选元素 `candidate`。
- 遍历数组中的每个元素：
    - 如果 `count` 为 0，更新 `candidate` 为当前元素，并将 `count` 设置为 1。
    - 如果当前元素等于 `candidate`，则将 `count` 加 1。
    - 如果当前元素不等于 `candidate`，则将 `count` 减 1。
- 由于数组中一定存在多数元素，最终 `candidate` 将是我们要找的元素。

```cpp
int majorityElement(vector<int>& nums) {
    int count = 0;
    int candidate = 0;
    
    for (int num : nums) {
        if (count == 0) {
            candidate = num;
            count = 1;
        } else if (num == candidate) {
            count++;
        } else {
            count--;
        }
    }
    
    return candidate;
}
```

##### 哈希表
- 将数组中的每个元素加入哈希映射中
- 遍历哈希映射中的所有键值对，返回值最大的键
- 在遍历数组 `nums` 时候使用打擂台的方法，维护最大的值，可省去了最后对哈希映射的遍历

```cpp
    int majorityElement(vector<int>& nums) {
        unordered_map<int, int> counts;
        int majority = 0, cnt = 0;
        for (int num: nums) {
            ++counts[num];
            if (counts[num] > cnt) {
                majority = num;
                cnt = counts[num];
            }
        }
        return majority;
    }
```

##### 排序
- 如果将数组 `nums` 中的所有元素按照单调递增或单调递减的顺序排序，那么下标为 ⌊2n​⌋ 的元素（下标从 `0` 开始）一定是众数

```cpp
    int majorityElement(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        return nums[nums.size() / 2];
    }
```

##### 随机化

**思路** : 因为超过 ⌊$n/2$​⌋ 的数组下标被众数占据了，这样我们随机挑选一个下标对应的元素并验证，有很大的概率能找到众数。
- 由于一个给定的下标对应的数字很有可能是众数，我们随机挑选一个下标，检查它是否是众数，如果是就返回，否则继续随机挑选。
```cpp
    int majorityElement(vector<int>& nums) {
        while (true) {
            int candidate = nums[rand() % nums.size()];
            int count = 0;
            for (int num : nums)
                if (num == candidate)
                    ++count;
            if (count > nums.size() / 2)
                return candidate;
        }
        return -1;
    }
```
