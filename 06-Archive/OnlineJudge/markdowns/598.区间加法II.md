[598. 区间加法 II](https://leetcode.cn/problems/range-addition-ii/)
- **初始条件**：
    
    - 矩阵的大小为 `m x n`，初始时所有元素都可以被视为 `0`。
- **操作的影响**：
    
    - `ops` 是一个二维数组，表示对矩阵的增量操作，每个元素 `ops[i]` 是一个长度为 `2` 的数组 `[a, b]`，表示对矩阵左上角为 `(1, 1)` 到 `(a, b)` 的区域进行增量操作。
- **寻找最小边界**：
    
    - 通过遍历 `ops` 中的每个操作，找到所有操作的最小 `a` 和最小 `b` 值。
    - 这两个值代表了最终能够被所有操作影响的矩阵区域的右下角。
- **计算结果**：
    
    - 矩阵中被影响的区域的大小即为 `minX * minY`，其中 `minX` 和 `minY` 分别是所有操作中 `a` 和 `b` 的最小值。
    - 如果没有任何操作（`ops` 为空），则整个矩阵 `m * n` 都是有效的。
```cpp
    int maxCount(int m, int n, vector<vector<int>>& ops) {
        if(ops.empty())return m*n;
        int minX = 40001;
        int minY = 40001;
        for(vector<int>& xy:ops){
            minX=min(minX,xy[0]);
            minY=min(minY,xy[1]);
        }
        return minX * minY;
    }
```
