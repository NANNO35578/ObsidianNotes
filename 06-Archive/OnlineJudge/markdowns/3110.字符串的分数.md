[3110. 字符串的分数](https://leetcode.cn/problems/score-of-a-string/)
- 模拟
```cpp
    int scoreOfString(string s) {
	    int score = 0;
	    // 计算相邻字符的 ASCII 差值绝对值的和
	    for (size_t i = 1; i < s.length(); ++i) {
	        score += abs(static_cast<int>(s[i]) - static_cast<int>(s[i - 1]));
	    }
	    return score;
    }
```
