[1007. 行相等的最少多米诺旋转](https://leetcode.cn/problems/minimum-domino-rotations-for-equal-row/)

### 问题理解

我们需要使一个多米诺骨牌的上半部分 `tops` 或下半部分 `bottoms` 中的所有值相同。可以通过旋转多米诺骨牌来实现这一点，旋转后，上半部分和下半部分的值会交换。我们的目标是找到最小的旋转次数，或者在无法实现时返回 -1。

### 代码思路

1. **确定目标值**：
    - 由于我们只能选择 `tops` 或 `bottoms` 中的数字作为目标值，因此我们考虑 `tops[0]` 和 `bottoms[0]` 这两个数字。我们将这两个数字作为可能的目标值进行检查。
2. **初始化变量**：
    - 对于每一个目标值，我们需要两个计数器：
        - `rotationsTop`：记录为了使所有的上半部分变为目标值所需的旋转次数。
        - `rotationsBottom`：记录为了使所有的下半部分变为目标值所需的旋转次数。
3. **遍历多米诺骨牌**：
    - 对于每一个多米诺骨牌：
        - 检查当前多米诺的上半部分 `tops[i]` 和下半部分 `bottoms[i]` 是否能与目标值匹配。
        - 如果两者都无法匹配，则当前目标值无效，跳出循环。
        - 如果 `tops[i]` 不能匹配目标值，则增加 `rotationsTop`。
        - 如果 `bottoms[i]` 不能匹配目标值，则增加 `rotationsBottom`。
4. **有效性检查**：
    - 如果在遍历过程中发现无法将所有多米诺牌的上半部分或下半部分转换为目标值，标记为无效，跳出当前目标值的检查。
5. **返回最小旋转次数**：
    - 如果某个目标值有效，返回 `rotationsTop` 和 `rotationsBottom` 中的较小值，表示所需的最小旋转次数。
    - 如果两个目标值都无法实现，返回 -1。

```cpp
    int minDominoRotations(vector<int>& tops, vector<int>& bottoms) {
        int n = tops.size();
        
        // 计算可能的目标值
        for (int target : {tops[0], bottoms[0]}) {
            int rotationsTop = 0, rotationsBottom = 0;
            bool valid = true;

            for (int i = 0; i < n; ++i) {
                if (tops[i] != target && bottoms[i] != target) {
                    valid = false;
                    break;
                }
                if (tops[i] != target) {
                    ++rotationsTop; // 需要旋转 tops
                }
                if (bottoms[i] != target) {
                    ++rotationsBottom; // 需要旋转 bottoms
                }
            }

            if (valid) {
                return min(rotationsTop, rotationsBottom);
            }
        }
        
        return -1; // 如果没有找到有效的目标值
    }
```

#### 方法一：贪心

**分析**

我们随便选其中的一个多米诺骨牌，它的标号为 `i`，上半部分的数字为 `A[i]`，下半部分的数字为 `B[i]`。

![bla](https://pic.leetcode-cn.com/Figures/1007/config.png)

此时可能会有三种情况：

1. 以数字 `A[i]` 作为基准，将 `A` 或 `B` 中的所有值都变为 `A[i]`。例如，下图中，我们选择了第 0 个多米诺骨牌，这样可以将 `A` 中的所有值都变为 2。

![bla](https://pic.leetcode-cn.com/Figures/1007/s1.png)

2. 以数字 `B[i]` 作为基准，将 `A` 或 `B` 中的所有值都变为 `B[i]`。例如，下图中，我们选择了第 1 个多米诺骨牌，这样可以将 `B` 中的所有值都变为 2。

![bla](https://pic.leetcode-cn.com/Figures/1007/s2.png)

3. 无论选择 `A[i]` 还是 `B[i]` 都没有办法将 `A` 或 `B` 中的所有值变为都相同。例如，下图中，我们选择了最后一个多米诺骨牌，无论是它的上半部分 5 还是下半部分 4，都无法满足条件。

![bla](https://pic.leetcode-cn.com/Figures/1007/s3.png)

如果要满足第 1 种或是第 2 种情况，就必须存在一块多米诺骨牌，它的上半部分或者下半部分的数字 `x` 在所有其它的多米诺骨牌中都出现过。若该条件满足，则说明所有多米诺骨牌中都出现了数字 `x`。因此，我们只要选择任意一块多米诺骨牌，判断它的上半部分或下半部分的数字是否可以作为 `x` 即可。

**算法**

- 选择第一块多米诺骨牌，它包含两个数字 `A[0]` 和 `B[0]`；
    
- 检查其余的多米诺骨牌中是否出现过 `A[0]`。如果都出现过，则求出最少的翻转次数，其为将 `A[0]` 全部翻到 `A` 和全部翻到 `B` 中的较少的次数。
    
- 检查其余的多米诺骨牌中是否出现过 `B[0]`。如果都出现过，则求出最少的翻转次数，其为将 `B[0]` 全部翻到 `A` 和全部翻到 `B` 中的较少的次数。
    
- 如果上述两次检查都失败，则返回 `-1`。

```cpp
    int check(int x, vector<int>& A, vector<int>& B, int n) {
        int rotations_a = 0, rotations_b = 0;
        for (int i = 0; i < n; i++) {
            // rotations coudn't be done
            if (A[i] != x && B[i] != x) return -1;
            // A[i] != x and B[i] == x
            else if (A[i] != x) rotations_a++;
            // A[i] == x and B[i] != x    
            else if (B[i] != x) rotations_b++;
        }
        // min number of rotations to have all
        // elements equal to x in A or B
        return min(rotations_a, rotations_b);
    }

    int minDominoRotations(vector<int>& A, vector<int>& B) {
        int n = A.size();
        int rotations = check(A[0], B, A, n);
        // If one could make all elements in A or B equal to A[0]
        if (rotations != -1 || A[0] == B[0]) return rotations;
        // If one could make all elements in A or B equal to B[0]
        else return check(B[0], B, A, n);
    }

```
