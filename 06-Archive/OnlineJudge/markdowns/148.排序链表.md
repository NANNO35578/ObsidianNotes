
[148. 排序链表](https://leetcode.cn/problems/sort-list/) 

题目要求时间复杂度$O(nlog_2(n))$ 空间复杂度为常数级别


*链表对比与数组* : 优点是在中间节点增删快, 空间不连续
 若采用插入排序, 遍历数组需要$O(n)$ 时间复杂度, 再优化查找时采用二分, 时间复杂度才够用
 但链表不能随机访问, 传统二分不能实现, 有没有能优化到的地方呢, 考虑存储有序部分中间点的值
 这时, 插入时寻找节点可优化到$O(n/2)$ 但依然是$O(n^2)$ 
实际上
- 对于单向链表, 我们无法进行随机访问, 或者说在空间复杂度为常数的情况下找到前一个元素. 
- 因此, 采用寻找前一个元素的排序算法不能使用: 快排, 堆排. 
- 对于数据范围有要求的不能使用: 桶排, 计数排序. 
- 选择, 插入, 冒泡可以排, 但时间复杂度为$O(n^2)$ 可以考虑优化
- 而*归并* 刚好符合要求为$O(nlog_2(n))$ 时间复杂度


----

##### 归并排序链表思路

- 归并就是递归合并, 合并两个有序链表
- 首先递归, 我们要将链表分为大致等长的两部分, 这时我们可以考虑使用*快慢指针*来找到中间点
1. 假设我们的递归参数为start 与end. 
2. 有slow 指针一次走一步, fast指针一次走两步, 当fast指针走到链表末尾时, slow就是大致终点
3. 然后将链表分为$[start,slow]$ 与$[slow,end]$ 两部分, 继续当前操作. 即进行递归
	- 递归结束条件为`start->next==end`, 此时我们将start的next节点设置为nullptr 然后递归结束
4. 最底层递归结束就进行合并操作, 由底向上
- 最终就从最底层左右链表长度为1依次合并为长度为n的链表了

```cpp
    ListNode* merge(ListNode* left, ListNode* right) {
        if (left == nullptr) {
            return left;
        }
        if (left->next == right) {
            left->next = nullptr;
            return left;
        }
        ListNode* fast = left;
        ListNode* slow = left;

        while (fast != right) {
            slow = slow->next;
            fast = fast->next;
            if (fast != right) {
                fast = fast->next;
            }
        }

        return mergeTwoList(merge(left, slow), merge(slow, right));
    }

    ListNode* sortList(ListNode* head) { return merge(head, nullptr); }

    ListNode* mergeTwoList(ListNode* list1, ListNode* list2) {
        if (list1 == nullptr)
            return list2;
        if (list2 == nullptr)
            return list1;

        ListNode a = ListNode(-999);
        ListNode* dummy = &a;

        ListNode* point = nullptr;
        if (list1->val < list2->val) {
            dummy->next = list1;
            point = list1;
            list1 = list1->next;
        } else {
            dummy->next = list2;
            point = list2;
            list2 = list2->next;
        }

        while (list1 != nullptr && list2 != nullptr) {
            if (list1->val <= list2->val) {
                point->next = list1;
                list1 = list1->next;
                point = point->next;
            } else {
                point->next = list2;
                point = point->next;
                list2 = list2->next;
            }
        }

        if (list1 != nullptr) {
            point->next = list1;
        }
        if (list2 != nullptr) {
            point->next = list2;
        }
        return dummy->next;
    }
```
