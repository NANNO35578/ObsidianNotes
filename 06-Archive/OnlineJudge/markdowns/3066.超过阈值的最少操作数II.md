[3066. 超过阈值的最少操作数 II](https://leetcode.cn/problems/minimum-operations-to-exceed-threshold-value-ii/)
##### 解题思路
1. **使用优先队列**：
   - 利用最小堆（优先队列）来高效地获取和删除最小的两个元素。这使得我们能够快速找到需要进行操作的元素。
1. **执行操作**：
   - 在堆中不断取出最小的两个元素 `x` 和 `y`，并计算新的元素。
   - 将新元素插入堆中，并记录操作次数。
1. **检查条件**：
   - 在每次操作后检查堆中的元素，确保所有元素都大于或等于 `k`。如果无法满足条件，返回一个特定值（如 -1）。
1. **结束条件**：
   - 当堆中元素的数量小于 2 或所有元素都大于等于 `k` 时，停止操作。
##### 复杂度分析
- **时间复杂度**：`O(n log n)`，其中 `n` 是数组的长度，因每次插入和删除的复杂度为 `O(log n)`。
- **空间复杂度**：`O(n)`，用于存储堆中的元素。

```cpp
    int minOperations(vector<int>& nums, int k) {
        priority_queue<long long, vector<long long>, greater<long long>> minHeap;
        // 将所有元素插入最小堆
        for (int num : nums) {
            minHeap.push(num);
        }
        long long operations = 0;
        while (minHeap.size() >= 2 && minHeap.top() < k) {
            long long x = minHeap.top(); minHeap.pop();
            long long y = minHeap.top(); minHeap.pop();

            // 计算新元素
            long long newElement = min(x, y) * 2 + max(x, y);
            minHeap.push(newElement);
            operations++;
        }
        return operations;
    }
```

##### 优化
```cpp
int minOperations(vector<int> &nums, int k) {
    int res = 0;
    priority_queue<long long, vector<long long>, greater<long long>> pq(nums.begin(), nums.end());
        while (pq.top() < k) {
            long long x = pq.top(); pq.pop();
            long long y = pq.top(); pq.pop();
            pq.push(x + x + y);
            res++;
        }
    return res;
}
```
