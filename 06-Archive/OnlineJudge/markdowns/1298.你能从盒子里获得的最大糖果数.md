## 方法一：BFS + 双队列


- 动态地维护两类盒子集合：
1. **可立即打开的盒子队列** `q`  
    条件：我们已经 “拥有” 这个盒子，并且它是开着的 (`status=1`) 或者我们已拿到其钥匙
2. **暂时无法打开的盒子集合** `pending`  
    条件：我们拥有盒子但它是关的，且还没有钥匙

利用这两者，我们做一个「BFS 式」的遍历：每次从 `q` 里取一个盒子打开，利用它产出的钥匙和内含盒子，不断地把新打开的盒子塞回 `q`
## 详细步骤
1. **初始化**
    - 遍历 `initialBoxes`：
        - 标记 `owned[b] = true`
        - 如果 `status[b] == 1`，直接 `q.push(b)`；  
            否则放到 `pending` 里，等待钥匙
2. **主循环**  
    当 `q` 非空时，重复以下操作：
    a. 从 `q` 里弹出盒子 `b`，标记为已打开 `opened[b] = true`，并加上 `candies[b]`
    b. **拿钥匙** 遍历 `keys[b]` 中的每个 `k`：
    - 如果这是新钥匙，则 `haveKey[k] = true`
    - 如果我们已经“拥有”盒子 `k` 且还没打开，就可以立刻 `q.push(k)`
    c. **拿内含的盒子** 遍历 `containedBoxes[b]` 中的每个 `nb`：
    - 标记 `owned[nb] = true`
    - 如果 `status[nb] == 1` 或者 `haveKey[nb] == true`，立即 `q.push(nb)`；  
        否则放入 `pending`，稍后再试
    d. **重试 pending**  
    遍历一次当前的 `pending`，把所有此刻已经满足“可打开”（`status==1` 或 `haveKey==true`）的盒子移到 `q`
    剩下的仍留在 `pending`，等待下一轮
3. **终止条件**  
    当 `q` 为空，且 `pending` 中所有盒子都无法再打开时，整个过程结束 
    累加的糖果数即为答案

这种做法等价于在「盒子-钥匙-新盒子」的有向图中做一次可达扫描，用队列不断扩张「已打开」的部分，直到无法再扩张为止

**复杂度分析**
- 每个盒子最多进出 `q` 和 `pending` 常数次，整体 $O(n + ∑|keys[i]| + ∑|containedBoxes[i]|)$
- 空间 O(n + 输入大小)

```cpp
#include <bits/stdc++.h>
using namespace std;

int maxCandies(vector<int>& status, vector<int>& candies, vector<vector<int>>& keys, 
               vector<vector<int>>& containedBoxes, vector<int>& initialBoxes) {
    int n = status.size();
    vector<bool> owned(n, false), opened(n, false), haveKey(n, false), inPending(n, false);
    queue<int> q;           // 可立即尝试打开的盒子
    queue<int> pending;     // 已拥有但暂时打不开的盒子

    // 初始化：拥有初始盒子
    for (int b : initialBoxes) {
        owned[b] = true;
        if (status[b] == 1) {
            q.push(b);
            opened[b] = true;  // 标记为“准备打开”
        } else {
            pending.push(b);
            inPending[b] = true;
        }
    }

    int ans = 0;
    while (!q.empty()) {
        int b = q.front(); q.pop();
        // 打开盒子 b
        ans += candies[b];

        // 1) 拿到新钥匙
        for (int k : keys[b]) {
            if (!haveKey[k]) {
                haveKey[k] = true;
                // 如果我们已经“拥有”这个盒子，且它还没被打开，就可以打开它
                if (owned[k] && !opened[k]) {
                    q.push(k);
                    opened[k] = true;
                }
            }
        }

        // 2) 拿到新盒子
        for (int nb : containedBoxes[b]) {
            if (!owned[nb]) {
                owned[nb] = true;
                if (status[nb] == 1 || haveKey[nb]) {
                    // 立即可开
                    q.push(nb);
                    opened[nb] = true;
                } else {
                    // 暂时打不开，放 pending
                    pending.push(nb);
                    inPending[nb] = true;
                }
            }
        }

        // 3) 尝试重开 pending 中的盒子
        int sz = pending.size();
        while (sz--) {
            int pb = pending.front(); pending.pop();
            inPending[pb] = false;
            if (opened[pb]) continue;       // 已经打开过
            if (status[pb] == 1 || haveKey[pb]) {
                q.push(pb);
                opened[pb] = true;
            } else {
                // 依然打不开，放回去
                pending.push(pb);
                inPending[pb] = true;
            }
        }
    }

    return ans;
}
```

## 方法二：迭代扫描 + DFS 解锁（O(n²)）

思路：

1. 用三个数组／标记
    - `owned[i]` 表示是否拿到过盒子 i
    - `opened[i]` 表示是否已经打开过盒子 i
    - `haveKey[i]` 表示是否拥有盒子 i 的钥匙
2. 反复扫描所有「已拥有但未打开」的盒子，凡是满足 `status[i]==1 || haveKey[i]` 的就 DFS 打开，拿到糖果、钥匙、以及新盒子
3. 只要本轮有任何新盒子或新钥匙导致能开的盒子数增加，就继续下一轮。直到一整轮没有新增可开的盒子为止

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<int> status, candies;
vector<vector<int>> keys, containedBoxes;
vector<bool> owned, opened, haveKey;

int total = 0;

void dfsOpen(int b) {
    // 只在第一次满足可开时调用
    opened[b] = true;
    total += candies[b];
    // 拿钥匙
    for (int k : keys[b]) {
        haveKey[k] = true;
    }
    // 拿盒子
    for (int nb : containedBoxes[b]) {
        owned[nb] = true;
    }
}

int maxCandies(vector<int>& _status,
               vector<int>& _candies,
               vector<vector<int>>& _keys,
               vector<vector<int>>& _containedBoxes,
               vector<int>& initialBoxes) {
    status = _status;
    candies = _candies;
    keys = _keys;
    containedBoxes = _containedBoxes;

    n = status.size();
    owned.assign(n, false);
    opened.assign(n, false);
    haveKey.assign(n, false);

    // 一开始拿到初始盒子
    for (int b : initialBoxes) {
        owned[b] = true;
    }

    bool progress = true;
    while (progress) {
        progress = false;
        // 遍历所有箱子，尝试打开
        for (int i = 0; i < n; i++) {
            if (owned[i] && !opened[i] && (status[i] == 1 || haveKey[i])) {
                dfsOpen(i);
                progress = true;
            }
        }
    }

    return total;
}
```
