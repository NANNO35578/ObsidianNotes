[3305. 元音辅音字符串计数 I](https://leetcode.cn/problems/count-of-substrings-containing-every-vowel-and-k-consonants-i/)

- **定义元音和辅音**：
    - 我们将元音字母定义为 `{'a', 'e', 'i', 'o', 'u'}`。
- **滑动窗口**：
    - 使用双重循环来遍历字符串，外层循环设置起始位置，内层循环设置结束位置，形成一个滑动窗口。
- **检查条件**：
    - 在窗口内维护一个计数器来统计辅音字母的数量，并使用一个集合来存储出现的元音字母。
    - 每次扩展窗口时，检查当前窗口是否包含所有元音字母，并且辅音的数量是否等于 `k`。
- **返回结果**：
    - 记录符合条件的子字符串数量并返回。

```cpp
    int countOfSubstrings(string word, int k) {
        int count = 0;
        int n = word.size();
        unordered_set<char> vowels = {'a', 'e', 'i', 'o', 'u'};

        // 遍历所有起始位置
        for (int start = 0; start < n; start++) {
            int consonantCount = 0;
            unordered_set<char> seenVowels;

            // 从起始位置扩展窗口
            for (int end = start; end < n; end++) {
                char currentChar = word[end];

                // 统计辅音字母
                if (vowels.find(currentChar) == vowels.end()) {
                    consonantCount++;
                } else {
                    seenVowels.insert(currentChar);
                }

                // 检查当前窗口是否符合条件
                if (consonantCount == k && seenVowels.size() == 5) {
                    count++;
                }
            }
        }

        return count;
    }
```

#### 方法一：暴力枚举

枚举字符串 word 的所有子字符串，统计每个元音字母都出现且辅音字母出现次数等于 k 的子字符串数目。

```cpp
    long long countOfSubstrings(string word, int k) {
        set<char> vowels = {'a', 'e', 'i', 'o', 'u'};
        int n = word.size();
        long long res = 0;
        for (int i = 0; i < n; i++) {
            set<char> occur;
            int consonants = 0;
            for (int j = i; j < n; j++) {
                if (vowels.count(word[j])) {
                    occur.insert(word[j]);
                } else {
                    consonants++;
                }
                if (occur.size() == vowels.size() && consonants == k) {
                    res++;
                }
            }
        }
        return res;
    }
```
