# `strlen`与`sizeof`的区别
### `strlen`
- **功能**：计算字符串的长度（不包括终止的空字符`'\0'`）。
- **参数**：接收一个指向字符数组（字符串）的指针。
- **返回值**：返回字符串中的字符数（`size_t`类型）。
- **示例**：
    ```c
    const char *str = "Hello";
    size_t len = strlen(str); // len为5
    ```
### `sizeof`
- **功能**：返回一个对象或类型的大小（以字节为单位）。
- **参数**：可以是变量、类型或数组等。
- **返回值**：返回对象或类型的大小（`size_t`类型）。
- **注意**：对于数组，`sizeof`会返回整个数组的大小，而不是数组中元素的个数。
- **示例**：
    ```c
    int arr[10];
    size_t size = sizeof(arr); // size为40（假设int为4字节）
    ```
### 主要区别
1. **用途**：
    - `strlen`用于获取字符串长度。
    - `sizeof`用于获取任何类型的大小。
2. **参数类型**：
    - `strlen`需要字符串指针。
    - `sizeof`可以接受任意类型或变量。
3. **返回值**：
    - `strlen`返回字符串中的字符数，不包括空字符。
    - `sizeof`返回对象的总字节数。
### 例子对比
```c
const char *str = "Hello";
size_t str_len = strlen(str); // 返回5
size_t arr_size = sizeof(str); // 返回指针的大小（通常为4或8）

int arr[10];
size_t arr_len = sizeof(arr) / sizeof(arr[0]); // 返回10（数组元素个数）
```

# 已经有了`malloc`为什么还要提出`new`
- 都是用于动态内存分配的，但它们之间有一些重要的区别，具体如下：
### 1. **语法和类型安全**
- **`malloc`**：
  - 返回的是`void*`，需要显式转换为目标类型。
  - 不会调用构造函数。
  - 示例：
    ```c
    int* ptr = (int*)malloc(sizeof(int));
    ```

- **`new`**：
  - 返回目标类型的指针，自动进行类型转换。
  - 会调用构造函数（如果有的话）。
  - 示例：
    ```cpp
    int* ptr = new int;
    ```

### 2. **内存初始化**
- **`malloc`**： 分配的内存未初始化，内容是未定义的。
- **`new`**： 可以初始化对象。
  - 示例：
    ```cpp
    int* ptr = new int(5); // 初始化为5
    ```

### 3. **内存释放**
- **`malloc`**： 使用`free`来释放内存。
- **`new`**：
  - 使用`delete`来释放内存。
  - 会调用析构函数（如果有的话）。
  - 示例：
    ```cpp
    delete ptr; // 对应new
    ```

### 4. **适用场景**
- **`malloc`**： 适用于C语言或需要手动管理内存的场景。
- **`new`**： 更适用于C++，尤其是对象的动态管理和面向对象编程。

如果使用C++，推荐使用`new`和`delete`，因为它们提供了更好的类型安全和对象管理功能。而`malloc`通常用于C语言或在需要兼容C的情况下

# `new`如何重载，有何作用
在C++中，`new`运算符可以被重载，允许自定义内存分配的行为。重载`new`的主要作用包括：

### 1. **自定义内存分配**
- 可以在分配内存时添加额外的功能，例如日志记录、内存池管理或错误处理。

### 2. **重载方法**
- 可以重载全局的`new`和`delete`运算符，也可以为特定类重载。

### 3. **示例**

#### 重载全局`new`和`delete`
```cpp
#include <iostream>
#include <cstdlib>

void* operator new(std::size_t size) {
    std::cout << "Allocating " << size << " bytes\n";
    void* p = std::malloc(size);
    if (!p) throw std::bad_alloc();
    return p;
}

void operator delete(void* p) noexcept {
    std::cout << "Deallocating memory\n";
    std::free(p);
}

int main() {
    int* p = new int; // 会调用重载的new
    delete p;        // 会调用重载的delete
    return 0;
}
```

#### 重载类的`new`和`delete`
```cpp
#include <iostream>

class MyClass {
public:
    static void* operator new(std::size_t size) {
        std::cout << "MyClass allocating " << size << " bytes\n";
        return ::operator new(size);
    }

    static void operator delete(void* p) noexcept {
        std::cout << "MyClass deallocating memory\n";
        ::operator delete(p);
    }
};

int main() {
    MyClass* obj = new MyClass; // 会调用MyClass的重载new
    delete obj;                // 会调用MyClass的重载delete
    return 0;
}
```

### 作用
- **调试**：可以在内存分配和释放时输出日志，帮助调试内存泄漏和其他问题。
- **性能优化**：在特定情况下，可以实现更高效的内存分配策略。
- **内存管理**：可以实现自定义的内存池，减少频繁的分配和释放带来的性能开销。

# 什么是单例模式
单例模式的实现方式主要有两种：懒汉式和饿汉式。它们的区别在于实例化的时机和内存管理。
### 1. 懒汉式（Lazy Initialization）
- **特点**：
  - 实例在需要时才创建（延迟加载）。
  - 适合资源消耗较大的对象。
- **实现**： 通常使用静态方法获取实例，第一次调用时创建实例。
- **示例**：
  ```cpp
  class Singleton {
  private:
      static Singleton* instance;

      // 私有构造函数
      Singleton() {}

  public:
      static Singleton* getInstance() {
          if (!instance) {
              instance = new Singleton();
          }
          return instance;
      }

      // 防止拷贝构造和赋值
      Singleton(const Singleton&) = delete;
      Singleton& operator=(const Singleton&) = delete;
  };

  Singleton* Singleton::instance = nullptr;
  ```

### 2. 饿汉式（Eager Initialization）
- **特点**：
  - 类加载时就实例化，确保在程序启动时就创建对象。
  - 适合实例化开销较小的对象。
- **实现**： 在类的静态成员变量中直接初始化实例。
- **示例**：
  ```cpp
  class Singleton {
  private:
      static Singleton* instance;

      // 私有构造函数
      Singleton() {}

  public:
      static Singleton* getInstance() {
          return instance;
      }

      // 防止拷贝构造和赋值
      Singleton(const Singleton&) = delete;
      Singleton& operator=(const Singleton&) = delete;
  };

  // 饿汉式，直接初始化
  Singleton* Singleton::instance = new Singleton();
  ```
### 比较

| 特性          | 懒汉式                  | 饿汉式                  |
|---------------|------------------------|------------------------|
| 实例化时机    | 需要时才创建            | 类加载时立即创建        |
| 资源消耗      | 适合资源消耗大的对象    | 适合资源消耗小的对象    |
| 线程安全      | 需要额外处理            | 天然线程安全（类加载时） |
| 内存管理      | 需手动释放              | 通常在程序结束时释放    |

### 总结
- **懒汉式**适合在需要时才创建实例的场景，节省资源，但需考虑线程安全。
- **饿汉式**在类加载时就创建实例，简单且天然线程安全，适合轻量级对象。

# 单例模式回收
### 单例模式的内存回收总结

单例模式确保一个类只有一个实例，并提供全局访问点。内存回收是管理单例生命周期的重要部分，以下是几种常见的内存回收方法及其特点：

#### 1. **手动回收**
- **实现方式**：通过静态方法手动释放内存。
- **示例**：
    ```cpp
    static void release() {
        delete instance;
        instance = nullptr;
    }
    ```
- **优点**：简单直接，控制权限。
- **缺点**：需要用户主动调用，容易导致内存泄漏。
#### 2. **友元类回收**
- **实现方式**：定义友元类，允许其访问私有成员进行回收。
- **示例**：
    ```cpp
    friend class SingletonCleaner;
    static void release() {
        delete instance;
    }
    ```
- **优点**：封装性强，确保内存安全。
- **缺点**：增加了类之间的耦合。

#### 3. **内部类回收**
- **实现方式**：在单例类中定义内部类，内部类负责实例化和析构。
- **示例**：
    ```cpp
    class InstanceHolder {
    public:
        ~InstanceHolder() {
            delete Singleton::instance;
        }
    };
    ```
- **优点**：自动管理内存，保持良好封装。
- **缺点**：可能增加复杂性。

#### 4. **智能指针**
- **实现方式**：使用`std::unique_ptr`或`std::shared_ptr`自动管理内存。
- **示例**：
    ```cpp
    static std::unique_ptr<Singleton> instance;
    ```
- **优点**：自动回收内存，减少内存泄漏风险。
- **缺点**：可能不适合所有场景，特别是需要独占访问的情况。
