[75. 颜色分类](https://leetcode.cn/problems/sort-colors/)

```cpp
void sortColors(vector<int>& nums) {
    int redIndex = 0; // 紅色的指針
    int whiteIndex = 0; // 白色的指針
    int blueIndex = nums.size() - 1; // 藍色的指針

    while (whiteIndex <= blueIndex) {
        if (nums[whiteIndex] == 0) {
            // 如果是红色，交换到前面
            swap(nums[redIndex], nums[whiteIndex]);
            redIndex++;
            whiteIndex++;
        } else if (nums[whiteIndex] == 1) {
            // 如果是白色，直接移动
            whiteIndex++;
        } else {
            // 如果是蓝色，交换到后面
            swap(nums[whiteIndex], nums[blueIndex]);
            blueIndex--;
        }
    }
}
```

1. **指针初始化**：
   - `redIndex` 用于指向下一个红色（0）的位置。
   - `whiteIndex` 用于遍历数组。
   - `blueIndex` 用于指向最后一个蓝色（2）的位置。
1. **遍历数组**：
   - 使用 `while` 循环，当 `whiteIndex` 小于等于 `blueIndex` 时进行遍历。
1. **条件判断**：
   - **遇到红色（0）**：
     - 将当前的 `whiteIndex` 位置的元素与 `redIndex` 位置的元素交换。
     - 增加 `redIndex` 和 `whiteIndex`，因为红色已被放到正确位置。
   - **遇到白色（1）**：
     - 直接移动 `whiteIndex`，因为白色的位置是正确的。
   - **遇到蓝色（2）**：
     - 将当前的 `whiteIndex` 位置的元素与 `blueIndex` 位置的元素交换。
     - 只减少 `blueIndex`，不增加 `whiteIndex`，因为交换后新到 `whiteIndex` 的元素可能是 0 或 1，需要继续处理。
2. **完成排序**：
   - 循环结束后，数组中的元素将按照红色、白色和蓝色的顺序排列。

## 复杂度分析

- **时间复杂度**：O(n)，每个元素最多被访问和交换一次。
- **空间复杂度**：O(1)，只使用了常数空间。

# 题解：荷兰国旗问题

## 前言

本题是经典的「荷兰国旗问题」，由计算机科学家 Edsger W. Dijkstra 首先提出。我们需要对一个包含红色、白色和蓝色（分别用 0、1 和 2 表示）的数组进行排序。

## 方法一：单指针

### 思路与算法

我们可以对数组进行两次遍历：

1. **第一次遍历**：将所有的 0 移动到数组的前面。
2. **第二次遍历**：将所有的 1 移动到 0 的后面。

使用一个指针 `ptr` 表示「头部」，初始值为 0，表示数组的前 `ptr` 个元素都为 0。在遍历时，找到 0 后与 `ptr` 位置的元素交换，并将 `ptr` 向后移动。

### 代码

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int ptr = 0;
        
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 0) {
                swap(nums[i], nums[ptr]);
                ++ptr;
            }
        }
        
        for (int i = ptr; i < n; ++i) {
            if (nums[i] == 1) {
                swap(nums[i], nums[ptr]);
                ++ptr;
            }
        }
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 方法二：双指针

### 思路与算法

在此方法中，我们只需一次遍历，使用两个指针 `p0` 和 `p1`：

- `p0` 用于交换 0
- `p1` 用于交换 1

遍历数组时：

- 如果找到 1，交换到 `p1` 并移动 `p1`。
- 如果找到 0，交换到 `p0`，并检查 `p0 < p1`，如果成立，交换当前元素与 `p1`。

### 代码

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int p0 = 0, p1 = 0;
        
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 1) {
                swap(nums[i], nums[p1]);
                ++p1;
            } else if (nums[i] == 0) {
                swap(nums[i], nums[p0]);
                if (p0 < p1) {
                    swap(nums[i], nums[p1]);
                }
                ++p0;
                ++p1;
            }
        }
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)

## 方法三：双指针（另一种实现）

### 思路与算法

使用指针 `p0` 和 `p2`：

- `p0` 从左向右，指向 0 的位置
- `p2` 从右向左，指向 2 的位置

遍历数组时：

- 如果找到 0，交换到 `p0` 并向后移动。
- 如果找到 2，交换到 `p2` 并向前移动。

### 代码

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();
        int p0 = 0, p2 = n - 1;
        
        for (int i = 0; i <= p2; ++i) {
            while (i <= p2 && nums[i] == 2) {
                swap(nums[i], nums[p2]);
                --p2;
            }
            if (nums[i] == 0) {
                swap(nums[i], nums[p0]);
                ++p0;
            }
        }
    }
};
```

### 复杂度分析

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)
