[3442. 奇偶频次间的最大差值 I](https://leetcode.cn/problems/maximum-difference-between-even-and-odd-frequency-i/)

1. **频次计算**：
    - 使用一个 `unordered_map` 来统计字符串中每个字符出现的频次。
    - 通过遍历字符串，将每个字符作为键，频次作为值存入 `freqMap` 中。
2. **初始化最大差值**： 使用 `INT_MIN` 初始化 `maxDiff`，以便后续可以找到更大的差值。
3. **遍历字符频次**：
    - 对于 `freqMap` 中的每个字符频次：
        - 如果字符的频次是奇数（`count1 % 2 != 0`），则进入内层循环。
        - 在内层循环中，再次遍历 `freqMap`，寻找频次为偶数的字符（`count2 % 2 == 0`）。
        - 计算 `count1 - count2`，并更新 `maxDiff` 为两者之间的最大值。
4. **返回结果**： 如果在遍历过程中没有找到合适的字符对（即 `maxDiff` 仍为 `INT_MIN`），则返回 0；否则返回 `maxDiff`。

```cpp
    int maxDifference(string s) {
          std::unordered_map<char, int> freqMap;

    // 计算每个字符的频次
    for (char c : s) {
        freqMap[c]++;
    }

    int maxDiff = INT_MIN;

    // 迭代字符频次
    for (const auto& entry1 : freqMap) {
        char a1 = entry1.first;
        int count1 = entry1.second;

        if (count1 % 2 != 0) { // a1出现奇数次
            for (const auto& entry2 : freqMap) {
                char a2 = entry2.first;
                int count2 = entry2.second;

                if (count2 % 2 == 0) { // a2出现偶数次
                    maxDiff = std::max(maxDiff, count1 - count2);
                }
            }
        }
    }

    return maxDiff == INT_MIN ? 0 : maxDiff; // 如果没有找到合适的字符对，返回0  
    }
```
