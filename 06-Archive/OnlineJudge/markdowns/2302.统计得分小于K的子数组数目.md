[2302. 统计得分小于 K 的子数组数目](https://leetcode.cn/problems/count-subarrays-with-score-less-than-k/)
- **定义分数**：对每个子数组，我们的分数定义为 `(子数组元素之和) * (子数组长度)`。
- **遍历所有子数组**：可以通过嵌套循环来生成所有可能的子数组。外层循环用于确定子数组的起始位置，内层循环用于确定子数组的结束位置。
- **计算和与长度**：对于每个子数组，计算其元素之和和长度。
- **比较分数**：计算分数，并检查其是否小于 `k`。
- **计数**：维护一个计数器，记录符合条件的子数组数量。

- **`countSubarrays` 函数**：接收一个整数数组 `nums` 和一个整数 `k`，返回符合条件的非空子数组数量。
- **外层循环**：遍历每个可能的起始点 `start`。
- **内层循环**：从 `start` 开始，扩展到每个可能的结束点 `end`，计算当前子数组的和和长度。
- **分数计算**：根据定义计算分数，并进行比较。
- **计数**：符合条件时，增加计数器。

```cpp
    long long countSubarrays(vector<int>& nums, long long k) {
        long long sum = 0; // Use long long to avoid overflow
        long long count = 0;
        int start = 0; // Two pointers
        
        for (int end = 0; end < nums.size(); ++end) {
            sum += nums[end]; // Expand the window by adding the new element
            
            // Calculate the score for the current subarray from start to end
            while (start <= end) {
                long long length = end - start + 1;
                long long score = sum * length;
                
                if (score < k) {
                    // If score is valid, count all subarrays ending at 'end' with 
                    // start moving from 'start' to 'end'
                    count += (end - start + 1);
                    break; // We can stop as increasing 'start' will only increase the score
                } else {
                    // Move the start pointer to reduce the score
                    sum -= nums[start];
                    start++;
                }
            }
        }
        
        return count;
    }
```
##### 滑动窗口


#### 方法一：滑动窗口

根据题目对数组分数的定义，以及 nums 是正整数数组这一条件，对于子数组 `[i,j]`，当右端点 j 固定时，随着左端点 i 增加，子数组的和会减少，长度也会缩短，因此子数组的分数会单调递减。如果子数组 `[i,j]` 的分数小于 k，由于分数单调递减，那么子数组 `[p,j],i<p≤j` 的分数也小于 k。

基于以上性质，我们可以使用滑动窗口的方法求解。从 j=0 开始枚举子数组的右端点，并维护一个左端点 i（初始值为 0）。对于每个 j：

- 扩展窗口：将 `nums[j]` 加入当前窗口对应的子数组和 total。
- 收缩窗口：如果当前窗口对应的子数组分数 `total×(j−i+1)` 大于等于 k，说明子数组不符合要求，因此需要向右移动左端点 i，直到分数小于 k 为止。
- 计算子数组数量：此时，以 j 为右端点且分数小于 k 的子数组的数量为 `j−i+1`，累加到最终结果 res。

枚举结束后，返回最终结果 res。

```cpp
class Solution {
public:
    long long countSubarrays(vector<int>& nums, long long k) {
        int n = nums.size();
        long long res = 0, total = 0;
        for (int i = 0, j = 0; j < n; j++) {
            total += nums[j];
            while (i <= j && total * (j - i + 1) >= k) {
                total -= nums[i];
                i++;
            }
            res += j - i + 1;
        }
        return res;
    }
};
```
