
[2. 两数相加](https://leetcode.cn/problems/add-two-numbers/)
1. **初始化**：
    - 创建一个哑节点（dummy node）作为结果链表的头节点，方便链表的构建。
    - 初始化一个指针 `current` 指向哑节点，用于逐步构建结果链表。
    - 初始化一个变量 `carry` 用于存储进位，初始值为 0。
2. **逐位相加**：
    - 使用一个循环，直到两个链表都为空且没有剩余的进位。
    - 在每次循环中：
        - 计算当前位的和 `sum`，初始值为进位 `carry`。
        - 如果链表 `l1` 的当前节点不为空，将 `l1` 的值加到 `sum` 中，并将 `l1` 指针移动到下一个节点。
        - 如果链表 `l2` 的当前节点不为空，将 `l2` 的值加到 `sum` 中，并将 `l2` 指针移动到下一个节点。
        - 更新进位：`carry = sum / 10`。
        - 当前位的值为 `sum % 10`。
        - 创建一个新节点，存储当前位的值，并将其连接到结果链表的末尾。
        - 将 `current` 指针移动到新节点。
3. **返回结果**：
    - 循环结束后，返回哑节点的下一个节点（即结果链表的头节点）。

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        // 创建一个哑节点作为结果链表的头节点
        ListNode* dummy = new ListNode(0);
        // 当前节点指针，用于构建结果链表
        ListNode* current = dummy;
        // 初始化进位
        int carry = 0;

        // 遍历两个链表，直到两个链表都为空且没有剩余的进位
        while (l1 || l2 || carry) {
            // 当前位的和，初始值为进位
            int sum = carry;

            // 如果 l1 不为空，将 l1 的值加到 sum，并移动 l1 指针
            if (l1) {
                sum += l1->val;
                l1 = l1->next;
            }

            // 如果 l2 不为空，将 l2 的值加到 sum，并移动 l2 指针
            if (l2) {
                sum += l2->val;
                l2 = l2->next;
            }

            // 更新进位
            carry = sum / 10;

            // 创建新节点存储当前位的值，并将其连接到结果链表
            current->next = new ListNode(sum % 10);
            // 移动当前节点指针
            current = current->next;
        }

        // 返回结果链表的头节点（去掉哑节点）
        return dummy->next;
    }
};
```
---

**思路与算法**

由于输入的两个链表都是**逆序**存储数字的位数的，因此两个链表中同一位置的数字可以直接相加。

我们同时遍历两个链表，逐位计算它们的和，并与当前位置的进位值相加。具体而言，如果当前两个链表处相应位置的数字为 n1,n2，进位值为 carry，则它们的和为 n1+n2+carry；其中，答案链表处相应位置的数字为 (n1+n2+carry)mod 10，而新的进位值为 ⌊(n1+n2+carry​)/10⌋。

如果两个链表的长度不同，则可以认为长度短的链表的后面有若干个 0 。

此外，如果链表遍历结束后，有 carry>0，还需要在答案链表的后面附加一个节点，节点的值为 carry。

```cpp
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode *head = nullptr, *tail = nullptr;
        int carry = 0;
        while (l1 || l2) {
            int n1 = l1 ? l1->val: 0;
            int n2 = l2 ? l2->val: 0;
            int sum = n1 + n2 + carry;
            if (!head) {
                head = tail = new ListNode(sum % 10);
            } else {
                tail->next = new ListNode(sum % 10);
                tail = tail->next;
            }
            carry = sum / 10;
            if (l1) {
                l1 = l1->next;
            }
            if (l2) {
                l2 = l2->next;
            }
        }
        if (carry > 0) {
            tail->next = new ListNode(carry);
        }
        return head;
    }
};

```
