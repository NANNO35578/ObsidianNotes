[2918. 数组的最小相等和](https://leetcode.cn/problems/minimum-equal-sum-of-two-arrays-after-replacing-zeros/)

- **初始化变量**：
    - `sum1` 和 `sum2`：分别用于存储 `nums1` 和 `nums2` 中非零元素的和。
    - `lack1` 和 `lack2`：分别用于计数 `nums1` 和 `nums2` 中的 `0` 的数量。
- **遍历数组并计算和**：
    - 对于 `nums1`：
        - 如果元素是 `0`，则 `lack1` 加 1。
        - 如果元素是非零，累加到 `sum1`。
    - 对于 `nums2`：
        - 同样的逻辑，计算 `sum2` 和 `lack2`。
- **检查条件**：
    - **无 `0` 的数组**：
        - 如果 `nums1` 中没有 `0`（即 `lack1 == 0`），但 `sum1` 小于 `nums2` 的和加上 `nums2` 中的 `0` 的数量（`sum2 + lack2`），这意味着即使我们用 `1` 替换 `nums2` 中的 `0` 也无法使得两个数组相等，此时返回 `-1`。
        - 反之，如果 `nums2` 中没有 `0`（即 `lack2 == 0`），但 `sum2` 小于 `nums1` 的和加上 `nums1` 中的 `0` 的数量（`sum1 + lack1`），同样返回 `-1`。
- **计算最小相等和**：
    - 如果上述条件都不满足，那么可以通过将 `0` 替换为合适的正整数，使得两个数组的和相等。这时，我们可以直接返回 `max(sum1 + lack1, sum2 + lack2)`。
    - 这里的逻辑是，`sum1 + lack1` 表示将 `nums1` 中所有的 `0` 替换为 `1` 后的最大可能和，`sum2 + lack2` 则是 `nums2` 的情况。
```cpp
    long long minSum(vector<int>& nums1, vector<int>& nums2) {
        long long sum1 = 0, sum2 = 0;
        int lack1 = 0, lack2 = 0;

        // 计算 nums1 的和与缺失的零的数量
        for (int n1 : nums1) {
            if (n1 == 0)
                lack1++;
            else
                sum1 += n1;
        }

        // 计算 nums2 的和与缺失的零的数量
        for (int n2 : nums2) {
            if (n2 == 0)
                lack2++;
            else
                sum2 += n2;
        }

        // 检查是否可以通过替换使两数组的和相等
        if (lack1 == 0 && sum1 < sum2 + lack2) {
            return -1;
        } else if (lack2 == 0 && sum2 < sum1 + lack1) {
            return -1;
        }

        // 返回最小相等和
        return max(sum1 + lack1, sum2 + lack2);
    }
```


##### 优化

```cpp
    long long minSum(vector<int>& nums1, vector<int>& nums2) {
        long long sum1 = 0, sum2 = 0;
        long long zero1 = 0, zero2 = 0;
        for (int i : nums1) {
            sum1 += i;
            if (i == 0) {
                sum1++;
                zero1++;
            }
        }
        for (int i : nums2) {
            sum2 += i;
            if (i == 0) {
                sum2++;
                zero2++;
            }
        }
        if (!zero1 && sum2 > sum1 || !zero2 && sum1 > sum2) {
            return -1;
        }
        return max(sum1, sum2);
    }
```
