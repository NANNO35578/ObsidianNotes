[2410. 运动员和训练师的最大匹配数](https://leetcode.cn/problems/maximum-matching-of-players-with-trainers/) 

1. **排序**：`std::sort` 对运动员和训练师的能力值进行排序
2. **双指针遍历**：
    - 当运动员的能力值小于等于训练师的能力值时，计数器加一，两个指针都向前移动
    - 否则，只移动训练师的指针，继续寻找可以匹配的训练师

```cpp
int matchPlayersAndTrainers(std::vector<int>& players, std::vector<int>& trainers) {
    std::sort(players.begin(), players.end());
    std::sort(trainers.begin(), trainers.end());

    int playerIndex = 0, trainerIndex = 0;
    int matches = 0;

    while (playerIndex < players.size() && trainerIndex < trainers.size()) {
        if (players[playerIndex] <= trainers[trainerIndex]) {
            matches++;
            playerIndex++; // Move to next player
            trainerIndex++; // Move to next trainer
        } else {
            // cannot match, try next trainer
            trainerIndex++;
        }
    }
    return matches;
}
```

---
##### 优化
- 二分查找
```cpp
    std::sort(players.begin(), players.end());
    std::sort(trainers.begin(), trainers.end());

    int matches = 0;
    int trainerIndex = 0;

    for (int player : players) {
        // 使用二分搜索找到第一个大于等于 player 的训练师
        while (trainerIndex < trainers.size() && trainers[trainerIndex] < player) {
            trainerIndex++;
        }
        // 若找到了合适的训练师，则匹配
        if (trainerIndex < trainers.size()) {
            matches++;
            trainerIndex++; // 移动到下一个训练师
        }
    }

    return matches;
```
