[滑动窗口最大值](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457591344)
- **初始化**：创建一个结果 vector 来存储每个窗口的最大值和一个双向队列 `maxDeque` 来存储窗口内的元素值。
- **遍历数组**：
    - **移除过期元素**：检查队首元素是否是窗口外的元素，如果是，则从队首移除。
    - **维护递减顺序**：在队列中保持元素的递减顺序，弹出队尾的元素直到队尾元素大于或等于当前元素。
    - **添加当前元素**：将当前元素值添加到 `maxDeque` 中。
    - **记录最大值**：当窗口大小达到 k 时，将队首元素（当前窗口的最大值）添加到结果中。
```cpp
    vector<int> maxInWindows(vector<int>& num, int size) {
        // write code here
        if(size==0||size>num.size())return {};
        if (size == num.size()) return {*max_element(num.begin(), num.end())};
        std::vector<int> result;
        std::deque<int> maxDeque;

        for (int i = 0; i < num.size(); ++i) {
            // 移除过期元素
            if (!maxDeque.empty() && maxDeque.front() == num[i - size]) {
                maxDeque.pop_front();
            }

            // 维护递减顺序
            while (!maxDeque.empty() && maxDeque.back() < num[i]) {
                maxDeque.pop_back();
            }

            // 添加当前元素
            maxDeque.push_back(num[i]);

            // 记录最大值
            if (i >= size - 1) {
                result.push_back(maxDeque.front());
            }
        }

        return result;
    }
```
