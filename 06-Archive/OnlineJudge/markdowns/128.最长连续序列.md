[128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)


- 将所有元素插入到一个哈希集（unordered_set）中，这样可以在 O(1) 时间内查找元素。
- 遍历每个元素，如果它是一个序列的起始元素（即 `num - 1` 不在集合中），则从这个元素开始向上查找连续的数字，直到找不到连续的数字为止。
- 记录下最长的连续序列长度。

```cpp
int longestConsecutive(vector<int>& nums) {
    unordered_set<int> numSet(nums.begin(), nums.end());
    int longestStreak = 0;

    for (int num : numSet) {
        // 只有在 num-1 不在集合中时，才是一个序列的起始点
        if (numSet.find(num - 1) == numSet.end()) {
            int currentNum = num;
            int currentStreak = 1;

            // 向上查找连续的数字
            while (numSet.find(currentNum + 1) != numSet.end()) {
                currentNum++;
                currentStreak++;
            }

            // 更新最长序列长度
            longestStreak = max(longestStreak, currentStreak);
        }
    }

    return longestStreak;
}
```

```cpp
    int longestConsecutive(vector<int>& nums) {
        if (nums.size() == 0)
            return 0;
        unordered_map<int,int> numsMap;
        for (int i = 0; i < nums.size(); ++i)
        {
            numsMap[nums[i]] = i;              
        }
        vector<int> tmpVec;
        for (auto it = numsMap.begin(); it != numsMap.end(); ++it)
        {
            tmpVec.emplace_back(it->first);
        }
        sort(tmpVec.begin(), tmpVec.end());
        unordered_map<int, vector<int>> mp;
        int curkey = tmpVec[0];
        mp[curkey] = vector<int>{};
        for (int i = 1; i < tmpVec.size(); ++i) {
            if (curkey + mp[curkey].size() + 1 == tmpVec[i])
                mp[curkey].emplace_back(tmpVec[i]);
            else
                curkey = tmpVec[i];
        }
        int ret = 0;
        for (auto it = mp.begin(); it != mp.end(); ++it) {
            ret = ret > it->second.size() ? ret : it->second.size();
        }
        return ret + 1;
    }
```

- **使用哈希映射存储元素**：
    - 通过 `unordered_map<int, int> numsMap` 将每个元素及其索引存储在映射中。尽管索引在这个问题中并不必要，但这一步是为了后续处理。
- **提取并排序元素**：
    - 将 `numsMap` 中的所有键（即数组中的元素）提取到 `tmpVec` 中，并对其进行排序。这使得后续查找连续序列时更容易。
- **构建连续序列的映射**：
    - 使用另一个 `unordered_map<int, vector<int>> mp` 来存储每个元素及其后续连续元素的列表。`curkey` 变量用于追踪当前的序列起始元素。
    - 遍历 `tmpVec`，检查当前元素是否是连续序列的一部分。如果是，则将其添加到当前序列；如果不是，则更新 `curkey` 为当前元素。
- **计算最长序列长度**：
    - 遍历 `mp`，计算所有连续序列的长度，并找出最长的序列。最终返回最长序列的长度加一（因为序列长度是基于元素数量的，而我们开始时只有一个元素）。
