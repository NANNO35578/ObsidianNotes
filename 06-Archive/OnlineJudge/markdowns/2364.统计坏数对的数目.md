[2364. 统计坏数对的数目](https://leetcode.cn/problems/count-number-of-bad-pairs/)

- **差值计算**：对于每个 `i`，计算 `diff = nums[i] - i`，这是判断坏数对的关键。
- **哈希表计数**：使用 `unordered_map` 来记录每个差值出现的次数。
- **坏数对计数**：对于每个 `i`，当前的坏数对数量为 `i - countMap[diff]`，其中 `countMap[diff]` 是之前出现的满足条件的索引数量。
- **返回结果**：最后返回坏数对的总数。
```cpp
int countBadPairs(const std::vector<int>& nums) {
    int n = nums.size();
    int badPairs = 0;
    std::unordered_map<int, int> countMap;

    for (int i = 0; i < n; ++i) {
        // 计算差值
        int diff = nums[i] - i;
        
        // 计算当前 bad pairs 数量
        // countMap[diff] 是满足条件的 j 的数量
        badPairs += i - countMap[diff];
        
        // 更新计数
        countMap[diff]++;
    }

    return badPairs;
}
```

##### 优化
### 1. 理解坏数对与有效对

- **坏数对定义**：对于数组中的索引对 `(i, j)`（其中 `i < j`），如果满足 `nums[j] - nums[i] != j - i`，则称该对为坏数对。
- **转化思路**：可以等价地将上述条件转化为 `nums[i] - i != nums[j] - j`。因此，我们可以通过计算满足 `nums[i] - i` 相同的对来识别有效对。

### 2. 计算总对数

- **总对数计算**：使用组合数学公式计算总对数，即 n choose 2=n(n−1)2\text{n choose 2} = \frac{n(n-1)}{2}n choose 2=2n(n−1)​。这是所有可能的 `(i, j)` 对的数量。

### 3. 有效对计数

- **哈希表**：使用 `unordered_map` 来存储每个 `nums[i] - i` 的出现次数。这个哈希表的作用是快速查找之前已经遇到的相同差值。

### 4. 遍历数组

- **循环遍历**：
    - 对于每个元素 `nums[i]`，计算 `key = nums[i] - i`。
    - 检查哈希表中是否已经存在这个 `key`：
        - 如果存在，说明之前有多少个 `j` 使得 `nums[j] - j` 与当前 `key` 相同，从而形成有效对。将这个数量加到 `validPairs` 中。
    - 将当前的 `key` 在哈希表中的计数加 1，以便后续的元素可以利用这个信息。

### 5. 计算坏数对数量

- **坏数对计算**：通过从总对数 `totalPairs` 中减去有效对数 `validPairs`，得到坏数对的数量。

### 6. 返回结果

- 最后，返回计算出的坏数对数量。

```cpp
int countBadPairs(const std::vector<int>& nums) {
    int n = nums.size();
    long long totalPairs = static_cast<long long>(n) * (n - 1) / 2; // Total pairs (n choose 2)
    long long validPairs = 0;
    std::unordered_map<long long, long long> countMap;

    for (int i = 0; i < n; ++i) {
        long long key = static_cast<long long>(nums[i]) - i;
        validPairs += countMap[key]; // Count valid pairs for this key
        countMap[key]++; // Update the count for this key
    }

    long long badPairs = totalPairs - validPairs; // Calculate bad pairs
    return badPairs;
}
```
