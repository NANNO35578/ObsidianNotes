[2597. 美丽子集的数目](https://leetcode.cn/problems/the-number-of-beautiful-subsets/)

##### 解题思路
1. **回溯法**：
	- 使用回溯算法生成所有可能的子集。
	- 在每次添加新元素之前，检查当前子集是否仍然保持美丽的性质。
2. **状态检查**： 在检查当前子集时，遍历已经选择的元素，如果新元素与任何一个已经选择的元素的绝对差等于 `k`，则该子集不再美丽。
3. **计数**： 每当找到一个符合条件的非空子集时，计数器加一。
##### 具体步骤
1. **初始化**：
    - 创建一个计数器用以记录美丽子集的数量。
    - 使用一个数组或向量来存储当前的子集元素。
2. **递归函数**：
    - 定义一个递归函数，该函数接收当前索引、子集和计数器作为参数。
    - 在函数中，检查当前子集是否非空，是则增加计数。
3. **选择与回溯**：
    - 对于每个元素，决定是否将其添加到当前子集：
        - 如果添加后仍然满足美丽条件，则递归调用。
        - 回溯时移除最后添加的元素，尝试下一个元素。

```cpp
class Solution {
public:
    int beautifulSubsets(vector<int>& nums, int k) {
        int count = 0;
        vector<int> subset; // 用于存放当前子集
        backtrack(nums, k, 0, subset, count);
        return count;
    }

private:
    void backtrack(vector<int>& nums, int k, int index, vector<int>& subset, int& count) {
        if (!subset.empty()) {
            count++; // 计数非空子集
        }
        
        for (int i = index; i < nums.size(); i++) {
            // 检查当前元素是否可以添加到子集
            if (!isBeautiful(subset, nums[i], k)) {
                continue;
            }
            subset.push_back(nums[i]); // 添加当前元素
            backtrack(nums, k, i + 1, subset, count); // 递归
            subset.pop_back(); // 回溯
        }
    }

    bool isBeautiful(const vector<int>& subset, int num, int k) {
        for (int s : subset) {
            if (abs(s - num) == k) {
                return false; // 不是美丽子集
            }
        }
        return true; // 是美丽子集
    }
};
```

##### 优化
注意到 $nums$ 的长度范围较小，可以考虑枚举所有子集。

枚举子集时，可以考虑是否将第 $i$ 个数加入子集。对于每一个 $nums_i$​，有两种可能：

1. 不将 $nums_i​$ 添加到子集中，无条件满足。
2. 将 $nums_i$​ 添加到子集中，需要满足 $nums_i​−k$ 和 $nums_i​+k$ 还没有被添加到子集中。

为了检查当前子集中已经添加了哪些数，可以使用一个哈希表记录。

```cpp
class Solution {
public:
    int beautifulSubsets(vector<int>& nums, int k) {
        int ans = 0;
        unordered_map<int, int> cnt;
        function<void(int)> dfs = [&](int i) {
            if (i == nums.size()) {
                ans++;
                return;
            }
            dfs(i + 1);
            if (cnt[nums[i] - k] == 0 && cnt[nums[i] + k] == 0) {
                ++cnt[nums[i]];
                dfs(i + 1);
                --cnt[nums[i]];
            }
        };
        dfs(0);
        return ans - 1;
    }
};
```

#### 方法二：动态规划

**思路与算法**

我们可以考虑将每个数根据模 $k$ 的结果进行分组，如果模 $k$ 不同余，那么它们一定不相差 $k$。由于不同组之间的选择不会互相影响，我们只需要计算组内的选法，并把每组的选法相乘就能得到答案。

假设 $arr$ 表示 $nums$ 中模 $k$ 值相等的某一组数排序并去重后组成的数组，$cnt_i​$ 表示 $arr_i$​ 的出现次数。

由于 $arr$ 中数字相互之间的差值都是 $k$ 的整数倍且已经有序，那么只有与 $arr_i$​ 相邻的数字有可能与 $arr_i$​ 相差为 $k$，因此我们只需要考虑相邻的数能否同时选中。

令 $f(i,0)$ 表示 $arr_i$ 不加入子集，$f(i,1)$ 表示 $arr_i$​ 加入子集。

不选择 $arr_i​$ 时，前面的数可以任选，则递推方程为：

$f(i,0)=f(i−1,0)+f(i−1,1)$

当选择 $arr_i​$ 时，其与 $arr_i−1$​ 的差不能为 $k$。由于 $nums$ 中可能有多个值为 $arr_i​$，至少选择其中一个的方案数为 $2cnt_i​−1$。递推方程为：
$$f(a, 1) = \begin{cases} 
f(i-1, 0) + f(i-1, 1) \times (2^{cnt-1}), & arr[i] - arr[i-1] \neq k \\
f(i-1, 0) \times (2^{cnt-1}), & arr[i] - arr[i-1] = k 
\end{cases}$$

初值 $f(0,0)=1，f(0,1)=2cnt_i​−1，f(n−1,0)+f(n−1,1)$ 就是答案。

```cpp
class Solution {
public:
    int beautifulSubsets(vector<int>& nums, int k) {
        unordered_map<int, map<int, int>> groups;
        for (int a : nums) {
            ++groups[a % k][a];
        }
        int ans = 1;
        for (auto& [_, g] : groups) {
            int m = g.size();
            vector<vector<int>> f(m, vector<int>(2, 0));
            f[0][0] = 1, f[0][1] = (1 << g.begin()->second) - 1;
            int i = 1;
            for (auto it = next(g.begin()); it != g.end(); it++, i++) {
                f[i][0] = f[i - 1][0] + f[i - 1][1];
                if (it->first - prev(it)->first == k) {
                    f[i][1] = f[i - 1][0] * ((1 << it->second) - 1);
                } else {
                    f[i][1] =
                        (f[i - 1][0] + f[i - 1][1]) * ((1 << it->second) - 1);
                }
            }
            ans *= f[m - 1][0] + f[m - 1][1];
        }
        return ans - 1;
    }
};

```
