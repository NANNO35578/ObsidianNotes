[旋转数组的最小数字](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457523390)
- ==二分法==
- **空数组处理**：添加了对空数组的检查。
- **更新最小值**：在每次迭代中更新 `minN`。
- **边界调整逻辑**：根据 `nums[mid]` 和 `nums[r]` 的比较来调整 `l` 和 `r` 的值。
- **最后的最小值检查**：确保在循环结束后检查 `l` 位置的值。

```cpp
    int minNumberInRotateArray(vector<int>& nums) {
        // write code here
	    if (nums.empty()) return 0; // 处理空数组的情况
	 
	    int l = 0;
	    int r = nums.size() - 1;
	    int minN = INT_MAX;
	 
	    while (l < r) {
	        int mid = l + (r - l) / 2;
	 
	        // 更新最小值
	        minN = min(minN, nums[mid]);
	 
	        // 检查中间值是否在旋转数组的右半部分
	        if (nums[mid] > nums[r]) {
	            l = mid + 1; // 最小值在右半边
	        } else if (nums[mid] < nums[r]) {
	            r = mid; // 最小值可能在左半边或是当前中间
	        } else {
	            r--; // 处理重复元素
	        }
	    }
	 
	    // 最后检查 l 位置的值
	    minN = min(minN, nums[l]);
	     
	    return minN;
    }
```
