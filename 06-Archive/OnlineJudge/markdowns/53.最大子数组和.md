[53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)


##### 前缀和
- 最大和的子数组和即前缀和中最大减去最小
1. **初始化变量**：
    - `maxSum` 用于存储当前找到的最大子数组和，初始值设为最小整数。
    - `minPreSum` 用于存储遍历过程中计算得到的最小前缀和，初始值为 0。
    - `currentSum` 用于跟踪当前的前缀和，初始值为 0。
2. **遍历数组**：
    - 对于输入数组 `nums` 中的每个元素：
        - 将当前元素加到 `currentSum` 中，更新前缀和。
        - 计算当前子数组和：通过 `currentSum - minPreSum` 计算以当前位置为结尾的子数组的和，并更新 `maxSum`，如果此值更大。
        - 更新 `minPreSum`：将当前的 `currentSum` 与 `minPreSum` 进行比较，以便在后续循环中使用。
3. **返回结果**：
    - 遍历完成后，`maxSum` 中存储的就是数组的最大子数组和，返回该值。
```cpp
int maxSubArray(std::vector<int>& nums) {
    int maxSum = std::numeric_limits<int>::min(); // 初始化最大和为最小整数
    int minPreSum = 0;                            // 初始化最小前缀和为0
    int currentSum = 0;                           // 当前前缀和

    for (int num : nums) {
        currentSum += num;                        // 更新当前前缀和
        maxSum = std::max(maxSum, currentSum - minPreSum); // 更新最大子数组和
        minPreSum = std::min(minPreSum, currentSum); // 更新最小前缀和
    }

    return maxSum;
}
```

##### 动态规划
Kadane’s Algorithm（卡登算法）用于求解最大子数组和，主要原理如下：

1. **状态定义**：
    - **`currentMax`**：表示以当前元素为结尾的最大子数组和。
    - **`globalMax`**：表示遍历过程中发现的最大子数组和。
2. **状态转移**：
    - 对于每个元素 `nums[i]`，可以选择两种情况：
        - **只包含当前元素**：即 `nums[i]`。
        - **包含当前元素和之前的子数组**：即 `currentMax + nums[i]`。
    - 通过比较这两个值，更新 `currentMax`：$$currentMax=max(nums[i],currentMax+nums[i])$$
3. **全局最大值更新**：
    - 在每一步，检查 `currentMax` 是否大于 `globalMax`，如果是，则更新 `globalMax`：$$globalMax=max(globalMax,currentMax)$$
4. **初始化**：
    - 将 `currentMax` 和 `globalMax` 初始化为数组的第一个元素，以便在处理负数时也能正确计算。

```cpp
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        
        int currentMax = nums[0];
        int globalMax = nums[0];
        
        for (int i = 1; i < n; i++) {
            currentMax = max(nums[i], currentMax + nums[i]);
            globalMax = max(globalMax, currentMax);
        }
        
        return globalMax;
    }
```
