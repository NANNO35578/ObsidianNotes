[300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)


### 方法一：动态规划 O($n^2$)

1. **定义状态**： 使用一个数组 `dp`，其中 `dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列的长度
2. **状态转移**：对于每一个元素 `nums[i]`，我们遍历前面的所有元素 `nums[j]`（`j < i`），如果 `nums[j] < nums[i]`，则可以更新 `dp[i]`： `dp[i] = max(dp[i], dp[j] + 1)`
3. **初始化**：每个元素自身可以作为一个子序列，所以 `dp[i]` 初始值为 1
4. **结果**：最长递增子序列的长度就是 `dp` 数组中的最大值

```cpp
int lengthOfLIS(vector<int>& nums) {
    if (nums.empty()) return 0;

    vector<int> dp(nums.size(), 1); // 初始化 dp 数组
    int maxLength = 1;

    for (int i = 1; i < nums.size(); ++i) {
        for (int j = 0; j < i; ++j) {
            if (nums[j] < nums[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        maxLength = max(maxLength, dp[i]);
    }

    return maxLength;
}
```

### 方法二：贪心 + 二分查找 O($nlog_n$)

1. **维护一个数组**：使用一个数组 `tails` 来存储当前找到的递增子序列的最小尾部元素
2. **二分查找**：对于每个元素 `num`，使用二分查找在 `tails` 中找到第一个大于或等于 `num` 的位置. 如果找到了，更新这个位置的值；如果没有找到，说明 `num` 可以扩展当前子序列
3. `tails` 数组的长度就是最长递增子序列的长度

```cpp
int lengthOfLIS(vector<int>& nums) {
    vector<int> tails;

    for (const int& num : nums) {
        auto it = lower_bound(tails.begin(), tails.end(), num);
        if (it == tails.end()) {
            tails.push_back(num); // 新增一个更大的元素
        } else {
            *it = num; // 更新已存在的元素
        }
    }

    return tails.size();
}
```
