
[面试题 17.18. 最短超串](https://leetcode.cn/problems/shortest-supersequence-lcci/)

> 假设你有两个数组，一个长一个短，短的元素均不相同。找到长数组中包含短数组所有的元素的最短子数组，其出现顺序无关紧要。
> 返回最短子数组的左端点和右端点，如有多个满足条件的子数组，返回左端点最小的一个。若不存在，返回空数组。

##### 滑动窗口和哈希表
- **哈希表记录短数组元素**：使用一个哈希表（或 unordered_map）记录短数组中的每个元素及其出现次数。
- **滑动窗口**：使用两个指针（`left` 和 `right`）来维护一个滑动窗口，遍历长数组。
- **扩展窗口**：移动 `right` 指针，逐步将元素加入当前窗口，并更新哈希表中对应元素的计数。
- **判断包含条件**：每次移动 `right` 指针后，检查当前窗口是否包含短数组中的所有元素。可以使用一个计数器来跟踪当前窗口中已满足条件的短数组元素的数量。
- **收缩窗口**：当窗口满足条件时，尝试移动 `left` 指针收缩窗口，直到不再满足条件为止，同时记录当前满足条件的最小窗口。
- **返回结果**：如果找到合法的窗口，返回其左端点和右端点；如果没有找到，返回空数组。
```cpp
     std::unordered_map<int, int> shortMap;
     for (int num : small) {
         shortMap[num]++;
     }

     int required = shortMap.size();
     int left = 0, right = 0, formed = 0;
     std::unordered_map<int, int> windowMap;
     int minLength = std::numeric_limits<int>::max();
     std::vector<int> result;

     while (right < big.size()) {
         int rightChar = big[right];
         windowMap[rightChar]++;

         if (shortMap.count(rightChar) &&
             windowMap[rightChar] == shortMap[rightChar]) {
             formed++;
         }

         while (left <= right && formed == required) {
             int leftChar = big[left];

             if (right - left + 1 < minLength) {
                 minLength = right - left + 1;
                 result = {left, right};
             }

             windowMap[leftChar]--;
             if (shortMap.count(leftChar) &&
                 windowMap[leftChar] < shortMap[leftChar]) {
                 formed--;
             }
             left++;
         }
         right++;
     }

     return result.empty() ? std::vector<int>() : result;
 }
```
