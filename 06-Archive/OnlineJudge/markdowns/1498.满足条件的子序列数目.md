[1498. 满足条件的子序列数目](https://leetcode.cn/problems/number-of-subsequences-that-satisfy-the-given-sum-condition/) 

----


##### 方法一：排序 + 双指针

1. **排序**: 先将 `nums` 升序排序，这样最小值和最大值就分别出现在区间两端
2. **预处理 2 的幂**  
   定义 `pow2[k] = 2^k mod (1e9+7)`，用于快速计算“某个长度为 k 的区间，任意选或不选”的子集数（每个元素二选一，故有 `2^k` 种可能）
3. **双指针枚举**  
   - 用 `i` 指向最小元素候选（从左向右推进），用 `j` 指向最大元素候选（从右向左推进）
   - 若 `nums[i] + nums[j] <= target`，说明在区间 `[i, j]` 里：
     - 我们**必须**选 `nums[i]`（作为最小元素）和**可以自由选或不选** `(j - i)` 个其它元素，因而子序列数为 `2^(j-i)` 
     - 将 `i` 向右移一位，考虑下一个最小元素
   - 否则如果 `nums[i] + nums[j] > target`，说明当前 `j` 太大，必须将 `j` 左移，缩小区间
4. **累加答案**  
   双指针遍历结束后，所有满足条件的子序列都被计入

$O(n log_2(n) )$  

```cpp
class Solution {
public:
	using ll = long long;
	const int MOD = 1e9 + 7;
	
    int numSubseq(vector<int>& nums, int target) {
        int n = nums.size();
        sort(nums.begin(), nums.end());
        // 预处理 pow2[i] = 2^i % MOD
        vector<int> pow2(n+1, 1);
        for (int i = 1; i <= n; ++i)
          pow2[i] = (pow2[i-1] * 2LL) % MOD;
        
        ll ans = 0;
        int i = 0, j = n - 1;
        // 双指针：当 nums[i] + nums[j] <= target 时，
        // 以 nums[i] 为最小元素，区间 (i, j] 上任取子集都合法，共 2^(j-i) 种
        while (i <= j) {
            if (nums[i] + nums[j] <= target) {
                ans = (ans + pow2[j - i]) % MOD;
                ++i;
            } else 
              --j;
        }
        return (int)ans;
    }
};
```

##### 方法二：排序 + 二分查找

1. **排序**  **预处理 2 的幂**  
2. **枚举最小值 + 二分确定最大值**  
   对每个下标 `i`（作为子序列的最小元素）：
   - 计算剩余容量 `rem = target - nums[i]`
   - 在区间 `[i, n-1]` 中，用二分查找找到最后一个 `nums[pos] ≤ rem` 的位置 `pos`
   - 在 `[i, pos]` 范围里：
     - 必选 `nums[i]`，其它 `pos - i` 个数自由取或不取，共 `2^(pos-i)` 种子序列 
   - 累加到答案


```cpp
class Solution {
public:
	using ll = long long;
	const int MOD = 1e9 + 7;
	
    int numSubseq(vector<int>& nums, int target) {
        int n = nums.size();
        sort(nums.begin(), nums.end());
        // 预处理 pow2[i] = 2^i % MOD
        vector<int> pow2(n+1, 1);
        for (int i = 1; i <= n; ++i) {
            pow2[i] = (pow2[i-1] * 2LL) % MOD;
        }
        
        ll ans = 0;
        // 对每个 i 作为最小元素，二分寻找最大下标 j 使得 nums[i] + nums[j] <= target
        for (int i = 0; i < n; ++i) {
            int rem = target - nums[i];
            // upper_bound 找到第一个 > rem 的位置，减一即为最大合法 j
            int lo = i, hi = n - 1, pos = i - 1;
            while (lo <= hi) {
                int mid = (lo + hi) >> 1;
                if (nums[mid] <= rem) {
                    pos = mid;
                    lo = mid + 1;
                } else {
                    hi = mid - 1;
                }
            }
            if (pos >= i) {
                // 区间 [i, pos] 长度 = pos-i+1，必须选 nums[i]，其它 pos-i 元素自由取舍 => 2^(pos-i)
                ans = (ans + pow2[pos - i]) % MOD;
            }
        }
        return (int)ans;
    }
};
```
