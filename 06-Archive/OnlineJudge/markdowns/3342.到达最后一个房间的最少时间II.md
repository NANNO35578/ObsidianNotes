[3342. 到达最后一个房间的最少时间 II](https://leetcode.cn/problems/find-minimum-time-to-reach-last-room-ii/)

1. **问题理解**：
    
    - 在一个 `n x m` 的网格中，每个房间有一个最早可进入的时间 `moveTime[i][j]`。
    - 从 `(0, 0)` 出发，每次移动到相邻房间的时间依赖于上一次移动的次数：第一次为 1 秒，第二次为 2 秒，依此类推。移动次数的奇偶性决定了当前移动的时间。
2. **数据结构**：
    
    - 使用一个三维数组 `d[n][m][2]` 来记录到达每个房间的最短时间，`d[i][j][0]` 表示偶数次移动时的时间，`d[i][j][1]` 表示奇数次移动时的时间。
    - 使用优先队列（最小堆）来处理待访问的房间，保证总是处理当前最小的时间。
3. **初始化**：
    
    - 将起点 `(0, 0)` 的偶次移动时间初始化为 `0`，将奇次移动时间初始化为无穷大。
4. **Dijkstra 算法**：
    
    - 从起点开始，将初始状态 `(0, 0)` 和时间 `0` 加入优先队列。
    - 当队列不为空时：
        - 取出当前时间最小的状态 `(currentTime, x, y, parity)`。
        - 如果当前房间是终点 `(n - 1, m - 1)`，返回当前时间。
        - 遍历四个相邻房间（上、下、左、右）：
            - 检查新房间的坐标是否在网格范围内。
            - 计算到达新房间的时间，具体为：
                - 如果 `parity` 为 `0`（偶数次移动），则当前移动时间为 `1`；如果为 `1`（奇数次移动），则时间为 `2`。
                - 计算到达时间为 `max(currentTime, moveTime[newX][newY]) + moveCount`。
            - 切换奇偶状态，更新 `newParity` 为 `1 - parity`。
            - 如果找到更快的到达方式，更新 `d[newX][newY][newParity]` 并将新状态加入优先队列。
5. **结束条件**：
    
    - 如果最终无法到达终点，返回 `-1`。

```cpp
int minTimeToReachEnd(const vector<vector<int>>& moveTime) {
    int n = moveTime.size();
    int m = moveTime[0].size();
    
    // d[i][j][0] 表示到达 (i,j) 偶数次移动的最短时间
    // d[i][j][1] 表示到达 (i,j) 奇数次移动的最短时间
    vector<vector<vector<long long>>> d(n, vector<vector<long long>>(m, vector<long long>(2, LLONG_MAX)));
    d[0][0][0] = 0; // 从 (0, 0) 开始，初始为偶数次移动

    // 优先队列存储 (时间, 行, 列, 移动次数的奇偶性)
    priority_queue<tuple<long long, int, int, int>, vector<tuple<long long, int, int, int>>, greater<tuple<long long, int, int, int>>> pq;
    pq.emplace(0, 0, 0, 0); // 初始状态

    // 四个方向：上下左右
    vector<int> directions = {-1, 0, 1, 0, -1, 0};

    while (!pq.empty()) {
        auto [currentTime, x, y, parity] = pq.top();
        pq.pop();

        // 如果到达终点，返回时间
        if (x == n - 1 && y == m - 1) {
            return currentTime;
        }

        // 遍历相邻的房间
        for (int i = 0; i < 4; ++i) {
            int newX = x + directions[i];
            int newY = y + directions[i + 1];

            // 检查边界
            if (newX >= 0 && newX < n && newY >= 0 && newY < m) {
                // 计算到达新房间所需的时间
                long long moveCount = (parity == 0) ? 1 : 2; // 偶数次移动时间为 1，奇数次为 2
                long long arriveTime = max(currentTime, static_cast<long long>(moveTime[newX][newY])) + moveCount;

                // 更新状态
                int newParity = 1 - parity; // 切换奇偶状态

                // 如果找到更快的到达方式
                if (arriveTime < d[newX][newY][newParity]) {
                    d[newX][newY][newParity] = arriveTime;
                    pq.emplace(arriveTime, newX, newY, newParity);
                }
            }
        }
    }

    return -1; // 如果无法到达终点，返回 -1
}
```
