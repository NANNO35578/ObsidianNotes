[链表的奇偶重排](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457456649)
- **初始化指针**：
    - `fast` 指向链表的第一个节点（奇数位置）。
    - `slow` 指向链表的第二个节点（偶数位置）。
    - `even` 保存偶数位置链表的头节点，用于最后连接。
    - `mF` 用于记录当前处理的奇数节点。
- **遍历链表**：
    - 使用 `while (slow != nullptr)` 循环遍历偶数节点。
    - 在每次迭代中，检查 `fast->next->next` 是否为 `nullptr`，如果是，则将 `fast` 的下一个节点设为 `nullptr`，并退出循环。
    - 更新 `mF` 到当前的 `fast`。
    - 更新 `fast` 为下一个奇数节点（即 `fast->next->next`）。
    - 将 `slow->next` 指向下一个偶数节点（即 `fast->next`），并更新 `slow`。
- **连接奇数和偶数列表**：在循环结束后，将奇数链表的最后一个节点的下一个节点指向偶数链表的头节点 `even`。
```cpp
    ListNode* oddEvenList(ListNode* head) {
        // write code here
        if(head==nullptr||head->next==nullptr)return head;
        ListNode* fast = head;
        ListNode* slow = head->next;
        ListNode* even = head->next;
        ListNode* mF = fast;
 
        while (slow != nullptr) {
            if (fast->next->next == nullptr) {
                fast->next = nullptr;
                break;
            }
 
            mF = fast;
            fast = fast->next->next;
            slow->next = fast->next;
            slow = fast->next;
            mF->next = fast;
        }
        fast->next = even;
        return head;
    }
```
