[检查平衡数](https://leetcode.cn/problems/check-balanced-string/description/)
- **初始化和遍历**：
    - 使用变量 `s` 来累计加权和。
    - 遍历字符串 `num` 中的每个字符，`i` 代表当前字符的权重，初始为 1。
- **加权和计算**：
    - 对于每个字符 `ch`，将其转换为数字（通过 `ch - '0'`），并乘以当前权重 `i`。
    - 将结果累加到 `s` 中。
    - 权重 `i` 在每次迭代后取反，即在每次循环中交替为正负。
- **判断平衡**：
    - 最后，检查 `s` 是否为零。如果为零，则说明数字是平衡的，返回 `true`；否则返回 `false`

```cpp
    bool isBalanced(string num) {
        int s = 0;
        for (int i = 1; char ch : num) {
            s += i * (ch - '0'), i = -i;
        }
        return !s;
    }
```

##### 字符 ASCII 值的加减

- **初始化和遍历**：
    - 使用变量 `sum` 来累计和。
    - 使用 `for` 循环遍历字符串 `num`，但循环变量 `i` 设为 `0`，并在循环中手动更新。
- **加权和计算**：
    - 在每次循环中，首先从 `sum` 中减去当前字符的 ASCII 值（`num[i++]`）。
    - 接着检查 `i` 是否已达到字符串末尾，如果是则跳出循环。
    - 如果没有到达末尾，接着累加下一个字符的 ASCII 值到 `sum` 中。
- **判断平衡**：
    - 最后返回 `sum` 是否等于 `-48` 或 `0`。这里 `-48` 是因为字符 `'0'` 的 ASCII 值是 `48`，因此 `sum` 为 `-48` 意味着正负字符的加权和抵消。

```cpp
    bool isBalanced(string num) {
        int sum = 0;
        for (int i = 0; i < num.size();) {
            sum -= num[i++];
            if (i == num.size()) break;
            sum += num[i++];
        }
        return sum==-48||sum==0;
    }
```
