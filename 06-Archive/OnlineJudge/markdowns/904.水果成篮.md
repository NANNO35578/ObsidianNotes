[904. 水果成篮](https://leetcode.cn/problems/fruit-into-baskets/) 

----

## 方法一：滑动窗口 + 哈希表


1. 维护左右指针 `[l, r]`，窗口内用一个 `unordered_map<int,int> cnt` 记录每种水果的出现次数
2. 右指针不断向右扩展，将 `fruits[r]` 加入 `cnt`
3. 若 `cnt.size() > 2`，说明超过两种水果，左指针 `l` 向右收缩，直到恰好剩下 ≤2 种
4. 每次扩展后更新答案 `res = max(res, r-l+1)`

```cpp
    int totalFruit(vector<int>& fruits) {
        unordered_map<int,int> cnt;
        int l = 0, res = 0;
        for (int r = 0; r < (int)fruits.size(); r++) {
            cnt[fruits[r]]++;
            // 当超过两种水果时，左指针收缩
            while (cnt.size() > 2) {
                if (--cnt[fruits[l]] == 0)
                    cnt.erase(fruits[l]);
                l++;
            }
            res = max(res, r - l + 1);
        }
        return res;
    }
```

## 方法二：双指针

*常数空间优化*
1. 只记录“最近两种水果” `last`、`second_last`，以及当前窗口长度 `curr`，和“尾部连续 `last` 的数量” `lastCount`
2. 遍历 `fruits[i]`：
    - 若 `fruits[i]` 等于 `last` 或 `second_last`，则 `curr++`；
    - 否则，窗口被第三种水果打断，重置 `curr = lastCount + 1`（保留尾部所有 `last`，再加上当前这棵树）
3. 更新尾部统计：
    - 若 `fruits[i] == last`，`lastCount++`；
    - 否则，将 `(second_last, last) = (last, fruits[i])`，并重置 `lastCount = 1`
4. 每步更新 `res = max(res, curr)`

```cpp
    int totalFruit(vector<int>& fruits) {
        int n = fruits.size();
        if (n < 3) return n;

        int second_last = -1;     // 倒数第二种水果
        int last = fruits[0];     // 最后一种水果
        int lastCount = 1;        // 窗口末尾连续 last 的个数
        int curr = 1;             // 当前窗口大小
        int res = 1;

        for (int i = 1; i < n; i++) {
            int f = fruits[i];
            // 如果是现有两种中的一种，窗口可继续
            if (f == last || f == second_last) {
                curr++;
            } else {
                // 遇到第三种，重置窗口长度
                curr = lastCount + 1;
            }
            // 更新尾部连续 last 的计数，及 last/second_last
            if (f == last) {
                lastCount++;
            } else {
                second_last = last;
                last = f;
                lastCount = 1;
            }
            res = max(res, curr);
        }
        return res;
    }
```
