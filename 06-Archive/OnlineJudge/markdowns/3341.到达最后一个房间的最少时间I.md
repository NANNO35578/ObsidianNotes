[3341. 到达最后一个房间的最少时间 I](https://leetcode.cn/problems/find-minimum-time-to-reach-last-room-i/)

### 代码思路

1. **问题理解**：
    
    - 我们有一个 `n x m` 的网格，每个房间有一个最早可以进入的时间 (`moveTime[i][j]`)。
    - 你需要从起点 `(0, 0)` 到达终点 `(n-1, m-1)`，每次移动到相邻的房间需要 1 秒。
2. **数据结构**：
    
    - 使用一个优先队列（最小堆）来存储待处理的房间，按到达时间排序。
    - 使用一个二维数组 `d` 来记录到达每个房间的最短时间，初始化为无穷大（`INT_MAX`），起点的时间设为 0。
3. **Dijkstra 算法**：
    
    - 初始化优先队列，将起点 `(0, 0)` 和时间 `0` 放入队列。
    - 当队列不为空时，取出当前时间最小的房间 `(currentTime, x, y)`。
    - 如果当前房间是终点 `(n-1, m-1)`，返回当前时间。
    - 遍历四个方向（上、下、左、右），计算移动到相邻房间的时间：
        - 计算到达新房间的时间为 `max(currentTime, moveTime[newX][newY]) + 1`。
        - 如果这个时间小于之前记录的时间，更新 `d[newX][newY]` 并将新状态加入优先队列。
4. **边界检查**：
    
    - 确保新房间的坐标在网格范围内，避免越界。
5. **返回值**：
    
    - 如果最终无法到达终点，返回 -1。

```cpp
int minTimeToReach(vector<vector<int>>& moveTime) {
    int n = moveTime.size();
    int m = moveTime[0].size();
    vector<vector<int>> d(n, vector<int>(m, INT_MAX));
    d[0][0] = 0;

    // 优先队列存储 (时间, 行, 列)
    priority_queue<tuple<int, int, int>, vector<tuple<int, int, int>>, greater<tuple<int, int, int>>> pq;
    pq.emplace(0, 0, 0); // 从 (0, 0) 开始

    // 四个方向：上下左右
    vector<int> directions = {-1, 0, 1, 0, -1, 0};

    while (!pq.empty()) {
        auto [currentTime, x, y] = pq.top();
        pq.pop();

        // 如果到达终点，返回时间
        if (x == n - 1 && y == m - 1) {
            return currentTime;
        }

        // 遍历相邻的房间
        for (int i = 0; i < 4; ++i) {
            int newX = x + directions[i];
            int newY = y + directions[i + 1];

            // 检查边界
            if (newX >= 0 && newX < n && newY >= 0 && newY < m) {
                // 计算到达新房间所需的时间
                int arriveTime = max(currentTime, moveTime[newX][newY]) + 1;

                // 如果找到更快的到达方式
                if (arriveTime < d[newX][newY]) {
                    d[newX][newY] = arriveTime;
                    pq.emplace(arriveTime, newX, newY);
                }
            }
        }
	}

    return -1; // 如果无法到达终点，返回 -1
}
```


#### 方法一：最短路 + Dijkstra

**思路与算法**

题目给定一个大小为 `n×m` 的二维数组，需求解从位置 `(0,0)` 移动到位置 `(n−1,m−1)` 所需的最短时间。移动时，可以从当前位置移动到上下左右四个位置，并且每个位置有最早的移动时间，在该时间之后才可往该位置移动。

因此，二维数组可以看作一个大小为 `n×m` 的无向图，位置 `(i,j)` 有连向 `(i−1,j)、(i+1,j)、(i,j−1)、(i,j+1)` 的无向边，我们要求解 `(0,0)` 到 `(n−1,m−1)` 的最短路。

求解最短路的算法有很多，我们这里选用 Dijkstra，可以参考「[网络延迟时间](https://leetcode.cn/problems/network-delay-time/solutions/909575/wang-luo-yan-chi-shi-jian-by-leetcode-so-6phc/)」的题解来了解 Dijkstra 的基本流程。

与普通的 Dijkstra 不同的是，在本题中，我们设 `d[i][j]` 表示从 `(0,0)` 到 `(i,j)` 所需的最短时间，那么从 `(i,j)` 走到相邻坐标 `(u,v)` 的时间为 `max(d[i][j],moveTime[u][v])+1`。其他过程与 Dijkstra 一致。

**代码**
```cpp
class Solution {
    struct State {
        int x;
        int y;
        int dis;
        State(int x, int y, int dis) : x(x), y(y), dis(dis) {};
        bool operator < (const State &rth) const {
            return dis > rth.dis;
        } 
    };
public:
    const int inf = 0x3f3f3f3f;
    int minTimeToReach(vector<vector<int>>& moveTime) {
        int n = moveTime.size(), m = moveTime[0].size();
        vector<vector<int>> d(n, vector<int>(m, inf));
        vector<vector<int>> v(n, vector<int>(m, 0));

        int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        d[0][0] = 0;
        priority_queue<State> q;
        q.push(State(0, 0, 0));

        while (q.size()) {
            State s = q.top();
            q.pop();
            if (v[s.x][s.y]) {
                continue;
            }
            v[s.x][s.y] = 1;
            for (int i = 0; i < 4; i++) {
                int nx = s.x + dirs[i][0];
                int ny = s.y + dirs[i][1];
                if (nx < 0 || nx >= n || ny < 0 || ny >= m) {
                    continue;
                }
                int dist = max(d[s.x][s.y], moveTime[nx][ny]) + 1;
                if (d[nx][ny] > dist) {
                    d[nx][ny] = dist;
                    q.push(State(nx, ny, dist));
                }
            }
        }
        return d[n - 1][m - 1];
    }
};

```
