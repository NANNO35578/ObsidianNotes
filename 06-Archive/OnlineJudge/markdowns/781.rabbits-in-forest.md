[兔子数量](https://leetcode.cn/problems/rabbits-in-forest/description/?envType=daily-question&envId=2025-04-20)
- **理解回答**：如果一只兔子回答 `k`，意味着它有 `k` 只与它颜色相同的兔子。因此，实际上这一组颜色的兔子总数是 `k + 1`（包括它自己）。
- **计数**：我们可以用一个哈希表（或字典）来统计每个回答出现的次数。
- **计算最少数量**：
    - 对于每个不同的回答 `k`，我们需要计算出至少需要多少只兔子。假设某个回答 `k` 出现了 `count` 次，那么这组兔子至少需要 `ceil(count / (k + 1)) * (k + 1)` 只兔子。
```cpp
    int numRabbits(vector<int>& answers) {
        int ttl = 0;
        unordered_map<int, int> hasnum;
        for(int i = 0;i<answers.size();i++){
            if(hasnum.find(answers[i]) == hasnum.end()){
                ttl += answers[i]+1;
                hasnum[answers[i]] = 1;
            }
            else{
                if(hasnum[answers[i]]%(answers[i]+1) == 0){
                    ttl += answers[i]+1;
                }
                hasnum[answers[i]] += 1;

            }
        }
        return ttl;
    }
```
