[2270. 分割数组的方案数](https://leetcode.cn/problems/number-of-ways-to-split-array/)

##### 前缀和

计算前 `i+1` 个元素的和，并与剩余元素的和进行比较

1. *计算总和*：首先计算整个数组的和 `totalSum`
2. *计算前缀和*：通过遍历数组计算前缀和 `prefixSum`
3. *判断合法分割*：对于每一个可能的分割点 `i`，检查 `prefixSum[i]` 是否大于等于 `totalSum - prefixSum[i]`

```cpp
int waysToSplitArray(vector<int>& nums) {
    int n = nums.size();
    if (n < 2) return 0; // 至少需要两个元素

    long long totalSum = 0;
    for (int num : nums) {
        totalSum += num;
    }

    long long prefixSum = 0;
    int count = 0;

    for (int i = 0; i < n - 1; ++i) {
        prefixSum += nums[i];
        // 检查合法分割条件
        if (prefixSum >= (totalSum - prefixSum)) {
            count++;
        }
    }

    return count;
}
```

#### 枚举 + 前缀和
我们只需要枚举所有的分割位置，并找出其中的合法分割即可

用 left 和 right 分别表示分割左侧和右侧的所有元素之和
初始时，left=0，right 的值为给定数组 nums 的所有元素之和
- 从小到大依次枚举每一个分割位置，当枚举到位置 i 时，我们将 left 加上 `nums[i]`，并将 right 减去 `nums[i]`，这样就可以实时正确地维护分割左侧和右侧的元素之和
如果 left≥right，那么就找出了一个合法分割
 ##### 初始化
- **`left`**：用于存储前 `i+1` 个元素的和
- **`right`**：用于存储从 `i+1` 开始到数组末尾的元素的和。初始时为整个数组的总和
- 使用 `accumulate` 函数计算整个数组的总和，并将其赋值给 `right`
- `left` 初始化为 0，因为开始时没有任何元素
 ##### 遍历
- 使用 `for` 循环遍历数组，循环的条件是 `i < n - 1`，保证 `i` 的右边至少有一个元素
- 在每次迭代中，更新 `left` 和 `right`：
    - 将当前元素 `nums[i]` 加入 `left`
    - 从 `right` 中减去 `nums[i]`，更新剩余元素的和
 ##### 判断
- 在每次迭代后，判断 `left >= right`。如果成立：
    - 说明前 `i+1` 个元素的和大于或等于剩余元素的和，`i` 是一个合法的分割点
    - 将计数器 `ans` 加一

```cpp
    int waysToSplitArray(vector<int>& nums) {
        int       n     = nums.size();
        long long left  = 0;
        long long right = accumulate(nums.begin(),nums.end(),0LL);
        int       ans   = 0;
        for(int i=0;i<n-1;i++) {
            left  = left+nums[i];
            right = right-nums[i];
            if(left>=right) {
                ans++;
            }
        }
        return ans;
    }
```
