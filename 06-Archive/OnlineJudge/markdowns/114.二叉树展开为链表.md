[114. 二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)
##### 栈存储右孩子 用于遍历
- 如果 `root` 为 `null`，直接返回。
- 使用栈来存储节点，以实现先序遍历。
- 在遍历过程中，更新每个节点的右指针指向下一个节点，左指针设置为 `null`。
- 先将右子树入栈，再将左子树入栈，以确保遍历顺序。


```cpp
void flatten(TreeNode* root) {
    if (!root) return;

    // 使用栈来模拟先序遍历
    std::stack<TreeNode*> nodeStack;
    nodeStack.push(root);
    
    TreeNode* prev = nullptr;

    while (!nodeStack.empty()) {
        TreeNode* current = nodeStack.top();
        nodeStack.pop();

        // 连接前一个节点和当前节点
        if (prev) {
            prev->right = current;
            prev->left = nullptr; // 左指针始终为 null
        }

        // 先将右子树入栈，再将左子树入栈，以保持先序遍历的顺序
        if (current->right) {
            nodeStack.push(current->right);
        }
        if (current->left) {
            nodeStack.push(current->left);
        }

        // 更新前一个节点
        prev = current;
    }
}
```

# 寻找前驱节点
- 如果一个节点的左子节点为空，则该节点不需要进行展开操作。
- 如果一个节点的左子节点不为空，则该节点的左子树中的最后一个节点被访问之后，该节点的右子节点被访问。
- 该节点的左子树中最后一个被访问的节点是左子树中的最右边的节点，也是该节点的前驱节点。
 
因此，问题转化成寻找当前节点的前驱节点。

- 具体做法是，对于当前节点，如果其左子节点不为空，则在其左子树中找到最右边的节点，作为前驱节点，将当前节点的右子节点赋给前驱节点的右子节点，然后将当前节点的左子节点赋给当前节点的右子节点，并将当前节点的左子节点设为空。
- 对当前节点处理结束后，继续处理链表中的下一个节点，直到所有节点都处理结束。

```cpp
    void flatten(TreeNode* root) {
        TreeNode *curr = root;
        while (curr != nullptr) {
            if (curr->left != nullptr) {
                auto next = curr->left;
                auto predecessor = next;
                while (predecessor->right != nullptr) {
                    predecessor = predecessor->right;
                }
                predecessor->right = curr->right;
                curr->left = nullptr;
                curr->right = next;
            }
            curr = curr->right;
        }
    }
```
