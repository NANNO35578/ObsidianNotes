[1206. 设计跳表](https://leetcode.cn/problems/design-skiplist/) [OI Wiki 跳表](https://oi-wiki.org/ds/skiplist/)

## 每四元素提升一层
##### 节点（Node）
- 每个节点包含：
	- `val`：节点值
	- `forward`：一个指针数组，`forward[i]` 指向第 `i` 层的下一个节点
##### 头节点（header）
- 头节点值为负无穷（或其他特殊值），拥有最大层数的 forward 指针。
##### 层数（level）
- 跳表有多层，第 0 层包含所有节点，每高一层节点数减少
- 层数提升规则为：每4个节点提升一层，即第 0 层每4个节点中有1个会出现在第 1 层，第 1 层每4个节点中有1个会出现在第 2 层，依此类推
##### 层数分配规则
- 每插入一个新节点时，统计当前节点总数 `nodeCount`
- 新节点的层数 `level` 由 `nodeCount` 决定：
	- 初始 `level = 1`
	- 只要 `nodeCount` 能被 4 整除，`level++`
	- 继续用 `nodeCount/4` 判断能否再提升一层，直到不能整除或达到最大层数
	- 这样保证每4个节点提升一层，层数分布均匀且可预测

*查找（search）*
- 从最高层开始，逐层向下查找
- 在每一层，沿着 forward 指针向右，直到遇到大于等于目标值的节点
- 若第 0 层找到目标值，则返回 true，否则 false

*插入（add）*
- 记录每一层最后一个小于目标值的节点（update 数组）
- 随机生成新节点的层数
- 若新节点层数超过当前最大层数，提升头节点的 forward 指针
- 在每一层插入新节点，调整指针

*删除（erase）*
- 记录每一层最后一个小于目标值的节点（update 数组）
- 若第 0 层找到目标值，逐层断开指针，释放节点内存
- 若某一层已无节点，降低当前最大层数

```cpp
class Skiplist {
    struct Node {
        int val;
        std::vector<Node*> forward;
        Node(int v, int level) : val(v), forward(level, nullptr) {}
    };

    Node* header;
    int maxLevel;
    int currentLevel;
    int nodeCount; // 统计节点数

    // 每4个节点提升一层
    int getLevel() {
        int level = 1;
        int n = nodeCount + 1;
        while (n % 4 == 0 && level < maxLevel) {
            level++;
            n /= 4;
        }
        return level;
    }

public:
    Skiplist() : maxLevel(16), currentLevel(1), nodeCount(0) {
        header = new Node(INT_MIN, maxLevel);
    }

    bool search(int target) {
        Node* curr = header;
        for (int i = currentLevel - 1; i >= 0; --i) {
            while (curr->forward[i] && curr->forward[i]->val < target) {
                curr = curr->forward[i];
            }
        }
        curr = curr->forward[0];
        return curr && curr->val == target;
    }

    void add(int num) {
        std::vector<Node*> update(maxLevel, nullptr);
        Node* curr = header;
        for (int i = currentLevel - 1; i >= 0; --i) {
            while (curr->forward[i] && curr->forward[i]->val < num) {
                curr = curr->forward[i];
            }
            update[i] = curr;
        }

        nodeCount++;
        int level = getLevel();
        if (level > currentLevel) {
            for (int i = currentLevel; i < level; ++i) {
                update[i] = header;
            }
            currentLevel = level;
        }

        Node* newNode = new Node(num, level);
        for (int i = 0; i < level; ++i) {
            newNode->forward[i] = update[i]->forward[i];
            update[i]->forward[i] = newNode;
        }
    }

    bool erase(int num) {
        std::vector<Node*> update(maxLevel, nullptr);
        Node* curr = header;
        for (int i = currentLevel - 1; i >= 0; --i) {
            while (curr->forward[i] && curr->forward[i]->val < num) {
                curr = curr->forward[i];
            }
            update[i] = curr;
        }
        curr = curr->forward[0];
        if (!curr || curr->val != num) return false;

        for (int i = 0; i < currentLevel; ++i) {
            if (update[i]->forward[i] != curr) break;
            update[i]->forward[i] = curr->forward[i];
        }
        delete curr;
        nodeCount--;

        // 降低层数
        while (currentLevel > 1 && header->forward[currentLevel - 1] == nullptr) {
            currentLevel--;
        }
        return true;
    }

    ~Skiplist() {
        Node* curr = header;
        while (curr) {
            Node* next = curr->forward[0];
            delete curr;
            curr = next;
        }
    }
};
```

## 概率提升一层

##### 跳表结构
- 节点（Node）
	- 值（value）
	- 多个前向指针（forward），每个指针指向不同层的下一个节点
- 头节点（header）
一个特殊的头节点，通常值为无效值（如 -1），拥有最大层数的 forward 指针
- 层数（level）

##### 随机层数生成
- 新插入节点的层数通过随机函数生成，概率 P=0.5。
- 生成方式：每次 toss 一次硬币（rand() % 2），为正则层数加一，直到失败或达到最大层数。




```cpp
class Skiplist {
private:
    struct Node {
        int value;
        std::vector<Node*> forward; // 前向指针

        Node(int v, int level) : value(v), forward(level, nullptr) {}
    };

    Node* header;
    int maxLevel;
    int currentLevel;
    const float P; // 增加一层概率

    int randomLevel() {
        int level = 0;
        while (rand() % 2 == 0 && level < maxLevel) {
            level++;
        }
        return level;
    }

public:
    Skiplist() : maxLevel(16), currentLevel(0), P(0.5) {
        header = new Node(-1, maxLevel); // 头节点
        srand(time(0));                  
    }

    bool search(int target) {
        Node* current = header;
        for (int i = currentLevel; i >= 0; i--) 
            while (current->forward[i] != nullptr && current->forward[i]->value < target) 
                current = current->forward[i];
            
        current = current->forward[0]; // 移动到最底层
        return current != nullptr && current->value == target;
    }

    void add(int num) {
        Node* current = header;
        std::vector<Node*> update(maxLevel, nullptr);

        for (int i = currentLevel; i >= 0; i--) {
            while (current->forward[i] != nullptr && current->forward[i]->value < num) 
                current = current->forward[i];
	            
            update[i] = current;
        }

        int newLevel = randomLevel();
        if (newLevel > currentLevel) {
            for (int i = currentLevel + 1; i <= newLevel; i++) 
                update[i] = header;
		        
            currentLevel = newLevel;
        }

        Node* newNode = new Node(num, newLevel + 1);
        for (int i = 0; i <= newLevel; i++) {
            newNode->forward[i] = update[i]->forward[i];
            update[i]->forward[i] = newNode;
        }
    }

    bool erase(int num) {
        Node* current = header;
        std::vector<Node*> update(maxLevel, nullptr);

        for (int i = currentLevel; i >= 0; i--) {
            while (current->forward[i] != nullptr && current->forward[i]->value < num)
                current = current->forward[i];
                
            update[i] = current; // 存储待删除目标前的最后一个元素
        }

        current = current->forward[0]; 

        if (current == nullptr || current->value != num) 
            return false; // 没找到

        for (int i = 0; i <= currentLevel; i++) {
            if (update[i]->forward[i] != current)
                continue;
            update[i]->forward[i] = current->forward[i]; // 绕过
        }

        delete current; 

        // 调整层数
        while (currentLevel > 0 && header->forward[currentLevel] == nullptr) 
            currentLevel--;

        return true;
    }
};
```
