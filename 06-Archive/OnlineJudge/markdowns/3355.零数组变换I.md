[3355. 零数组变换 I](https://leetcode.cn/problems/zero-array-transformation-i/)

##### 暴力
*665/668*超时
```cpp
bool isZeroArray(vector<int>& nums, vector<vector<int>>& queries) {
        for (vector<int>& index : queries) {
            int bg = index[0];
            int ed = index[1];
            while (bg <= ed) {
                nums[bg++]--;
            }
        }
        for (int i : nums) { if (i > 0) return false; }
        return true;
    }
```

##### 差分
1. **创建差分数组**：
    - 创建一个与 `nums` 同长度的差分数组 `diff`，并初始化为零。
2. **处理查询**：
    - 对于每个查询 `[li, ri]`，在 `diff` 数组中进行更新：
        - `diff[li] -= 1`（在 `li` 位置开始减1）
        - `diff[ri + 1] += 1`（在 `ri + 1` 位置恢复1）
3. **应用差分数组**：
    - 遍历 `diff` 数组，计算最终的 `nums` 值。
4. **检查结果**：
    - 最后检查 `nums` 是否全部为零。
```cpp
    bool isZeroArray(vector<int>& nums, vector<vector<int>>& queries) {
	    int n = nums.size();
	    std::vector<int> diff(n + 1, 0); // 差分数组，长度比 nums 多 1
	
	    // 处理每个查询
	    for (const auto& query : queries) {
	        int li = query[0];
	        int ri = query[1];
	        diff[li] -= 1; // 在 li 位置减 1
	        if (ri + 1 < n) {
	            diff[ri + 1] += 1; // 在 ri + 1 位置恢复
	        }
	    }
	
	    // 应用差分数组到 nums
	    int currentDecrease = 0; // 当前的减量
	    for (int i = 0; i < n; ++i) {
	        currentDecrease += diff[i]; // 计算当前的减量
	        nums[i] += currentDecrease; // 更新 nums
	    }
	
	    // 检查 nums 是否为零数组
	    return std::all_of(nums.begin(), nums.end(), [](int x) { return x <= 0; });
    }
```

#差分  差分算法是一种高效处理区间更新和查询的技术，特别适用于需要频繁对数组进行增量更新的场景。它的核心思想是通过引入一个差分数组，将区间更新问题转化为点更新问题，从而提高效率。
##### 基本原理
1. **差分数组定义**：
    - 对于一个数组 `nums`，构建一个差分数组 `diff`，其中 `diff[i] = nums[i] - nums[i-1]`。
    - 这样，`nums` 的任何前缀和都可以通过 `diff` 计算出来。
2. **区间更新**：
    - 对于要在 `nums[l]` 到 `nums[r]` 之间的每个元素加上一个值 `val`，只需在 `diff` 中：
        - `diff[l] += val` （从 `l` 开始增加 `val`）
        - `diff[r + 1] -= val` （在 `r + 1` 位置减去 `val`）
    - 通过这样的方式，`nums` 中的值在后续的前缀和计算中将反映出更新。
3. **计算最终数组**：
    - 最后，可以通过遍历 `diff` 数组，计算出对应的 `nums` 数组。
##### 示例
假设有数组 `nums = [1, 2, 3, 4, 5]`，我们想要对区间 `[1, 3]` 增加 `2`。
1. **初始化差分数组**：
    - `diff = [1, 1, 1, 1, 1]`（计算 `nums` 的差分）
2. **进行更新**：
    - `diff[1] += 2` → `diff = [1, 3, 1, 1, 1]`
    - `diff[4] -= 2` → `diff = [1, 3, 1, 1, -1]`
3. **计算最终结果**：
    - 使用差分数组计算 `nums`：
        - `nums[0] = 1`
        - `nums[1] = nums[0] + diff[1] = 1 + 3 = 4`
        - `nums[2] = nums[1] + diff[2] = 4 + 1 = 5`
        - `nums[3] = nums[2] + diff[3] = 5 + 1 = 6`
        - `nums[4] = nums[3] + diff[4] = 6 - 1 = 5`
    - 最终得到更新后的 `nums = [1, 4, 5, 6, 5]`。
##### 优点
- **高效**：使用差分数组进行区间更新只需常数时间 `O(1)`，而不需要逐个更新。
- **灵活**：可以处理多次区间更新和查询，适合需要频繁修改的场景。
##### 应用
差分算法广泛应用于竞赛编程、数据处理、图像处理等领域，尤其是在需要高效处理连续区间更新的任务中。
