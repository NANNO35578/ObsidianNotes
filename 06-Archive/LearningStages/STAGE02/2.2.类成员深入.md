# 2.2 类成员深入

## 成员属性 vs 成员函数

| 对比项 | 成员属性 | 成员函数 |
|--------|----------|----------|
| 归属 | 属于**对象** | 属于**类** |
| 存在时机 | 定义对象时存在 | 编译期就存在 |
| 份数 | 定义多个对象会存在多份，各自维护、彼此独立 | 一个类中只存在一份，被多个对象共享使用 |
| 与对象关系 | 无对象则不存在 | 与是否定义对象无关 |

---

## `this` 指针

非静态成员函数（包括构造函数、析构函数）都会有一个隐藏的 **`this` 指针参数**，类型为 `类名* const this`，指向当前对象。在函数内部使用成员时，都是通过 `this` 指针间接访问的。

```cpp
class CTest {
    int m_a;
public:
    void setA(int a) {
        this->m_a = a;  // 等价于 m_a = a;
    }
};
```

---

## 静态成员（`static`）

### 静态成员属性

- 属于**类**，编译期存在。
- 在**类外定义**（去掉 `static` 关键字，加上类名作用域）。
- 一个类中只存在一份，被多个对象共享。
- 可通过对象访问；没有对象时，可通过**类名作用域**直接访问。

```cpp
class CTest {
public:
    static int m_count;  // 类内声明
};
int CTest::m_count = 0;   // 类外定义
```

### 静态成员函数

- 属于**类**，编译期存在，一个类中只存在一份。
- 可通过对象或类名作用域调用。

### 静态函数与普通成员函数的区别

| 对比项 | 静态成员函数 | 普通成员函数 |
|--------|-------------|-------------|
| `this` 指针 | **无** `this` 指针 | 有隐藏的 `this` 指针参数 |
| 可访问成员 | 只能使用类中的其他**静态成员** | 所有成员均可使用 |

## `const` 成员

### 常成员属性

- 必须在**构造函数的初始化参数列表**中初始化。
- 初始化顺序取决于成员在类中**声明的先后顺序**，与初始化列表中的顺序无关。

```cpp
class ConstTest {
    int m_a;
    const int m_const;
public:
    ConstTest(int v1, int v2) : m_a(v1), m_const(m_a) {}
};
```

> 常量的存储位置取决于定义方式：
> - `const int a = 2;` —— 位于栈区（的常量区）
> - `const int* pConst = new const int;` —— 位于堆区的常量

---

## 常成员函数

在函数参数列表后加 `const` 修饰，表示该函数不会修改对象的状态：

```cpp
class classType {
    mutable int varName;  // mutable 修饰的成员可在常函数中修改
public:
    void functionName(/* const classType* const this */) const {
        varName++;  // mutable 成员可以修改
    }
};
```

- 常成员函数中 `this` 指针类型为 `const 类名* const`，不可修改除静态成员外的属性。
- 若需在常函数中修改某个成员，有两种方式：
  1. **指针绕回**：通过指针间接修改（不推荐，破坏 const 语义）。
  2. **`mutable` 修饰**：在成员声明时加 `mutable`，表示该成员永远处于可修改状态。

### 常对象与常函数

```cpp
const CTest obj;   // 常对象
obj.normalFunc();  // 错误：常对象只能调用常成员函数
obj.constFunc();   // 正确
```
