# 1.2 函数与引用

## 函数默认参数

```cpp
void fun(int a = 1);  // 声明时指定默认值
```

- **作用**：辅助代码开发，调用时可省略已有默认值的参数。

> [!warning] 默认参数规则
> 1. 多个参数时，**有默认值的参数从右向左放置**，无默认值的放左侧，**不得交叉**。
> 2. 函数声明与定义分开时，以**声明处**的默认值为准；定义处写默认值无效且会报错。
> 3. 多次声明时，取**最近声明处**的默认值。

> [!error] error C2572: 重定义默认参数
> 定义处再次写默认值会触发重定义错误。函数调用前一定会经过声明。

```cpp
#include <iostream>

void fun1(std::string a = "abcd") {
    std::cout << a << '\n';
}

void fun(int a = 0) {
    std::cout << a << '\n';
}

int main() {
    void fun(int a = -1);   // 局部声明，覆盖全局默认值
    fun();                   // -1
    ::fun();                 // 0  —— 显式调用全局域
    return 0;
}
```

## 函数重载（Function Overloading）

在**同一作用域**内，允许有多个同名函数，但参数列表必须不同。编译器根据传递的参数类型和数量自动选择合适的函数。

```cpp
int    add(int a, int b)       { return a + b; }
double add(double a, double b) { return a + b; }
```

> [!error] error C2084: 函数已有主体
> - `void funArr(int arr[])` 与 `void funArr(int* arr)` 视为**重定义**——数组名作参数会退化为指针。
> - `void fun(int a)` 与 `void fun(const int a)` 也视为**重定义**——函数传参是"复制"，顶层 `const` 不影响参数类型。

> [!warning] 以下是合法重载
> - `void fun(int* a);` 与 `void fun(const int* a);` —— 指针指向的内容是否为常量是不同类型。

### 无参函数与带默认值函数的区分

`void fun();` 与 `void fun(int a = -1);` 在调用 `fun()` 时存在歧义，可通过**声明局部化**提高优先级：

```cpp
{ void fun();            fun(); }  // 调用无参版本
{ void fun(int a = -1);  fun(); }  // 调用带默认值版本
```

## `nullptr` 与 `NULL`

| 概念 | 说明 |
|------|------|
| 野指针 / 悬空指针 | 指向一块已申请后使用并已释放的空间 |
| `NULL` | C 语言宏定义 `#define NULL 0`，会出现含义不明确的问题 |
| `nullptr` | C++11 关键字，明确表示空指针 |

> [!tip] 重载歧义示例
> ```cpp
> void fun(int a);   // 版本1
> void fun(int* a);  // 版本2
> fun(NULL);         // 实际调用版本1（NULL 即 0，匹配 int）
> fun(nullptr);      // 明确调用版本2
> ```

## 引用（Reference）

对已存在的变量或一段空间取**别名**：

```cpp
int  a  = 9;
int& a_ = a;   // a_ 是 a 的引用，指向同一地址
```

- `&a_` 等于 `&a`，二者指向同一块内存。
- 引用必须在声明时初始化，且不能再绑定到其他变量。

### 值传递 / 引用传递 / 指针传递

| 传递方式 | 函数签名 | 能否修改实参 | 额外开销 |
|----------|----------|-------------|----------|
| 值传递 | `void fun(int a);` | 否 | 复制实参 |
| 引用传递 | `void fun(int& a);` | 是 | 无（底层为指针常量） |
| 指针传递 | `void fun(int* a);` | 是（通过解引用） | 复制指针 |

> [!tip] 重载区分
> - `void fun(int a);` 与 `void fun(int& a);` 是重载（引用底层为指针常量，与值类型不同）。
> - 常量传入时调用值传递版本；非常量传入时存在歧义，可通过声明局部化或函数指针明确指定：
>   ```cpp
>   void (*pOrigin)(int)   = &fun;  // 指向值传递版本
>   void (*pRef)(int&)     = &fun;  // 指向引用传递版本
>   ```

### 使用建议

- 仅查看实参时，三种方式均可。
- 需要修改实参时，优先使用**引用传递**；指针传递不推荐（需判空、语法繁琐）。
- 对于复合类型（类、结构体），值传递会伴随实参大小额外申请空间，**不可控**，应优先使用引用或指针。
