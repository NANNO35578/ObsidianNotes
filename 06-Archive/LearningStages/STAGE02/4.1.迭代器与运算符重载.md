# 4.1 迭代器与运算符重载

## 迭代器（Iterator）

迭代器是一种**抽象的访问接口**，用于遍历容器中的元素，而不暴露容器的内部表示。通过重载运算符，迭代器可以像指针一样使用 `++`、`*`、`==`、`!=` 等操作。

### 自定义迭代器实现

以下是一个链表迭代器的完整实现：

```cpp
class iterator {
public:
    Node* point;

    iterator(Node* pHead) : point(pHead) {}

    // 基础方法
    bool isNullptr() { return point == nullptr; }
    bool isEqualPtr(Node* Ptr) { return point == Ptr; }
    int  getValue() { return point->val; }

    // 移动
    Node* leftAdd()  { return point = point->pNext; }
    Node* rightAdd() {
        Node* pOrg = point;
        point = point->pNext;
        return pOrg;
    }

    // 运算符重载
    bool operator==(Node* pNode) { return point == pNode; }
    bool operator!=(Node* pNode) { return point != pNode; }
    int  operator*() { return point->val; }

    // 前置 ++（默认左加加）
    Node* operator++() { return point = point->pNext; }
    // 后置 ++（括号加 int 表示右加加）
    Node* operator++(int) {
        Node* pOrg = point;
        point = point->pNext;
        return pOrg;
    }
};
```

### 使用迭代器遍历链表

```cpp
// 方式一：使用基础方法
void List::show_list_ite() {
    iterator ite(pHead);
    while (!ite.isNullptr()) {
        std::cout << ite.getValue() << ' ';
        ite.leftAdd();
    }
}

// 方式二：使用重载运算符（更接近 STL 风格）
void List::show_list_ite_operator() {
    iterator ite(pHead);
    while (ite != nullptr) {
        std::cout << *ite << ' ';
        ++ite;
    }
}
```

## 运算符重载（`operator`）

### 语法

```cpp
返回值类型 operator运算符(参数列表) {
    // 函数定义
}
```

### 前置/后置自增自减

| 形式 | 语法 | 说明 |
|------|------|------|
| 前置 `++` | `返回类型 operator++()` | 无参数，默认左操作 |
| 后置 `++` | `返回类型 operator++(int)` | 参数为 `int`（占位符），表示右操作 |
| 前置 `--` | `返回类型 operator--()` | 无参数 |
| 后置 `--` | `返回类型 operator--(int)` | 参数为 `int` |

> 前置返回引用（可作左值），后置返回原值副本。

### 示例：重载 `>>` 实现尾插

```cpp
void List::operator>>(int val) {
    this->push_back(val);
}

// 使用
List newList;
for (int i = 0; i < 10; i++) {
    newList >> i;  // 等价于 newList.push_back(i);
}
```

### 可重载与不可重载的运算符

| 类别 | 运算符 |
|------|--------|
| **可重载** | `+` `-` `*` `/` `%` `^` `&` `\|` `~` `!` `=` `<` `>` `+=` `-=` `*=` `/=` `%=` `^=` `&=` `\|=` `<<` `>>` `<<=` `>>=` `==` `!=` `<=` `>=` `&&` `\|\|` `++` `--` `,` `->*` `->` `()` `[]` `new` `delete` |
| **不可重载** | `.` `.*` `::` `?:` `sizeof` `typeid` |

## `std::list` 链表

`std::list` 是双向链表，支持在任意位置 O(1) 插入和删除，但不支持随机访问。

```cpp
#include <iostream>
#include <list>

int main() {
    std::list<int> newList;

    // 尾插
    for (int i = 0; i < 5; i++)
        newList.push_back(i * 31 + 17);

    // 迭代器遍历
    list<int>::iterator ite = newList.begin();
    while (ite != newList.end())
        std::cout << *ite++ << ' ';
    std::cout << '\n';

    // 头插
    newList.push_front(90);
    newList.push_front(110);

    // 插入（在迭代器指向位置之前插入，返回新插入元素的迭代器）
    ite = ++newList.begin();
    newList.insert(ite, 99);

    // 删除（返回删除元素的下一个迭代器，原迭代器失效）
    ite = ++newList.begin();
    std::advance(ite, 3);       // 迭代器向后偏移 3
    ite = newList.erase(ite);

    // 范围 for 遍历
    for (int& i : newList)
        std::cout << i << ' ';

    // 首尾元素
    std::cout << *newList.begin() << ' ' << *--newList.end() << '\n';
    std::cout << newList.front() << ' ' << newList.back() << '\n';

    // 大小与清空
    std::cout << "Size : " << newList.size() << '\n';
    newList.clear();
    std::cout << newList.size() << '\n';

    return 0;
}
```

### `std::list` 常用操作

| 操作 | 说明 |
|------|------|
| `push_back(val)` | 尾部插入 |
| `push_front(val)` | 头部插入 |
| `insert(ite, val)` | 在迭代器位置前插入，返回新元素迭代器 |
| `erase(ite)` | 删除迭代器指向元素，返回下一个迭代器 |
| `begin()` / `end()` | 首尾迭代器 |
| `front()` / `back()` | 首尾元素引用 |
| `size()` | 元素个数 |
| `clear()` | 清空所有元素 |
| `sort()` | 链表自带排序（`std::sort` 不支持链表） |
