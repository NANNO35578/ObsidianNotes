# 1.1 C++ 基础入门

## 输入与输出

```cpp
std::cin  >> var;   // 输入
std::cout << var;   // 输出
```

> [!tip] `std::cout` 与 `char*`
> - `char* pCh` 初始化为一个字符的地址时，`std::cout << pCh` 会**输出以该字符地址开始的字符串**；加上 `(void*)` 强制转换后才输出地址值。
> - 其他类型的指针输出 `p` 直接输出地址。
> - 输出 `*p` 则输出单个字符。

## 命名空间 `namespace`

| 作用域 | 语法 |
|--------|------|
| 全局域 | `::var` |
| 自定义域 | `namespace name { ... }` |

```cpp
#include <iostream>

int var = 0;                 // 全局变量

namespace nameA {
    int var = 3;             // 命名空间 nameA 中的 var
}

namespace nameB {
    int var = -1;            // 命名空间 nameB 中的 var
}

int main() {
    int var = 9;             // 局部变量
    std::cout << ::var       // 0  —— 全局域
              << var         // 9  —— 局部域
              << '\n';
    std::cout << nameA::var  // 3
              << '\n';
    std::cout << nameB::var  // -1
              << '\n';
    return 0;
}
```

## 动态内存管理 `new` / `delete`

> [!abstract] 动态申请空间
> - **"动态"** 指在程序**运行期间**（而非编译期）分配空间，程序需要时分配，更加灵活。
> - `new` / `delete` 为**关键字**，`malloc()` / `free()` 为**函数**。
> - `new` 分配内存时调用**构造函数**，`delete` 释放内存时调用**析构函数**；`malloc` / `free` 只做单纯的空间申请与释放。

### `malloc` / `free` 与 `new` / `delete` 的区别

| 对比项 | `malloc` / `free` | `new` / `delete` |
|--------|-------------------|-------------------|
| 性质 | C 语言中的**函数**，需头文件支持 | C++ **关键字**，需编译器支持 |
| 传递参数 | 申请空间大小（单位为字节） | 直接跟类型 |
| 返回值 | `void*`，多数情况需强制类型转换 | 对应类型空间首地址 |
| 能否初始化 | 不能 | `new int(99);` `new int[2]{99, 999};` |
| 构造/析构 | 不调用 | `new` 自动调用构造函数，`delete` 自动调用析构函数 |

### 常见申请形式

```cpp
int*  pInt = new int;          // 申请一个 int
int** pPI  = new int*;         // 申请一个 int*
int*  pAI  = new int[5];       // 申请一个 int[5]
int** pPA  = new int*[3];      // 申请指针数组 int*[3]，首元素为 int*，其指针为 int**
int(**pAP)[3] = new (int(*)[3]); // 数组指针 int(*)[3]
int (*p2D)[3] = new int[2][3]; // 多维数组，首元素为 int[3]
```

> [!warning] 释放对应形式
> - 单个对象：`delete pInt;`
> - 数组：`delete[] pAI;`
> - 必须配对使用，否则行为未定义。

## 布尔类型 `bool`

| 对比项 | C | C++ |
|--------|---|-----|
| 头文件 | `<Windows.h>` | 无需头文件 |
| 类型名 | `BOOL`（`TRUE` / `FALSE`），本质为 `typedef` / `#define` | `bool`（`true` / `false`），关键字 |
| 存储空间 | 4 字节（`int`） | 1 字节 |

## 字符串 `std::string`

| 对比项 | C 风格 | C++ `std::string` |
|--------|--------|-------------------|
| 头文件 | `<string.h>` | `<string>` |
| 初始化 | `const char* pC = "ABC";` | `string str = "ABC";` |
| 可修改性 | `pC[0] = 'a';` 不可操作（字符串常量） | `str[0] = 'a';` 可操作 |
| 数组初始化 | `char str[] = "ABC";` | — |
| 重新赋值 | `str = "abcd";` 不可操作（数组名不可改） | `str = "abcd";` 可操作 |
| 比较 | `strcmp(s1, s2);` | `s1 > s2 && s1 == s2` |
| 复制 | `strcpy(s1, s2);` | `s1 = s2;` |
| 追加 | `strcat(s1, s2);` | `s1 += s2;` |

### 常用成员函数

以 `string str = "1234567";` 为例：

| 函数 | 作用 | 示例结果 |
|------|------|----------|
| `str.size()` / `str.length()` | 返回字符串长度 | `7` |
| `str.find("34")` | 返回首次找到的子串下标 | `2` |
| `str.rfind("34")` | 从末端查找子串下标 | — |
| `str.substr(index, count)` | 返回偏移 `index` 起长度 `count` 的子串 | — |
| `str.c_str()` | 返回 `const char*` 类型，常用于 C 接口转换 | — |

## 范围 for 循环（range-based for）

C++11 引入范围 for 循环，用冒号 `:` 指定遍历范围：

```cpp
for (元素类型 变量名 : 遍历范围) {
    // 循环体
}
```

- **遍历范围**：可以是数组、容器（`std::vector`、`std::list` 等）、拥有 `begin()` / `end()` 成员的序列，或花括号初始化列表。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    for (int num : vec) {
        std::cout << num << std::endl;
    }
    return 0;
}
```

> [!tip] 使用 `auto&` 避免拷贝
> ```cpp
> for (auto& i : vec) { ... }  // 引用，可修改元素且避免拷贝
> for (const auto& i : vec) { ... }  // 只读引用
> ```
