# 2.6 拷贝控制

## 隐式类型转换

当某个类存在一个**基本类型数据作参数**即可完成初始化的构造函数时，可以使用如下形式初始化：

```cpp
ClassName varName = BASIC_DATA_TYPE;  // 隐式类型转换
```

```cpp
class className {
public:
    int m_a;
public:
    className() : m_a(0) {}
    className(int a) : m_a(a) {}           // 隐式类型转换构造：int → className
    className(int a, int b = 9) : m_a(a + b) {}  // 同样是隐式类型转换构造
    explicit className(int a, int b = 99) : m_a(a + b) {}  // explicit 禁止隐式转换
};

className c0 = 10;  // 隐式调用 className(int)
```

### `explicit` 关键字

- 修饰构造函数，**禁止发生隐式类型转换**。
- 被 `explicit` 修饰的构造函数只能显式调用：`className c0(10);` 或 `className c0 = className(10);`。

## 拷贝构造函数

### 定义

用一个已存在的同类对象初始化新对象：

```cpp
className newClass_1;
className newClass_Copy(newClass_1);  // 拷贝构造（浅拷贝）
```

### 默认拷贝构造函数

类中除了默认的无参构造函数，编译器还会提供一个默认的拷贝构造函数：

- **参数**：`const 当前类对象的引用`
- **函数体**：形参对象中的成员依次给 `this` 对象成员做初始化
- **性质**：默认的拷贝构造是**浅拷贝**——对于类中指针成员，只是简单地将地址做了一个拷贝，指针指向的空间并没有拷贝。

### 浅拷贝的问题

当类中存在指针成员并申请/释放空间时，浅拷贝会导致：

1. 两个对象的指针指向同一块内存。
2. 一个对象释放该内存后，另一个对象的指针变成**悬空指针**。
3. 第二次释放同一块内存导致**重复释放**（undefined behavior）。

### 深拷贝

手动重构拷贝构造函数，对指针成员申请新空间并复制内容：

```cpp
CTest(const CTest& newTest) : m_a(newTest.m_a), m_p(nullptr) {
    if (newTest.m_p != nullptr) {
        m_p = new int(*newTest.m_p);  // 申请新空间并复制值
    }
}
```

### 拷贝构造规则

- 应当尽量避免拷贝，采用引用、指针等方式传递对象。
- 默认会提供拷贝构造函数；如果手动重构，则编译器不再提供默认版本。
- 如果手动重构拷贝构造函数，默认的无参构造函数也不会提供（需自己定义）。

## `operator=` 等号运算符重载

### 默认赋值运算符

编译器提供的默认 `operator=`：

- **参数**：`const 当前类对象的引用`
- **返回类型**：`当前类对象的引用`（支持连续赋值 `a = b = c`）
- **函数体**：形参对象中的成员依次给 `this` 对象中的成员做赋值操作
- **性质**：默认的 `operator=` 是**浅拷贝**，存在与浅拷贝构造相同的问题。

### 深拷贝赋值运算符

手动重构 `operator=`，需处理**自赋值**和**释放旧资源**：

```cpp
CTest& operator=(const CTest& rhs) {
    if (this != &rhs) {          // 防止自赋值
        delete m_p;               // 释放旧资源
        m_a = rhs.m_a;
        if (rhs.m_p != nullptr) {
            m_p = new int(*rhs.m_p);  // 深拷贝
        } else {
            m_p = nullptr;
        }
    }
    return *this;
}
```

> 如果手动重构了 `operator=`，编译器则不会提供默认版本。

---

## 拷贝控制总结

| 特殊成员函数 | 编译器默认提供 | 默认行为 | 需手动重构的场景 |
|-------------|---------------|----------|-----------------|
| 默认构造函数 | 是（无任何构造函数时） | 空实现 | 需要初始化成员时 |
| 拷贝构造函数 | 是 | 浅拷贝（逐成员复制） | 类含指针/资源成员时 |
| 析构函数 | 是 | 空实现 | 类含动态申请资源时 |
| `operator=` | 是 | 浅拷贝（逐成员赋值） | 类含指针/资源成员时 |

> [!tip]  Rule of Three
> 如果需要手动定义析构函数、拷贝构造函数、赋值运算符中的**任何一个**，通常三个都需要手动定义。
