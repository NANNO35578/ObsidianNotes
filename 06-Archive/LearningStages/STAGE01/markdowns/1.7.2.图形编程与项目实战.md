# EasyX 图形编程与贪吃蛇项目实战

## EasyX 图形库基础

EasyX 是基于 Windows 的 C++ 图形库，需在 Visual Studio 中使用，头文件为 `<graphics.h>`。

### 创建绘图窗口

```c
#include <graphics.h>
#include <stdlib.h>   // system("pause")

int main() {
    initgraph(800, 600);   // 创建 800×600 绘图窗口
    system("pause");       // 阻塞，防止窗口立即关闭
    closegraph();          // 关闭绘图窗口
    return 0;
}
```

> `initgraph(int width, int height, int flag = 0)` 定义于 easyx.h。坐标系原点在窗口左上角，x 轴向右，y 轴向下。

### 绘制图形

```c
circle(400, 300, 100);   // 绘制空心圆，参数：圆心 x, 圆心 y, 半径
```

### 加载与显示图片

```c
IMAGE tu;                                  // 定义 IMAGE 对象保存图片
loadimage(&tu, L".\\fox\\0-0.png");       // 从硬盘加载图像（宽字符路径）
putimage(400, 300, &tu);                  // 在坐标 (400, 300) 显示图片
```

- `loadimage(IMAGE* pDstImg, LPCTSTR pImgFile)`：加载图片到内存
- `putimage(int x, int y, const IMAGE* pSrcImg)`：将图片绘制到窗口指定位置
- 路径使用 `L"..."` 宽字符字符串；相对路径相对于可执行文件（`.exe`）所在目录

### 动画原理

```c
#include <Windows.h>   // Sleep 所需头文件（注意 S 大写）

IMAGE arr[4][4];
// ... 加载多帧图片 ...

while (1) {
    for (int i = 0; i < 4; i++) {
        putimage(100, 200, &arr[3][i]);
        Sleep(150);       // 延时 150 毫秒，控制动画帧率
    }
}
```

动画本质：循环切换帧 + 延时控制。`Sleep(DWORD dwMilliseconds)` 是 Windows API，首字母大写，仅 Windows 平台可用。

### 批量加载图片（二维 IMAGE 数组）

```c
IMAGE images[4][4];
wchar_t path[30];
for (int i = 0; i < 4; i++)
    for (int j = 0; j < 4; j++) {
        swprintf_s(path, L".\\fox\\%d-%d.png", i, j);  // 安全版本，VS 推荐
        loadimage(&images[i][j], path);
    }
```

> `swprintf_s` 是 VS 安全 CRT 函数（宽字符 sprintf），需缓冲区大小参数；标准 C 用 `swprintf`。仅 Windows / VS 环境可用。

## 游戏框架

基于 EasyX 的游戏框架是半成品项目，把游戏开发共性代码准备好，开发者只需在提供的插入点（TODO）写代码。

### 框架运行机制

类比舞台剧：
- **全局变量**：共享信息（舞台上的道具和角色状态）
- **绘图**：擦除重绘（每帧重新画画面）
- **定时处理**："机器人"自动推进游戏逻辑
- **键盘 / 鼠标交互**：玩家输入

### 开发三步法

1. 静态外观：确定画面上有什么元素
2. 找变化形成全局变量：哪些状态会变（位置、方向、分数等）
3. 何时变化，写变化逻辑：在定时处理和键盘控制中修改变量

### 框架插入点

```c
// TODO: 1 设置窗口：宽度高度
int screenWidth = 600, screenHeight = 600;

// TODO: 2 全局变量声明位置

// TODO: 3 游戏初始化位置
void gameInit() { }

// TODO: 4 绘图处理位置
void gamePaint() { }

// TODO: 5 定时处理位置
void gameInterval() { }

// TODO: 6 处理键盘控制位置
void gameKeypress(int key) { }
```

> VS 中可通过 视图 → 任务列表（Ctrl+\, T）查看所有 TODO 注释。

## 项目实战：贪吃蛇

### 需求分析与设计

**用例图（use case）**：宏观说明参与者与功能边界
- 参与者：player（玩家）、机器人-定时处理
- 功能：打开游戏、闯关模式、查看历史排名、蛇转向、蛇爬

**活动图（activity）**：对用例细化，说明"怎么做"
- 蛇开始 → 爬行
- 分支判断：能咬到自己 / 能撞墙 / 能吃苹果
- 能吃苹果 → 长个 → 生成新苹果 → 继续
- 撞墙或咬到自己 → gameover → 关闭项目

### 全局变量设计

```c
IMAGE imgBG, imgApple, imgBody;   // 背景、苹果、蛇身图片
IMAGE imgHead[4];                  // 4 个方向的蛇头图片
int fangXiang = 1;                 // 方向：1上 2左 3下 0右
int appleHang, appleLie;           // 苹果所在行、列
int snakeHang[100] = {10, 11, 12, 13, 14};  // 蛇身各行坐标
int snakeLie[100] = {10, 10, 10, 10, 10};   // 蛇身各列坐标
int snakeLen = 5;                  // 当前蛇身长度
int stop = 0;                      // 是否停止游戏（0运行 1停止）
```

每个格子 30 像素，屏幕 600×600 对应 20×20 格子（行列 0~19）。坐标换算：`像素x = 列 × 30`，`像素y = 行 × 30`。

### 初始化 gameInit()

```c
#include <stdlib.h>   // rand, srand
#include <time.h>     // time

void gameInit() {
    loadimage(&imgBG, L".\\she\\bg.bmp");
    loadimage(&imgApple, L".\\she\\apple.bmp");
    loadimage(&imgBody, L".\\she\\body.bmp");

    TCHAR str[100];   // 动态拼装图片路径
    for (int tu = 0; tu < 4; tu++) {
        _stprintf(str, L".\\she\\head%d.bmp", tu);
        loadimage(&imgHead[tu], str);
    }

    srand((unsigned)time(NULL));          // 设置随机数种子
    appleHang = rand() % 14 + 3;          // 苹果随机行（3~16，避开边界）
    appleLie = rand() % 14 + 3;           // 苹果随机列
}
```

> `srand((unsigned)time(NULL))` 用当前时间做种子，确保每次运行随机序列不同。`rand() % 14 + 3` 生成 [3, 16] 范围内的整数。

### 绘图 gamePaint()

```c
void gamePaint() {
    putimage(0, 0, &imgBG);                              // 背景
    putimage(appleLie * 30, appleHang * 30, &imgApple);  // 苹果
    for (int j = 1; j < snakeLen; j++)                    // 蛇身（从第1节开始）
        putimage(snakeLie[j] * 30, snakeHang[j] * 30, &imgBody);
    putimage(snakeLie[0] * 30, snakeHang[0] * 30, &imgHead[fangXiang]);  // 蛇头（按方向选图）
}
```

### 定时处理 gameInterval()

**蛇的移动**：先身体后移，再蛇头前进。

```c
void gameInterval() {
    // 身体爬：从尾到头，每节继承前一节的位置
    for (int i = snakeLen - 1; i >= 1; i--) {
        snakeHang[i] = snakeHang[i - 1];
        snakeLie[i] = snakeLie[i - 1];
    }
    // 蛇头爬：按方向移动
    switch (fangXiang) {
        case 1: snakeHang[0]--; break;   // 上
        case 2: snakeLie[0]--;  break;   // 左
        case 3: snakeHang[0]++; break;   // 下
        case 0: snakeLie[0]++;  break;   // 右
    }

    // 能吃苹果：蛇头坐标与苹果坐标重合
    if (appleHang == snakeHang[0] && appleLie == snakeLie[0]) {
        snakeLen++;                                  // 长个
        appleHang = rand() % 14 + 3;                // 生成新苹果
        appleLie = rand() % 14 + 3;
    }

    // 能撞墙：蛇头到达边界（0 或 19）
    if (snakeHang[0] == 0 || snakeHang[0] == 19 ||
        snakeLie[0] == 0 || snakeLie[0] == 19) {
        stop = 1;  // game over
    }

    // 能咬到自己：蛇头坐标与任意身体节重合
    int neng = 0;
    for (int j = 1; j < snakeLen; j++) {
        if (snakeHang[0] == snakeHang[j] && snakeLie[0] == snakeLie[j]) {
            neng = 1;
            break;
        }
    }
    if (neng) stop = 1;
}
```

### 键盘控制 gameKeypress()

```c
void gameKeypress(int key) {
    switch (key) {
        case VK_LEFT:  fangXiang = 2; break;
        case VK_RIGHT: fangXiang = 0; break;
        case VK_UP:
            if (fangXiang != 3) fangXiang = 1;   // 正在向下时不能直接向上
            break;
        case VK_DOWN:
            if (fangXiang != 1) fangXiang = 3;   // 正在向上时不能直接向下
            break;
    }
}
```

> `VK_LEFT` / `VK_RIGHT` / `VK_UP` / `VK_DOWN` 是 Windows 虚拟键码，定义于 `<Windows.h>`。反向限制防止蛇直接掉头咬到自己。

### 主循环

```c
while (1) {
    // 消息处理（键盘等）
    // 绘图
    paint();
    // 定时控制
    Sleep(1);
    if (stop) break;   // 游戏结束跳出循环
}
```

## 平台相关函数说明

| 函数 / 宏 | 平台 | 说明 |
|---|---|---|
| `initgraph` / `circle` / `putimage` / `loadimage` | Windows + EasyX | EasyX 图形库函数，需安装 EasyX 并在 VS 中使用 |
| `IMAGE` 类型 | Windows + EasyX | EasyX 图像对象类型 |
| `Sleep(DWORD)` | Windows | 首字母大写，毫秒级延时，需 `<Windows.h>` |
| `VK_UP` 等虚拟键码 | Windows | 定义于 `<Windows.h>` |
| `swprintf_s` / `_stprintf` | Windows (VS) | 安全宽字符格式化，VS 推荐；标准 C 用 `swprintf` |
| `system("pause")` | Windows | 调用 cmd 暂停，跨平台行为不一致 |
| `rand()` / `srand()` | 标准 C | 伪随机数，需 `<stdlib.h>`；`time()` 需 `<time.h>` |
| `TCHAR` / `L"..."` | Windows | 宽字符类型和字符串字面量，EasyX 路径参数需要 |
