# 指针基础

## 指针的本质

**指针是一种数据类型**，与 `int`、`char`、`double` 等基本类型并列，属于扩展类型。指针类型的数据存储的是**内存地址**。

- 指针可以是**变量**（指针变量），其值可以改变，指向不同的内存空间
- 指针也可以是**常量**（指针常量），其指向不可改变
- 指针可以指向各种基本类型：`int*`、`char*`、`float*`、`double*`、`short*`、`long long*` 等

### 内存与地址

内存（memory）由字节组成，每个字节有唯一的地址编号，地址连续、从小到大排列。

- **直接访问**：通过变量名读写内存（如 `a = 5`）
- **间接访问**：通过地址找到对应内存空间进行读写

类比：小区（内存）→ 门牌号（地址）→ 一套房子（变量空间）→ 钥匙（指针）

## 地址运算符 `&` 与间接访问运算符 `*`

| 运算符 | 名称 | 作用 | 优先级 | 结合性 |
|---|---|---|---|---|
| `&` | 取地址运算符 | 取得变量的首地址（最小号地址） | 2 | 右→左 |
| `*` | 间接访问/解引用运算符 | 通过地址访问对应内存空间 | 2 | 右→左 |

`&` 与 `*` 互为逆运算：`*&a == a`。

```c
int a = 5;
&a;        // 取 a 的地址
*(&a);     // 通过地址访问 a，等价于 a
```

## 指针变量的声明与使用

```c
int a = 5;
int* p;     // 声明指针变量 p，* 是指针类型的标记
p = &a;     // p 存储 a 的地址，p 与 a 构成指向关系

printf("%d", a);   // 直接访问：5
printf("%d", *p);  // 间接访问：5
```

### 声明多个指针变量

`*` 不能省略，每个指针变量前都要写：

```c
int x, y, z;          // 三个都是 int 变量
int* k, *n, *m;       // 三个都是 int* 指针
int* q, t = &a;       // q 是指针，t 是 int（错误！t 不是指针）
```

### 指针变量的字节数

指针变量的大小由**操作系统位数**决定，与指向类型无关：

| 系统 | 指针大小 | 地址宽度 |
|---|---|---|
| 32 位（x86） | 4 字节 | 8 位十六进制地址 |
| 64 位（x64） | 8 字节 | 16 位十六进制地址 |

```c
sizeof(int*);    // 4（x86）或 8（x64）
sizeof(p);       // 同上
sizeof(&a);      // 同上
```

## 指针类型的两个作用

指针类型（如 `int*`、`char*`）决定了两件事：

### 1. 间接访问时的空间使用权

解引用 `*p` 时，从地址开始读取多少个字节由指向类型决定：

| 指针类型 | `*p` 访问字节数 |
|---|---|
| `char*` | 1 字节 |
| `short*` | 2 字节 |
| `int*` | 4 字节 |
| `long long*` | 8 字节 |
| `float*` | 4 字节 |
| `double*` | 8 字节 |

### 2. 指针位移的步长

指针加减整数时，地址偏移量 = 指向类型的字节数：

```c
int a = 5;
int* p = &a;
char* pc = (char*)&a;
short* ps = (short*)&a;
long long* pll = (long long*)&a;

p + 1;    // 地址 +4
pc + 1;   // 地址 +1
ps + 1;   // 地址 +2
pll + 1;  // 地址 +8
```

> 不同类型的指针指向同一地址时，`sizeof(*p)` 和 `p+1` 的步长不同，但指针变量本身的大小相同。

## void* 无类型指针

`void*` 是**无类型/不确定类型指针**，只能保存地址，**无法间接访问，也无法进行位移运算**。

```c
void* pointer = &a;
*pointer = 1;       // 编译错误：表达式必须是可修改的左值
pointer + 1;        // 编译错误：不明确指向类型，无法偏移
```

使用前必须**强制类型转换**为具体指针类型：

```c
*(int*)pointer = 1;   // 先转为 int* 再解引用
```

`void*` 常用于通用接口参数（如 `malloc` 返回值、`qsort` 比较函数参数）。

---

## NULL 空指针

```c
#define NULL  ((void*)0)
```

`NULL` 即 0 号地址，称为空地址/空指针，代表**不指向任何合法字节**。

```c
double* pp = NULL;   // 指针初始化为空，避免野指针
```

> 解引用空指针（`*NULL`）会导致程序崩溃（访问违例）。指针使用前应确保指向合法空间。

## 指针常量与指向常量的指针

根据 `const` 的位置，有四种组合：

| 声明 | 指向能否改 | 指向的值能否改 | 说明 |
|---|---|---|---|
| `int* p` | 能 | 能 | 普通指针变量 |
| `const int* p` | 能 | 不能 | 指向常量的指针（不能通过 p 修改值） |
| `int* const p = &a` | 不能 | 能 | 指针常量（p 必须初始化，指向不可改） |
| `const int* const p = &a` | 不能 | 不能 | 指向常量的指针常量 |

```c
int a = 5, b = 10;
const int* p1 = &a;   p1 = &b;   // 合法，指向可改
*p1 = 6;                         // 错误，不能通过 p1 修改值

int* const p2 = &a;              // 必须初始化
*p2 = 6;                         // 合法，值可改
p2 = &b;                         // 错误，指向不可改
```

## 多级指针

指向指针的指针，称为多级指针。

```c
int a = 5;
int* p = &a;       // 一级指针，指向 int
int** pp = &p;     // 二级指针，指向 int*
printf("%d", **pp); // 间接再间接，输出 5
```

`**pp` 的解析：`*pp` 得到 `p`（一个 `int*`），再 `*` 得到 `a` 的值。

调试器中可观察：`pp` 存 `p` 的地址，`*pp` 即 `p` 的值（`a` 的地址），`**pp` 即 `a` 的值。

## 通过指针修改变量

间接访问与直接访问对同一空间的操作完全等价：

```c
int a = 5;
int* p = &a;

// 直接访问
a = 8;    a += 2;    a *= 5;    a++;    ++a;

// 间接访问（等价）
*p = 8;   *p += 2;   *p *= 5;   (*p)++;  ++*p;
```

> 注意 `(*p)++` 与 `*p++` 的区别：
> - `(*p)++`：先解引用，再对值自增（p 指向不变）
> - `*p++`：等价于 `*(p++)`，先取 `*p` 的值，再将 p 指向下一个元素（地址偏移）

## 指针使用注意事项

1. **不要越界访问**：指针位移到不属于本程序的空间，或修改不属于本程序的空间，会触发内存访问冲突（Access Violation）。
   ```c
   int a = 6;
   int* p = &a;
   p += 5000;   // 位移到非法地址
   *p = 666;    // 运行时错误：写入访问冲突
   ```
2. **避免野指针**：未初始化的指针值是随机的，解引用可能崩溃。声明时应初始化为 `NULL` 或合法地址。
3. **避免悬空指针**：指向的空间已释放后，指针仍保留原地址，应置为 `NULL`。

## 大端与小端存储

多字节数据在内存中的字节排列方式：

| 模式 | 低地址存 | 高地址存 | 使用场景 |
|---|---|---|---|
| 大端（Big-Endian） | 高位字节 | 低位字节 | 网络传输、部分嵌入式 |
| 小端（Little-Endian） | 低位字节 | 高位字节 | x86 / x64 CPU |

以 `int age = 9`（十六进制 `0x00000009`）为例：

```
大端：00 00 00 09   （低地址→高地址）
小端：09 00 00 00   （低地址→高地址，x86/x64 默认）
```

算术计算和打印时按高位到低位理解，与存储顺序无关。

## VS 调试查看指针

- **监视窗口**：调试 → 窗口 → 监视（Ctrl+Alt+W,1），输入 `&a` 查看地址，输入 `*p` 查看指向的值
- **内存窗口**：调试 → 窗口 → 内存（Ctrl+Alt+M,1），输入地址查看原始字节，可验证大小端
