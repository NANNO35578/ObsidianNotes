# 运算符与表达式

## 基本概念

编程思维的三大支柱：流程结构（控制思维）、数据类型与变量（存储思维）、运算符与表达式（运算思维）。

- **运算符**：运算的符号（如 `+`、`*`），本身无计算结果
- **操作数**：参与运算的数据
- **表达式**：运算符 + 操作数构成，**一定有一个计算结果**
- **语句**：表达式 + 分号 `;`
- **优先级**：决定运算先后顺序
- **结合性**：优先级相同时的运算方向

> 牢记：只要是表达式，就有一个计算结果。

```c
3 + 4 * 5 / 6 - 7 % 3;     // 算术表达式（有结果）
int a;
a = 3 + 4 * 5 / 6 - 7 % 3; // 赋值语句
8;                          // 常量语句
```

### 表达式结果分析方法

1. 先看**优先级**，优先级相同再看**结合性**
2. `&&`、`||`、`?:` 结构优先，可能存在**短路**（某些部位不计算）
3. 结构确定后再算结果

## 运算符优先级（精简）

| 优先级 | 运算符 | 名称 | 结合性 |
|---|---|---|---|
| 1 | `[]` `()` `.` `->` | 下标、函数调用、成员访问 | 左→右 |
| 2 | `-` `~` `++` `--` `*` `&` `!` `(类型)` `sizeof` | 单目运算符 | 右→左 |
| 3 | `*` `/` `%` | 乘、除、取余 | 左→右 |
| 4 | `+` `-` | 加、减 | 左→右 |
| 5 | `<<` `>>` | 左移、右移 | 左→右 |
| 6 | `<` `<=` `>` `>=` | 关系运算 | 左→右 |
| 7 | `==` `!=` | 等于、不等于 | 左→右 |
| 8 | `&` | 按位与 | 左→右 |
| 9 | `^` | 按位异或 | 左→右 |
| 10 | `|` | 按位或 | 左→右 |
| 11 | `&&` | 逻辑与 | 左→右 |
| 12 | `||` | 逻辑或 | 左→右 |
| 13 | `?:` | 条件（三目） | 右→左 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `|=` | 赋值 | 右→左 |
| 15 | `,` | 逗号 | 左→右 |

## 算术运算符

### 除法与取余

```c
printf("%d", 9 / 2);   // 4，整型除法截断小数
printf("%d", 9 % 2);   // 1，余数
```

**取余 `%` 的规则**：
- 两个操作数必须为整型，浮点数不能取余（编译错误 C2124）
- 余数符号与**被除数**相同

```c
-9 / 2;  // -4
-9 % 2;  // -1（与被除数 -9 同号）
 9 / -2; // -4
 9 % -2; //  1（与被除数 9 同号）
```

> 除数为 0 是未定义行为，VS 会报 C2124（被零除或对零求模）。

## 单目运算符

优先级 2，**右→左**结合。包括：负号 `-`、按位取反 `~`、自增 `++`、自减 `--`、解引用 `*`、取地址 `&`、逻辑非 `!`、强制类型转换 `(类型)`、`sizeof`。

```c
int num = 8;
-num;        // 取相反数，结果 -8
!!996;       // 逻辑非两次，结果 1（非0→0→1）
```

---

## 自增自减运算符

`++` 和 `--` 可前置或后置，**谁在前，谁代表表达式的值**。

```c
int a = 10, b = 10, c, d;
c = a++;     // 先把 a 的值(10)给 c，再 a 自增 → c=10, a=11
d = ++b;     // 先 b 自增(→11)，再把 b 的值给 d → d=11, b=11
```

| 形式 | 表达式的值 | 变量最终值 |
|---|---|---|
| `a++`（后置） | 自增前的值 | a+1 |
| `++a`（前置） | 自增后的值 | a+1 |

---

## 赋值运算符

优先级 14，**右→左**结合。赋值表达式的值 = 左侧变量的值。

```c
int a, b, c, d;
a = b = c = d = 9;  // 右结合：d=9 → c=9 → b=9 → a=9，全部为 9
```

复合赋值：`+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `|=`

```c
a += 5;   // 等价于 a = a + 5;
```

## 关系与逻辑运算符

### 关系运算

结果为 `1`（真）或 `0`（假）。

```c
printf("%d %d", 3 > 5, 3 < 5);  // 0 1
```

> 典型错误：数学写法 `12 <= 75 <= 16` 在 C 中从左到右计算：`12<=75` 为真(1)，`1<=16` 为真(1)，结果恒为 1。正确写法：`12 <= 15 && 15 <= 16`。

### 逻辑运算

| 运算符 | 规则 |
|---|---|
| `&&` 逻辑与 | 全真则真，有假即假 |
| `||` 逻辑或 | 全假则假，有真即真 |
| `!` 逻辑非 | 取反（单目，优先级 2） |

```c
printf("%d", !996);   // 0，非0取反为0
printf("%d", !!996);  // 1
```

### 短路求值

- `A && B`：A 为假时，B **不计算**
- `A || B`：A 为真时，B **不计算**

```c
int a = 10, b = 10, m;
m = a++ > 10 && ++b > 10;
// a++>10 为假(10>10)，a→11，&&短路，++b不执行
// 结果：a=11, b=10, m=0

m = a++ >= 10 || ++b > 10;
// a++>=10 为真(10>=10)，a→11，||短路，++b不执行
// 结果：a=11, b=10, m=1
```

## 三目运算符（条件运算符）

`条件 ? 表达式1 : 表达式2`，简化版 `if-else`。优先级 13，右→左结合。

```c
int a = 10;
char r = (a % 2 == 0) ? 'T' : 'F';  // r='T'
```

嵌套示例（根据性别判断结婚年龄）：

```c
int age = 18, sex = 1;  // sex: 1男 0女
printf("%d", sex ? (age >= 22) : (age >= 20));
```

## 逗号运算符

优先级最低（15），左→右结合。连接多个表达式，整个逗号表达式的值 = **最右侧表达式的值**。

```c
int a;
a = (1, 2, 3, 7, 8, 9);  // a=9，括号使逗号先运算
a = 1, 2, 3, 7, 8, 9;    // a=1，=优先级高于,，等价于 (a=1),2,3,...
```

典型用途：`for` 循环中初始化/更新多个变量。

```c
for (int i = 0, j = 1, k = 50; i < 10; i++, k /= 2, j += 2) { }
```

## 位运算符

对二进制的每一位（0 或 1）进行运算。以 `a = 10`（`00001010`）、`b = 5`（`00000101`）为例：

| 运算符 | 规则 | 示例 | 结果 |
|---|---|---|---|
| `&` 按位与 | 全 1 则 1，有 0 就 0 | `10 & 5` | `00000000` = 0 |
| `|` 按位或 | 全 0 则 0，有 1 就 1 | `10 | 5` | `00001111` = 15 |
| `^` 按位异或 | 相同则 0，不同就 1 | `10 ^ 5` | `00001111` = 15 |
| `~` 按位取反 | 0 变 1，1 变 0 | `~10` | `11110101`（有符号 = -11） |
| `<<` 左移 | 各位左移，低位补 0，等价 ×2 | `10 << 1` | `00010100` = 20 |
| `>>` 右移 | 各位右移，高位补符号位*，等价 ÷2 | `10 >> 1` | `00000101` = 5 |

> *有符号数右移，VS/GCC 等主流编译器采用**算术右移**（高位补符号位）；无符号数采用逻辑右移（高位补 0）。标准未强制规定有符号右移行为，但实际平台基本一致。

位运算常见用途：
- `n & 1`：判断奇偶（等价于 `n % 2`）
- `n << k`：快速乘 $2^k$
- `n >> k`：快速除 $2^k$（对非负整数）
- `n | (1 << k)`：将第 k 位置 1
- `n & ~(1 << k)`：将第 k 位清 0
- `n ^ (1 << k)`：将第 k 位翻转
