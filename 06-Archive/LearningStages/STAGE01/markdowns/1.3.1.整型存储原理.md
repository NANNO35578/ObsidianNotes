# 整型存储原理

## 计算机存储基本概念

- **位（bit）**：最小信息单位，存储 0 或 1
- **字节（Byte，B）**：最小存储单位，1 Byte = 8 bit
- 换算：$2^{10}=1024$，即 1024 B = 1 KB，1024 KB = 1 MB，1024 MB = 1 GB，1024 GB = 1 TB
- 8 个二进制位 = 1 字节；2 个十六进制位 = 1 字节

---

## 进制表示与转换

### 整型字面值常量

格式：`进制前缀 + 数值 + 存储类型后缀`

| 进制 | 前缀 | 示例 | 可用数字 |
|---|---|---|---|
| 十进制 | 无（默认） | `2024` | 0-9 |
| 二进制 | `0b` / `0B` | `0b1011011` | 0-1 |
| 八进制 | `0` 开头 | `0356` | 0-7 |
| 十六进制 | `0x` / `0X` | `0x2fb` | 0-9, a-f, A-F |

### R 进制转十进制

按权展开：$a_n \times r^n + a_{n-1} \times r^{n-1} + \dots + a_1 \times r^1 + a_0 \times r^0$

- $(1011011)_2 = 1 \times 2^6 + 0 \times 2^5 + 1 \times 2^4 + 1 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 91$
- $(356)_8 = 3 \times 8^2 + 5 \times 8^1 + 6 \times 8^0 = 238$
- $(2FB)_{16} = 2 \times 16^2 + 15 \times 16^1 + 11 \times 16^0 = 763$

### 十进制转 R 进制

**除 R 取余，直至商为零，余数倒序排序。**

以 185 为例：
- 转二进制：除 2 取余 → `10111001`
- 转八进制：除 8 取余 → `271`
- 转十六进制：除 16 取余 → `B9`

## 原码、反码、补码

计算机中**整型以补码形式存储**。最高位为符号位：0 表示正数，1 表示负数。

### 定义

| 码制 | 正数 | 负数 |
|---|---|---|
| 原码 | 符号位 0 + 数值二进制 | 符号位 1 + 数值二进制 |
| 反码 | 与原码相同 | 符号位不变，其余各位取反 |
| 补码 | 与原码相同 | 反码 + 1 |

### 示例（以 int 型 -5 为例，32 位）

```
原码：10000000 00000000 00000000 00000101
反码：11111111 11111111 11111111 11111010
补码：11111111 11111111 11111111 11111011  ← 实际存入内存
```

### -1 的补码

```
原码：10000000 00000000 00000000 00000001
反码：11111111 11111111 11111111 11111110
补码：11111111 11111111 11111111 11111111  ← 全 1，内存中显示 ff ff ff ff
```

-1 的补码全为 1，是整型二进制存储中"位模式最大"的数。

## sizeof 运算符

`sizeof` 是**运算符**（非函数），返回一个类型/变量/字面值在当前编译器下的内存字节数，类型为 `size_t`。

```c
signed int iValue = 9;
printf("类型字节数：%d %d %d\n",
       sizeof(int),       // 4
       sizeof(iValue),    // 4
       sizeof(9));        // 4
```

## 有符号与无符号

同一段二进制位模式，按 signed / unsigned 不同角度解读，呈现不同值。

```c
char aa = -16, bb = 5;
char cc = aa - bb;   // cc = -21，内存位模式 0xEB = 11101011
printf("%hhd %hhu\n", cc, cc);  // 输出 -21 4294967275
```

> `%hhd` 按有符号 char 解读；`%hhu` 按无符号 char 解读。注意 `%hhu` 实际接收的是经整型提升后的 unsigned int，故输出较大值。

### unsigned 赋值 -1（定义良好的模运算）

unsigned 类型不存在负数，赋值 -1 时按模 $2^n$ 回绕到最大值：

```c
unsigned char a = -1;           // 255
unsigned short b = -1;          // 65535
unsigned int c = -1;            // 4294967295
unsigned long long d = -1LL;    // 18446744073709551615
printf("%hhu %hu %u %llu\n", a, b, c, d);
```

## 溢出现象

一个字节（8 位）可表示 $2^8=256$ 个数：
- unsigned char：0 ~ 255
- signed char：-128 ~ 127

```c
char n = -1;
unsigned char m = -1;
printf("%hhd %hhu\n", n/2+1, n/2+1);  // -128 128
printf("%hhd %hhu\n", m/2+1, m/2+1);  // -128 128
```

推导：m = 255，m/2 = 127，127+1 = 128。对 signed char 而言 128 超出上限 127，位模式 `10000000` 被解读为 -128。

> **注意**：signed 整数溢出属于**未定义行为（UB）**，编译器可做任意优化；unsigned 整数溢出是**定义良好**的模 $2^n$ 回绕。实际编程中应避免依赖 signed 溢出结果。

## 左值与右值

- **左值（lvalue）**：赋值号左侧，拥有可修改的存储空间
- **右值（rvalue）**：字面量或临时值，不可被赋值

```c
int number;
number = 8;   // 正确：number 是可修改的左值
8 = number;   // 错误：表达式必须是可修改的左值
```

## printf 格式化输出（整型）

格式说明符原型：`%[flags][width][.precision][length]specifier`

### length 修饰符

| length | 对应类型 |
|---|---|
| (none) | int |
| `hh` | signed char / unsigned char |
| `h` | short / unsigned short |
| `l` | long / unsigned long |
| `ll` | long long / unsigned long long |

### 同值不同进制输出

```c
int age = 1000;
printf("十进制角度：%d 八进制角度：%o 十六进制角度：%X\n", age, age, age);
// 输出：十进制角度：1000 八进制角度：1750 十六进制角度：3E8
```

- `%d` / `%i`：有符号十进制
- `%u`：无符号十进制
- `%o`：无符号八进制
- `%x` / `%X`：无符号十六进制（小写/大写）
