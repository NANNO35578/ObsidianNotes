# 流程结构综合运用

## 编程思维

用**面向过程**的思维写基本算法：
1. **先结构**：搭建模块化、结构化的代码骨架
2. **补充内容**：在结构内填充具体逻辑

具体问题拆解为三要素：
- **流程结构控制**：拆解动作，用顺序、选择、循环、嵌套表达
- **运算符与表达式**：表达式书写、结果分析
- **数据类型与变量**：临时存储数据

## 随机数

### 相关函数

| 函数 | 头文件 | 作用 |
|---|---|---|
| `time(NULL)` | `time.h` | 返回 1970 年至今的秒数（类型 `time_t`） |
| `srand(seed)` | `stdlib.h` | 设置随机数种子，`void srand(unsigned int seed)` |
| `rand()` | `stdlib.h` | 返回伪随机整数，范围 `0 ~ RAND_MAX`（至少 32767） |

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main()
{
    srand((unsigned)time(NULL));  // 用当前时间作种子，确保每次运行序列不同
    int a = rand();               // 生成伪随机数
    return 0;
}
```

> `rand()` 是**伪随机**：相同种子产生完全相同的序列。用 `time(NULL)` 作种子可使每次运行不同。

### 生成指定范围随机数

```c
num = rand() % 9000 + 1000;  // 0~8999 + 1000 = 1000~9999（四位数）
```

通用公式：`rand() % (b - a + 1) + a` 生成 `[a, b]` 范围内的整数。

## 综合案例一：猜数字游戏

计算机随机生成一个四位数，玩家逐位猜测，猜对的位显示数字，猜错显示 `*`。

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main()
{
    srand((unsigned)time(NULL));
    int num = rand() % 9000 + 1000;  // 随机四位数
    int guess = 0;

    // 取目标数各位
    int q = num / 1000;          // 千位
    int b = num % 1000 / 100;    // 百位
    int s = num % 100 / 10;      // 十位
    int g = num % 10;            // 个位

    do {
        printf("请输入一个四位正整数：");
        scanf_s("%4u", &guess);         // 限制最多读4位
        setvbuf(stdin, NULL, _IOFBF, 100);  // 清除输入缓冲区剩余数据*

        if (!(guess >= 1000 && guess < 10000))
            continue;   // 不是四位数，跳过本次循环体，重新输入

        int qq = guess / 1000;
        int bb = guess % 1000 / 100;
        int ss = guess % 100 / 10;
        int gg = guess % 10;

        printf("%c", q == qq ? q + '0' : '*');  // 数字转字符：数字 + '0'
        printf("%c", b == bb ? b + '0' : '*');
        printf("%c", s == ss ? s + '0' : '*');
        printf("%c\n", g == gg ? g + '0' : '*');

    } while (guess != num);

    printf("恭喜你 猜对了\n");
    return 0;
}
```

> *`setvbuf(stdin, NULL, _IOFBF, 100)` 通过重设 stdin 缓冲区来丢弃多余输入。更标准的清除方式是 `while (getchar() != '\n');`。
>
> `continue`：结束本次循环体，直接进入循环条件判断；`break`：立即退出所在循环。

## 综合案例二：水仙花数

水仙花数：一个三位数，各位数字的立方和等于它本身（如 $153 = 1^3 + 5^3 + 3^3$）。

```c
#include <stdio.h>
#include <math.h>   // pow

int main()
{
    for (int num = 100; num < 1000; num++) {
        int b = num / 100;          // 百位
        int s = num % 100 / 10;     // 十位
        int g = num % 10;           // 个位

        // 推荐用整数乘法，避免浮点精度问题
        if (b * b * b + s * s * s + g * g * g == num)
            printf("%d\n", num);
    }
    return 0;
}
```

输出：`153` `370` `371` `407`

> `pow(b, 3)` 返回 `double`，与 `int` 比较可能因浮点精度导致误判，整数场景优先用连乘。
>
> `for (;;)` 三个表达式均为空，是**无限循环**（等价于 `while(1)`），需在循环体内用 `break` 退出。

## 综合案例三：求素数

素数（质数）：大于 1 的自然数，除了 1 和自身外没有其他因数。

判断优化：若 n 有因数，则必有一个因数 $\le \sqrt{n}$，因此只需检查到 `sqrt(n)`。

```c
#include <stdio.h>
#include <math.h>

int main()
{
    int n = 0;
    printf("输入一个正整数：");
    scanf_s("%d", &n);

    for (int num = 2; num < n; num++) {
        double pfg = sqrt(num);  // 计算平方根
        int ys = 2;

        for (; ys <= pfg; ys++) {
            if (num % ys == 0)   // 找到真正的因数
                break;           // 中途退出，非素数
        }

        // 循环正常结束（ys > pfg）说明没找到因数，是素数
        if (!(ys <= pfg))
            printf("%d ", num);
    }
    return 0;
}
```

**根据循环退出位置判断**：
- `break` 中途退出 → 找到因数 → 非素数
- 条件不满足正常退出（`ys > pfg`）→ 未找到因数 → 素数
