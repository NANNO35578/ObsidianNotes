# 字符串函数与组件封装

## C 语言字符串基础

C 语言没有内置字符串类型，字符串以 `char` 数组存储，以**空字符 `'\0'`** 结尾。

```c
char str1[] = "hello";        // 自动补 '\0'，占 6 字节
char str2[6] = {'h','e','l','l','o','\0'};  // 等价写法
char str3[5] = "hello";       // 错误！没有空间存 '\0'
```

> 字符串字面量存储在常量区，不可修改；修改字符串字面量是未定义行为。

## 标准库 string.h 常用函数

### 长度与复制

| 函数 | 作用 | 注意 |
|---|---|---|
| `strlen(s)` | 返回字符串长度（不含 `'\0'`） | 遇到 `'\0'` 停止 |
| `strcpy(dst, src)` | 复制 src 到 dst | 不检查边界，可能溢出 |
| `strncpy(dst, src, n)` | 最多复制 n 个字符 | 不一定补 `'\0'` |

```c
#include <string.h>

char src[] = "hello";
char dst[20];
strcpy(dst, src);          // dst = "hello"
strncpy(dst, src, 3);      // dst = "hel"（需手动补 '\0'）
```

### 拼接与比较

| 函数 | 作用 |
|---|---|
| `strcat(dst, src)` | 将 src 拼接到 dst 末尾 |
| `strncat(dst, src, n)` | 最多拼接 n 个字符 |
| `strcmp(s1, s2)` | 比较字符串，返回 0/正/负 |
| `strncmp(s1, s2, n)` | 比较前 n 个字符 |

```c
strcmp("abc", "abd");   // 负数（'c' < 'd'）
strcmp("abc", "abc");   // 0
```

### 查找与分割

| 函数 | 作用 |
|---|---|
| `strchr(s, c)` | 查找字符 c 首次出现的位置 |
| `strrchr(s, c)` | 查找字符 c 末次出现的位置 |
| `strstr(s1, s2)` | 查找子串 s2 在 s1 中的位置 |
| `strtok(s, delim)` | 按分隔符分割字符串（破坏性，不可重入） |

```c
char s[] = "a,b,c,d";
char* token = strtok(s, ",");
while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, ",");   // 后续调用传 NULL
}
```

> `strtok` 会修改原字符串（将分隔符替换为 `'\0'`），且使用内部静态变量，线程不安全。VS 中推荐 `strtok_s`。

### 其他常用

| 函数 | 作用 |
|---|---|
| `memset(ptr, val, n)` | 将 n 字节设为 val（常用于清零） |
| `memcpy(dst, src, n)` | 复制 n 字节（不处理重叠） |
| `memmove(dst, src, n)` | 复制 n 字节（可处理重叠） |
| `memcmp(p1, p2, n)` | 比较 n 字节 |
| `sprintf(buf, fmt, ...)` | 格式化写入字符串（VS 用 `sprintf_s`） |

## 字符串组件封装

C 语言原生字符串功能薄弱，实际项目中常封装为自定义字符串组件，统一管理长度和内存。

### 封装思路

- 用结构体保存字符串指针、长度、容量
- 提供创建、销毁、追加、插入、删除、查找等操作
- 内部管理堆内存，避免缓冲区溢出

### 示例：动态字符串结构体

```c
typedef struct {
    char*  data;    // 字符串数据（堆内存）
    size_t len;     // 当前长度
    size_t cap;     // 已分配容量
} MyString;

// 创建
MyString* strCreate(const char* init) {
    MyString* s = (MyString*)malloc(sizeof(MyString));
    s->len = strlen(init);
    s->cap = s->len + 1;
    s->data = (char*)malloc(s->cap);
    strcpy(s->data, init);
    return s;
}

// 追加
void strAppend(MyString* s, const char* tail) {
    size_t add = strlen(tail);
    if (s->len + add + 1 > s->cap) {
        s->cap = s->len + add + 1;
        s->data = (char*)realloc(s->data, s->cap);
    }
    strcat(s->data, tail);
    s->len += add;
}

// 销毁
void strDestroy(MyString* s) {
    free(s->data);
    free(s);
}
```

### 封装的优势

- 自动管理内存，减少缓冲区溢出
- 记录长度，避免重复 `strlen` 扫描
- 接口统一，便于维护和扩展
- 可加入引用计数、写时复制等高级特性

> VS 中 `strcpy`/`sprintf` 等函数会报 C4996 警告，可使用 `_CRT_SECURE_NO_WARNINGS` 宏禁用，或改用 `_s` 安全版本（`strcpy_s`、`sprintf_s`、`strtok_s` 等，需额外传缓冲区大小参数）。
