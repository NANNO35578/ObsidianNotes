# 文件操作

## 文件基本概念

文件是**数据持久化**的手段之一（另一手段是数据库），将内存中的数据保存到外存（硬盘）。

- `FILE*`：文件指针，指向文件处理缓存区（buffer）
- I/O 流（Stream）：内存与外存之间的数据通道
- `fopen` 建立流，`fclose` 关闭流

### 二进制文件 vs 文本文件

| 类型 | 标识 | 说明 |
|---|---|---|
| 二进制文件 (binary) | `b` | 按内存原始字节存储，读写效率高，不可直接阅读 |
| 文本文件 (text) | `t`（默认） | 按字符编码存储，可用记事本打开阅读 |

---

## fopen 打开方式

```c
FILE* fopen(const char* filename, const char* mode);
```

| 模式 | 功能 | 文件不存在时 | 文件存在时 |
|---|---|---|---|
| `r` (read) | 只读 | 打开失败 | 正常打开 |
| `w` (write) | 覆写 | 创建新文件 | 覆盖原有内容 |
| `a` (append) | 追加 | 创建新文件 | 在尾部增加 |
| `r+` | 读写 | 打开失败 | 可读可写，随意更新 |
| `w+` | 写读 | 创建新文件 | 覆盖后可读可写 |
| `a+` | 追读 | 创建新文件 | 尾部追加，可读可写 |

后缀组合：加 `b` 为二进制（`rb`/`wb`/`ab`/`r+b`），加 `t` 为文本（`rt`/`wt`/`at`）。

## 文件基本操作

### 打开与关闭

```c
FILE* p = fopen("d:\\file\\data.txt", "rb");
if (p != NULL) {
    // 处理文件
    fclose(p);   // 关闭文件流
    p = NULL;    // 释放后置空，避免野指针
} else {
    printf("文件不存在\n");
}
```

> 路径中 `\` 需转义为 `\\`，或使用正斜杠 `/`。

### 重命名与删除

```c
int r = rename("d:/file/黑名单.txt", "d:/file/白名单.txt");  // 成功返回0，失败非0
remove("d:/file/白名单.txt");                                 // 删除文件
```

## 文本文件读写

### 写入

| 函数 | 作用 | 示例 |
|---|---|---|
| `fprintf(FILE*, 格式, ...)` | 格式化写入 | `fprintf(p, "hello %d\n", 88);` |
| `fputc(int, FILE*)` | 写一个字符 | `fputc('A', p);` |
| `fputs(const char*, FILE*)` | 写字符串 | `fputs("how are you", p);` |

### 读取

| 函数 | 作用 | 示例 |
|---|---|---|
| `fscanf(FILE*, 格式, ...)` | 格式化读取 | `fscanf(p, "%d,", &num);` |
| `fgetc(FILE*)` | 读一个字符 | `char c = fgetc(p);` |
| `fgets(char*, int, FILE*)` | 读一行 | `fgets(str, 50, p);` |

### 读取到文件末尾

```c
int num;
while (!feof(p) && fscanf(p, "%d,", &num) > 0) {
    printf("%d\n", num);
}
```

`feof(p)` 判断是否到达文件末尾（file end of file）。

> **中文乱码问题**：C 语言 `char` 是单字节，Windows 中文环境需将文本文件保存为 **ANSI 编码**（记事本 → 另存为 → 编码选 ANSI）。UTF-8 编码的中文会乱码。

## 文件光标（游标）操作

| 函数 | 作用 |
|---|---|
| `ftell(FILE*)` | 获取当前光标位置（返回 `long`） |
| `rewind(FILE*)` | 光标回到文件开头 |
| `fseek(FILE*, long offset, int origin)` | 移动光标到指定位置 |
| `fgetpos(FILE*, fpos_t*)` | 获取当前位置（`fpos_t` 类型，支持大文件） |
| `fsetpos(FILE*, const fpos_t*)` | 设置光标位置 |

### fseek 的参考位置

| 常量 | 参考位置 |
|---|---|
| `SEEK_SET` | 文件开头 |
| `SEEK_CUR` | 当前光标位置 |
| `SEEK_END` | 文件结尾 |

```c
fseek(p, 0, SEEK_CUR);   // 确认当前位置（偏移0）
fputc('8', p);            // 在当前位置写入
```

## 二进制文件读写

### fwrite 写入

```c
size_t fwrite(const void* ptr, size_t size, size_t count, FILE* stream);
```

- `ptr`：数据的内存地址
- `size`：每个数据单位的字节数
- `count`：数据单位的数量
- 返回实际写入的单位数

```c
int n = -1;
fwrite(&n, sizeof(int), 1, writeFile);        // 写一个整型

int arr[5] = {97, 98, 10, 48, 49};
fwrite(arr, sizeof(int), 5, writeFile);       // 写整个数组
fwrite(arr, sizeof(int[5]), 1, writeFile);    // 等价写法
```

### fread 读取

```c
size_t fread(void* ptr, size_t size, size_t count, FILE* stream);
```

返回实际读取的单位数（到达末尾时可能小于 count）。

```c
int n;
fread(&n, sizeof(int), 1, readFile);          // 读一个整型
printf("%x\n", n);

int arr[100];
int count = fread(arr, sizeof(int), 100, readFile);  // 读数组，count 为实际读取数
```

## 文件复制

适用于任意大小的文件（包括大文件如视频），分批读取写入：

```c
FILE* from = fopen("源文件路径", "rb");
FILE* to = fopen("目标文件路径", "wb");
unsigned char buffer[1024];   // 1KB 缓冲区
int len;

if (from != NULL && to != NULL) {
    while ((len = fread(buffer, sizeof(char), 1024, from)) > 0) {
        fwrite(buffer, sizeof(char), len, to);
    }
    fclose(from);
    fclose(to);
    from = to = NULL;
}
```

## 综合应用：文本导入与二进制存储

### 从文本文件导入数据

```c
void importData() {
    FILE* pImport = fopen(".\\导入.txt", "rt");
    if (pImport) {
        SCORE temp;   // 栈内存临时变量
        // fscanf_s 是 VS 安全函数，读字符串需传缓冲区大小
        while (fscanf_s(pImport, "%s%d%d%d",
               temp.stuName, 20, &temp.math, &temp.eng, &temp.cn) == 4) {
            PScore ps = (PScore)malloc(sizeof(SCORE));  // 堆内存
            memcpy(ps, &temp, sizeof(SCORE));
            add(listScore, ps);   // 加入链表
        }
        fclose(pImport);
        pImport = NULL;
    }
}
```

### 写入二进制数据库文件

```c
FILE* pDB = fopen(".\\mydb.txt", "ab");
if (pDB) {
    fwrite(ps, sizeof(SCORE), 1, pDB);   // 每条记录写入
    fclose(pDB);
    pDB = NULL;
}
```

### 从二进制文件加载

```c
void loadData() {
    FILE* p = fopen(".\\mydb.txt", "rb");
    if (p) {
        SCORE temp;
        while (fread(&temp, sizeof(SCORE), 1, p) > 0) {
            PScore ps = (PScore)malloc(sizeof(SCORE));
            memcpy(ps, &temp, sizeof(SCORE));
            add(listScore, ps);
        }
        fclose(p);
        p = NULL;
    }
}
```

## 函数内分配内存的三种传参方式

当需要在被调函数中分配内存并带给调用者时，有三种方式：

| 方式 | 形参 | 函数内 | 调用 |
|---|---|---|---|
| 传值（无效） | `char* input` | `input = malloc(128)` 修改的是副本 | `modifyPionter(output1)` 外部不变 |
| 传地址（二级指针） | `char** input` | `*input = malloc(128)` | `modifyPionter2(&output2)` |
| 返回值 | 无 | `return malloc(128)` | `output3 = modifyPionter3()` |

三种方式分配的堆内存都需调用者 `free()` 释放。
