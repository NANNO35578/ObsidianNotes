# 流程结构

## 概述

控制思维：**三种结构，六种表示**。任何行为动作都可用这三个控制表达。

| 结构 | 思维 | 语法表示 |
|---|---|---|
| 顺序 | 一步步依次执行 | 普通语句自上而下 |
| 选择 | 二选一 / 多选一 | `if-else` / `switch` |
| 循环 | 重复执行 | `for`（明确起止次数）/ `do while`（至少一次直到型）/ `while`（至少 0 次每当型） |

读代码方法：整体看结构，关注**入口**和**出口**。

---

## 顺序结构

语句自上而下依次执行，是最基础的流程结构。

---

## 选择结构

### 布尔值

C 语言默认没有 `bool` / `boolean` 类型，用**整数**表示逻辑值：
- **0 代表假（false）**
- **非 0 代表真（true）**

### if-else（二选一）

```c
#include <stdio.h>
int main()
{
    int score = 290;
    if (score >= 280)
        printf("能上理工类本科二批\n");
    else
        printf("不能上\n");
    return 0;
}
```

结构要点：从哪里进，从哪里出；条件为真走 if 分支，为假走 else 分支。

多分支：

```c
if (a) { }
else if (a) { }
else { }   // 三选一
```

### switch（多选一）

```c
char c = 'a';
switch (c) {
    case '1':
        break;
    case '2':
    case '3':       // 两个 case 共享同一分支
        break;
    default:
        ;
}
```

- `case` 后必须跟常量表达式
- 不加 `break` 会顺序穿透到下一个 case
- `default` 处理所有未匹配的情况

## 循环结构

### for 循环（明确起止次数）

```c
for (int days = 1; days <= 21; days++)
    printf("隔离第%d天\n", days);
```

四要素与执行顺序：

1. **初始化**：从哪里开始（`days = 1`）
2. **条件判断**：是否进入循环体（`days <= 21`）
3. **循环体**：重复执行的语句
4. **增量变化**：`days++`

执行流程：`1 → 2 → 3 → 4 → 2 → 3 → 4 → ...`，条件为假时退出。

### while 循环（至少 0 次，每当型）

```c
while (a != 5) {
    a++;
}
```

先判断后执行，条件为假则一次都不执行。

### do-while 循环（至少 1 次，直到型）

```c
do {
    a--;
} while (a > 0);
```

先执行后判断，循环体至少执行一次。

## 清屏与暂停

```c
#include <stdio.h>
#include <stdlib.h>     // system
#include <Windows.h>    // Sleep

int main()
{
    int floor = 25;
    while (floor > -3) {
        floor--;
        if (floor != 0) {       // == 等于，!= 不等于
            system("cls");      // 清除屏幕
            printf("%d\n", floor);
            Sleep(200);         // 暂停 200 毫秒（1秒=1000毫秒）
        }
    }
    return 0;
}
```

- `system("cls")`：调用系统命令清屏，需 `stdlib.h`
- `Sleep(毫秒)`：Windows API 暂停，需 `Windows.h`，首字母大写

## VS 实用技巧

### 批量重命名符号
右键变量名 →「重命名(R)...」（快捷键 `Ctrl+R, Ctrl+R`），可在当前项目范围内批量替换所有引用，预览后应用。

### 断点调试
在代码行号左侧点击设置断点，调试运行时程序会在断点处暂停，可查看局部变量当前值、单步执行，用于看懂代码执行流程。
