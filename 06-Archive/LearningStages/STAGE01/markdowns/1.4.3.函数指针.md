# 函数指针

## 函数名的本质

函数名代表**函数在内存代码区中的地址**。

```c
int add_int(int a, int b);

printf("%p %p", add_int, &add_int);  // 两者输出相同，函数名本身就是地址
```

- 变量名代表的空间是为了存数据
- 函数被执行的本质：通过函数所代表的代码区地址找到代码，**必须用 `()` 传入实参才能执行函数**

---

## 函数指针变量的定义

定义步骤：
1. 先写函数特征（返回类型 + 参数类型）：`int (int, int)`
2. 函数名位置用 `(*变量名)` 占位

```c
int (*)(int, int);    // 函数指针类型（返回 int，两个 int 参数）
int (*pfun)(int, int); // 函数指针变量 pfun
```

> 类比数组指针 `int (*p)[4]`：`*` 先与变量名结合说明是指针，后面的 `(int, int)` 说明指向的是函数。

---

## 函数指针的使用

### 指向函数

```c
// 显式方式
pfun = &add_int;
// 隐式方式（推荐，函数名自动退化为地址）
pfun = add_int;
```

### 调用函数

```c
// 显式方式：找到·得到
printf("%d", (*pfun)(10, 20));
// 隐式方式（推荐）
printf("%d", pfun(15, 25));
```

两种方式效果完全相同，隐式方式更简洁。

## 模块化与面向过程

C 语言是**面向过程**的语言，通过函数实现模块化、结构化：

- 项目 = 共享信息（全局变量）+ 多个函数
- 每个函数内部封装流程结构
- `main` 函数作为入口调用其他函数
- 编译链接后生成可执行文件（`.exe`），运行于操作系统之上，依赖运行时库（如 MSVCRT）
