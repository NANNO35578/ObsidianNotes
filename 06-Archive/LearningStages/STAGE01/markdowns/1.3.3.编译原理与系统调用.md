## C/C++ 编译原理

### 语言层级关系

- **高级语言**：人写的源代码（`.c` / `.cpp`），如 `int money = 368;`
- **汇编语言**：机器语言的助记符号，如 `mov`、`cdq`、`idiv`、`push`、`call`
- **机器语言**：二进制指令，计算机直接执行，如 `0101011101`

转换路径：高级语言 →（编译器）→ 汇编语言 →（汇编器）→ 机器语言。

### 编译四阶段（以 gcc/g++ 为例）

`.h` 头文件不单独编译，在预处理阶段被 `#include` 展开进 `.c`/`.cpp` 源文件。

| 阶段 | 命令 | 输入 | 输出 | 主要工作 |
|---|---|---|---|---|
| 1. 预处理 | `gcc -E a.c -o a.i` | `.c` / `.h` | `.i`（预处理后文件） | 展开 `#include` 头文件、替换宏定义 `#define`、删除注释、处理条件编译 `#ifdef` |
| 2. 编译 | `gcc -S a.i -o a.s` | `.i` | `.s`（汇编文件） | 词法分析、语法分析、语义分析、优化，翻译成汇编语言 |
| 3. 汇编 | `gcc -c a.s -o a.o` | `.s` | `.o` / `.obj`（目标文件） | 汇编器将汇编指令翻译成二进制机器码，生成可重定位目标文件 |
| 4. 链接 | `gcc a.o -o a.exe` | `.o` + 库文件 | `.exe` / `a.out`（可执行文件） | 合并多个目标文件、解析外部符号引用、链接静态/动态库，生成可执行文件 |

> g++ 与 gcc 命令格式一致，区别在于 g++ 按 C++ 语义编译（会链接 C++ 标准库 libstdc++），gcc 按 C 语义编译。

### 各阶段产物说明

- `.i`：纯 C 代码，所有头文件和宏已展开，可直接阅读
- `.s`：文本格式的汇编代码，可用文本编辑器查看
- `.o` / `.obj`：二进制目标文件，含机器码和符号表，但地址尚未最终定位
- `.exe` / `a.out`：最终可执行文件，操作系统可直接加载运行

### 常见错误对应阶段

- **语法错误（C2xxx）**：产生于编译阶段，词法/语法分析不通过
- **链接错误（LNKxxxx）**：产生于链接阶段，符号未定义或多重定义（如多个 `main`、缺少 `&` 导致的外部符号无法解析）

## goto 语句

`goto` 可跳转到代码中指定的行标记，实现无条件转移。

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 0;
flag:                                    // 行标记
    printf("请输入任意三位数:");
    scanf_s("%3d", &n);
    int nn = n * 1001;                   // 变为6位数
    printf("变为6位数是：%d\n", nn);
    nn /= 7;
    nn /= 11;
    nn /= 13;
    printf("连续除7,11,13后是：%d\n", nn);
    system("pause");
    goto flag;                            // 跳回标记处，形成循环
    return 0;
}
```

- 行标记格式：`标记名:`，后面跟冒号
- `goto 标记名;` 跳转到对应标记继续执行
- 可用于跳出多层循环，但滥用会破坏程序结构，实际开发中不推荐

## system 函数

`system` 用于调用操作系统命令，需包含头文件 `stdlib.h`（std 标准的 lib 库，常用功能函数）。

```c
#include <stdlib.h>

system("pause");     // 调用系统 pause 命令，阻止命令行窗口关闭
system("notepad");   // 启动记事本
system("mspaint");   // 启动画图板
```

- `system("pause")`：输出"请按任意键继续..."，等待用户按键后窗口才关闭
- `system` 是向操作系统发出指令，引号内是系统可识别的程序或命令
- 仅 Windows 平台有效，跨平台程序应避免使用
