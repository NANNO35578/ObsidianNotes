# 一维数组与指针

## 一维数组基础

### 数组的特性

长度固定、同类型、有编号（下标从 0 开始）。

### 声明与初始化

```c
int ages[5];              // 声明 5 个 int，未初始化
int arr[4] = {2, 4, 6, 7}; // 完全初始化
int arr1[4] = {3, 7};      // 不完全初始化，其余默认 0
int arr3[4] = {0};         // 全部清零
int arr4[] = {7, 9, 6, 2}; // 由初始化列表自动决定长度
```

> 数组长度必须是**常量表达式**（如 `8*5`），不能是变量。VS 不支持 C99 的可变长度数组（VLA）。

### 大小计算

```c
sizeof(int[5]);   // 20，整个数组类型的大小
sizeof(ages);     // 20，数组占总字节数
int len = sizeof(ages) / sizeof(int);       // 成员数 = 5
int len2 = sizeof(ages) / sizeof(ages[0]);  // 更通用的写法
```

### 元素访问与越界

```c
ages[0] = 1; ages[1] = 3; ages[2] = 7;
ages[5] = 66;   // 越界！运行时 Stack around the variable was corrupted
ages[-1] = 99;  // 越界！
```

### 遍历

```c
for (int i = 0; i < len; i++)
    printf("%d ", ages[i]);
```

## 数组名的特性

**数组名代表第 0 个成员的首地址**，但数组名是**指针常量**，不可被修改。

```c
int arr[5] = {1, 2, 3, 4, 5};
arr++;    // 错误！数组名不能被改变（否则数组就丢失了）
```

### arr 与 &arr 的区别

| 表达式 | 类型 | 含义 | +1 偏移量 |
|---|---|---|---|
| `arr` | `int*`（退化后） | 第 0 个成员的地址 | 1 个成员（4 字节） |
| `&arr` | `int(*)[5]`（数组指针） | 整个数组的地址 | 整个数组（20 字节） |

```c
arr + 1;     // 地址 +4，指向 arr[1]
&arr + 1;    // 地址 +20，跳过整个数组
```

### 下标与指针的等价关系

`*(参考地址 + 偏移数) == 参考地址[偏移数]`

```c
arr[2]      == *(arr + 2)   // 最常用
*(2 + arr)  == 2[arr]       // 等价写法，不推荐
(arr + 1)[2] == *((arr+1)+2) == arr[3]
```

- `arr, arr+1, arr+2`：找到地址
- `*(arr+0), *(arr+1), *(arr+2)`：得到空间（可读写）

## 数组指针与指针数组

### 区别

`[]` 优先级高于 `*`，据此区分：

| 声明 | 名称 | 本质 |
|---|---|---|
| `int (*pa)[4]` | 数组指针 | 一个指针，指向含 4 个 int 的数组 |
| `int *parr[4]` | 指针数组 | 一个数组，4 个成员都是 `int*` 指针 |

记忆：`int (*pa)[4]` 中 `*` 先与 `pa` 结合（括号），所以 pa 是指针；`int *parr[4]` 中 `[]` 先与 `parr` 结合，所以 parr 是数组。

### 数组指针

```c
int (*pa)[4];    // 指向 int[4] 的指针，pa+1 偏移 16 字节
pa = &arr;       // 必须取整个数组的地址
```

### 指针数组

每个成员都是指针变量，常用于管理多个地址：

```c
int a = 99;
int arr[4] = {5, 7, 9, 8};
int* parr[4] = {&a, arr, arr + 1, &arr[3]};

printf("%d", *parr[0]);  // 99（parr[0] = &a，*parr[0] = a）
printf("%d", *parr[1]);  // 5（parr[1] = arr，指向 arr[0]）
```

> 指针数组成员未初始化时为野指针，应初始化为 `NULL` 或合法地址。`int *p[4] = {0};` 在 C 中合法（0 是空指针常量），但建议写 `{NULL}`。

## 用指针遍历数组

```c
int as[] = {10, 20, 30, 40, 50};
int* p = as;            // p 指向 as[0]，等价于 p = &as[0]

// 方式1：指针偏移
for (int i = 0; i < 5; i++)
    printf("%d ", *(p + i));

// 方式2：指针自增（p 会移动）
for (int i = 0; i < 5; i++)
    printf("%d ", *p++);  // *p++ 等价于 *(p++)，先取值再偏移
```

### 指针变量 vs 数组名

- `p++`：指针变量可以改变，指向任意空间
- `as++`：数组名是指针常量，不可改变

## 一维数组典型算法

### 求最大值

```c
int ds[] = {10, 30, 43, 43, 23, 12, 40};
int len = sizeof(ds) / sizeof(ds[0]);
int max = ds[0];
for (int i = 1; i < len; i++)
    if (max < ds[i]) max = ds[i];
```

### 首位翻转（第一个元素移到末尾）

```c
// 方法1：串数
int tmp = ds[0];
for (int i = 1; i < len; i++) ds[i - 1] = ds[i];
ds[len - 1] = tmp;

// 方法2：相邻交换
for (int i = 0; i < len - 1; i++) {
    int t = ds[i]; ds[i] = ds[i + 1]; ds[i + 1] = t;
}
```

### 查找指定元素首次出现的下标

```c
int i;  // 注意：i 必须在 for 外声明，循环后还要用
for (i = 0; i < len; i++) {
    if (ds[i] == find) {
        printf("下标是：%d\n", i);
        break;
    }
}
if (!(i < len)) printf("没找到");
```

> `for (int i = 0; ...)` 中 i 仅在 for 内有效，外部使用会报"变量未初始化"。

### 折半查找（二分查找）

前提：数组**有序**。

```c
int d[] = {1, 5, 8, 12, 23, 44, 56, 78, 99, 200};
int left = 0, right = sizeof(d) / sizeof(d[0]) - 1, mid;
do {
    mid = (left + right) >> 1;  // 等价于 (left+right)/2
    if (d[mid] == find) { printf("下标：%d\n", mid); break; }
    else if (d[mid] > find) right = mid - 1;
    else left = mid + 1;
} while (left <= right);
if (!(left <= right)) printf("没找到");
```

### 选择排序

```c
for (int suo = 0; suo < len - 1; suo++)
    for (int bi = suo + 1; bi < len; bi++)
        if (ds[suo] > ds[bi]) {
            int t = ds[suo]; ds[suo] = ds[bi]; ds[bi] = t;
        }
```

### 约瑟夫环

n 个人围成一圈，数到 m 的出列：

```c
int r[41], m = 3, n = 41;
for (int k = 0; k < 41; k++) r[k] = k + 1;
int swxb = 0;  // 死亡下标
while (n > 1) {
    swxb = (swxb + m - 1) % n;   // 确定死亡位置
    printf("%d ", r[swxb]);
    for (int hr = swxb + 1; hr < n; hr++)  // 活人覆盖死人
        r[hr - 1] = r[hr];
    n--;
}
```

## 指针与大小端笔试题

### 通过 char* 读取多字节数据

小端模式下，低地址存低位字节：

```c
long long data = 0x1234567890;
// 小端内存：90 78 56 34 12 00 00 00（低地址→高地址）
char* p = (char*)&data;
p += 4;                  // 指向第 5 个字节
printf("%x", *p);        // 输出 12
```

> 强制类型转换在 C 中可用；C++ 编译器语法检查更严格，不同类型指针直接赋值会报错，需显式强制转换。

### 指针大小与偏移

x86 下所有指针变量都是 4 字节，但 `+1` 偏移量由指向类型决定：

| 指针 | sizeof(指针) | sizeof(*指针) | 指针+1 偏移 |
|---|---|---|---|
| `int* p` | 4 | 4 | +4 |
| `double* pd` | 4 | 8 | +8 |
| `long long* pll` | 4 | 8 | +8 |
| `char* pc` | 4 | 1 | +1 |

### 指针操作等价性

```c
int a = 10;
int* p = &a;
*p = 100;     // a = 100
*p += 55;     // a = 155
(*p)++;       // a = 156（注意括号，*p++ 是指针偏移）
```
