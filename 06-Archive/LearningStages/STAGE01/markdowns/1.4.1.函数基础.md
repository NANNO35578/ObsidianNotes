# 函数基础

## 函数的三种状态

| 状态 | 作用 | 示例 |
|---|---|---|
| 声明状态 | 打广告/告知，告诉编译器函数存在 | `int enabledMarry(int sex, int age);` |
| 调用状态 | 使用函数，传入实际数据 | `enabledMarry(1, 30)` |
| 定义状态 | 创建/生产，函数的完整实现 | 函数体 `{ ... }` |

- **返回类型**：函数执行完产生什么类型的结果数据
- **形式参数**：函数执行需要的条件（形参）
- **实际参数**：调用时传入的实际数据（实参）
- **流程结构**：函数体内描述具体功能

## 函数的执行原理

函数调用时在栈区执行，执行完空间释放（"消失"）。

### 栈（Stack）

- 数据结构的一种，**先进后出 / 后进先出（LIFO）**
- **压入栈（push）**：函数调用时，在栈区为形参和局部变量分配空间
- **弹出栈（pop）**：函数执行完毕，释放栈空间

### 内存分区与函数

```
高地址 → 代码区（函数指令，函数指针指向此处）
         常量区
         全局/静态区
         堆区（heap，手动分配释放）
低地址 → 栈区（stack，函数形参、局部变量，自动管理）
```

### 调用堆栈调试

VS 中：调试 → 窗口 → 调用堆栈（Ctrl+Alt+C），可查看函数调用链。

> 函数实参的执行顺序：**从右到左**。例如 `printf("%d %d", add(5,10), add(9,8))` 先执行 `add(9,8)` 再执行 `add(5,10)`。函数逻辑可被无限次调用。

## return 的使用

```c
return 0;   // 结束函数调用，返回值
```

- `return` 会立即终止当前函数，后续代码不再执行
- 中途结束必须配合条件语句使用，否则会产生不可达代码（死代码）

```c
int fun2(int a, int b) {
    if (a > b)
        return 0;   // 条件满足时提前返回
    for (a++; a < b; a++) { ... }
}
```

## 函数参数传递

### 值传递（copy 方式）—— 无法修改实参

```c
void exchange(int a, int b) {
    int t = a; a = b; b = t;   // 交换的是形参副本
}
int m = 5, n = 8;
exchange(m, n);   // m 和 n 仍然是 5 和 8，未被交换
```

形参 `a, b` 是实参 `m, n` 的**副本**，修改副本不影响原变量。这是常见的"坑"。

### 地址传递 —— 可修改实参

```c
void swap(int* m, int* n) {
    int t = *m; *m = *n; *n = t;   // 通过指针间接修改原变量
}
int m = 5, n = 8;
swap(&m, &n);   // m 和 n 成功交换为 8 和 5
```

传址相当于把变量的地址复制给形参，通过解引用操作原变量空间。

### 传值 vs 传址

| 方式 | 传递内容 | 能否修改实参 |
|---|---|---|
| 传值 | 复制变量的值 | 不能 |
| 传址 | 复制变量的地址 | 能（通过指针间接修改） |

函数间数据传递方向：传实参（0~多个值）→ 函数 → 返回（return 0 或 1 个值）。函数彼此独立、互相调用。

## 数组作为函数参数

### 常见的坑

```c
int add_all(int a[]) {       // 数组模样的形参
    int len = sizeof(a) / sizeof(a[0]);  // 错误！a 本质是指针
    ...
}
```

数组作为形参时，**本质退化为指针变量**，`sizeof(a)` 得到的是指针大小（x86 为 4 字节），不是整个数组的大小，因此无法在函数内计算数组长度。

### 正确做法：额外传递长度

```c
int add_all(int a[], int len) {   // 首地址 + 有效长度
    int sum = 0;
    for (int i = 0; i < len; i++)
        sum += a[i];
    return sum;
}

int arr[] = {7, 9, 5, 6, 7, 2, 10};
int s = add_all(arr, 7);   // 同时传入数组和长度
```

> 形参写 `int a[]` 只是给调用者一个"数组"的暗示，编译器实际按 `int* a` 处理。也可显式写为 `int add_all(int* a, int len)`。

## 函数提取与重构

### 重构的基本思想

函数的意义：**对流程结构的封装**。

- 变化的数据甩在外面（作为参数）
- 固定的逻辑进行封装（函数体）
- 函数名用动词/功能名命名

### VS 提取函数操作

选中代码 → 快速操作和重构（Ctrl+.）→ 提取函数 → 输入函数名 → 确定。

> "函数"、"功能"、"方法"（function / method）在不同语境下是同义词。

### 重构（Refactor）

- **目的**：应对变化，重新改变代码结构
- **前提**：既有代码已经能正常运行，优化结构不影响功能
- **解决的问题**：可读性差、维护性差、复用性差（扩展/修改困难）
- 函数是实现技术，模块化是思维方式，重构是更高层次的代码改善
- 好代码自带阅读性
