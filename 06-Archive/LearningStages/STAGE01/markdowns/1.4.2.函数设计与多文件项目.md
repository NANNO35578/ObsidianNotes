# 函数设计与多文件项目重构

## 函数开发的三种状态

| 状态 | 角色 | 说明 |
|---|---|---|
| 前置声明 | 设计规划 | 先写函数声明，规划接口（参数、返回值） |
| 按需调用 | 场景模拟 | 在 main 中调用函数，验证使用方式 |
| 定义实现 | 请人干活 | 编写函数体，完成具体逻辑 |

表面是语法，实际是**分工协作的开发方式**。

### 函数设计规范

- 函数名用**动词**，表达功能
- 三要素：输入（参数）→ 处理 → 返回
- 声明前写注释：功能、参数含义、返回值含义

```c
/*
得到最大值所在的下标
参数：arr 数组，len 数组长度
返回值：下标
*/
unsigned getMaxValueIndex(double arr[], int len);
```

> 只有声明没有定义会报 **LNK2019**（无法解析的外部符号）。VS 中可点击函数名旁的快速操作 → "创建…的定义"自动生成函数骨架。

## 典型函数示例

### 求最大值下标

```c
unsigned getMaxValueIndex(double arr[], int len) {
    int maxIndex = 0;
    for (int i = 1; i < len; i++)
        if (arr[maxIndex] < arr[i])
            maxIndex = i;
    return maxIndex;
}
```

### 判断素数

```c
#include <math.h>

// 参数：num 一个整数
// 返回值：0 代表否，1 代表是
int isOrNot(int num) {
    double pjg = sqrt(num);
    for (int ys = 2; ys <= pjg; ys++)
        if (num % ys == 0)
            return 0;   // 找到因数，不是素数，提前返回
    return 1;
}
```

### 通过指针带回多个结果（求因数）

函数只能用 `return` 返回一个值；需要带回多个数据时，用指针参数间接写入调用者的空间。

```c
// 参数：n 正整数，a 指向数组，把因数存入其中
// 返回：实际存入数组的个数
int fun16(int n, int* a) {
    int len = 0;
    a[len++] = 1;
    for (int ys = 2; ys <= n / 2; ys++)
        if (n % ys == 0)
            a[len++] = ys;
    a[len++] = n;
    return len;
}

// 调用
int ys[50];
int count = fun16(50, ys);
for (int i = 0; i < count; i++)
    printf("%d ", ys[i]);
```

## 自定义头文件与多文件项目

### 创建头文件

VS 中：右键"头文件" → 添加 → 新建项 → 头文件(.h)。

### include 两种形式

```c
#include <stdio.h>     // 尖括号：在系统目录中寻找
#include "apple.h"     // 双引号：在当前项目中寻找
```

### 头文件放什么

```c
#pragma once          // 防止头文件被重复包含（VS 支持，非标准但常用）

/* 自定义类型 */
/* 全局变量声明（extern） */
/* 函数声明 */
void newApple(void);
```

> 标准 C 中也可用 `#ifndef` / `#define` / `#endif` 守卫宏实现同样效果，`#pragma once` 是 VS/GCC 等主流编译器的扩展。

### 源文件放什么

```c
#include "apple.h"    // 包含对应头文件
#include <stdlib.h>

int appleHang = 0;    // 全局变量的定义（只能在一个源文件中）
int appleLie = 0;

void newApple(void) { // 函数的定义实现
    appleHang = rand() % 14 + 3;
    appleLie = rand() % 14 + 3;
}
```

## extern 与跨文件全局变量

全局变量在**一个源文件中定义**，在其他源文件中使用时需用 `extern` 声明：

```c
// apple.cpp 中定义
int appleHang = 0;

// snake.h 中声明（供其他文件使用）
extern int appleHang;   // 外部全局变量链接声明，不分配空间
```

`extern` 告诉编译器"这个变量在别处定义"，链接时再解析地址。

## 贪吃蛇项目模块化重构

### 按参与者划分模块

| 模块 | 头文件 | 源文件 | 职责 |
|---|---|---|---|
| 蛇 | snake.h | snake.cpp | 爬行、吃苹果判断、长个、出界判断、咬自己判断 |
| 苹果 | apple.h | apple.cpp | 生成新苹果 |
| 游戏本身 | game.h | game.cpp | 初始化、绘图、定时处理、键盘控制、gameover |

### 模块原则

- **谁的功能，谁的变量信息，放在谁的代码内**
- **高内聚、低耦合**
- 重构前提：功能已经 OK，改变结构后仍然 OK（解耦）

### snake 模块函数

```c
void snakeMove(void);              // 蛇爬行
int  enabledEatApple(void);        // 能否吃到苹果（0不能 1能）
void grow(void);                   // 长个
int  enabledOut(void);             // 能否出界（0不能 1能）
int  enabledEatSelf(void);         // 能否咬自己（0不能 1能）
```

### 重构后的 gameInterval

```c
void gameInterval() {
    snakeMove();                        // 爬
    if (enabledEatApple()) {            // 能吃苹果
        grow();                         // 长个
        newApple();                     // 生成新苹果
    }
    if (enabledOut())                   // 能撞墙
        gameover();
    if (enabledEatSelf())               // 能咬自己
        gameover();
}
```

函数名即注释，可读性显著提升。

## 函数的价值

函数能够增强代码的：**可维护性、复用性、可读性**。本质是对流程结构的封装，把变化的数据作为参数，把固定的逻辑封装起来。
