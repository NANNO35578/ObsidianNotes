## C 语言编程思维

C 语言的三大机制：**模块化、结构化、面向过程**。

### 模块化思维
通过 `#include` 打开模块，包含头文件后才能使用其中的功能。

```c
#include<stdio.h>  // std：标准的 input 输入 output 输出，.h 头文件
```

> 注意：必须先打开模块（`#include`），后使用里面的功能。若未包含 `stdio.h` 就使用 `printf`，会报 C4013（"printf"未定义；假设外部返回 int）、LNK2019（无法解析的外部符号 _printf）、LNK1120（1 个无法解析的外部命令）。

### 结构化思维
不同结构解决不同问题，先写完整的结构，再补充内容。

```c
// 解决：代码的可执行问题
int main()
{
    // 面向过程 —— 控制思维
    printf("hello world.\n");
    return 0;
}
```

**写代码的灵魂感：在思维基础上写代码**
- 结构是固定的语法格式
- 步骤 1：先写好结构
- 步骤 2：再在结构内补充内容

### 面向过程思维
通过控制思维，按步骤执行语句。

## main 函数注意事项

### main 是项目的执行入口
`main` 函数是程序的唯一执行入口，拼写必须准确。

**拼写错误示例**：将 `main` 写成 `mian`，会报：
- LNK2019：无法解析的外部符号 `_main`，函数 `int __cdecl invoke_main(void)` 中引用了该符号
- LNK1120：1 个无法解析的外部命令

报错环境信息：MS（微软 VC++ RunTime），调试环境（Debug）。

### 一个项目中只能有一个 main
在同一个项目中创建多个 `.c` 源文件（如 `1.c` 和 `2.c`），若每个文件都定义了 `main` 函数，会导致链接错误：
- LNK2005：`_main` 已经在 `1.obj` 中定义
- LNK1169：找到一个或多个多重定义的符号

原因：重名了，找到了多个执行入口。

## 语句种类

语句（sentence）即指令，分为三类：

| 种类 | 形式 | 说明 |
|---|---|---|
| 标准单条语句 | 以分号 `;` 结尾 | 最常见的语句形式 |
| 空语句 | 只有分号 `;` | 占位作用 |
| 复合语句 | 用 `{}` 包裹多条语句 | 语法视角视为"一句" |

示例：

```c
int main()
{
    // 面向过程 —— 控制思维
    printf("hello world.\n");

    // 空语句：占位作用
    ;

    // 多条语句表达一个逻辑块——复合语句
    {
        printf("我是谁？");
        printf("我从哪里来");
        printf("要到哪里去");
    }

    return 0;
}
```

## printf 格式化输出

源自库 `stdio.h`。

### 模板思维：固定 + 可变

`printf` = **print format**（格式化打印），核心是模板思维：固定部分不变，变化部分用 `%` 占位，准备好对应数据，类型匹配一一对应。

以人民币为例：
- 固定描述："中国人民银行 100 元 毛泽东 国徽"
- 模板化："中国人民银行 %d 元 毛泽东 国徽", 100

### printf 模板用法三步走
1. 写好数据准确的样子：`printf("北京时间：4:11PM\n");`
2. 找变化的部位，用 `%` 占位，准备好对应数据：`printf("北京时间：%d:%d PM\n", 4, 11);`
3. 修饰数据：`printf("北京时间：%02d:%02d PM\n", 4, 11);`

### 格式说明符原型

```
%[flags][width][.precision][length]specifier
```

各部分含义：修饰标记（flags）、宽度（width）、精度（.precision）、长度（length）、数据类型占位符（specifier）。

> [!abstract] 例：`Hello World!`
```c
#include <stdio.h>

int main(){
    printf("Hello World!\n");
    return 0;
}
```

| o | Unsigned octal | 610 |

### flags（修饰标记）

| flags | description |
|---|---|
| - | Left-justify within the given field width; Right justification is the default |
| + | Forces to preceed the result with a plus or minus sign (+ or -) even for positive numbers. By default, only negative numbers are preceded with a - sign. |
| (space) | If no sign is going to be written, a blank space is inserted before the value. |
| # | Used with o, x or X specifiers the value is preceeded with 0, 0x or 0X respectively for values different than zero. Used with a, A, e, E, f, F, g or G it forces the written output to contain a decimal point even if no more digits follow. |
| 0 | Left-pads the number with zeroes (0) instead of spaces when padding is specified. |

### width（宽度）

| width | description |
|---|---|
| (number) | Minimum number of characters to be printed. If the value to be printed is shorter than this number, the result is padded with blank spaces. The value is not truncated even if the result is larger. |
| * | The width is not specified in the format string, but as an additional integer value argument preceding the argument that has to be formatted. |

### .precision（精度）

| .precision | description |
|---|---|
| .number | For integer specifiers (d, i, o, u, x, X): precision specifies the minimum number of digits to be written. If the value to be written is shorter than this number, the result is padded with leading zeros. A precision of 0 means that no character is written for the value 0. For a, A, e, E, f and F specifiers: this is the number of digits to be printed after the decimal point (by default, this is 6). For g and G specifiers: This is the maximum number of significant digits to be printed. For s: this is the maximum number of characters to be printed. |
| .* | The precision is not specified in the format string, but as an additional integer value argument preceding the argument that has to be formatted. |

> `%f` 默认输出 6 个小数位。

### 格式修饰示例

以 `%7d*%-7.1f=%.1f` 为例：
- `7`：整体宽度（最小字符数）
- `-`：代表左对齐，不写则默认右对齐
- `.1`：小数位占 1 位

代码示例：

```c
printf("%7d*%-7.1f=%.1f\n", 3, 0.7, 3*0.7);
printf("%7.1f*%-7.1f=%.2f\n", 3.3, 6.7, 3.3*6.7);
```

输出：
```
      3*0.7    =2.1
    3.3*6.7    =22.11
```

## 常见错误与调试

### 中英文符号混淆
C 语言代码中必须使用英文半角符号，中文符号会导致编译错误。

### 缺少头文件
未 `#include<stdio.h>` 就使用 `printf`，会报 C4013、LNK2019、LNK1120 错误。

### VS 调试运行
- 「开始执行(不调试)」：快捷键 Ctrl+F5，只看结果，不跟踪过程
- 程序正常结束时输出：进程已退出，代码为 0

### 找茬对比
以下两段代码的区别在于左侧缺少 `#include <stdio.h>`，无法通过编译：

```c
// 左侧（错误）：缺少头文件
int main ()
{
    printf("hello world");
    return 0;
}

// 右侧（正确）
#include <stdio.h>
int main ( )
{
    printf( "hello world" );
    return 0;
}
```
