# 字符型 · 浮点型存储原理

## 字符型存储原理

### 字符显示原理

字符在内存中以**编码值**（整数）存储，输出时由显卡将编码映射为字符影像显示在液晶屏上。

```
字符编码 → 显卡 → 显示器液晶屏 → 字符影像
```

`'A'` 的等价表示：`'A' == 65 == '\101' == '\x41'`

```c
char ch = 'A';
char ch2 = 66;
printf("影像方式 %c 编码方式：%hhd\n", ch, ch);   // 影像方式 A 编码方式：65
printf("影像方式 %c 编码方式：%hhd\n", ch2, ch2); // 影像方式 B 编码方式：66
```

### ASCII 与 Unicode

| 字符集 | 字节数 | 类型 | 表达范围 |
|---|---|---|---|
| ASCII | 单字节 | `char` | 0~127（英文字符） |
| Unicode | 双字节 | `wchar_t` | 可表达汉字等多语言字符 |

关键编码值：`'0' = 48`，`'A' = 65`，`'a' = 97`。

### 字符字面值的三种设置方式

```c
char letter;
letter = 'a';         // 1. 影像方式（所见即所得）
letter = '\142';      // 2. 八进制编码
letter = '\x5a';      // 3. 十六进制编码
printf("\141\142\x63\x64\x65\n");  // 输出 abcde
```

### 转义字符

| 转义符 | 含义 | ASCII 十进制 |
|---|---|---|
| `\n` | 换行（LF） | 10 |
| `\r` | 回车，回到行首（CR） | 13 |
| `\b` | 退格（BS） | 8 |
| `\a` | 响铃（BEL） | 7 |
| `\\` | 反斜杠本身 | 92 |
| `\'` | 单引号 | 39 |
| `\"` | 双引号 | 34 |
| `%%` | printf 中输出一个 `%` | - |

```c
printf("ABC\nDE\n");  // \n 换行
printf("ABC\bDE\n");  // \b 退格
printf("ABC\rDE\n");  // \r 回车回到行头部
printf("\\ \' \"");    // 输出 \ ' "
```

> Windows 文本换行通常为 `\r\n`（CR+LF），Linux/macOS 为 `\n`（LF）。

### 字符编码规律与常见算法

利用 ASCII 编码的连续性：

```c
// 1. 大小写字母互转：差 32
char zm = 't';
zm += 32;  // 't' → 'T'（小写转大写应为 -= 32，此处示例）
zm -= 32;

// 2. 数字字符与数字互转：±'0'
int num = '8';
num -= '0';  // '8' → 8
printf("%d\n", num);  // 8
```

## 浮点型存储原理

### 基本类型

| 类型 | 字节 | 范围 | 字面值后缀 | 打印格式 |
|---|---|---|---|---|
| float（单精度） | 4 | 3.4e-38~3.4e38 | `F` / `f` | `%f` / `%e` / `%g` |
| double（双精度） | 8 | 1.7e-308~1.7e308 | 无（默认） | `%f` / `%e` / `%g` |
| long double | 平台相关* | 更大 | `L` / `l` | `%Lf` |

> *VS x86 下 `long double` 为 8 字节；Linux GCC 下通常为 16 字节（80 位扩展精度）。跨平台代码不应假设其大小。

```c
float  fValue  = .25f;    // float 字面值需加 f 后缀
double dValue  = .25;     // 默认为 double
long double ldValue = .25l;

// 字面值类型由后缀决定
sizeof(3.1415926F)  // 4（float）
sizeof(3.1415926)   // 8（double）
sizeof(3.1415926L)  // 8 或 16（long double，依平台）
```

### 浮点字面值两种写法

```c
double pi  = 3.1415926;    // 小数方式
double dis = 45.1e9;       // 指数方式，e 代表 10 的几次方
```

打印格式：
- `%f`：小数格式（默认 6 位小数）
- `%e` / `%E`：指数方式（科学计数法）
- `%g` / `%G`：最简短方式（自动选 %f 或 %e）

### IEEE 754 存储格式

浮点数由三个字段组成，遵循 IEEE 754 标准：

| 类型 | 总位 | 符号位 s | 指数位 exp | 尾数位 frac | 指数偏移量 |
|---|---|---|---|---|---|
| float | 32 | 1 位 | 8 位 | 23 位 | 127 |
| double | 64 | 1 位 | 11 位 | 52 位 | 1023 |

存储值 = $(-1)^s \times (1.\text{frac})_2 \times 2^{\text{exp} - \text{偏移量}}$

### float 存储举例：10.127f

1. 二进制化：$10.127 \approx 1010.00100000100000100001\ldots_2$
2. 规格化：$1.01000100000100000100001\ldots \times 2^3$（注：指数为 3，非 11）
3. 指数偏移：$3 + 127 = 130 = 10000010_2$
4. 尾数：取小数点后 23 位

实际存储：
- 符号位：`0`
- 指数：`10000010`（130）
- 尾数：`010000100000100000110001`
- 十六进制：`0x41220831`

> 由于尾数位数有限，10.127 实际存储值为 **10.12699985504150390625**，存在转换误差。因此**浮点数不能直接用 `==` 比较**，应判断差值是否小于某个精度阈值（如 `1e-6`）。

### 浮点型结论

1. 单精度与双精度的区别：基于尾数位数的有效数字不同（float 约 6~7 位，double 约 15~17 位）
2. 浮点数并不真正准确，存在精度误差
3. 存储原理复杂度高于整型，可以表达更大范围的数据
4. 整型存储更准确，但存在溢出现象

## 自动类型转换

### 转换规则

算术混合运算时，编译器按以下规则自动转换（usual arithmetic conversions）：

1. **相同存储原理（定点）**：字节数少的向字节数多的转换
   `char → short → int → long → long long`
2. **不同存储原理**：定点存储向浮点存储转换
   `整型 → float → double → long double`
3. **signed 与 unsigned**：同级别时 unsigned 优先（可能导致意外结果，需谨慎）

```c
int num = 45.12;     // 45，浮点赋给整型，截断小数部分
double p = 48;       // 48.0，整型赋给浮点，自动提升

sizeof(8 + 'a' + 5LL);          // 8，结果为 long long
sizeof(8 + 'a' + 5LL + 3.1f);   // 8，结果为 double
sizeof(8 + 'a' + 5LL + 3.1f + 0.L); // long double
```

> 注意：`printf("%f", 7/2)` 输出异常，因为 `7/2` 是整型除法结果为 3，`%f` 不会自动转换。应写 `7/2.` 或 `(double)7/2` 使运算在浮点域进行。

## 实践：密码强弱判断

逐个字符读取密码，统计字符种类（数字/大写/小写/其他），结合长度判断强度。

```c
#include <stdio.h>
int main()
{
    char pwd;
    int count = 0;
    int hasNumber = 0, hasUpper = 0, hasLower = 0, hasOthers = 0;

    do {
        scanf_s("%c", &pwd, 1);  // 逐字符读取，第三个参数为缓冲区大小
        if (pwd != '\n') {
            count++;
            if (pwd >= '0' && pwd <= '9')       hasNumber = 1;
            else if (pwd >= 'A' && pwd <= 'Z')  hasUpper = 1;
            else if (pwd >= 'a' && pwd <= 'z')  hasLower = 1;
            else                                 hasOthers = 1;
        }
    } while (pwd != '\n');

    if (count <= 6) {
        printf("弱密码\n");
    } else {
        switch (hasNumber + hasUpper + hasLower + hasOthers) {
            case 1: case 2: printf("弱密码\n"); break;
            case 3:         printf("中密码\n"); break;
            case 4:         printf("强密码\n"); break;
        }
    }
    return 0;
}
```

> `scanf_s` 是 VS 提供的安全版本，读取 `%c` 时需第三个参数指定缓冲区大小（此处为 1）。标准 C 的 `scanf` 不需要该参数。
