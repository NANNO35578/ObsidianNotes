## 变量基本概念

**变量（variable）**：临时存储数据的容器。C 语言是**强类型语言**，对数据类型特别敏感，定义变量时必须声明类型。

```c
int money = 745;  // 定义变量/创建变量，数据类型为整数类型
```

### 变量的三种操作

| 操作 | 语法 | 说明 |
|---|---|---|
| 赋值 | `变量名 = 值;` | 覆盖原值 |
| 取值 | `printf("%d", 变量名);` | 读取变量当前值 |
| 增值 | `变量名 += 值;` / `变量名++;` | 在原值基础上增加 |

```c
int age = 1;          // 创建并初始化
age = 5;              // 赋值：覆盖原值
age += 5;             // 复合赋值（专业写法），等价于 age = age + 5
age++;                // 自增 1（后置）
++age;                // 自增 1（前置）
```

复合赋值运算符：`+=` `-=` `*=` `/=` `%=`
自增自减：`++` `--`（仅增减 1）

## C 语言标准与保留字

### 标准版本
- **C89 / C90 / ANSI C**：同一标准。1989 年 ANSI 推出，1990 年 ISO 参照发布，故称 C90。
- **C99**：1994 年 ANSI/ISO 联合修订，1999 年推出。增加国际化字符、修正缺陷、数值计算增强。
- **C11**：2011 年标准委员会推出。

VS2019 可在项目属性中设置 C 语言标准：默认(旧 MSVC)、ISO C11 (`/std:c11`)、ISO C17 (`/std:c17`)。

### 保留字（关键字）

**C89/C90（32 个）**：
`auto` `break` `case` `char` `const` `continue` `default` `do` `double` `else` `enum` `extern` `float` `for` `goto` `if` `int` `long` `register` `return` `short` `signed` `sizeof` `static` `struct` `switch` `typedef` `union` `unsigned` `void` `volatile` `while`

**C99 新增（5 个）**：`_Bool` `_Complex` `_Imaginary` `inline` `restrict`

**C11 新增（7 个）**：`_Alignas` `_Alignof` `_Atomic` `_Generic` `_Noreturn` `_Static_assert` `_Thread_local`

## 变量命名

### 语法规则（必须遵守）
1. 首字符必须为字母（a-z A-Z）、下划线（`_`）或美元符号（`$`）
2. 只能由字母、数字（0-9）、下划线（`_`）或 `$` 组成，不能含空格
3. 不能使用 C 语言保留字

### 开发规范（行业惯例）
- **小驼峰**：`tuoFeng`（推荐）
- **大驼峰**：`TuoFeng`
- **匈牙利命名法**：`iValue` `ullValue`（不建议）

> 注意：中文变量名（如`身高`、`体重`）符合语法规则，但违背行业标准，不推荐。

### 有效/无效判断示例
- `Fruit_price`、`color_type`、`_12345`、`iValue` → 有效
- `double` → 无效（保留字）

## scanf 格式化输入

`scanf` = **scan format**（扫描格式化），从键盘输入缓冲区读取数据，通过 `&` 取变量内存地址存入。

### 工作原理
键盘输入 → 键盘输入缓冲区 → scanf 按格式扫描 → `&` 计算变量实际内存地址 → 存入对应内存单元。

### 安全警告（C4996）
VS 认为 `scanf` 有安全隐患，两种解决方式：

```c
#define _CRT_SECURE_NO_WARNINGS  // 方式一：关闭安全警告，务必放在第一句
#include <stdio.h>

int main() {
    int a;
    scanf("%d", &a);       // 配合宏可正常使用
    // scanf_s("%d", &a);  // 方式二：使用安全函数（C11 标准）
    return 0;
}
```

### 核心要点

**1. 必须加 `&`（取地址符）**
```c
scanf("%d%d%d%d", &a, &b, &c, &d);  // 正确
scanf("%d%d%d%d", a, b, c, d);      // 错误：缺少 &
```

**2. float 与 double 严格区分**
- `scanf`：float 用 `%f`，double 用 `%lf`（严格区分）
- `printf`：float 和 double 都用 `%f`（不区分）

**3. 默认数据间隔**
读取整型时，**空格和换行（回车）都是合法的数据间隔**。

**4. 格式串中的普通字符必须原样输入**
```c
scanf("a=%d,b=%d", &a, &b);  // 输入必须为：a=888,b=999
```
推荐做法：减少不必要的修饰，直接用 `"%d%d%d%d"`。

**5. 返回值**
`scanf` 返回**成功存入变量的个数**。若不使用会触发 C6031 警告。
```c
int count = scanf("%d%d%d%d", &a, &b, &c, &d);
printf("成功存入到变量的个数 %d\n", count);
```

### length 修饰符
`hh`(char) `h`(short) `l`(long / double) `ll`(long long) 等，用于匹配不同长度的类型。

## 应用实践：找零问题

**问题**：368 元需要哪些不同面值的人民币？
**知识点**：整除 `/`、取余数 `%`、格式化打印。

```c
#include <stdio.h>
int main()
{
    int money = 368;
    printf("100元需要%d张\n", money / 100);
    money %= 100;
    printf("50元需要%d张\n", money / 50);
    money %= 50;
    printf("20元需要%d张\n", money / 20);
    money %= 20;
    printf("10元需要%d张\n", money / 10);
    money %= 10;
    printf("5元需要%d张\n", money / 5);
    money %= 5;
    printf("1元需要%d张\n", money);
    return 0;
}
```

输出：
```
100元需要3张
50元需要1张
20元需要0张
10元需要1张
5元需要1张
1元需要3张
```
