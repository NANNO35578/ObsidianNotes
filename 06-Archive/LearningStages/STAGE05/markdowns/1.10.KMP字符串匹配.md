# 1.10 KMP 字符串匹配

## 算法概述

KMP（Knuth-Morris-Pratt）算法用于在主串中高效查找模式串，核心是利用已匹配的前缀信息，避免主串指针回退。

- 时间复杂度：$O(n+m)$（n 为主串长度，m 为模式串长度）
- 空间复杂度：$O(m)$（next 数组）

---

## 核心概念：next 数组（最长相等前后缀）

`next[i]` 表示模式串 `p[0..i]` 中，最长相等真前缀和真后缀的长度。

### 示例

模式串 `p = "aabaaf"`

| i | 子串 | 最长相等前后缀 | next[i] |
|---|------|---------------|---------|
| 0 | a | 无（真前缀/后缀为空） | 0 |
| 1 | aa | "a" | 1 |
| 2 | aab | 无 | 0 |
| 3 | aaba | "a" | 1 |
| 4 | aabaa | "aa" | 2 |
| 5 | aabaaf | 无 | 0 |

### 构建 next 数组

```cpp
vector<int> buildNext(const string& p) {
    int m = p.size();
    vector<int> next(m, 0);
    int j = 0;  // j 表示当前最长相等前后缀长度
    for (int i = 1; i < m; i++) {
        while (j > 0 && p[i] != p[j])
            j = next[j - 1];  // 回退到更短的前后缀
        if (p[i] == p[j])
            j++;
        next[i] = j;
    }
    return next;
}
```

---

## 匹配过程

```cpp
int kmpSearch(const string& s, const string& p) {
    vector<int> next = buildNext(p);
    int j = 0;  // 模式串指针
    for (int i = 0; i < (int)s.size(); i++) {
        while (j > 0 && s[i] != p[j])
            j = next[j - 1];  // 不匹配时模式串回退，主串 i 不动
        if (s[i] == p[j])
            j++;
        if (j == (int)p.size())
            return i - j + 1;  // 匹配成功，返回起始下标
    }
    return -1;  // 未找到
}
```

### 关键思想

- 主串指针 `i` **永不回退**
- 不匹配时，模式串指针 `j` 回退到 `next[j-1]`，利用已匹配部分的最长相等前后缀，跳过不可能匹配的位置

---

## 完整示例

主串 `s = "aabaabaaf"`，模式串 `p = "aabaaf"`

next 数组：`[0, 1, 0, 1, 2, 0]`

匹配过程：
1. `i=0..4`：`s[0..4]="aabaa"` 与 `p[0..4]="aabaa"` 匹配，`j=5`
2. `i=5`：`s[5]='b'` vs `p[5]='f'` 不匹配，`j=next[4]=2`
3. `i=5`：`s[5]='b'` vs `p[2]='b'` 匹配，`j=3`
4. `i=6..8`：继续匹配，`j=6` 等于模式串长度，匹配成功，返回 `i-j+1=3`

---

## 与暴力匹配对比

| 方法 | 时间 | 主串指针 |
|------|------|----------|
| 暴力匹配 | $O(nm)$ | 不匹配时回退 |
| KMP | $O(n+m)$ | 永不回退 |

> [!bug] 常见错误
> - next 数组构建时 `j` 回退应使用 `next[j-1]` 而非 `next[j]`
> - 匹配成功后若需查找所有出现位置，应继续 `j = next[j-1]` 而非重置为 0
