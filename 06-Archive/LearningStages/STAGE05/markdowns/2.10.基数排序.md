# 2.10 基数排序

## 算法思想

非比较排序。按数字的每一位进行排序，从最低位（LSD）或最高位（MSD）开始，每一位使用稳定的计数排序，逐位处理后整体有序。

适用于整数或字符串排序，尤其是数据范围不大但位数较少的情况。

---

## 两种方式

| 方式 | 说明 | 特点 |
|------|------|------|
| LSD（低位优先） | 从个位开始，逐位向高位排序 | 实现简单，常用 |
| MSD（高位优先） | 从最高位开始，递归处理 | 适合高位差异大的数据，可提前终止 |

---

## LSD 基数排序步骤

1. 找到最大值，确定最大位数
2. 从个位开始（`exp = 1`），对每一位执行：
   - 使用计数排序按当前位数字（0-9）排序
   - 必须使用**稳定**排序，保证高位排序后低位的相对顺序不被破坏
3. `exp *= 10`，处理下一位，直到所有位处理完毕

```cpp
void countingSortByDigit(vector<int>& a, int exp) {
    int n = a.size();
    vector<int> output(n);
    vector<int> count(10, 0);
    // 统计当前位数字出现次数
    for (int x : a) count[(x / exp) % 10]++;
    // 前缀和
    for (int i = 1; i < 10; i++) count[i] += count[i - 1];
    // 从后向前放置（保证稳定）
    for (int i = n - 1; i >= 0; i--) {
        int digit = (a[i] / exp) % 10;
        output[count[digit] - 1] = a[i];
        count[digit]--;
    }
    a = output;
}

void radixSort(vector<int>& a) {
    if (a.empty()) return;
    int maxVal = *max_element(a.begin(), a.end());
    for (int exp = 1; maxVal / exp > 0; exp *= 10)
        countingSortByDigit(a, exp);
}
```

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n \times k)$ | k 为最大位数 |
| 平均 | $O(n \times k)$ | |
| 最坏 | $O(n \times k)$ | |
| 空间 | $O(n+k)$ | 输出数组 + 计数数组 |
| 稳定性 | 稳定 | 每轮使用稳定计数排序 |

---

## 特点

- 非比较排序，时间复杂度与数据范围无关，只与位数有关
- 每轮必须使用稳定排序，否则结果错误
- 适合整数、固定长度字符串
- 当位数 k 较大时（如大整数），效率可能不如比较排序
- 可扩展到任意进制（如 256 进制处理字节）
