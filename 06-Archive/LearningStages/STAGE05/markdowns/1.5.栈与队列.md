# 1.5 栈与队列

## 一、栈（Stack）

**特点**：后进先出（LIFO, Last In First Out），只能在栈顶操作。

### 基本操作

| 操作 | 说明 | 时间 |
|------|------|------|
| `push(x)` | 元素入栈 | $O(1)$ |
| `pop()` | 栈顶元素出栈 | $O(1)$ |
| `top()` | 获取栈顶元素 | $O(1)$ |
| `empty()` | 判断栈是否为空 | $O(1)$ |

### C++ 实现

```cpp
#include <stack>
stack<int> st;
st.push(1);
st.push(2);
int x = st.top();  // 2
st.pop();
```

### 常见应用

1. **括号匹配**：左括号入栈，右括号与栈顶匹配
2. **表达式求值**：中缀转后缀、后缀表达式计算
3. **函数调用**：系统栈保存调用帧
4. **深度优先搜索（DFS）**：用栈模拟递归
5. **单调栈**：找下一个更大/更小元素

---

## 二、队列（Queue）

**特点**：先进先出（FIFO, First In First Out），队尾入队，队首出队。

### 基本操作

| 操作 | 说明 | 时间 |
|------|------|------|
| `push(x)` | 元素入队尾 | $O(1)$ |
| `pop()` | 队首元素出队 | $O(1)$ |
| `front()` | 获取队首元素 | $O(1)$ |
| `back()` | 获取队尾元素 | $O(1)$ |
| `empty()` | 判断队列是否为空 | $O(1)$ |

### C++ 实现

```cpp
#include <queue>
queue<int> q;
q.push(1);
q.push(2);
int x = q.front();  // 1
q.pop();
```

### 常见应用

1. **广度优先搜索（BFS）**：层序遍历
2. **任务调度**：按到达顺序处理
3. **缓冲区**：生产者-消费者模型
4. **单调队列**：滑动窗口最大值

---

## 三、双端队列（Deque）

**特点**：两端都可以入队和出队。

```cpp
#include <deque>
deque<int> dq;
dq.push_back(1);   // 尾部入队
dq.push_front(2);  // 头部入队
dq.pop_back();      // 尾部出队
dq.pop_front();     // 头部出队
```

## 四、经典应用：最小栈

设计一个支持 `push`、`pop`、`top` 操作，并能在常数时间内检索到最小元素的栈。

**思路**：用两个栈，一个存数据，一个存当前最小值。

```cpp
class MinStack {
private:
    stack<int> data;
    stack<int> minSt;
public:
    void push(int val) {
        data.push(val);
        if (minSt.empty() || val <= minSt.top())
            minSt.push(val);
    }
    void pop() {
        if (data.top() == minSt.top())
            minSt.pop();
        data.pop();
    }
    int top() { return data.top(); }
    int getMin() { return minSt.top(); }
};
```

- 所有操作时间 $O(1)$，空间 $O(n)$

## 五、栈与队列对比

| 特性 | 栈 | 队列 |
|------|-----|------|
| 进出顺序 | 后进先出 LIFO | 先进先出 FIFO |
| 操作端 | 仅栈顶 | 队尾入、队首出 |
| 典型应用 | 括号匹配、DFS、递归 | BFS、任务调度 |
| 底层实现 | 数组/链表 | 数组（循环）/链表 |
