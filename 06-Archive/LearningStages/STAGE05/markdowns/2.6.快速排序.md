# 2.6 快速排序

## 算法思想

采用分治策略：选择一个基准元素（pivot），将数组分为小于基准和大于基准两部分，递归对两部分排序。

---

## 算法步骤（Lomuto 分区）

1. 选择基准元素（通常取末尾元素 `pivot = a[r]`）
2. 遍历数组，将小于 pivot 的元素换到左侧
3. 将 pivot 放到正确位置，返回其下标
4. 递归排序 pivot 左右两部分

```cpp
int partition(vector<int>& a, int l, int r) {
    int pivot = a[r];
    int i = l - 1;  // 小于pivot区域的右边界
    for (int j = l; j < r; j++) {
        if (a[j] <= pivot) {
            i++;
            swap(a[i], a[j]);
        }
    }
    swap(a[i + 1], a[r]);
    return i + 1;
}

void quickSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int p = partition(a, l, r);
    quickSort(a, l, p - 1);
    quickSort(a, p + 1, r);
}
```

### Hoare 分区（更高效）

```cpp
int hoarePartition(vector<int>& a, int l, int r) {
    int pivot = a[l + (r - l) / 2];
    int i = l - 1, j = r + 1;
    while (true) {
        do { i++; } while (a[i] < pivot);
        do { j--; } while (a[j] > pivot);
        if (i >= j) return j;
        swap(a[i], a[j]);
    }
}
```

## 基准选择优化

| 方法 | 说明 |
|------|------|
| 固定取首/尾 | 最简单，但有序数据时退化 |
| 随机选取 | `rand() % (r-l+1) + l`，避免最坏情况 |
| 三数取中 | 取首、中、尾三者的中位数作为 pivot |

```cpp
// 三数取中
int mid = l + (r - l) / 2;
if (a[l] > a[mid]) swap(a[l], a[mid]);
if (a[l] > a[r]) swap(a[l], a[r]);
if (a[mid] > a[r]) swap(a[mid], a[r]);
swap(a[mid], a[r]);  // 中位数放到末尾作为 pivot
```

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n \log n)$ | 每次分区均匀 |
| 平均 | $O(n \log n)$ | |
| 最坏 | $O(n^2)$ | 已有序且固定取尾为 pivot |
| 空间 | $O(\log n)$ | 递归栈（平均） |
| 稳定性 | 不稳定 | 分区交换可能改变相等元素顺序 |

---

## 特点

- 平均性能最好的内部排序算法
- 原地排序，缓存友好
- 不稳定
- 最坏情况可通过随机化或三数取中避免
- 递归深度大时可能栈溢出，可改用迭代或设置深度阈值切换堆排序
