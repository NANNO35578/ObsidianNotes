# 5.1 图的基本概念与存储

## 一、图的定义

图 $G = (V, E)$，其中：
- $V$：顶点（Vertex）集合，表示对象
- $E$：边（Edge）集合，表示对象之间的关系

---

## 二、基本术语

| 术语 | 定义 |
|------|------|
| 依附 | 边 $E_1$ 依附于顶点 $V_1, V_2$ |
| 完全图 | 任意两点都相连。无向图边数 $C_n^2 = n(n-1)/2$，有向图边数 $A_n^2 = n(n-1)$ |
| 路径 | 从一个顶点到另一个顶点的边序列 |
| 路径长度 | 路径上边的数量 |
| 简单路径 | 路径中不包含重复顶点 |
| 环 | 起点和终点相同的路径 |
| 连通 | 无向图中任意两顶点之间都有路径 |
| 强连通 | 有向图中任意两顶点之间双向都有路径 |
| 弱连通 | 有向图忽略方向后是连通的 |
| 连通分量 | 无向图的极大连通子图 |
| 强连通分量 | 有向图的极大强连通子图 |
| 子图 | $V' \subseteq V, E' \subseteq E$ |
| 度 | 无向图中依附于该顶点的边数 |
| 入度/出度 | 有向图中指向/离开该顶点的边数 |

### 重要结论

- $n$ 个顶点的连通图最少有 $n-1$ 条边（树）
- $n$ 个顶点的图一定连通需要 $C_n^2 + 1$ 条边（完全图加一条）
- 无向图所有顶点度数之和 = $2|E|$（握手定理）
- 有向图所有顶点入度之和 = 出度之和 = $|E|$

## 三、图的类型

| 类型 | 说明 |
|------|------|
| 无向图 | 边无方向 |
| 有向图 | 边有方向 |
| 加权图 | 边上有权重（距离、成本等） |
| 简单图 | 无自环、无多重边 |
| 多重图 | 允许多重边和自环 |
| 完全图 | 任意两点相连 |
| 连通图 | 任意两点可达 |
| DAG | 有向无环图 |
| 树 | 连通无环的无向图，$n-1$ 条边 |

## 四、图的存储方法

### 1. 邻接矩阵

用 $n \times n$ 二维数组表示，`matrix[i][j]` 表示顶点 $i$ 到 $j$ 是否有边（或边的权重）。

```cpp
// 无权图
vector<vector<int>> adj(n, vector<int>(n, 0));
adj[u][v] = 1;  // 有边

// 加权图
vector<vector<int>> adj(n, vector<int>(n, INT_MAX));
adj[u][v] = weight;
```

- 有向图：行表示出边，列表示入边
- 适用于**密集图**
- 空间 $O(V^2)$，查边 $O(1)$

### 2. 邻接表

每个顶点维护一个链表（或 vector），存储其所有邻接顶点。适用于**稀疏图**。

```cpp
// 无权图
vector<vector<int>> adj(n);
adj[u].push_back(v);

// 加权图
struct Edge { int to, weight; };
vector<vector<Edge>> adj(n);
adj[u].push_back({v, weight});
```

- 空间 $O(V + E)$
- 遍历邻接点高效
- 查特定边 $O(V)$（最坏）

### 3. 边列表

用一个数组存储所有边，每条边为 `(u, v, weight)`。

```cpp
struct Edge { int u, v, weight; };
vector<Edge> edges;
```

- 适合 Kruskal 等需要遍历所有边的算法
- 空间 $O(E)$
- 查边 $O(E)$

### 4. 十字链表

邻接表的改进，同时存储出边和入边信息，适合有向图。

---

## 五、存储方法对比

| 方法 | 空间 | 查边 | 遍历邻接点 | 适用场景 |
|------|------|------|-----------|----------|
| 邻接矩阵 | $O(V^2)$ | $O(1)$ | $O(V)$ | 密集图 |
| 邻接表 | $O(V+E)$ | $O(V)$ | $O(度)$ | 稀疏图（最常用） |
| 边列表 | $O(E)$ | $O(E)$ | 不支持 | Kruskal、边遍历 |
| 十字链表 | $O(V+E)$ | - | 高效 | 有向图需同时看出/入边 |
