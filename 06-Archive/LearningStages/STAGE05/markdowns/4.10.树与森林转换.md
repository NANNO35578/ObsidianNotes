# 4.10 树与森林转换

## 一、普通树转二叉树

利用**孩子兄弟表示法**（左孩子右兄弟），将任意普通树转换为二叉树。

### 转换规则

1. **连接兄弟**：将同一父节点的所有兄弟节点从左到右用右指针连接
2. **断开多余父子连接**：除最左侧孩子外，其余孩子与父节点的连接断开
3. **确定左右孩子**：
   - 原树中节点的**最左孩子** → 二叉树中该节点的**左孩子**
   - 原树中节点的**右侧第一个兄弟** → 二叉树中该节点的**右孩子**

### 示例

```
原树：                     转换后二叉树：
      A                          A
     /|\                        /
    B C D                      B
   /|   \                     / \
  E F    G                   E   C
                              \   \
                               F   D
                                    \
                                     G
```

- A 的左孩子 = B（最左孩子），右孩子 = 无（A 无兄弟）
- B 的左孩子 = E（最左孩子），右孩子 = C（右侧兄弟）
- E 的左孩子 = 无，右孩子 = F（右侧兄弟）
- C 的左孩子 = 无，右孩子 = D（右侧兄弟）
- D 的左孩子 = G（最左孩子），右孩子 = 无

## 二、森林转二叉树

森林是多棵树的集合，转换方法：

### 转换规则

1. 将森林中每棵树分别转换为二叉树
2. 将各棵二叉树的**根节点视为兄弟**，从左到右用右指针连接
3. 第一棵树的根作为整个二叉树的根
4. 后续每棵树的根作为前一棵树根的右孩子

### 示例

```
森林：                     转换后二叉树：
  树1       树2                树1根
   A         D                   / \
  / \       / \    →           B   树2根
 B   C     E   F                   / \
                                    E   F
```

---

## 三、二叉树还原为树/森林

### 还原为树

逆操作：
1. 若节点是其父亲的**左孩子**，则将该节点的右孩子、右孩子的右孩子...都连接到该节点的父亲
2. 断开所有右孩子连接

### 还原为森林

1. 断开根节点与其右孩子的连接，以及右孩子链上的所有连接
2. 每个断开后的部分都是一棵二叉树
3. 将每棵二叉树还原为普通树

## 四、遍历对应关系

| 普通树遍历 | 对应二叉树遍历 |
|-----------|---------------|
| 先根遍历 | 前序遍历 |
| 后根遍历 | 中序遍历 |
| 层次遍历 | （无直接对应） |

| 森林遍历 | 对应二叉树遍历 |
|---------|---------------|
| 先序遍历 | 前序遍历 |
| 中序遍历 | 中序遍历 |

---

## 五、应用意义

- 普通树和森林的操作可以通过转换为二叉树来简化
- 二叉树的算法（遍历、查找等）可复用到普通树
- 孩子兄弟表示法是存储普通树最常用的方式
