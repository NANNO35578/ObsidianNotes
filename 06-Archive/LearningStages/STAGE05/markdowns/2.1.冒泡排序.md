# 2.1 冒泡排序

## 算法思想

重复遍历数组，每次比较相邻两个元素，若顺序错误则交换。每轮遍历后，最大的元素会"冒泡"到数组末尾。

---

## 算法步骤

1. 从数组头部开始，依次比较相邻元素 `a[j]` 和 `a[j+1]`
2. 若 `a[j] > a[j+1]`，交换两者
3. 一轮结束后，最大元素已在末尾
4. 对剩余未排序部分重复上述过程，共需 n-1 轮

```cpp
void bubbleSort(vector<int>& a) {
    int n = a.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;  // 本轮无交换，已有序
    }
}
```

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n)$ | 已有序，一轮无交换即退出 |
| 平均 | $O(n^2)$ | |
| 最坏 | $O(n^2)$ | 完全逆序 |
| 空间 | $O(1)$ | 原地排序 |
| 稳定性 | 稳定 | 相等元素不交换 |

---

## 特点

- 实现最简单的排序算法
- 适合小规模或基本有序的数据
- 通过 `swapped` 标志可提前终止，最好情况达 $O(n)$
