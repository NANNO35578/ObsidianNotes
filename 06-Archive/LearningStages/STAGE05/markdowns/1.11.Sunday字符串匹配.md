# 1.11 Sunday 字符串匹配

## 算法概述

Sunday 算法是一种高效的字符串匹配算法，通过关注模式串后一位的字符来决定跳跃距离，平均性能优于 KMP。

- 平均时间复杂度：$O(n/m)$
- 最坏时间复杂度：$O(nm)$
- 空间复杂度：$O(|\Sigma|)$（字符集大小）

---

## 核心思想

当匹配失败时，关注**主串中与模式串末尾对齐的下一个字符**（记为 `c`）：
- 若 `c` 在模式串中存在，将模式串中最右侧的 `c` 与主串中的 `c` 对齐
- 若 `c` 不在模式串中，直接跳过整个模式串长度

---

## 偏移表（Shift Table）

预计算每个字符在模式串中最后一次出现的位置，用于快速计算跳跃距离。

```
shift[c] = m - lastIndex[c] - 1
```

其中 `m` 为模式串长度，`lastIndex[c]` 为字符 `c` 在模式串中最后一次出现的下标，不存在则为 `-1`。

等价于：跳跃距离 = `m - 字符在模式串中最后出现位置`（从右向左数）。

### 构建偏移表

```cpp
vector<int> buildShift(const string& p) {
    int m = p.size();
    vector<int> shift(256, m + 1);  // 不存在的字符跳跃 m+1
    for (int i = 0; i < m; i++)
        shift[(unsigned char)p[i]] = m - i;  // 最后出现位置决定跳跃
    return shift;
}
```

> 偏移表以字符 ASCII 码为索引，存储该字符对应的跳跃步数。不存在的字符跳跃 `m+1`（直接跳过整个模式串及当前比较位）。

---

## 匹配过程

```cpp
int sundaySearch(const string& s, const string& p) {
    int n = s.size(), m = p.size();
    if (m == 0) return 0;
    vector<int> shift = buildShift(p);
    int i = 0;  // 主串中模式串起始对齐位置
    while (i <= n - m) {
        int j = 0;
        while (j < m && s[i + j] == p[j])  // 从左向右匹配
            j++;
        if (j == m) return i;  // 匹配成功
        // 匹配失败，看主串中模式串末尾的下一个字符
        if (i + m < n)
            i += shift[(unsigned char)s[i + m]];
        else
            break;
    }
    return -1;
}
```

### 算法步骤

1. 初始化偏移表：以字符 ASCII 为索引，存该字符在模式串中最右出现位置对应的跳跃步数
2. 主串起始位置 `i = 0`，从左向右逐字符比较
3. 若全部匹配，返回起始下标
4. 若不匹配，取主串中 `s[i + m]`（模式串末尾的下一个字符），查偏移表得到跳跃距离，更新 `i`
5. 重复直到匹配或超出主串范围

---

## 示例演示

主串 `s = "substring searching"`，模式串 `p = "search"`

偏移表（m=6）：
- `s`: 跳跃 6（最后出现在下标 0，6-0=6）
- `e`: 跳跃 2（最后出现在下标 4，6-4=2）
- `a`: 跳跃 3（最后出现在下标 3，6-3=3）
- `r`: 跳跃 1（最后出现在下标 5，6-5=1）
- `c`: 跳跃 4（最后出现在下标 2，6-2=4）
- `h`: 跳跃 5（最后出现在下标 1，6-1=5）
- 其他字符：跳跃 7

匹配过程中每次不匹配都能大步跳跃，平均比较次数远少于暴力匹配。

---

## Sunday 与 KMP 对比

| 特性 | KMP | Sunday |
|------|-----|--------|
| 平均时间 | $O(n+m)$ | $O(n/m)$ |
| 最坏时间 | $O(n+m)$ | $O(nm)$ |
| 空间 | $O(m)$ | $O(\|\Sigma\|)$ |
| 跳跃依据 | 最长相等前后缀 | 模式串后一位字符 |
| 实现难度 | 中等 | 简单 |

> [!tip] 实际应用
> Sunday 算法实现简单、平均性能优秀，是实际工程中常用的字符串匹配算法之一。但最坏情况下退化到 $O(nm)$，对性能有严格保证的场景应使用 KMP。
