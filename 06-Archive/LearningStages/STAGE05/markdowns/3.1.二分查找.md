# 3.1 二分查找

## 算法思想

在有序数组中，每次取中间元素与目标比较，根据比较结果将搜索范围缩小一半。

---

## 基本二分查找

```cpp
int binarySearch(vector<int>& a, int target) {
    int l = 0, r = a.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;  // 避免溢出
        if (a[mid] == target) return mid;
        else if (a[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;  // 未找到
}
```

- 时间 $O(\log n)$，空间 $O(1)$

> [!note] 防溢出
> `mid = l + (r - l) / 2` 优于 `mid = (l + r) / 2`，避免 `l + r` 整数溢出。

---

## 查找左边界（第一个 >= target）

```cpp
int lowerBound(vector<int>& a, int target) {
    int l = 0, r = a.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < target) l = mid + 1;
        else r = mid;
    }
    return l;  // 第一个 >= target 的位置，可能等于 size()
}
```

## 查找右边界（第一个 > target）

```cpp
int upperBound(vector<int>& a, int target) {
    int l = 0, r = a.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] <= target) l = mid + 1;
        else r = mid;
    }
    return l;
}
```

---

## 模板总结

| 查找目标 | 循环条件 | 收缩方式 | 返回值 |
|----------|----------|----------|--------|
| 是否存在 | `l <= r` | `l=mid+1` / `r=mid-1` | mid 或 -1 |
| 左边界（>=） | `l < r` | `l=mid+1` / `r=mid` | l |
| 右边界（>） | `l < r` | `l=mid+1` / `r=mid` | l |

---

## 适用场景

- 有序数组中的查找
- 查找满足条件的第一个/最后一个位置
- 最大值最小化 / 最小值最大化（二分答案）
- 旋转有序数组查找

> [!bug] 常见错误
> - 循环条件 `l <= r` 与 `l < r` 混用导致死循环或漏查
> - `mid` 计算溢出
> - 左闭右开区间 `[l, r)` 与左闭右闭区间 `[l, r]` 边界处理不一致
