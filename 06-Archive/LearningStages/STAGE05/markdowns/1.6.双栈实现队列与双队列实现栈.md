# 1.6 双栈实现队列与双队列实现栈

## 一、用两个栈实现队列

> 定义两个栈，一个用于 Push（入栈），一个用于 Pop（出栈）。

### 核心思路

- **入队**：直接 push 到 `inStack`
- **出队**：若 `outStack` 为空，将 `inStack` 全部元素弹出并压入 `outStack`（顺序反转），再从 `outStack` 弹出

```cpp
class MyQueue {
private:
    stack<int> inStack, outStack;
    void in2out() {
        while (!inStack.empty()) {
            outStack.push(inStack.top());
            inStack.pop();
        }
    }
public:
    void push(int x) { inStack.push(x); }
    int pop() {
        if (outStack.empty()) in2out();
        int x = outStack.top(); outStack.pop();
        return x;
    }
    int peek() {
        if (outStack.empty()) in2out();
        return outStack.top();
    }
    bool empty() { return inStack.empty() && outStack.empty(); }
};
```

**复杂度**：
- 入队 $O(1)$
- 出队 均摊 $O(1)$（每个元素最多被搬运一次）
- 空间 $O(n)$

## 二、用两个队列实现栈

> 定义两个队列 q1、q2，利用队列 FIFO 特性模拟栈 LIFO。

### 核心思路

- **入栈**：push 到非空队列（第一个元素可入任意队列）
- **出栈**：将非空队列的前 `n-1` 个元素转移到空队列，剩余的最后一个元素即为栈顶，弹出返回

```cpp
class MyStack {
private:
    queue<int> q1, q2;
public:
    void push(int x) {
        if (!q1.empty()) q1.push(x);
        else q2.push(x);
    }
    int pop() {
        queue<int>& from = q1.empty() ? q2 : q1;
        queue<int>& to = q1.empty() ? q1 : q2;
        while (from.size() > 1) {
            to.push(from.front());
            from.pop();
        }
        int x = from.front(); from.pop();
        return x;
    }
    int top() {
        queue<int>& from = q1.empty() ? q2 : q1;
        queue<int>& to = q1.empty() ? q1 : q2;
        while (from.size() > 1) {
            to.push(from.front());
            from.pop();
        }
        int x = from.front();
        to.push(x); from.pop();  // top 不删除，需放回
        return x;
    }
    bool empty() { return q1.empty() && q2.empty(); }
};
```

**复杂度**：
- 入栈 $O(1)$
- 出栈 $O(n)$（需搬运 n-1 个元素）
- 空间 $O(n)$

### 单队列优化

只需一个队列，入栈时将新元素入队后，把前面所有元素依次出队再入队，使新元素位于队首。

```cpp
class MyStack {
private:
    queue<int> q;
public:
    void push(int x) {
        int n = q.size();
        q.push(x);
        for (int i = 0; i < n; i++) {
            q.push(q.front());
            q.pop();
        }
    }
    int pop() { int x = q.front(); q.pop(); return x; }
    int top() { return q.front(); }
    bool empty() { return q.empty(); }
};
```

- 入栈 $O(n)$，出栈 $O(1)$

## 对比总结

| 实现 | 入操作 | 出操作 | 空间 |
|------|--------|--------|------|
| 双栈实现队列 | $O(1)$ | 均摊 $O(1)$ | $O(n)$ |
| 双队列实现栈 | $O(1)$ | $O(n)$ | $O(n)$ |
| 单队列实现栈 | $O(n)$ | $O(1)$ | $O(n)$ |
