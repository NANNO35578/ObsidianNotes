# 4.1 树与二叉树基础

## 一、树的基本概念

**树（Tree）**：$n$ 个节点的有限集合，$n=0$ 时为空树。非空树满足：
- 有且仅有一个根节点（Root）
- 其余节点可分为 $m$ 个互不相交的有限集合，每个集合本身又是一棵树（子树）

### 基本术语

| 术语 | 定义 |
|------|------|
| 节点的度 | 该节点的孩子个数 |
| 树的度 | 树中节点的最大度数 |
| 叶子节点 | 度为 0 的节点 |
| 分支节点 | 度不为 0 的节点 |
| 节点深度 | 从根到该节点的路径长度（边数） |
| 节点高度 | 从该节点到最远叶子的路径长度 |
| 树的高度 | 根节点的高度 |
| 路径 | 从一个节点到另一个节点的边序列 |
| 路径长度 | 路径上边的数量 |

### 树的表示方法

- 孩子表示法：每个节点存储所有孩子指针
- 双亲表示法：每个节点存储双亲指针（数组实现）
- 双亲孩子表示法：结合以上两种
- 孩子兄弟表示法：左孩子右兄弟，可将任意树转为二叉树

## 二、二叉树

每个节点最多有两个子节点（左孩子、右孩子），且有左右之分。

### 特殊二叉树

#### 1. 满二叉树

高度为 $k$ 且有 $2^k - 1$ 个节点的二叉树，每一层都满。

- $k$ 层总结点数：$2^k - 1$
- 第 $k$ 层节点数：$2^{k-1}$
- 叶子节点数：$2^{k-1}$

#### 2. 完全二叉树（CBT）

只允许从右向左连续缺少叶子节点的二叉树（即除最后一层外每层都满，最后一层节点靠左排列）。

- 高度：$\lfloor \log_2 n \rfloor + 1$
- 从上到下、从左到右从 1 开始编号：
  - 节点 $i$ 的左孩子：$2i$（若 $2i \le n$）
  - 节点 $i$ 的右孩子：$2i+1$（若 $2i+1 \le n$）
  - 节点 $i$ 的父节点：$\lfloor i/2 \rfloor$
  - 父节点编号范围：$1 \sim \lfloor n/2 \rfloor$
- 从 0 开始编号：左孩子 $2i+1$，右孩子 $2i+2$，父节点 $(i-1)/2$

#### 3. 二叉搜索树（BST）

左子树所有节点值 < 根节点值 < 右子树所有节点值。

#### 4. 平衡搜索树

- AVL 树：左右子树高度差不超过 1
- 红黑树（RBT）：通过颜色约束保持近似平衡
- B 树 / B+ 树：多路平衡搜索树

## 三、二叉树重要性质

### 性质 1：叶子节点与度为 2 的节点关系

$$n_0 = n_2 + 1$$

即任意二叉树中，度为 0 的节点（叶子）总比度为 2 的节点多一个。

**证明**：
- 总节点数 $S = n_0 + n_1 + n_2$
- 从孩子角度：$S = n_0 \times 0 + n_1 \times 1 + n_2 \times 2 + 1$（根节点无父节点）
- 联立得 $n_0 = n_2 + 1$

### 性质 2：第 i 层最多节点数

第 $i$ 层最多有 $2^{i-1}$ 个节点（$i \ge 1$）。

### 性质 3：高度为 k 的二叉树最多节点数

高度为 $k$ 的二叉树最多有 $2^k - 1$ 个节点。

### 性质 4：n 个节点的完全二叉树高度

$$h = \lfloor \log_2 n \rfloor + 1$$
