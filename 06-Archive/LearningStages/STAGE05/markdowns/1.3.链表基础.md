# 1.3 链表基础

## 链表结构定义

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};
```

---

## 核心操作

### 1. 遍历链表

```cpp
void printList(ListNode* head) {
    ListNode* cur = head;
    while (cur) {
        cout << cur->val << " ";
        cur = cur->next;
    }
}
```

### 2. 反转链表

**迭代法**：三指针逐个翻转。

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* cur = head;
    while (cur) {
        ListNode* next = cur->next;  // 保存下一个节点
        cur->next = prev;              // 翻转指针
        prev = cur;                    // prev 前移
        cur = next;                    // cur 前移
    }
    return prev;
}
```

**递归法**：

```cpp
ListNode* reverseList(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode* newHead = reverseList(head->next);
    head->next->next = head;
    head->next = nullptr;
    return newHead;
}
```

- 时间 $O(n)$，空间 $O(1)$（迭代）/ $O(n)$（递归栈）

### 3. 判断链表是否有环

**快慢指针法（Floyd 判圈）**：
- 慢指针每次走 1 步，快指针每次走 2 步
- 若有环，两指针必然在环内相遇

```cpp
bool hasCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

- 时间 $O(n)$，空间 $O(1)$

### 4. 找环的入口节点

1. 先用快慢指针找到相遇点
2. 将一个指针移回表头，两个指针同速前进，再次相遇处即为环入口

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            slow = head;
            while (slow != fast) {
                slow = slow->next;
                fast = fast->next;
            }
            return slow;
        }
    }
    return nullptr;
}
```

### 5. 找链表倒数第 k 个节点

**双指针法**：快指针先走 k 步，然后两指针同速前进，快指针到尾时慢指针即为倒数第 k 个。

```cpp
ListNode* getKthFromEnd(ListNode* head, int k) {
    ListNode *fast = head, *slow = head;
    for (int i = 0; i < k; i++) {
        if (!fast) return nullptr;  // k 超过链表长度
        fast = fast->next;
    }
    while (fast) {
        fast = fast->next;
        slow = slow->next;
    }
    return slow;
}
```

### 6. 删除链表节点（只给节点指针）

将后继节点的值复制到当前节点，然后删除后继节点。

```cpp
void deleteNode(ListNode* node) {
    node->val = node->next->val;
    node->next = node->next->next;
}
```

> [!note] 前提：该节点不是尾节点。

## 常用技巧

| 技巧 | 适用场景 |
|------|----------|
| 虚拟头节点 `dummy` | 头节点可能被删除/修改时，简化边界处理 |
| 快慢指针 | 判环、找中点、找倒数第 k 个 |
| 双指针 | 找交点、合并有序链表 |
| 递归 | 反转链表、两两交换 |
