# 1.4 合并有序链表

## 问题描述

将两个升序链表合并为一个新的升序链表并返回。新链表通过拼接给定的两个链表的节点组成。

---

## 解法一：迭代法

**核心思想**：用虚拟头节点简化操作，双指针分别遍历两个链表，每次取较小值节点接入结果。

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* cur = &dummy;
    while (l1 && l2) {
        if (l1->val <= l2->val) {
            cur->next = l1;
            l1 = l1->next;
        } else {
            cur->next = l2;
            l2 = l2->next;
        }
        cur = cur->next;
    }
    cur->next = l1 ? l1 : l2;  // 拼接剩余部分
    return dummy.next;
}
```

**步骤**：
1. 创建虚拟头节点 `dummy`，指针 `cur` 指向它
2. 当 `l1` 和 `l2` 都非空时，比较值大小，将较小节点接到 `cur` 后
3. 被取节点的指针后移，`cur` 后移
4. 循环结束后，将非空链表的剩余部分直接接到 `cur` 后
5. 返回 `dummy.next`

- 时间 $O(m+n)$，空间 $O(1)$

---

## 解法二：递归法

**核心思想**：比较两个链表头节点，取较小者，其 `next` 指向剩余部分的合并结果。

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    if (!l1) return l2;
    if (!l2) return l1;
    if (l1->val <= l2->val) {
        l1->next = mergeTwoLists(l1->next, l2);
        return l1;
    } else {
        l2->next = mergeTwoLists(l1, l2->next);
        return l2;
    }
}
```

- 时间 $O(m+n)$，空间 $O(m+n)$（递归栈深度）

---

## 扩展：合并 K 个升序链表

### 方法一：顺序合并

依次将每个链表与当前结果合并，共合并 k-1 次。

- 时间 $O(k^2 n)$（假设每个链表长度为 n），空间 $O(1)$

### 方法二：分治合并

将 k 个链表两两配对合并，递归进行。

```cpp
ListNode* mergeKLists(vector<ListNode*>& lists) {
    if (lists.empty()) return nullptr;
    return merge(lists, 0, lists.size() - 1);
}
ListNode* merge(vector<ListNode*>& lists, int l, int r) {
    if (l == r) return lists[l];
    int mid = l + (r - l) / 2;
    ListNode* left = merge(lists, l, mid);
    ListNode* right = merge(lists, mid + 1, r);
    return mergeTwoLists(left, right);
}
```

- 时间 $O(kn \log k)$，空间 $O(\log k)$（递归栈）

### 方法三：优先队列（小根堆）

将所有链表的头节点放入小根堆，每次取出最小值节点，将其后继入堆。

```cpp
ListNode* mergeKLists(vector<ListNode*>& lists) {
    auto cmp = [](ListNode* a, ListNode* b) { return a->val > b->val; };
    priority_queue<ListNode*, vector<ListNode*>, decltype(cmp)> pq(cmp);
    for (auto h : lists) if (h) pq.push(h);
    ListNode dummy(0), *cur = &dummy;
    while (!pq.empty()) {
        ListNode* node = pq.top(); pq.pop();
        cur->next = node;
        cur = cur->next;
        if (node->next) pq.push(node->next);
    }
    return dummy.next;
}
```

- 时间 $O(kn \log k)$，空间 $O(k)$
