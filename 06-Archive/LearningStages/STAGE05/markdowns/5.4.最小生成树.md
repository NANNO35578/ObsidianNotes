# 5.4 最小生成树（MST）

## 问题描述

在加权无向连通图中，找到一棵包含所有顶点、总权重最小的生成树（$V-1$ 条边，无环）。

---

## 一、Kruskal 算法

### 算法思想

**边贪心**：将所有边按权重从小到大排序，依次选取不构成环的边，直到选够 $V-1$ 条边。

### 算法步骤

1. 将所有边按权重从小到大排序
2. 初始化并查集，每个顶点独立成集合
3. 遍历排序后的边：
   - 若边的两个端点不在同一集合（加边不成环），选中该边，合并两个集合
   - 若已在同一集合（成环），跳过
4. 选中 $V-1$ 条边时结束

```cpp
struct Edge {
    int u, v, weight;
    bool operator<(const Edge& other) const { return weight < other.weight; }
};

int kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end());
    vector<int> parent(n), rank_(n, 0);
    iota(parent.begin(), parent.end(), 0);

    auto find = [&](auto&& self, int x) -> int {
        if (parent[x] != x) parent[x] = self(self, parent[x]);
        return parent[x];
    };
    auto unite = [&](int x, int y) -> bool {
        int rx = find(find, x), ry = find(find, y);
        if (rx == ry) return false;
        if (rank_[rx] < rank_[ry]) swap(rx, ry);
        parent[ry] = rx;
        if (rank_[rx] == rank_[ry]) rank_[rx]++;
        return true;
    };

    int totalWeight = 0, edgeCount = 0;
    for (auto& e : edges) {
        if (unite(e.u, e.v)) {
            totalWeight += e.weight;
            edgeCount++;
            if (edgeCount == n - 1) break;
        }
    }
    return totalWeight;  // 若 edgeCount < n-1 则图不连通
}
```

### 复杂度

- 时间：$O(E \log E)$（排序为主）
- 空间：$O(V + E)$
- 适合**稀疏图**

## 二、Prim 算法

### 算法思想

**点贪心**：从一个起始顶点开始，每次选取连接"已选顶点集合"与"未选顶点集合"的最小权重边，将新顶点加入集合，直到所有顶点都被选中。

### 算法步骤

1. 任选一个起始顶点，标记为已连接
2. 维护 `key[]` 数组：每个未连接顶点到已连接集合的最小边权重
3. 重复 $V-1$ 次：
   - 从未连接顶点中选 `key` 最小的顶点 `u`
   - 将 `u` 标记为已连接，累加边权重
   - 更新 `u` 的所有未连接邻接点的 `key` 值

### 朴素实现（邻接矩阵）

```cpp
int prim(vector<vector<int>>& graph, int n) {
    vector<int> key(n, INT_MAX);
    vector<bool> inMST(n, false);
    key[0] = 0;  // 从顶点0开始
    int totalWeight = 0;

    for (int count = 0; count < n; count++) {
        // 选未连接中 key 最小的顶点
        int u = -1;
        for (int v = 0; v < n; v++) {
            if (!inMST[v] && (u == -1 || key[v] < key[u]))
                u = v;
        }
        if (u == -1 || key[u] == INT_MAX) break;  // 图不连通
        inMST[u] = true;
        totalWeight += key[u];
        // 更新邻接点
        for (int v = 0; v < n; v++) {
            if (!inMST[v] && graph[u][v] != 0 && graph[u][v] < key[v])
                key[v] = graph[u][v];
        }
    }
    return totalWeight;
}
```

- 时间 $O(V^2)$，适合密集图

### 优先队列优化（邻接表）

```cpp
struct Edge { int to, weight; };

int primHeap(vector<vector<Edge>>& adj, int n) {
    vector<int> key(n, INT_MAX);
    vector<bool> inMST(n, false);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    key[0] = 0;
    pq.push({0, 0});
    int totalWeight = 0, count = 0;

    while (!pq.empty() && count < n) {
        auto [w, u] = pq.top(); pq.pop();
        if (inMST[u]) continue;
        inMST[u] = true;
        totalWeight += w;
        count++;
        for (auto& e : adj[u]) {
            if (!inMST[e.to] && e.weight < key[e.to]) {
                key[e.to] = e.weight;
                pq.push({e.weight, e.to});
            }
        }
    }
    return totalWeight;
}
```

- 时间 $O(E \log V)$，适合稀疏图

## 三、Kruskal vs Prim 对比

| 特性 | Kruskal | Prim |
|------|---------|------|
| 贪心对象 | 边 | 顶点 |
| 核心数据结构 | 并查集 | 优先队列 / 数组 |
| 时间（朴素） | $O(E \log E)$ | $O(V^2)$ |
| 时间（优化） | $O(E \log E)$ | $O(E \log V)$ |
| 空间 | $O(E)$ | $O(V)$ |
| 适合场景 | 稀疏图、边列表 | 密集图、邻接矩阵 |
| 对连通性要求 | 需图连通（否则得到森林） | 需图连通 |
