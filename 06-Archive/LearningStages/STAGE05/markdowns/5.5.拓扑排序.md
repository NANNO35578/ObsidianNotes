# 5.5 拓扑排序

## 问题描述

对**有向无环图（DAG）**的顶点进行线性排序，使得对于任意一条边 $u \to v$，顶点 $u$ 在排序中出现在顶点 $v$ 之前。

**应用**：任务调度、编译顺序、课程选修顺序、依赖关系处理。

> 拓扑排序不唯一，一个 DAG 可能存在多种合法排序。
> 有环图无法进行拓扑排序。

---

## 一、Kahn 算法（基于 BFS）

### 算法思想

维护入度数组，每次将入度为 0 的顶点输出，并删除其出边（更新邻接点入度），重复直到所有顶点输出。

### 算法步骤

1. 计算每个顶点的入度
2. 将所有入度为 0 的顶点加入队列
3. 循环：队首顶点出队，加入结果
4. 遍历该顶点的所有邻接点，入度 -1，若入度变为 0 则入队
5. 队列为空时结束
6. 若结果中顶点数 < 总顶点数，说明图中有环

```cpp
vector<int> topologicalSort(vector<vector<int>>& adj, int n) {
    vector<int> inDegree(n, 0);
    for (int u = 0; u < n; u++)
        for (int v : adj[u])
            inDegree[v]++;

    queue<int> q;
    for (int i = 0; i < n; i++)
        if (inDegree[i] == 0) q.push(i);

    vector<int> res;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        res.push_back(u);
        for (int v : adj[u]) {
            inDegree[v]--;
            if (inDegree[v] == 0) q.push(v);
        }
    }

    if ((int)res.size() < n) return {};  // 有环，无法拓扑排序
    return res;
}
```

- 时间 $O(V + E)$
- 空间 $O(V)$

## 二、DFS 方法

### 算法思想

对每个顶点执行 DFS，当一个顶点的所有邻接点都访问完毕后，将该顶点加入结果列表。最终反转结果列表即为拓扑排序。

### 顶点状态

- 0：未访问
- 1：访问中（在当前递归栈中）
- 2：已访问完成

```cpp
bool dfs(int u, vector<vector<int>>& adj, vector<int>& state, vector<int>& res) {
    state[u] = 1;  // 访问中
    for (int v : adj[u]) {
        if (state[v] == 1) return false;  // 遇到访问中节点，有环
        if (state[v] == 0 && !dfs(v, adj, state, res)) return false;
    }
    state[u] = 2;  // 访问完成
    res.push_back(u);
    return true;
}

vector<int> topologicalSortDFS(vector<vector<int>>& adj, int n) {
    vector<int> state(n, 0), res;
    for (int i = 0; i < n; i++) {
        if (state[i] == 0) {
            if (!dfs(i, adj, state, res)) return {};  // 有环
        }
    }
    reverse(res.begin(), res.end());
    return res;
}
```

- 时间 $O(V + E)$
- 空间 $O(V)$（递归栈）

---

## 三、两种方法对比

| 特性 | Kahn（BFS） | DFS |
|------|-------------|-----|
| 核心 | 入度为 0 的顶点 | 后序遍历反转 |
| 数据结构 | 队列 | 递归栈 |
| 环检测 | 结果数 < 顶点数 | 遇到"访问中"节点 |
| 实现 | 直观 | 简洁 |
| 时间 | $O(V+E)$ | $O(V+E)$ |

---

## 四、典型应用

1. **课程排序**：课程有先修要求，求可学习顺序
2. **编译顺序**：模块间有依赖，求编译顺序
3. **任务调度**：任务间有依赖，求执行顺序
4. **关键路径**：在 DAG 上求最长路径（项目最早完成时间）
5. **判断有向图是否有环**：拓扑排序结果不完整则有环
