# 5.2 图的遍历（BFS 与 DFS）

## 一、广度优先搜索（BFS）

**核心思想**：从起始顶点出发，先访问所有邻接点，再访问邻接点的邻接点，逐层向外扩展。

### 算法步骤

1. 起始顶点入队列，标记为已访问
2. 循环：队首顶点出队，访问它
3. 将队首顶点的所有未访问邻接点入队，标记为已访问
4. 队列为空时结束

```cpp
vector<int> bfs(vector<vector<int>>& adj, int start, int n) {
    vector<int> res;
    vector<bool> visited(n, false);
    queue<int> q;
    q.push(start);
    visited[start] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        res.push_back(u);  // 访问
        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
    return res;
}
```

### 特点

- 时间 $O(V + E)$
- 空间 $O(V)$（队列 + 访问标记）
- 可求**无权图最短路径**（BFS 第一次到达某顶点的路径即为最短路径）
- 层序遍历

## 二、深度优先搜索（DFS）

**核心思想**：从起始顶点出发，沿着一条路径尽可能深入，直到无法继续时回溯，再探索其他路径。

### 递归实现

```cpp
void dfsHelper(vector<vector<int>>& adj, int u, vector<bool>& visited, vector<int>& res) {
    visited[u] = true;
    res.push_back(u);  // 访问
    for (int v : adj[u]) {
        if (!visited[v])
            dfsHelper(adj, v, visited, res);
    }
}

vector<int> dfs(vector<vector<int>>& adj, int start, int n) {
    vector<int> res;
    vector<bool> visited(n, false);
    dfsHelper(adj, start, visited, res);
    return res;
}
```

### 迭代实现（栈）

```cpp
vector<int> dfsIter(vector<vector<int>>& adj, int start, int n) {
    vector<int> res;
    vector<bool> visited(n, false);
    stack<int> st;
    st.push(start);
    while (!st.empty()) {
        int u = st.top(); st.pop();
        if (visited[u]) continue;
        visited[u] = true;
        res.push_back(u);
        // 逆序压入，保证顺序与递归一致
        for (auto it = adj[u].rbegin(); it != adj[u].rend(); ++it) {
            if (!visited[*it]) st.push(*it);
        }
    }
    return res;
}
```

### 特点

- 时间 $O(V + E)$
- 空间 $O(V)$（递归栈或显式栈）
- 适合：拓扑排序、连通分量、环检测、路径搜索

## 三、连通分量

遍历所有顶点，对每个未访问顶点启动一次 BFS/DFS，每次遍历得到一个连通分量。

```cpp
int countComponents(vector<vector<int>>& adj, int n) {
    vector<bool> visited(n, false);
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            count++;
            // BFS or DFS from i
            queue<int> q;
            q.push(i); visited[i] = true;
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : adj[u]) {
                    if (!visited[v]) { visited[v] = true; q.push(v); }
                }
            }
        }
    }
    return count;
}
```

## 四、环检测

### 无向图

DFS 时，若遇到已访问顶点且该顶点不是当前顶点的父节点，则存在环。

### 有向图

DFS 时维护三种状态：未访问、访问中（在当前递归栈中）、已访问。若遇到"访问中"的顶点，则存在环。

## 五、BFS vs DFS 对比

| 特性 | BFS | DFS |
|------|-----|-----|
| 遍历顺序 | 逐层扩展 | 深入到底再回溯 |
| 数据结构 | 队列 | 栈（递归栈） |
| 空间 | $O(V)$ | $O(V)$ |
| 最短路径 | 无权图可求 | 不保证 |
| 适用场景 | 层序、最短路径、最近距离 | 拓扑排序、连通性、路径搜索、回溯 |
| 实现 | 迭代 | 递归（简洁）或迭代 |
