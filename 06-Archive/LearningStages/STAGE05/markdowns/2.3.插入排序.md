# 2.3 插入排序

## 算法思想

将数组分为已排序和未排序两部分，每次取未排序部分的第一个元素，插入到已排序部分的正确位置。

---

## 算法步骤

1. 从第二个元素开始（第一个元素视为已排序）
2. 取出当前元素 `key = a[i]`
3. 从 `i-1` 向前遍历已排序部分，若 `a[j] > key` 则后移一位
4. 找到插入位置，将 `key` 放入

```cpp
void insertSort(vector<int>& a) {
    int n = a.size();
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];  // 后移
            j--;
        }
        a[j + 1] = key;  // 插入
    }
}
```

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n)$ | 已有序，每个元素只需比较一次 |
| 平均 | $O(n^2)$ | |
| 最坏 | $O(n^2)$ | 完全逆序 |
| 空间 | $O(1)$ | 原地排序 |
| 稳定性 | 稳定 | 相等元素不后移 |

---

## 特点

- 对基本有序的数据效率很高（接近 $O(n)$）
- 是希尔排序的基础
- 稳定排序
- 适合小规模数据
