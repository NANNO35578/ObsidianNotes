# 1.7 约瑟夫环

## 问题描述

有 n 个人围成一圈，第一个人从 1 开始报数，数到第 k 个人出列，下一个人继续从 1 开始报数，重复此过程，求最后剩下的人的编号。

---

## 解法一：队列模拟

**思路**：将 n 个人依次入队，每次将队首元素出队并计数，若计数为 k 则淘汰（不再入队），否则重新入队尾，直到队列只剩一人。

```cpp
int josephus(int n, int k) {
    queue<int> q;
    for (int i = 1; i <= n; i++) q.push(i);
    while (q.size() > 1) {
        for (int i = 1; i < k; i++) {
            q.push(q.front());
            q.pop();
        }
        q.pop();  // 第 k 个人出列
    }
    return q.front();
}
```

- 时间 $O(nk)$，空间 $O(n)$

---

## 解法二：数学公式（递推）

**核心推导**：

设 `f(n, k)` 表示 n 个人报数 k 时最后幸存者的编号（从 0 开始编号）。

- 第一轮报数后，编号为 `(k-1) % n` 的人出列
- 剩余 n-1 人从 `k % n` 开始重新编号，形成一个新的约瑟夫环问题
- 新环中编号为 `x` 的人，对应原环中的编号为 `(x + k) % n`

因此递推公式：

$$f(n,k) = (f(n-1,k) + k) \bmod n$$

边界：$f(1,k) = 0$

```cpp
int josephus(int n, int k) {
    int res = 0;  // f(1, k) = 0
    for (int i = 2; i <= n; i++)
        res = (res + k) % i;
    return res + 1;  // 转为从 1 开始编号
}
```

- 时间 $O(n)$，空间 $O(1)$

---

## 解法对比

| 方法 | 时间 | 空间 | 适用场景 |
|------|------|------|----------|
| 队列模拟 | $O(nk)$ | $O(n)$ | 需要输出每轮出列顺序 |
| 数学递推 | $O(n)$ | $O(1)$ | 只需最终幸存者编号 |

> [!tip] 当 k 很大时
> 递推公式可优化为 $O(k \log n)$，利用每轮淘汰多人的跳跃思想。
