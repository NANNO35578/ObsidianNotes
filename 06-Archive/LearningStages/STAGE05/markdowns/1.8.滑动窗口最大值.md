# 1.8 滑动窗口最大值

## 问题描述（LeetCode 239）

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组最左侧移动到最右侧。窗口每次只向右移动一位，返回每个滑动窗口中的最大值。

---

## 解法：单调双端队列

**核心思想**：维护一个单调递减的双端队列，队列中存储元素下标，队首始终是当前窗口的最大值下标。

### 算法步骤

1. 遍历数组，对每个元素 `nums[i]`：
2. **移除过期元素**：若队首下标 `<= i - k`（已滑出窗口），从队首弹出
3. **维护单调递减**：从队尾弹出所有值小于 `nums[i]` 的下标（它们不可能成为后续窗口的最大值）
4. **入队**：将当前下标 `i` 压入队尾
5. **记录结果**：当 `i >= k - 1` 时，窗口已形成，队首对应值即为当前窗口最大值

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    if (k >= (int)nums.size())
        return {*max_element(nums.begin(), nums.end())};
    if (k == 1) return nums;

    deque<int> dq;       // 存下标，单调递减
    vector<int> res;
    for (int i = 0; i < (int)nums.size(); i++) {
        // 1. 移除滑出窗口的队首
        if (!dq.empty() && dq.front() == i - k)
            dq.pop_front();
        // 2. 维护单调递减：弹出队尾小于当前值的元素
        while (!dq.empty() && nums[dq.back()] < nums[i])
            dq.pop_back();
        // 3. 当前下标入队
        dq.push_back(i);
        // 4. 窗口形成后记录最大值
        if (i >= k - 1)
            res.push_back(nums[dq.front()]);
    }
    return res;
}
```

### 示例演示

`nums = [1, 3, -1, -3, 5, 3, 6, 7]`, `k = 3`

| i | 窗口 | 队列（下标:值） | 输出 |
|---|------|-----------------|------|
| 0 | [1] | 0:1 | - |
| 1 | [1,3] | 1:3 | - |
| 2 | [1,3,-1] | 1:3, 2:-1 | 3 |
| 3 | [3,-1,-3] | 1:3, 2:-1, 3:-3 | 3 |
| 4 | [-1,-3,5] | 4:5 | 5 |
| 5 | [-3,5,3] | 4:5, 5:3 | 5 |
| 6 | [5,3,6] | 6:6 | 6 |
| 7 | [3,6,7] | 7:7 | 7 |

结果：`[3, 3, 5, 5, 6, 7]`

---

## 复杂度分析

- **时间**：$O(n)$，每个元素最多入队和出队各一次
- **空间**：$O(k)$，队列最多存储 k 个元素

---

## 扩展：滑动窗口最小值

将单调递减队列改为单调递增队列即可（弹出队尾大于当前值的元素）。

```cpp
// 只需修改维护条件：
while (!dq.empty() && nums[dq.back()] > nums[i])  // 改为 >
    dq.pop_back();
```
