# 2.2 选择排序

## 算法思想

每轮从未排序部分中选出最小元素，与未排序部分的第一个元素交换。

---

## 算法步骤

1. 遍历未排序部分 `[i, n-1]`，找到最小值下标 `minIdx`
2. 将 `a[i]` 与 `a[minIdx]` 交换
3. `i++`，重复直到全部有序

```cpp
void selectSort(vector<int>& a) {
    int n = a.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIdx])
                minIdx = j;
        }
        if (minIdx != i)
            swap(a[i], a[minIdx]);
    }
}
```

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n^2)$ | 无论是否有序都需遍历找最小值 |
| 平均 | $O(n^2)$ | |
| 最坏 | $O(n^2)$ | |
| 空间 | $O(1)$ | 原地排序 |
| 稳定性 | 不稳定 | 交换可能改变相等元素相对顺序 |

> [!example] 不稳定示例
> `[5a, 5b, 2]`：第一轮选最小值 2 与 5a 交换 → `[2, 5b, 5a]`，5a 和 5b 相对顺序改变。

---

## 特点

- 交换次数最少（最多 n-1 次），适合交换成本高的场景
- 比较次数固定为 $n(n-1)/2$，不受数据初始顺序影响
- 不稳定
