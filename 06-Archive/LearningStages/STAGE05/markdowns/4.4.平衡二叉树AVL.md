# 4.4 平衡二叉树（AVL）

## 定义

AVL 树是一种自平衡二叉搜索树，满足：
- 任意节点的左右子树高度差（平衡因子）不超过 1
- 左右子树也都是 AVL 树

**平衡因子**：$BF = h_{left} - h_{right}$，取值为 `-1, 0, 1`。

---

## 判断二叉树是否平衡（LeetCode 110）

```cpp
int getHeight(TreeNode* root) {
    if (!root) return 0;
    int leftH = getHeight(root->left);
    if (leftH == -1) return -1;  // 左子树不平衡，提前返回
    int rightH = getHeight(root->right);
    if (rightH == -1) return -1;
    if (abs(leftH - rightH) > 1) return -1;  // 不平衡
    return max(leftH, rightH) + 1;
}

bool isBalanced(TreeNode* root) {
    return getHeight(root) != -1;
}
```

- 时间 $O(n)$，空间 $O(h)$

## 四种旋转

插入或删除后若平衡因子超出范围，通过旋转恢复平衡。

### 1. 右旋（LL 型）

**触发条件**：左子树的左子树插入导致不平衡（左左）。

```
      A                B
     / \              / \
    B   C    →       D   A
   / \                  / \
  D   E                E   C
```

```cpp
TreeNode* rotateRight(TreeNode* A) {
    TreeNode* B = A->left;
    A->left = B->right;
    B->right = A;
    // 更新高度
    return B;  // 新根
}
```

### 2. 左旋（RR 型）

**触发条件**：右子树的右子树插入导致不平衡（右右）。

```
    A                  B
   / \                / \
  C   B      →       A   E
     / \            / \
    D   E          C   D
```

```cpp
TreeNode* rotateLeft(TreeNode* A) {
    TreeNode* B = A->right;
    A->right = B->left;
    B->left = A;
    return B;
}
```

### 3. 左右旋（LR 型）

**触发条件**：左子树的右子树插入导致不平衡。

**步骤**：先对左孩子左旋，再对根节点右旋。

```
      A              A               E
     / \            / \             / \
    B   C    →     E   C    →      B   A
     \            /                 \   \
      E          B                   D   C
     /            \
    D              D
```

### 4. 右左旋（RL 型）

**触发条件**：右子树的左子树插入导致不平衡。

**步骤**：先对右孩子右旋，再对根节点左旋。

---

## 旋转选择总结

| 失衡类型 | 触发原因 | 旋转方式 |
|----------|----------|----------|
| LL | 左子树的左孩子插入 | 右旋 |
| RR | 右子树的右孩子插入 | 左旋 |
| LR | 左子树的右孩子插入 | 先左旋左孩子，再右旋根 |
| RL | 右子树的左孩子插入 | 先右旋右孩子，再左旋根 |

---

## 复杂度分析

| 操作 | 时间 | 说明 |
|------|------|------|
| 查找 | $O(\log n)$ | 树高恒为 $O(\log n)$ |
| 插入 | $O(\log n)$ | 查找 + 最多一次旋转 |
| 删除 | $O(\log n)$ | 查找 + 最多 $O(\log n)$ 次旋转 |
| 空间 | $O(n)$ | |

---

## AVL 与红黑树对比

| 特性 | AVL | 红黑树 |
|------|-----|--------|
| 平衡严格度 | 严格平衡（高度差≤1） | 近似平衡（最长路径≤2倍最短） |
| 插入旋转 | 最多 1 次 | 最多 2 次 |
| 删除旋转 | 最多 $O(\log n)$ 次 | 最多 3 次 |
| 查找效率 | 更高（更平衡） | 稍低 |
| 适用场景 | 查找密集型 | 插入删除频繁（如 STL map） |
