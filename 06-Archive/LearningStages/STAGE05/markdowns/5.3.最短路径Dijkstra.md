# 5.3 最短路径（Dijkstra）

## 问题描述

在**有向正权图**（边权非负）中，求从一个源点到其他所有顶点的最短路径（单源最短路径）。

---

## 算法思想

贪心策略：维护一个距离数组 `dist[]`，每次从未确定最短距离的顶点中选取距离最小的顶点，用它更新其邻接点的距离。

---

## 算法步骤

1. **初始化**：`dist[src] = 0`，其余 `dist[i] = INF`
2. **选择**：从未处理顶点中选择 `dist` 最小的顶点 `u`
3. **更新**：遍历 `u` 的所有邻接点 `v`，若 `dist[u] + weight(u,v) < dist[v]`，则更新 `dist[v]`
4. **标记**：将 `u` 标记为已处理
5. **重复**：步骤 2-4，直到所有顶点处理完毕

---

## 实现

### 朴素实现（邻接矩阵）

```cpp
vector<int> dijkstra(vector<vector<int>>& graph, int src, int n) {
    vector<int> dist(n, INT_MAX);
    vector<bool> visited(n, false);
    dist[src] = 0;

    for (int count = 0; count < n - 1; count++) {
        // 选未处理中距离最小的顶点
        int u = -1;
        for (int v = 0; v < n; v++) {
            if (!visited[v] && (u == -1 || dist[v] < dist[u]))
                u = v;
        }
        if (u == -1 || dist[u] == INT_MAX) break;
        visited[u] = true;
        // 更新邻接点
        for (int v = 0; v < n; v++) {
            if (!visited[v] && graph[u][v] != 0 && dist[u] != INT_MAX
                && dist[u] + graph[u][v] < dist[v]) {
                dist[v] = dist[u] + graph[u][v];
            }
        }
    }
    return dist;
}
```

- 时间 $O(V^2)$，适合密集图

### 优先队列优化（邻接表）

```cpp
struct Edge { int to, weight; };

vector<int> dijkstraHeap(vector<vector<Edge>>& adj, int src, int n) {
    vector<int> dist(n, INT_MAX);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;  // 小根堆 (距离, 顶点)
    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;  // 过期记录，跳过
        for (auto& e : adj[u]) {
            if (dist[u] + e.weight < dist[e.to]) {
                dist[e.to] = dist[u] + e.weight;
                pq.push({dist[e.to], e.to});
            }
        }
    }
    return dist;
}
```

- 时间 $O(E \log V)$，适合稀疏图

---

## 复杂度分析

| 实现 | 时间 | 空间 | 适用场景 |
|------|------|------|----------|
| 朴素（邻接矩阵） | $O(V^2)$ | $O(V)$ | 密集图 |
| 优先队列（邻接表） | $O(E \log V)$ | $O(V + E)$ | 稀疏图 |

---

## 注意事项

1. **边权必须非负**：Dijkstra 不能处理负权边（负权边会导致贪心策略失效）
2. **路径还原**：需额外维护 `prev[]` 数组记录前驱节点，最后从目标点回溯到源点
3. **多源最短路径**：可添加一个超级源点，连接所有源点（边权 0），转为单源问题

---

## 其他最短路径算法对比

| 算法 | 适用场景 | 时间 | 负权 |
|------|----------|------|------|
| Dijkstra | 单源、非负权 | $O(E \log V)$ | 不支持 |
| Bellman-Ford | 单源、可负权、检测负环 | $O(VE)$ | 支持 |
| SPFA | Bellman-Ford 队列优化 | 平均 $O(E)$，最坏 $O(VE)$ | 支持 |
| Floyd-Warshall | 全源最短路径 | $O(V^3)$ | 支持（无负环） |
