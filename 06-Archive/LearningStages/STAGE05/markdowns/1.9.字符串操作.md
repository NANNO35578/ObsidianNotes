# 1.9 字符串操作

## 一、`char*` 与 `char[]` 的区别

| 特性 | `char* str = "abc"` | `char str[] = "abc"` |
|------|---------------------|----------------------|
| 存储位置 | 字符串常量在只读数据段，指针在栈 | 数组在栈上，内容可修改 |
| 可修改性 | 不可修改 `str[0] = 'x'`（未定义行为） | 可修改 `str[0] = 'x'` |
| 重新赋值 | 可 `str = "def"` | 不可整体赋值（需 strcpy） |
| sizeof | 指针大小（8字节） | 数组总大小（4字节含'\0'） |

### C 与 C++ 字符串操作对比

| 操作 | C（`<string.h>`） | C++（`<string>`） |
|------|-------------------|-------------------|
| 初始化 | `const char* s = "abc";` | `string s = "abc";` |
| 比较 | `strcmp(s1, s2)` | `s1 == s2`, `s1 > s2` |
| 复制 | `strcpy(dst, src)` | `dst = src` |
| 追加 | `strcat(dst, src)` | `dst += src` |
| 长度 | `strlen(s)` | `s.size()` |

## 二、空格替换

### 问题描述

一个足够长的字符串，中间有若干空格，将每个空格替换为 `"Haha"`（或任意字符串），要求时间空间消耗尽可能小。

### 解法：双指针从后向前替换

**思路**：
1. 遍历一遍统计空格个数 `k`
2. 新字符串长度 = 原长度 + `k * (替换串长度 - 1)`
3. 用两个指针：`oldEnd` 指向原串末尾，`newEnd` 指向新串末尾
4. 从后向前复制：遇到空格则写入替换串，否则复制原字符

```cpp
void replaceSpace(char str[], int length, const string& rep = "Haha") {
    int spaceCount = 0;
    int oldLen = 0;
    for (int i = 0; str[i] != '\0'; i++) {
        oldLen++;
        if (str[i] == ' ') spaceCount++;
    }
    int newLen = oldLen + spaceCount * ((int)rep.size() - 1);
    if (newLen > length) return;  // 空间不足
    int oldEnd = oldLen;
    int newEnd = newLen;
    while (oldEnd >= 0 && newEnd > oldEnd) {
        if (str[oldEnd] == ' ') {
            for (int i = (int)rep.size() - 1; i >= 0; i--)
                str[newEnd--] = rep[i];
        } else {
            str[newEnd--] = str[oldEnd];
        }
        oldEnd--;
    }
}
```

- 时间 $O(n)$，空间 $O(1)$（原地修改）

## 三、单词反转

### 问题描述

将字符串中的单词倒序，例如 `"Here to you"` → `"you to Here"`。

### 解法一：两次反转

1. 将整个字符串反转（除 `'\0'`）
2. 遍历字符串，将每个单词分别反转

```cpp
void reverseWords(string& s) {
    reverse(s.begin(), s.end());  // 整体反转
    int n = s.size(), i = 0;
    while (i < n) {
        int j = i;
        while (j < n && s[j] != ' ') j++;
        reverse(s.begin() + i, s.begin() + j);  // 单词反转
        i = j + 1;
    }
}
```

### 解法二：栈

1. 遍历字符串，字符依次入栈
2. 遇到空格时，将栈内字符（一个单词）弹出到结果，再压入空格
3. 遍历结束后弹出栈中最后一个单词

```cpp
string reverseWordsStack(const string& s) {
    stack<char> st;
    string res;
    for (char c : s) {
        if (c == ' ') {
            while (!st.empty()) { res += st.top(); st.pop(); }
            res += ' ';
        } else {
            st.push(c);
        }
    }
    while (!st.empty()) { res += st.top(); st.pop(); }
    return res;
}
```

- 时间 $O(n)$，空间 $O(n)$

> [!note] 注意
> 栈方法得到的是每个单词内部字符也反转的结果。若只需单词顺序反转而单词内部不变，应用两次反转法。
