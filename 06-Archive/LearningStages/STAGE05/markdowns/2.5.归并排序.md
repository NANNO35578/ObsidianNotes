# 2.5 归并排序

## 算法思想

采用分治策略：将数组递归地分成两半，分别排序后再合并两个有序子数组。

---

## 算法步骤

1. **分解**：将数组从中间分成左右两部分
2. **递归**：对左右两部分分别递归排序
3. **合并**：将两个有序子数组合并为一个有序数组

```cpp
void merge(vector<int>& a, int l, int mid, int r) {
    vector<int> tmp(r - l + 1);
    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = 0; t < k; t++) a[l + t] = tmp[t];
}

void mergeSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int mid = l + (r - l) / 2;
    mergeSort(a, l, mid);
    mergeSort(a, mid + 1, r);
    merge(a, l, mid, r);
}
```

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n \log n)$ | 分解合并次数固定 |
| 平均 | $O(n \log n)$ | |
| 最坏 | $O(n \log n)$ | |
| 空间 | $O(n)$ | 需额外数组辅助合并 |
| 稳定性 | 稳定 | 合并时相等元素取左半部分 |

### 主定理验证

$$T(n) = 2T(n/2) + O(n)$$

$a=2, b=2, f(n)=O(n)$，$n^{\log_2 2}=n$ 与 $f(n)$ 同阶，故 $T(n)=O(n \log n)$。

---

## 特点

- 性能稳定，不受数据初始顺序影响
- 稳定排序
- 需额外 $O(n)$ 空间
- 适合外部排序（数据量大无法全部载入内存时）
