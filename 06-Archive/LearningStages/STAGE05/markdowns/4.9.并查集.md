# 4.9 并查集（Disjoint Set）

## 定义

并查集（Disjoint Set Union, DSU）是一种用于管理**不相交集合**的数据结构，支持两种核心操作：
- **查（Find）**：查找元素所属集合的根节点
- **并（Union）**：合并两个集合

---

## 核心思想

用**双亲表示法**（数组）存储森林，每个集合是一棵树，根节点代表集合。

### 数组表示

`parent[i]` 存储元素 `i` 的父节点下标，根节点的 `parent` 为 `-1`（或自身）。

| 元素 | A | B | C | D | E | F | ... |
|------|---|---|---|---|---|---|-----|
| parent | -1 | -1 | -1 | A | A | A | ... |

---

## 基本实现

### 初始化

```cpp
vector<int> parent;
vector<int> rank_;  // 树的秩（高度），用于按秩合并

void init(int n) {
    parent.resize(n);
    rank_.resize(n, 0);
    for (int i = 0; i < n; i++) parent[i] = i;
}
```

### 查找（Find）

查找元素 `x` 所在集合的根节点。

```cpp
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 路径压缩
    return parent[x];
}
```

### 合并（Union）

将元素 `x` 和 `y` 所在的集合合并。

```cpp
void unite(int x, int y) {
    int rx = find(x), ry = find(y);
    if (rx == ry) return;  // 已在同一集合
    // 按秩合并：小树挂到大树下
    if (rank_[rx] < rank_[ry]) swap(rx, ry);
    parent[ry] = rx;
    if (rank_[rx] == rank_[ry]) rank_[rx]++;
}
```

### 查询是否同集合

```cpp
bool connected(int x, int y) {
    return find(x) == find(y);
}
```

---

## 两大优化

### 1. 路径压缩（Path Compression）

查找过程中，将路径上所有节点的父指针直接指向根节点，使后续查找更快。

```cpp
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 递归时直接指向根
    return parent[x];
}
```

多次查找后，树高可压缩到 2。

### 2. 按秩合并（Union by Rank）

合并时将较矮的树挂到较高的树下，避免树退化为链表。

- 用 `rank[i]` 记录以 `i` 为根的树的高度上界
- 两棵树高度不同：矮树挂到高树下，高度不变
- 两棵树高度相同：任挂一棵，新根高度 +1

---

## 复杂度分析

| 操作 | 朴素 | 路径压缩 | 按秩合并 | 两者兼有 |
|------|------|----------|----------|----------|
| Find | $O(n)$ | 均摊 $O(\alpha(n))$ | $O(\log n)$ | 均摊 $O(\alpha(n))$ |
| Union | $O(n)$ | 均摊 $O(\alpha(n))$ | $O(\log n)$ | 均摊 $O(\alpha(n))$ |

$\alpha(n)$ 为反阿克曼函数，增长极慢，实际中可视为常数（$n < 10^{600}$ 时 $\alpha(n) \le 5$）。

---

## 典型应用

1. **连通性问题**：判断图中两点是否连通
2. **最小生成树**：Kruskal 算法中判断加边是否成环
3. **朋友圈/社交网络**：判断两人是否在同一社交圈
4. **岛屿数量**：合并相邻陆地
5. **冗余连接**：找图中导致环的边

---

## 完整模板

```cpp
class DSU {
private:
    vector<int> parent, rank_;
public:
    DSU(int n) : parent(n), rank_(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    bool unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false;
        if (rank_[rx] < rank_[ry]) swap(rx, ry);
        parent[ry] = rx;
        if (rank_[rx] == rank_[ry]) rank_[rx]++;
        return true;
    }
    bool connected(int x, int y) { return find(x) == find(y); }
};
```
