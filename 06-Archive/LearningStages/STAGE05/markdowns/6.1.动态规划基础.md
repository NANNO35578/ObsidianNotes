# 6.1 动态规划基础

## 核心思想

动态规划（Dynamic Programming, DP）通过将大问题拆分为重叠子问题，存储子问题的解避免重复计算，从而高效求解。

---

## 适用条件

1. **最优子结构**：大问题的最优解由子问题的最优解构成
2. **重叠子问题**：子问题会被多次重复计算
3. **无后效性**：一旦某一状态确定，不再关心过去如何计算（未来决策不影响过去状态）

---

## 解题五步

1. **定状态**：定义 `dp` 数组的含义，下标和值分别代表什么
2. **初始化**：确定初始状态（base case）
3. **遍历顺序**：确定状态转移的遍历方向（如背包问题中物品和容量的先后）
4. **状态转移方程**：核心，描述如何从子问题的解得到当前问题的解
5. **验证**：手动推导几个状态，验证方程正确性

---

## 两种实现方式

### 1. 自顶向下（记忆化递归）

用递归 + 备忘录，遇到已计算的子问题直接返回。

```cpp
vector<int> memo;
int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n - 1) + fib(n - 2);
}
```

### 2. 自底向上（迭代）

从初始状态开始，按顺序递推到目标状态。

```cpp
int fib(int n) {
    if (n <= 1) return n;
    vector<int> dp(n + 1);
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}
```

## 经典问题：找零钱（最少钞票数）

### 问题描述

物品价值 15 元，有 `[1, 5, 11]` 三种面额的钞票，求最少需要多少张钞票。

### 状态定义

- `dp[i]`：凑出价值 `i` 所需的最少钞票数
- `i`：物品价值

### 状态转移方程

$$dp[i] = \min_{V[j] \le i} \{ dp[i - V[j]] + 1 \}$$

其中 `V[j]` 为第 j 种钞票面额。

### 初始化

`dp[0] = 0`（价值 0 需 0 张钞票），其余初始化为无穷大。

### 手动推导（面额 [1, 5, 11]）

```
dp[0] = 0
dp[1] = dp[1-1] + 1 = dp[0] + 1 = 1
dp[2] = dp[2-1] + 1 = dp[1] + 1 = 2
dp[3] = dp[3-1] + 1 = dp[2] + 1 = 3
dp[4] = dp[4-1] + 1 = dp[3] + 1 = 4
dp[5] = min(dp[5-1]+1, dp[5-5]+1) = min(5, 1) = 1
dp[6] = min(dp[6-1]+1, dp[6-5]+1) = min(2, 2) = 2
...
dp[10] = min(dp[10-1]+1, dp[10-5]+1) = min(3, 3) = 2
dp[11] = min(dp[11-1]+1, dp[11-5]+1, dp[11-11]+1) = min(3, 3, 1) = 1
dp[15] = min(dp[15-1]+1, dp[15-5]+1, dp[15-11]+1) = min(?, ?, ?)
```

### 代码实现

```cpp
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, INT_MAX);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (coin <= i && dp[i - coin] != INT_MAX) {
                dp[i] = min(dp[i], dp[i - coin] + 1);
            }
        }
    }
    return dp[amount] == INT_MAX ? -1 : dp[amount];
}
```

- 时间 $O(amount \times |coins|)$
- 空间 $O(amount)$

## DP 问题分类

| 类型 | 特点 | 典型问题 |
|------|------|----------|
| 线性 DP | 一维状态转移 | 斐波那契、找零钱、打家劫舍 |
| 背包 DP | 物品+容量二维状态 | 0-1 背包、完全背包、多重背包 |
| 区间 DP | 状态为区间 [l, r] | 矩阵链乘法、最长回文子序列 |
| 树形 DP | 在树上做状态转移 | 树的最大独立集、树的直径 |
| 状态压缩 DP | 用二进制表示状态 | 旅行商问题（TSP）、棋盘问题 |
| 数位 DP | 按位统计满足条件的数 | 数字 1 的个数、单调递增数 |

---

## 常见优化

1. **滚动数组**：若状态只依赖前一行/前一状态，可用一维数组替代二维，空间从 $O(n^2)$ 降到 $O(n)$
2. **顺序优化**：0-1 背包逆序遍历容量，完全背包正序遍历容量
3. **单调队列优化**：转移方程含区间最值时，用单调队列将 $O(n)$ 转移降到 $O(1)$
4. **斜率优化**：转移方程可化为线性形式时，用凸包优化

## DP vs 贪心 vs 回溯

| 方法 | 思想 | 适用场景 | 效率 |
|------|------|----------|------|
| 动态规划 | 记录所有子问题最优解 | 有重叠子问题和最优子结构 | 高（多项式） |
| 贪心 | 每步取局部最优 | 贪心选择性质 + 最优子结构 | 最高 |
| 回溯 | 暴力搜索所有解 | 解空间小、需所有解 | 低（指数） |
