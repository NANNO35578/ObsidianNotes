# 4.3 二叉搜索树（BST）

## 定义

二叉搜索树（Binary Search Tree）满足：
- 左子树所有节点值 < 根节点值
- 右子树所有节点值 > 根节点值
- 左右子树也都是 BST

**性质**：BST 的中序遍历结果为升序序列。

---

## 基本操作

### 1. 查找

```cpp
TreeNode* search(TreeNode* root, int val) {
    while (root) {
        if (val == root->val) return root;
        else if (val < root->val) root = root->left;
        else root = root->right;
    }
    return nullptr;
}
```

- 平均 $O(\log n)$，最坏 $O(n)$（退化为链表）

### 2. 插入

```cpp
TreeNode* insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left = insert(root->left, val);
    else if (val > root->val) root->right = insert(root->right, val);
    return root;  // 已存在则不插入
}
```

### 3. 删除节点

分三种情况：
1. **叶子节点**：直接删除
2. **只有一个孩子**：用孩子替换该节点
3. **有两个孩子**：用左子树最大值（前驱）或右子树最小值（后继）替换该节点的值，再删除那个被替换的节点

```cpp
TreeNode* deleteNode(TreeNode* root, int key) {
    if (!root) return nullptr;
    if (key < root->val) root->left = deleteNode(root->left, key);
    else if (key > root->val) root->right = deleteNode(root->right, key);
    else {  // 找到目标节点
        if (!root->left) return root->right;   // 情况1+2：无左孩子
        if (!root->right) return root->left;    // 情况2：无右孩子
        // 情况3：有两个孩子，找右子树最小值（后继）
        TreeNode* successor = root->right;
        while (successor->left) successor = successor->left;
        root->val = successor->val;
        root->right = deleteNode(root->right, successor->val);
    }
    return root;
}
```

## 典型应用

### BST 转换为有序双向链表

**思路**：中序遍历 BST 得到升序序列，遍历过程中维护前驱节点，修改指针将左右孩子指针改为双向链表的前后指针。

```cpp
TreeNode* prev = nullptr;
TreeNode* head = nullptr;

void inorder(TreeNode* cur) {
    if (!cur) return;
    inorder(cur->left);
    if (!prev) head = cur;       // 第一个节点为链表头
    else {
        prev->right = cur;        // 前驱的右指针指向当前
        cur->left = prev;         // 当前的左指针回指前驱
    }
    prev = cur;
    inorder(cur->right);
}

TreeNode* convertToDoublyList(TreeNode* root) {
    if (!root) return nullptr;
    prev = nullptr; head = nullptr;
    inorder(root);
    // 若需循环双向链表：head->left = prev; prev->right = head;
    return head;
}
```

- 时间 $O(n)$，空间 $O(h)$（递归栈）

---

## 复杂度分析

| 操作 | 平均 | 最坏（斜树） |
|------|------|-------------|
| 查找 | $O(\log n)$ | $O(n)$ |
| 插入 | $O(\log n)$ | $O(n)$ |
| 删除 | $O(\log n)$ | $O(n)$ |

> [!bug] BST 的缺陷
> 若插入有序数据，BST 会退化为链表，所有操作降为 $O(n)$。需使用平衡 BST（AVL、红黑树）来保证性能。
