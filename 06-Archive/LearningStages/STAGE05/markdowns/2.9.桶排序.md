# 2.9 桶排序

## 算法思想

非比较排序。将数据按范围分到多个桶中，每个桶内单独排序（通常用插入排序或快速排序），最后按桶顺序合并。

适用于数据均匀分布在某个范围内的场景，如 `[0, 1)` 的浮点数排序。

---

## 算法步骤

1. 根据最大值和最小值确定桶的数量和每个桶的范围
2. 将数据分配到对应桶中
3. 对每个桶内的数据进行排序
4. 按桶顺序依次取出所有元素，合并为有序数组

```cpp
void bucketSort(vector<float>& a) {
    if (a.empty()) return;
    int n = a.size();
    // 1. 创建 n 个桶
    vector<vector<float>> buckets(n);
    // 2. 分配数据到桶
    for (float x : a) {
        int idx = (int)(n * x);  // 假设 x in [0,1)
        if (idx >= n) idx = n - 1;
        buckets[idx].push_back(x);
    }
    // 3. 每个桶内排序
    for (auto& bucket : buckets)
        sort(bucket.begin(), bucket.end());
    // 4. 合并
    a.clear();
    for (auto& bucket : buckets)
        for (float x : bucket) a.push_back(x);
}
```

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n+k)$ | 数据均匀分布，每个桶元素少 |
| 平均 | $O(n+k)$ | k 为桶数 |
| 最坏 | $O(n^2)$ | 所有元素集中在一个桶 |
| 空间 | $O(n+k)$ | 桶数组 |
| 稳定性 | 稳定 | 桶内用稳定排序 + 按顺序合并 |

---

## 特点

- 非比较排序，数据均匀时效率极高
- 桶数量和范围的选择直接影响性能
- 数据分布不均时可能退化到 $O(n^2)$
- 适合浮点数、均匀分布数据
- 是基数排序的思想来源之一

> [!tip] 桶数量选择
> 通常取桶数等于元素个数 `n`，使每个桶平均 1 个元素，桶内排序接近 $O(1)$。
