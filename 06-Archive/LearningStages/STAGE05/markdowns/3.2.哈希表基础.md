# 3.2 哈希表基础

## 核心思想

在一堆无序元素中进行多次查找，希望时间复杂度接近 $O(1)$。将元素的**键**通过**哈希函数**映射到数组下标，实现键与存储位置的直接映射。

---

## 哈希函数构造

### 1. 常数型函数

键与下标存在固定关系，如字符的 ASCII 码直接作为下标。

```cpp
// 字符数组中查找某个字符下标，元素不重复
char arr[] = {'a', ':', '1', '='};
int hashTable[256];
for (int i = 0; i < 4; i++)
    hashTable[(unsigned char)arr[i]] = i;  // 字符ASCII码作索引
```

### 2. 除留余数法

`hash(key) = key % p`，其中 `p` 通常取小于等于表长的最大素数，减少冲突。

```cpp
// 元素个数 13（素数），MOD_N = 13
int hashVal = key % 13;
```

---

## 哈希冲突处理

同一个哈希下标已有元素，称为哈希冲突。

### 1. 开放定址法

冲突时寻找下一个空槽位。

- **线性探测**：依次尝试 `+1, +2, +3, ...`，后面满了绕到前面
- **二次探测**：尝试 `+1, -1, +4, -4, +9, -9, ...`

**查找**：从哈希下标开始向后遍历，若遇到空槽则说明不存在；若到表尾则绕回前部继续。

### 2. 拉链法（链地址法）

相同哈希值的元素组成链表，哈希表存储链表头指针。

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

const int MOD_N = 13;
ListNode* hashTable[MOD_N] = {nullptr};

// 插入
void insert(int key) {
    int idx = key % MOD_N;
    ListNode* node = new ListNode(key);
    node->next = hashTable[idx];
    hashTable[idx] = node;
}

// 查找
bool find(int key) {
    int idx = key % MOD_N;
    ListNode* cur = hashTable[idx];
    while (cur) {
        if (cur->val == key) return true;
        cur = cur->next;
    }
    return false;
}
```

> 当同一下标链表过长（如 8+ 个元素），Java 会将链表转为红黑树，C++ 则通过扩容重新散列来降低冲突。

---

## 存储内容

哈希表可存储：
- **元素数据本身**：适合需要快速查找和操作，且数据值可能变化的场景
- **元素索引**：适合内存敏感、数据重复较多的场景

---

## 复杂度分析

| 操作 | 平均 | 最坏 |
|------|------|------|
| 查找 | $O(1)$ | $O(n)$（全部冲突） |
| 插入 | $O(1)$ | $O(n)$ |
| 删除 | $O(1)$ | $O(n)$ |
| 空间 | $O(n)$ | |

## C++ STL 容器

| 容器 | 底层 | 有序 | 平均查找 |
|------|------|------|----------|
| `unordered_map` | 哈希表 | 无序 | $O(1)$ |
| `unordered_set` | 哈希表 | 无序 | $O(1)$ |
| `map` | 红黑树 | 有序 | $O(\log n)$ |
| `set` | 红黑树 | 有序 | $O(\log n)$ |
