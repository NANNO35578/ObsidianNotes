# 5.7 回溯算法

## 核心思想

回溯算法是一种**暴力搜索 + 剪枝**的算法，通过深度优先搜索尝试所有可能的解，当发现当前路径不可能得到有效解时，撤销选择并尝试其他路径。

**本质**：在一棵隐式的决策树上做 DFS，遇到叶子节点得到一个解，遇到不可行分支则回溯。

---

## 算法模板

```cpp
void backtracking(参数) {
    if (结束条件) {
        收集结果;
        return;
    }
    for (选择 : 本层所有可能性) {
        做出选择;
        backtracking(参数');  // 递归
        撤销选择;  // 回溯
    }
}
```

### 三个核心要素

1. **路径**：已经做出的选择（当前状态）
2. **选择列表**：当前可以做的选择
3. **结束条件**：到达决策树底层，无法再做选择

---

## 典型问题类型

| 类型 | 特点 | 示例 |
|------|------|------|
| 子集 | 元素不重复使用，不考虑顺序 | 子集、子集 II |
| 排列 | 元素不重复使用，考虑顺序 | 全排列、排列 II |
| 组合 | 元素不重复使用，不考虑顺序 | 组合求和、电话号码字母组合 |
| 棋盘 | 二维网格上的约束搜索 | N 皇后、解数独 |
| 迷宫 | 网格路径搜索 | 迷宫路径、岛屿数量 |

---

## 经典示例

### 示例 1：子集

从 `[1, 2, 3]` 中选出所有子集。

```cpp
vector<vector<int>> subsets(vector<int>& nums) {
    vector<vector<int>> res;
    vector<int> path;
    function<void(int)> dfs = [&](int start) {
        res.push_back(path);  // 每个节点都是一个子集
        for (int i = start; i < (int)nums.size(); i++) {
            path.push_back(nums[i]);
            dfs(i + 1);
            path.pop_back();
        }
    };
    dfs(0);
    return res;
}
```

### 示例 2：全排列

求 `[1, 2, 3]` 的所有排列。

```cpp
vector<vector<int>> permute(vector<int>& nums) {
    vector<vector<int>> res;
    vector<int> path;
    vector<bool> used(nums.size(), false);
    function<void()> dfs = [&]() {
        if (path.size() == nums.size()) {
            res.push_back(path);
            return;
        }
        for (int i = 0; i < (int)nums.size(); i++) {
            if (used[i]) continue;
            used[i] = true;
            path.push_back(nums[i]);
            dfs();
            path.pop_back();
            used[i] = false;
        }
    };
    dfs();
    return res;
}
```

### 示例 3：组合求和

从 `[2, 3, 6, 7]` 中找出和为 7 的组合（元素可重复使用）。

```cpp
vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
    vector<vector<int>> res;
    vector<int> path;
    function<void(int,int)> dfs = [&](int start, int sum) {
        if (sum == target) { res.push_back(path); return; }
        if (sum > target) return;  // 剪枝
        for (int i = start; i < (int)candidates.size(); i++) {
            path.push_back(candidates[i]);
            dfs(i, sum + candidates[i]);  // i 不+1，允许重复使用
            path.pop_back();
        }
    };
    dfs(0, 0);
    return res;
}
```

## 去重技巧

当数组中有重复元素时，需避免生成重复结果：

1. **排序**：先对数组排序，使相同元素相邻
2. **同层去重**：在 for 循环中，若当前元素与前一个相同且前一个未被使用，则跳过

```cpp
// 排列去重
if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;

// 组合/子集去重
if (i > start && nums[i] == nums[i-1]) continue;
```

---

## 剪枝策略

1. **可行性剪枝**：当前路径已不可能满足条件时提前返回（如 sum > target）
2. **最优性剪枝**：当前路径已不可能优于已知最优解时提前返回
3. **排序剪枝**：排序后可提前判断后续元素是否都不可行

---

## 复杂度分析

回溯算法的时间复杂度通常为指数级，取决于解空间大小：

| 问题 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 子集 | $O(n \times 2^n)$ | $O(n)$ |
| 全排列 | $O(n \times n!)$ | $O(n)$ |
| 组合 | $O(n \times C(n,k))$ | $O(k)$ |
| N 皇后 | $O(n!)$ | $O(n)$ |

> 实际运行时间因剪枝策略而大幅减少。
