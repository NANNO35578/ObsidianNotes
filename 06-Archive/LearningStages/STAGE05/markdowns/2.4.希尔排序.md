# 2.4 希尔排序

## 算法思想

希尔排序（Shell Sort）是插入排序的改进版，又称"缩小增量排序"。通过设置增量 `gap`，将数组分为 `gap` 组，对每组分别进行插入排序，逐步缩小 `gap` 直到为 1，最终完成整体排序。

---

## 算法步骤

1. 选择初始增量 `gap = n / 2`（或其他序列）
2. 将数组按 `gap` 分组，对每组进行插入排序
3. 缩小增量 `gap = gap / 2`
4. 重复步骤 2-3，直到 `gap = 1`，此时进行最后一次插入排序

```cpp
void shellSort(vector<int>& a) {
    int n = a.size();
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个分组进行插入排序
        for (int i = gap; i < n; i++) {
            int key = a[i];
            int j = i;
            while (j >= gap && a[j - gap] > key) {
                a[j] = a[j - gap];
                j -= gap;
            }
            a[j] = key;
        }
    }
}
```

---

## 增量序列选择

| 序列 | 公式 | 复杂度 |
|------|------|--------|
| Shell 原始 | $gap = \lfloor n/2^k \rfloor$ | 最坏 $O(n^2)$ |
| Hibbard | $gap = 2^k - 1$ | 最坏 $O(n^{1.5})$ |
| Knuth | $gap = (3^k - 1)/2$ | 约 $O(n^{1.3})$ |
| Sedgewick | 混合序列 | 约 $O(n^{4/3})$ |

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n \log n)$ | 取决于增量序列 |
| 平均 | $O(n^{1.3})$ | Knuth 增量 |
| 最坏 | $O(n^2)$ | Shell 原始增量 |
| 空间 | $O(1)$ | 原地排序 |
| 稳定性 | 不稳定 | 分组插入可能改变相等元素顺序 |

---

## 特点

- 突破了简单排序 $O(n^2)$ 的限制
- 最后一次 `gap=1` 时数组已基本有序，插入排序效率高
- 不稳定
- 增量序列的选择直接影响性能
