# 2.8 计数排序

## 算法思想

非比较排序。利用数组下标记录每个值出现的次数，再按顺序输出。适用于元素值范围较小且密集的整数排序。

---

## 适用条件

- 元素为整数（或可映射为整数）
- 最大值与最小值差值不大（范围密集）
- 元素重复出现概率高

---

## 算法步骤

1. 找出最小值 `minVal` 和最大值 `maxVal`
2. 申请计数数组 `count`，大小为 `maxVal - minVal + 1`，初始化为 0
3. 遍历原数组，统计每个值出现次数：`count[a[i] - minVal]++`
4. 计算前缀和（确定每个值在输出数组中的位置）
5. 从后向前遍历原数组，将元素放入输出数组对应位置（保证稳定性）
6. 将输出数组复制回原数组，释放计数数组

```cpp
void countSort(vector<int>& a) {
    if (a.empty()) return;
    int minVal = *min_element(a.begin(), a.end());
    int maxVal = *max_element(a.begin(), a.end());
    int range = maxVal - minVal + 1;
    vector<int> count(range, 0);
    vector<int> output(a.size());
    // 统计次数
    for (int x : a) count[x - minVal]++;
    // 前缀和：确定位置
    for (int i = 1; i < range; i++) count[i] += count[i - 1];
    // 从后向前放置（保证稳定）
    for (int i = a.size() - 1; i >= 0; i--) {
        output[count[a[i] - minVal] - 1] = a[i];
        count[a[i] - minVal]--;
    }
    a = output;
}
```

---

## 稳定性优化

计数排序天然可以是稳定的，关键在于：
1. 使用前缀和确定输出位置
2. **从后向前**遍历原数组放置元素

这样相等元素中后出现的会放在后面，保持原相对顺序。

> [!note] 简化版（不稳定）
> 若不需要稳定性，可直接遍历计数数组，按次数依次输出，无需前缀和和反向遍历。

---

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n+k)$ | k 为值范围 |
| 平均 | $O(n+k)$ | |
| 最坏 | $O(n+k)$ | |
| 空间 | $O(n+k)$ | 输出数组 + 计数数组 |
| 稳定性 | 稳定 | 反向遍历 + 前缀和 |

---

## 特点

- 非比较排序，突破 $O(n \log n)$ 下界
- 速度快，但受值范围限制
- 是基数排序的基础（每一位用计数排序）
- 当 $k \gg n$ 时空间浪费严重，不适用
