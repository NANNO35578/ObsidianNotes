# 5.6 后缀表达式（逆波兰表达式）

## 表达式表示法

| 表示法 | 说明 | 示例（a+b*c） |
|--------|------|----------------|
| 前缀表达式（波兰表示法） | 运算符在操作数之前 | `+a*bc` |
| 中缀表达式 | 运算符在操作数之间（日常写法） | `a+b*c` |
| 后缀表达式（逆波兰表示法） | 运算符在操作数之后 | `abc*+` |

后缀表达式无需括号，计算顺序由运算符位置唯一确定，适合计算机处理。

---

## 一、中缀转后缀（Shunting-yard 算法）

### 算法步骤

1. 初始化运算符栈，输出队列
2. 从左到右扫描中缀表达式：
   - 遇到操作数：直接输出
   - 遇到运算符 `cur`：
     - 与栈顶运算符 `top` 比较优先级
     - 若 `cur` 优先级 > `top`：`cur` 入栈
     - 若 `cur` 优先级 <= `top`（左结合）：栈顶依次出栈输出，直到栈顶优先级 < `cur`，然后 `cur` 入栈
   - 遇到左括号 `(`：直接入栈
   - 遇到右括号 `)`：栈内元素依次出栈输出，直到遇到左括号 `(`（括号不输出）
3. 扫描结束后，栈内剩余运算符依次出栈输出

### 运算符优先级

| 运算符 | 优先级 | 结合性 |
|--------|--------|--------|
| `^` | 4 | 右结合 |
| `*` `/` | 3 | 左结合 |
| `+` `-` | 2 | 左结合 |
| `(` | 1 | - |

```cpp
int precedence(char op) {
    switch (op) {
        case '^': return 4;
        case '*': case '/': return 3;
        case '+': case '-': return 2;
        case '(': return 1;
        default: return 0;
    }
}

string infixToPostfix(const string& expr) {
    stack<char> opStack;
    string postfix;
    for (char c : expr) {
        if (isalnum(c)) {
            postfix += c;  // 操作数直接输出
        } else if (c == '(') {
            opStack.push(c);
        } else if (c == ')') {
            while (!opStack.empty() && opStack.top() != '(') {
                postfix += opStack.top(); opStack.pop();
            }
            opStack.pop();  // 弹出 '('
        } else {  // 运算符
            while (!opStack.empty() && precedence(opStack.top()) >= precedence(c)) {
                postfix += opStack.top(); opStack.pop();
            }
            opStack.push(c);
        }
    }
    while (!opStack.empty()) {
        postfix += opStack.top(); opStack.pop();
    }
    return postfix;
}
```

### 示例

中缀：`a+b*c-(d/e+f)*g`

转换过程：
- `a` → 输出：`a`
- `+` → 入栈
- `b` → 输出：`ab`
- `*` → 优先级 > `+`，入栈
- `c` → 输出：`abc`
- `-` → `*` 出栈，`+` 出栈，`-` 入栈 → 输出：`abc*+`
- `(` → 入栈
- `d` → 输出：`abc*+d`
- `/` → 入栈
- `e` → 输出：`abc*+de`
- `+` → `/` 出栈，`+` 入栈 → 输出：`abc*+de/`
- `f` → 输出：`abc*+de/f`
- `)` → `+` 出栈，弹出 `(` → 输出：`abc*+de/f+`
- `*` → 入栈
- `g` → 输出：`abc*+de/f+g`
- 结束 → `*` 出栈，`-` 出栈

结果：`abc*+de/f+g*-`

## 二、后缀表达式求值

### 算法步骤

1. 初始化操作数栈
2. 从左到右扫描后缀表达式：
   - 遇到操作数：入栈
   - 遇到运算符：弹出栈顶两个操作数（注意顺序：先弹的是右操作数，后弹的是左操作数），计算结果入栈
3. 扫描结束后，栈中剩余的唯一元素即为表达式的值

```cpp
int evalPostfix(const string& expr) {
    stack<int> st;
    for (char c : expr) {
        if (isdigit(c)) {
            st.push(c - '0');
        } else {
            int b = st.top(); st.pop();  // 右操作数
            int a = st.top(); st.pop();  // 左操作数
            switch (c) {
                case '+': st.push(a + b); break;
                case '-': st.push(a - b); break;
                case '*': st.push(a * b); break;
                case '/': st.push(a / b); break;
            }
        }
    }
    return st.top();
}
```

### 示例

后缀：`23*5+`
- `2` 入栈：[2]
- `3` 入栈：[2, 3]
- `*`：弹 3、2，计算 2*3=6，入栈：[6]
- `5` 入栈：[6, 5]
- `+`：弹 5、6，计算 6+5=11，入栈：[11]
- 结果：11

## 三、后缀转中缀

1. 初始化栈（存储表达式字符串）
2. 遇到操作数：入栈
3. 遇到运算符：弹出栈顶两个表达式，与运算符组成带括号的中缀表达式，入栈
4. 最终栈中唯一元素即为中缀表达式

## 复杂度

| 操作 | 时间 | 空间 |
|------|------|------|
| 中缀转后缀 | $O(n)$ | $O(n)$ |
| 后缀求值 | $O(n)$ | $O(n)$ |
