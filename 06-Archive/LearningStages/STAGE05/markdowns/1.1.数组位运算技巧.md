# 1.1 数组位运算技巧

## 一、value-index 检查数组重复元素

> 利用数组下标与值的映射关系，在原数组上原地标记是否出现重复。

**核心思想**：若数组元素值范围在 `[0, n-1]` 内，可将值 `v` 对应到下标 `v`，通过标记该下标位置来判断是否重复。

**步骤**：
1. 遍历数组，取当前元素值 `v = abs(nums[i])`
2. 若 `nums[v] < 0`，说明 `v` 之前已出现过，即为重复元素
3. 否则将 `nums[v]` 取反作为标记

```cpp
int findDuplicate(vector<int>& nums) {
    for (int i = 0; i < nums.size(); i++) {
        int v = abs(nums[i]);
        if (nums[v] < 0) return v;
        nums[v] = -nums[v];
    }
    return -1;
}
```

**复杂度**：时间 $O(n)$，空间 $O(1)$（原地修改）。

## 二、异或运算找唯一出现一次的数字

### 问题 1：n-1 个数字成对出现，一个数字只出现一次

**位运算基础**：
- 异或 `^`：二进制位相同为 0，不同为 1
- 按位或 `|`：全 0 为 0
- 按位与 `&`：全 1 为 1

**核心性质**：
- `a ^ a = 0`
- `a ^ 0 = a`
- 异或满足交换律和结合律

**解法**：将所有数字依次异或，成对的数字相互抵消为 0，最终结果即为唯一出现一次的数字。

```cpp
int singleNumber(vector<int>& nums) {
    int res = 0;
    for (int x : nums) res ^= x;
    return res;
}
```

### 问题 2：n-2 个数字成对出现，两个数字各出现一次

设这两个数字为 `a` 和 `b`。

**步骤**：
1. 所有数字异或得到 `xor = a ^ b`
2. 由于 `a ≠ b`，`xor` 至少有一位为 1。取最低位的 1 作为分组掩码 `mask = xor & (-xor)`
3. 按该位是否为 1 将数组分为两组，`a` 和 `b` 必然分属不同组
4. 对每组分别异或，得到两个数字

```cpp
vector<int> singleNumberIII(vector<int>& nums) {
    long long xorAll = 0;
    for (int x : nums) xorAll ^= x;
    int mask = xorAll & (-xorAll);  // 最低位的1
    int a = 0, b = 0;
    for (int x : nums) {
        if (x & mask) a ^= x;
        else b ^= x;
    }
    return {a, b};
}
```

**复杂度**：时间 $O(n)$，空间 $O(1)$。

## 三、不用加号实现加法（Add Without +）

**核心思想**：用位运算模拟加法。
- `a ^ b`：得到不考虑进位的加法结果
- `(a & b) << 1`：得到进位（只有两位都为 1 时产生进位，左移一位）

**步骤**：
1. 循环：当 `b != 0` 时
2. `carry = (a & b) << 1`（计算进位）
3. `a = a ^ b`（不进位加法）
4. `b = carry`（将进位作为新的 b 继续相加）
5. 最终 `a` 即为结果

```cpp
int add(int a, int b) {
    while (b != 0) {
        unsigned int carry = (unsigned int)(a & b) << 1;
        a = a ^ b;
        b = carry;
    }
    return a;
}
```

> [!note] 注意
> 使用 `unsigned int` 避免左移溢出时的未定义行为。

**复杂度**：时间 $O(1)$（最多循环 32 次），空间 $O(1)$。
