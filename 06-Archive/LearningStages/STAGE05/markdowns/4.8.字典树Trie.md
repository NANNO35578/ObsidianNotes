# 4.8 字典树（Trie）

## 定义

字典树（Trie，又称前缀树、单词树）是一种用于存储字符串集合的树形数据结构，特别适用于前缀匹配和单词查找。

---

## 三大功能

1. **查找**：判断某个单词是否存在
2. **计数**：统计以某个前缀开头的单词数量
3. **排序**：字典序遍历所有单词

---

## 结构

- 每个节点代表一个字符
- 从根到某个节点的路径表示一个字符串前缀
- 节点的子节点表示以该字符为前缀的后续字符
- 节点包含一个标记 `isEnd`，表示是否为某个完整单词的结尾

```
          (root)
         /   |   \
        a    b    c
       /     |     \
      p      a      a
     / \     |      |
    p   l    t      t
   /     \   |       \
  l       e  e        o
 /         \           \
e           s           g
```

存储了单词：apple, app, bat, cat

---

## C++ 实现

```cpp
struct TrieNode {
    TrieNode* next[26];
    int count;  // 以该节点为前缀的单词数
    bool isEnd; // 是否为单词结尾

    TrieNode() : count(0), isEnd(false) {
        for (int i = 0; i < 26; i++) next[i] = nullptr;
    }

    ~TrieNode() {
        for (int i = 0; i < 26; i++)
            delete next[i];  // 递归释放子节点
    }
};

class Trie {
private:
    TrieNode* root;
public:
    Trie() { root = new TrieNode(); }
    ~Trie() { delete root; }

    // 插入单词
    void insert(const string& word) {
        TrieNode* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->next[idx]) cur->next[idx] = new TrieNode();
            cur = cur->next[idx];
            cur->count++;
        }
        cur->isEnd = true;
    }

    // 查找单词是否存在
    bool search(const string& word) {
        TrieNode* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->next[idx]) return false;
            cur = cur->next[idx];
        }
        return cur->isEnd;
    }

    // 查找前缀是否存在
    bool startsWith(const string& prefix) {
        TrieNode* cur = root;
        for (char c : prefix) {
            int idx = c - 'a';
            if (!cur->next[idx]) return false;
            cur = cur->next[idx];
        }
        return true;
    }

    // 统计以 prefix 为前缀的单词数
    int countPrefix(const string& prefix) {
        TrieNode* cur = root;
        for (char c : prefix) {
            int idx = c - 'a';
            if (!cur->next[idx]) return 0;
            cur = cur->next[idx];
        }
        return cur->count;
    }
};
```

> [!bug] 内存释放注意
> `next` 是固定大小数组（在对象内部），不是 `new[]` 分配的，**不能用 `delete[]`**。应在析构函数中递归 `delete` 每个子节点指针。

---

## 复杂度分析

| 操作 | 时间 | 空间 |
|------|------|------|
| 插入 | $O(m)$，m 为单词长度 | $O(m \times n)$，n 为单词数 |
| 查找 | $O(m)$ | |
| 前缀查找 | $O(m)$ | |
| 前缀计数 | $O(m)$ | |

---

## 应用场景

- **单词自动补全**：根据前缀查找所有可能单词
- **拼写检查**：快速判断单词是否存在
- **IP 路由查找**：最长前缀匹配
- **词频统计**：统计大量文本中单词出现次数
- **字符串排序**：字典序遍历

---

## 与哈希表对比

| 特性 | Trie | 哈希表 |
|------|------|--------|
| 精确查找 | $O(m)$ | 平均 $O(1)$ |
| 前缀匹配 | $O(m)$，天然支持 | 不支持（需遍历） |
| 字典序排序 | 中序遍历即可 | 需额外排序 |
| 空间 | 可能较高（稀疏节点） | 较低 |
| 哈希冲突 | 无 | 有 |
