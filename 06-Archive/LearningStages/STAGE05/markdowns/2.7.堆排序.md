# 2.7 堆排序

## 数据结构：堆

堆是一个完全二叉树，分为：
- **大顶堆**：每个节点的值 >= 其子节点的值，堆顶为最大值
- **小顶堆**：每个节点的值 <= 其子节点的值，堆顶为最小值

### 数组表示（从 0 开始编号）

- 左孩子：`left = 2 * i + 1`
- 右孩子：`right = 2 * i + 2`
- 父节点：`parent = (i - 1) / 2`
- 最后一个非叶子节点下标：`n / 2 - 1`

---

## 算法思想

1. 将数组构建为大顶堆
2. 堆顶（最大值）与末尾元素交换，最大值归位
3. 对剩余部分重新调整为大顶堆
4. 重复步骤 2-3，直到全部有序

---

## 算法实现

### 调整堆（heapify）

从节点 `i` 开始向下调整，使其满足大顶堆性质。

```cpp
void heapify(vector<int>& a, int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    if (left < n && a[left] > a[largest]) largest = left;
    if (right < n && a[right] > a[largest]) largest = right;
    if (largest != i) {
        swap(a[i], a[largest]);
        heapify(a, n, largest);  // 递归调整被交换的子树
    }
}
```

### 堆排序主函数

```cpp
void heapSort(vector<int>& a) {
    int n = a.size();
    // 1. 建堆：从最后一个非叶子节点开始向上调整
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(a, n, i);
    // 2. 逐个取出堆顶
    for (int i = n - 1; i > 0; i--) {
        swap(a[0], a[i]);       // 堆顶与末尾交换
        heapify(a, i, 0);        // 调整剩余部分为堆
    }
}
```

## 复杂度分析

| 情况 | 时间 | 说明 |
|------|------|------|
| 最好 | $O(n \log n)$ | |
| 平均 | $O(n \log n)$ | |
| 最坏 | $O(n \log n)$ | 性能稳定 |
| 空间 | $O(1)$ | 原地排序（递归实现为 $O(\log n)$） |
| 稳定性 | 不稳定 | 堆顶与末尾交换可能改变相等元素顺序 |

### 建堆复杂度

- 自底向上建堆：$O(n)$（不是 $O(n \log n)$，因为大部分节点在低层，调整次数少）
- 每次调整堆：$O(\log n)$
- 共调整 n-1 次：$O(n \log n)$

---

## 特点

- 时间复杂度稳定为 $O(n \log n)$，无最坏情况退化
- 原地排序，空间 $O(1)$
- 不稳定
- 适合维护动态最大值/最小值（优先队列）
- 缓存不友好（跳跃访问），实际性能常不如快速排序
