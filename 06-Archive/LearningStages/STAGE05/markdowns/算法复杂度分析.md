# 算法复杂度分析

## 时间复杂度

> [!tip] 概述
> 计算机运行程序需要时间，每秒钟大约能进行 $10^8$ 次（1亿次）运算。
> Time Limit Exceed (TLE) 代表代码超时，当你的代码超时时，你可能使用了**效率低的算法**，需要分析一下你的代码需要执行多少条基本语句。
> 避免使用 `endl`，`endl` 很慢（每次都刷新缓冲区），建议替换为 `'\n'`。
> - $1+2+3+\ldots+10^{14}$ —— 暴力累加，执行 $10^{14}$ 次语句，会超时
> - $10^{14} \times (10^{14}+1) / 2$ —— 等差数列求和公式，仅执行几条语句

> [!note] 分析时间复杂度
> 时间复杂度通常用大 $O$ 表示。括号内含有关于输入变量的系数为 1 的单项式或多项式，表示执行了多少条基本语句。例如 $O(n)$、$O(n^2)$。

### 例题：嵌套循环复杂度分析

```cpp
#include <iostream>

int main() {
  int n, m, sum = 0;
  std::cin >> n >> m;
  for (int i = 1; i <= n; i *= 2)
    for (int j = 0; j <= m; j++) {
      sum += i;
      sum += j;
    }
  std::cout << sum;
  return 0;
}
```

A. $O(n \times m)$ 　 B. $O(n \times \log_2 m)$ 　 C. $O(\log_2(n \times m))$ 　 D. $O(m \times \log_2 n)$

> [!success] 答案与解析
> **答案：D. $O(m \times \log_2 n)$**
> - 外层循环：`i` 从 1 开始每次乘 2，直到超过 `n`，共执行 $\lfloor \log_2 n \rfloor + 1$ 次，即 $O(\log_2 n)$。
> - 内层循环：`j` 从 0 到 `m`，共执行 $m+1$ 次，即 $O(m)$。
> - 两层嵌套，总复杂度为 $O(m \times \log_2 n)$。

### 递归时间复杂度（主定理 Master Theorem）

对于形如分治递归的算法，其时间复杂度满足：

$$T(n) = a \cdot T\!\left(\frac{n}{b}\right) + f(n)$$

- $a$：子问题个数（每次递归分裂出多少个子问题）
- $b$：子问题规模缩小的倍数（每个子问题的输入规模是原问题的 $1/b$）
- $f(n)$：当前层除递归外的处理时间复杂度

**比较 $n^{\log_b a}$ 与 $f(n)$ 的阶，取较大者：**

1. 若 $n^{\log_b a} > f(n)$（多项式意义上更大），则 $T(n) = O(n^{\log_b a})$
2. 若 $n^{\log_b a} = f(n)$，则 $T(n) = O(n^{\log_b a} \cdot \log n)$
3. 若 $n^{\log_b a} < f(n)$（多项式意义上更小），则 $T(n) = O(f(n))$

> [!example] 例如：二叉树递归遍历
> - 子问题个数：分裂为左子树、右子树两个，$a = 2$
> - 子问题规模：理想平衡二叉树中，每棵子树节点数约为原树的一半，$b = 2$
> - 当前层处理：访问根节点，$f(n) = O(1)$
> - $n^{\log_2 2} = n^1 = n$，远大于 $O(1)$，故 $T(n) = O(n)$

> [!bug] 不适用于斐波那契数列问题
> 该问题子问题间结果互相影响（存在大量重复计算，非独立子问题），主定理不适用。朴素递归斐波那契的复杂度为 $O(2^n)$。

## 空间复杂度

> 空间复杂度的概念比时间复杂度简单，只需计算程序运行过程中申请的额外空间大小。

**单位换算：**
- $1\,\text{MB} = 1024\,\text{KB}$，$1\,\text{KB} = 1024\,\text{Byte}$，$1\,\text{Byte} = 8\,\text{Bit}$

**常见类型占用字节数：**

| 类型 | 字节数 |
|------|--------|
| `bool` | 1 |
| `int` | 4 |
| `long long` | 8 |
| `float` | 4 |
| `double` | 8 |
| `char` | 1 |
| 指针（64位） | 8 |

## 常见排序算法复杂度

| 排序算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|----------|----------|----------|------|--------|
| 1. 冒泡排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 |
| 2. 选择排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 不稳定 |
| 3. 插入排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 稳定 |
| 4. 希尔排序 | $O(n^{1.3})$ | $O(n^2)$ | $O(1)$ | 不稳定 |
| 5. 归并排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | 稳定 |
| 6. 快速排序 | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | 不稳定 |
| 7. 堆排序 | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | 不稳定 |
| 8. 计数排序 | $O(n+k)$ | $O(n+k)$ | $O(k)$ | 稳定 |
| 9. 桶排序 | $O(n+k)$ | $O(n^2)$ | $O(n+k)$ | 稳定 |
| 10. 基数排序 | $O(n \times k)$ | $O(n \times k)$ | $O(n+k)$ | 稳定 |

## 复杂度速记口诀

> **"常 对 幂 指 阶"**

按增长速度从慢到快排列：

$$O(1) < O(\log n) < O(n^k) < O(a^n) < O(n!)$$

- **常**：常数阶 $O(1)$
- **对**：对数阶 $O(\log n)$
- **幂**：幂函数/多项式阶 $O(n), O(n^2), O(n^k)$
- **指**：指数阶 $O(2^n), O(a^n)$
- **阶**：阶乘阶 $O(n!)$

## 补充：复杂度分析要点

1. **并列循环**：取各循环复杂度之和，如两个并列循环分别为 $O(m)$ 和 $O(n)$，总复杂度 $O(m+n)$。
2. **嵌套循环**：各层复杂度相乘。
3. **递归分治**：用主定理分析（见上文）。
4. **动态规划**：通常状态数 × 转移复杂度，常用空间换时间。
5. **只看最高阶项**：大 $O$ 表示忽略常数系数和低阶项，如 $3n^2 + 5n + 2 = O(n^2)$。
