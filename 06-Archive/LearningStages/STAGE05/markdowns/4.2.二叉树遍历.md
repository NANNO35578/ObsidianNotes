# 4.2 二叉树遍历

## 一、深度优先遍历（DFS）

### 1. 前序遍历（根-左-右）

```cpp
void preorder(TreeNode* root) {
    if (!root) return;
    cout << root->val << " ";  // 访问根
    preorder(root->left);       // 左子树
    preorder(root->right);      // 右子树
}
```

### 2. 中序遍历（左-根-右）

```cpp
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}
```

> BST 的中序遍历结果为升序序列。

### 3. 后序遍历（左-右-根）

```cpp
void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << " ";
}
```

## 二、迭代遍历（栈实现）

### 前序遍历

```cpp
vector<int> preorderIter(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* node = st.top(); st.pop();
        res.push_back(node->val);
        if (node->right) st.push(node->right);  // 先压右
        if (node->left) st.push(node->left);    // 后压左，保证左先出
    }
    return res;
}
```

### 中序遍历

```cpp
vector<int> inorderIter(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    TreeNode* cur = root;
    while (cur || !st.empty()) {
        while (cur) {  // 一直向左走
            st.push(cur);
            cur = cur->left;
        }
        cur = st.top(); st.pop();
        res.push_back(cur->val);  // 访问
        cur = cur->right;          // 转向右子树
    }
    return res;
}
```

### 后序遍历

利用"根-右-左"遍历后反转，得到"左-右-根"。

```cpp
vector<int> postorderIter(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* node = st.top(); st.pop();
        res.push_back(node->val);
        if (node->left) st.push(node->left);
        if (node->right) st.push(node->right);
    }
    reverse(res.begin(), res.end());
    return res;
}
```

## 三、广度优先遍历（BFS / 层序遍历）

### 基本层序遍历

用队列实现，逐层访问。

```cpp
vector<int> levelOrder(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        TreeNode* node = q.front(); q.pop();
        res.push_back(node->val);
        if (node->left) q.push(node->left);
        if (node->right) q.push(node->right);
    }
    return res;
}
```

### 层序遍历带换行（按层输出）

#### 方法 1：利用 `size()` 计数

```cpp
vector<vector<int>> levelOrderWithN(TreeNode* root) {
    vector<vector<int>> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int size = q.size();  // 当前层节点数
        vector<int> level;
        for (int i = 0; i < size; i++) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```

#### 方法 2：分隔标记

在每层末尾插入一个标记节点（如 `nullptr`），遇到标记时换行。

#### 方法 3：双队列

一个队列存当前层，一个存下一层，交替使用。

#### 方法 4：双计数器

`i` 记录当前层剩余节点数，`j` 记录下一层节点数，`i` 归零时换行。

## 四、数组转二叉树

对于完全二叉树的数组表示（从 0 开始编号）：
- 节点 `i` 的左孩子：`2i + 1`
- 节点 `i` 的右孩子：`2i + 2`
- 父节点编号范围：`0 ~ n/2 - 1`

```cpp
TreeNode* arrayToTree(vector<int>& a, int i = 0) {
    if (i >= (int)a.size() || a[i] == -1) return nullptr;  // -1 表示空
    TreeNode* root = new TreeNode(a[i]);
    root->left = arrayToTree(a, 2 * i + 1);
    root->right = arrayToTree(a, 2 * i + 2);
    return root;
}
```

## 五、遍历复杂度

| 遍历方式 | 时间 | 空间（递归栈/队列） |
|----------|------|---------------------|
| 前/中/后序（递归） | $O(n)$ | $O(h)$，$h$ 为树高 |
| 前/中/后序（迭代） | $O(n)$ | $O(h)$ |
| 层序遍历 | $O(n)$ | $O(w)$，$w$ 为最大层宽 |
