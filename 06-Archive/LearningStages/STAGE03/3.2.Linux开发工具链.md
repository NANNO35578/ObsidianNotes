# vi / vim 编辑器

Vi 有三种基本工作模式：
- **命令模式**（Normal mode）：默认模式，用于移动光标、删除、复制等操作
- **文本输入模式**（Insert mode）：输入文本，按 `i`/`a`/`o` 等进入，按 `Esc` 返回命令模式
- **末行模式**（Command-line mode）：按 `:` 进入，用于保存、退出、搜索替换等

# gcc 编译

## 基本用法

```bash
gcc main.c -o mainOut    # 编译生成可执行文件 mainOut
```

## 编译流程

1. **预处理**（Preprocessing）：展开宏、头文件，生成 `.i` 文件
2. **编译**（Compilation）：编译为汇编代码，生成 `.s` 文件
3. **汇编**（Assembly）：汇编为目标文件，生成 `.o` 文件
4. **链接**（Linking）：链接库文件，生成可执行文件

## 常用参数

| 参数 | 说明 |
|------|------|
| `-v` / `--version` | 查看 gcc 版本号 |
| `-I` | 指定头文件目录（注意 `-I` 和参数之间**没有**空格） |
| `-c` | 只编译，生成 `.o` 文件，不进行链接 |
| `-g` | 包含调试信息（用于 gdb 调试） |
| `-O0` ~ `-O3` | 编译优化等级，n 越大优化越多 |
| `-Wall` | 提示更多警告信息 |
| `-D` | 编译时定义宏（注意 `-D` 和参数之间没有空格） |
| `-E` | 生成预处理文件（`.i`） |
| `-M` | 生成 `.c` 文件与头文件依赖关系（用于 Makefile），包括系统库头文件 |
| `-MM` | 生成依赖关系，不包括系统库头文件 |
| `-l` | 链接指定库，如 `-lpthread` |
| `-L` | 指定库文件搜索路径 |
| `-std` | 指定 C 标准，如 `-std=c11` |

> 多文件编译示例：
> ```bash
> g++ main.cpp add.cpp dec.cpp mul.cpp sub.cpp -o mainOut -I../include
> ```

项目目录结构示例：

```
project/
├── include/
│   └── head.h
└── src/
    ├── main.cpp
    ├── add.cpp
    ├── dec.cpp
    ├── mul.cpp
    └── sub.cpp
```

# gdb 调试

- 在编译源代码时加入调试参数 `-g`，使用 `gdb` 启动可执行文件即可开始调试

```bash
gcc -g main.c -o main
gdb main
```

| `break` | `b` | 设置断点，参数为函数名或行号 |
| `info breakpoints` | | 显示断点信息及触发次数 |

# make 自动化构建

`makefile` 是一种用于自动化构建过程的文件，通常与 `make` 工具一起使用，定义了一系列规则和依赖关系，指导如何编译和链接程序。

## 优点

1. 便捷管理代码，不需要每次书写复杂的编译命令
2. 复用性强，可反复使用管理不同工程
3. 节省编译时间

## 编译时间优化原理

- 编译期：每个源文件对应生成一个 `.o` 文件
- 链接期：把所有 `.o` 文件和依赖的库文件链接生成可执行文件
- makefile 采用**空间换时间**的方式节省编译时间：
  - 第一次编译时保存所有生成的 `.o` 文件
  - 下一次编译时，只重新编译**修改过的源文件**，未修改的使用已保存的 `.o` 链接
- 编译器通过比较**源文件的修改时间**和 `.o` 文件的生成时间来识别哪个源文件被修改

> [!bug] 注意事项
> 1. 文件名必须为 `makefile` 或 `Makefile`
> 2. 注释使用 `#`
> 3. `make` 命令执行当前路径下的 makefile 文件
> 4. 向下建立依赖关系
> 5. 只有一个最终目标；若有多个目标，目标之间需要主从关系

## makefile 三要素

1. **目标**：要生成的文件名字（如可执行文件名）
2. **依赖**：编译目标所依赖的源文件或资源文件
3. **命令**：生成目标需要执行的命令（必须以 Tab 开头）

```makefile
目标:依赖
(Tab)命令
```

## 变量

### 自定义变量

- 无需指定类型，默认是字符串类型
- 变量名由大小写字母、数字、下划线构成，不能以数字开头
- 一般使用全大写命名
- 使用变量：`$(变量名)`

### 特殊变量（自动变量）

| 变量 | 说明 |
|------|------|
| `$@` | 代表目标的名字 |
| `$^` | 代表所有依赖项 |
| `$<` | 代表依赖项中的第一项 |

## 内置函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `wildcard` | 文件名获取（通配符展开） | `SRCFILE=$(wildcard *.c)` |
| `patsubst` | 字符串模式替换 | `DSTFILE=$(patsubst %.c, %.o, $(SRCFILE))` |

## 模式规则

```makefile
%.o: %.c
    gcc -c $< -o $@
```

## 功能命令（伪目标）

```makefile
output:
    echo "hahaha"

clean:
    rm -rf $(TARGET) $(DSTFILE)

install:
    sudo cp $(TARGET) $(INSTALL_PATH)

disclean:
    sudo rm -rf $(INSTALL_PATH)/$(TARGET)
```

> 伪目标需要用 `.PHONY` 声明，避免与同名文件冲突：
> ```makefile
> .PHONY: clean install
> ```

## 完整示例

基础版 makefile：

```makefile
TARGET = app
CC = gcc
CFLAGS = -Wall -g
OBJS = main.o add.o sub.o

$(TARGET): $(OBJS)
    $(CC) $(CFLAGS) $^ -o $@

%.o: %.c
    $(CC) $(CFLAGS) -c $< -o $@

clean:
    rm -rf $(OBJS) $(TARGET)

.PHONY: clean
```

![['attachments/makefile1.png']]

优化版 makefile（自动获取源文件）：

```makefile
TARGET = app
CC = gcc
CFLAGS = -Wall -g -I./include
SRC = $(wildcard ./src/*.c)
OBJS = $(patsubst %.c, %.o, $(SRC))

$(TARGET): $(OBJS)
    $(CC) $(CFLAGS) $^ -o $@

%.o: %.c
    $(CC) $(CFLAGS) -c $< -o $@

clean:
    rm -rf $(OBJS) $(TARGET)

.PHONY: clean
```
