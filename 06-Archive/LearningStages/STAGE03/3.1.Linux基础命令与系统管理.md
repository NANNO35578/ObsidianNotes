# Linux 基础命令与系统管理

## Linux 基础概念

- 终端可在任意目录下打开
- Linux 中**一切皆为文件**，不分盘符，从根目录 `/` 开始
- 文件夹（目录）默认大小为 4096 字节

### 根目录结构

| 目录 | 说明 |
|------|------|
| `/bin` | 存储可执行文件（基础命令） |
| `/sbin` | 对 `/bin` 的补充（系统管理命令） |
| `/boot` | 启动文件夹，存储启动所需配置文件和内核 |
| `/dev` | 设备文件夹（硬件设备以文件形式存在） |
| `/etc` | 配置文件目录 |
| `/home` | 用户（非 root）家目录 |
| `/lib` | 库文件夹（共享库和内核模块） |
| `/media` | 媒体文件夹（可移动设备自动挂载点） |
| `/mnt` | 挂载文件夹（临时挂载文件系统） |
| `/opt` | 第三方软件安装目录 |
| `/tmp` | 临时文件 |
| `/usr` | 用户安装的软件、文档、库文件等 |
| `/var` | 可变数据（日志、缓存、邮件等） |

> [!note] Shell（命令解释器）
> 将命令解释成操作系统能听懂的语言。
> - 可用 `cat /etc/shells` 查看系统安装的 shell
> - 当前 shell 存储在环境变量 `SHELL` 中，可用 `echo $SHELL` 查看

## 基本命令

| 序号 | 命令 | 说明 |
|------|------|------|

| 9 | `man` | 查看命令作用、参数等（手册） |
| 10 | `which` | 查看命令可执行文件位置 |
| 11 | `mkdir` | 创建文件夹，`-p` 创建有层级关系的文件夹 |
| 12 | `rmdir` | 仅删除空文件夹 |
| 13 | `tree` | 树状打印文件夹文件 |

| 16 | `cp` | 拷贝文件/文件夹（`-r` 递归拷贝目录） |
| 17 | `wc` | 计算文件统计：`-c` 字节数，`-l` 行数，`-w` 字数 |
| 18 | `df` | 查看磁盘使用情况 |
| 19 | `whoami` | 打印当前用户名 |

| 25 | `tar` | 压缩包管理（详见下文） |

### `ls` 命令详解

- `-l`：显示详细信息
- `-a`：显示隐藏文件
- `-R`：递归打印包含子目录的文件

`ls -l` 输出依次为：文件类型及权限、所属用户、用户组、大小、时间、文件名。

**文件类型**：

| 符号 | 类型 |
|------|------|
| `-` | 普通文件 |
| `d` | 目录 |
| `l` | 符号链接 |
| `b` | 块设备文件 |
| `c` | 字符设备文件 |
| `s` | socket 文件（网络套接字） |
| `p` | 管道（FIFO） |

**权限**：三组 `rwx`，若为 `-` 则无该权限。依次为文件创建者（所有者）、同组用户、其他组用户的权限。可用三个八进制数表示（r=4, w=2, x=1）。

![['attachments/ls_l_a.png']]

### `tar` 命令详解

**主选项**（五选一）：

| 选项 | 说明 |
|------|------|
| `c` | 创建新的档案文件 |
| `r` | 把要存档的文件追加到档案文件末尾 |
| `t` | 列出档案文件内容 |
| `u` | 更新文件，用新增文件取代原备份文件 |
| `x` | 从档案文件中释放文件（解包） |

**辅选项**：

| 选项 | 说明 |
|------|------|
| `f` | 使用档案文件或设备（通常必选） |
| `v` | 详细报告处理信息 |
| `z` | 用 gzip 压缩/解压缩 |
| `j` | 用 bzip2 压缩/解压缩 |
| `C` | 指定解压缩目标目录 |

**常用组合**：

```bash
# 打包/解包（不压缩）
tar cvf dir.tar dir
tar xvf dir.tar

# gz 压缩包
tar zcvf dir.tar.gz dir
tar zxvf dir.tar.gz

# bz2 压缩包
tar jcvf dir.tar.bz2 dir
tar jxvf dir.tar.bz2

# 指定目录解压缩
tar zxvf dir.tar.gz -C ~/test
```

## 磁盘管理

**挂载命令**：`mount [-t vfstype] [-o options] device dir`

**磁盘类型（`-t`）**：

| 类型 | 说明 |
|------|------|
| `iso9660` | 光盘或光盘镜像 |
| `msdos` | DOS fat16 文件系统 |
| `vfat` | Windows 9x fat32 文件系统 |
| `ntfs` | Windows NT ntfs 文件系统 |
| `smbfs` | Windows 文件网络共享 |
| `nfs` | UNIX/Linux 文件网络共享 |

**挂载方式（`-o`）**：

| 参数 | 说明 |
|------|------|
| `loop` | 把一个文件当成硬盘分区挂载 |
| `ro` | 只读方式挂载 |
| `rw` | 读写方式挂载 |
| `iocharset` | 指定访问文件系统所用字符集 |

**挂载 U 盘**：

```bash
sudo fdisk -l              # 检测存储设备名称
sudo mount /dev/sdb1 /mnt  # 挂载到 /mnt
# 访问 /mnt
sudo umount /mnt            # 卸载
```

### STAT 进程状态码

| 字符 | 英文名称 | 描述 |
|------|----------|------|
| R | Runnable | 正在运行或在运行队列中等待 |
| S | Sleeping | 休眠中，受阻，等待某个条件形成或接收到信号 |
| I | Idle | 空闲 |
| Z | Zombie | 僵死，进程已终止但进程描述符存在，直到父进程调用 `wait4()` 后释放 |
| D | Uninterruptible sleep | 不可中断睡眠，收到信号不唤醒，必须等待中断发生 |
| T | Stopped | 停止，收到 `SIGSTOP`/`SIGSTP`/`SIGTIN`/`SIGTOU` 信号后停止 |
| < | High priority | 高优先级进程 |
| N | Low priority | 低优先级进程 |
| s | Session leader | 会话领导者（其下有子进程） |
| l | Multi-threaded | 多线程进程 |
| + | Background process group | 位于后台的进程组 |

### `jobs` 与作业控制

> 第一列方括号中的数字表示作业序号（由当前 shell 分配，非操作系统统一分配）。第二列 `+` 表示优先级高于 `-`。第三列为作业状态。最后为创建作业的命令行。

### `kill` 信号

- 查看信号编号：`kill -l`
- 9（SIGKILL）/ 15（SIGTERM）号信号都能结束进程
- **被挂起的进程不能处理信号**，必须发 SIGKILL（9 号），由系统强制终止

### `umask` 详解

`umask` 定义在创建新文件和目录时，系统默认权限中应当"遮罩"掉的权限。

- 查看当前 umask 值：`umask`（通常是三位或四位八进制数）
- 设置 umask 值：`umask <mask>`
- 默认创建文件权限为 `666`（rw-rw-rw-），创建目录权限为 `777`（rwxrwxrwx）
- 实际权限 = 默认权限 - umask（按位取反后与运算）

> 例如 umask 为 `022` 时：
> - 新文件权限：`666 - 022 = 644`（rw-r--r--）
> - 新目录权限：`777 - 022 = 755`（rwxr-xr-x）

**常见 umask 值**：

| umask | 文件权限 | 目录权限 | 说明 |
|-------|---------|---------|------|
| `000` | 666 | 777 | 所有用户可读写（不推荐） |
| `022` | 644 | 755 | 用户可读写，组和其他可读（常用） |
| `027` | 640 | 750 | 用户可读写，组可读，其他无权限（较安全） |

- `umask` 只影响新创建的文件和目录，不会改变已有文件的权限
- 可在 Shell 配置文件（如 `.bashrc` 或 `.bash_profile`）中设置 umask，以便每次登录时自动应用
