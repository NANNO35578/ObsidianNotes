# 静态内存分配和动态内存分配的区别
### 静态内存分配与动态内存分配的综合总结

1. **资源占用**：
    
    - **静态内存分配**：在编译时完成，不占用 CPU 资源。
    - **动态内存分配**：在运行时完成，分配与释放过程需要占用 CPU 资源。
2. **内存位置**：
    
    - **静态内存分配**：主要在栈上分配。
    - **动态内存分配**：在堆上分配。
3. **数据类型支持**：
    
    - **静态内存分配**：不需要指针或引用，直接使用基本数据类型。
    - **动态内存分配**：需要使用指针或引用来管理动态分配的内存。
4. **内存大小确定**：
    
    - **静态内存分配**：在编译前按计划确定内存块的大小。
    - **动态内存分配**：在运行时按需分配，灵活性高。
5. **控制权**：
    
    - **静态内存分配**：内存的控制权交给编译器。
    - **动态内存分配**：内存的控制权交给程序员，需手动管理。
6. **运行效率**：
    
    - **静态内存分配**：运行效率较高，因为没有动态管理的开销。
    - **动态内存分配**：效率较低，管理不当可能导致内存泄漏，依赖于程序员的管理水平。

# 1.`NULL`和`nullptr`区别，有了`NULL`为什么还要`nullptr`呢

> 主流编译器中，`NULL` 实际上是一个整数常量，被定义为 `0`，在 C++11 之前，当我们想要将一个指针初始化为空时，我们通常使用 `NULL`；`nullptr` 是 C++11 中引入的新的关键字，专门用于表示空指针，它不是整数类型，而是特殊的指针类型`nullptr_t`。之所以引入`nullptr`，第一，`NULL`是整数类型，用户调用foo(NULL)的时候，不能区分调用的是`foo(int)`还是`foo(int*)`函数；第二，主流编译器中`NULL`值为`0`，通过`0`表示一个无效地址，但是有的架构下，`0`地址有特定用途，而`nullptr`指向的永远是一个无效地址。

在C++中，`NULL`和`nullptr`的主要区别如下：

### 1. 类型
- **`NULL`**:    
    - 在C++中，`NULL`通常被定义为整数0（或`((void*)0)`），其类型为整型。
    - 这可能导致类型不明确的问题，特别是在重载函数时。
- **`nullptr`**:    
    - `nullptr`是C++11引入的关键字，其类型是`std::nullptr_t`。
    - 这种类型的明确性使得在使用指针时能更好地与其他类型区分开，避免类型混淆。
### 2. 类型安全
- **`NULL`**:    
    - 因为是整型，可能会在某些上下文中引发意想不到的行为。例如，在函数重载中，它可能会被视为整数而不是指针。
- **`nullptr`**:    
    - 由于是专门为指针设计的，使用`nullptr`能提高代码的可读性和安全性，避免了类型的歧义。
### 3. 兼容性
- **`NULL`**:    
    - 在C和早期的C++中广泛使用，出于兼容性，仍然存在于代码中。
- **`nullptr`**:    
    - 只能在C++11及其后续版本中使用，因此在新代码中推荐使用`nullptr`。
### 总结
- 虽然`NULL`在早期的C++中是常用的，但`nullptr`提供了更好的类型安全和清晰度。因此，建议在新的C++代码中使用`nullptr`。

# 2.为什么引入枚举类型
> 传统的 C++ 枚举类型会将枚举值暴露在命名空间中，容易造成命名冲突，而枚举类则通过引入了作用域限定符来解决这个问题。其次，传统的 C++ 枚举类型是基于整数的，可以进行隐式的类型转换和比较操作，这可能会导致一些意想不到的错误，而枚举类则可以避免这个问题，因为它们只能进行显式的类型转换和比较操作。

C++引入枚举类型的主要原因如下：
 1. 可读性 **增强代码可读性**：枚举类型使用有意义的名称代替数字常量，使代码更易于理解。例如，使用`Color::Red`而不是`1`。
 2. 类型安全 **避免类型混淆**：枚举类型提供了更严格的类型检查，防止将不相关的整数混合使用，减少错误。
 3. 组织性 **分组常量**：枚举允许将相关的常量组合在一起，提供逻辑上的组织，使得代码结构更加清晰。
 4. 维护性 **简化维护**：如果需要更改常量值或名称，只需在枚举定义中修改，而不需要在多个地方查找和替换。
 5. 支持命名空间 **避免命名冲突**：枚举的作用域可以限制在枚举类型内，减少命名冲突的风险。
### 示例
```cpp
enum class Color {
    Red,
    Green,
    Blue
};

Color myColor = Color::Red;
```

### 总结

枚举类型提高了代码的可读性、类型安全性和维护性，是C++中定义常量的一种推荐方式。

# 3.C++可调用类型
可调用类型是指能够被调用的对象或类型，通常用来执行某种操作或计算。

在C++中，可调用类型主要包括以下几种：
 1. 函数指针 指向普通函数的指针，允许通过指针调用函数。
 2. 函数对象（仿函数） 实现了`operator()`的类实例，可以像函数一样被调用。
 3. Lambda 表达式 匿名函数，使用`[]`定义，可以捕获外部变量，简洁高效。
 4. 成员函数指针 指向类的成员函数的指针，调用时需要类的实例。
 5. std::function C++11引入的通用可调用对象，能够封装任何可调用类型，包括函数指针、函数对和lambda。
### 示例

```cpp
#include <iostream>
#include <functional>

void freeFunction() {
    std::cout << "Free function called!" << std::endl;
}

struct Functor {
    void operator()() {
        std::cout << "Functor called!" << std::endl;
    }
};

int main() {
    // 函数指针
    void (*funcPtr)() = freeFunction;
    funcPtr();

    // 仿函数
    Functor f;
    f();

    // Lambda 表达式
    auto lambda = []() { std::cout << "Lambda called!" << std::endl; };
    lambda();

    // std::function
    std::function<void()> func = []() { std::cout << "std::function called!" << std::endl; };
    func();

    return 0;
}
```
### 总结

C++中的可调用类型为灵活的函数调用提供了多种方式，使得代码更具表达力和可重用性。

# 4.**成员函数指针和普通函数指针区别？**
> 普通函数指针属于指针类型，成员函数指针不是指针类型。通常来说，函数指针的长度等于机器字长，而成员函数指针长度比函数指针更长，其内部存放了对象地址和成员函数地址信息。在没有给出对象地址的情况下，调用成员函数指针会报错。

成员函数指针和普通函数指针的主要区别如下：
### 1. **类型和声明**
- **普通函数指针**：    
    - 指向全局或静态函数，声明形式为 `返回类型 (*指针名)(参数类型)`。
    - 例：`void (*funcPtr)();`
- **成员函数指针**：    
    - 指向类的成员函数，声明形式为 `返回类型 (类名::*指针名)(参数类型)`。
    - 例：`void (MyClass::*memberPtr)();`
### 2. **调用方式**
- **普通函数指针**： 可以直接调用，不需要类的实例。
    - 例：`funcPtr();`
- **成员函数指针**： 必须通过类的实例调用，使用`->*`或`.*`运算符。
```cpp
	MyClass obj;
	(obj.*memberPtr)();
```
### 3. **上下文**
- **普通函数指针**： 在全局或静态上下文中使用，不依赖于任何类的状态。
- **成员函数指针**： 依赖于类的实例，可以访问该实例的成员变量和其他成员函数。
### 示例
```cpp
#include <iostream>

class MyClass {
public:
    void memberFunction() {
        std::cout << "Member function called!" << std::endl;
    }
};

void freeFunction() {
    std::cout << "Free function called!" << std::endl;
}

int main() {
    // 普通函数指针
    void (*funcPtr)() = freeFunction;
    funcPtr(); // 调用普通函数

    // 成员函数指针
    void (MyClass::*memberPtr)() = &MyClass::memberFunction;
    MyClass obj;
    (obj.*memberPtr)(); // 调用成员函数

    return 0;
}
```
### 总结
成员函数指针和普通函数指针在声明、调用方式和上下文上存在显著区别，以支持面向对象编程中的类和对象特性。

# 5.const 和 define 区别
const 在 C 语言中表示只读，在 C++ 中增加了常量的语义。而 define 用于定义宏，而宏也可以用于定义常量。它们的区别有：
1. const 生效于编译阶段，而 define 生效于预处理阶段；
2. define只是简单的字符串替换，没有类型检查，而 const 有对应的数据类型，编译器要进行判断的；
3. define 定义的常量是不可以用指针变量去指向的，用 const 定义的常量是可以用指针去指向该常量的地址的；
4. define 不分配内存，给出的是立即数，有多少次使用就进行多少次替换，在内存中会有多个拷贝，消耗内存大，const 在静态存储区中分配空间，在程序运行过程中内存中只有一个拷贝；
5. 可以对 const 常量进行调试，但是不能对宏常量进行调试。

### Lambda 表达式概述

Lambda 表达式是 C++11 引入的一种用于定义匿名函数的语法。它允许你在代码中定义一个可调用的函数对象，而不需要先声明一个函数。这种表达式特别适合于需要短小函数的场景，如回调、排序、过滤等。

### 语法

Lambda 表达式的基本语法如下：

```cpp
[capture](parameters) -> return_type {
    // function body
}
```

- **capture**：捕获列表，指定哪些外部变量可以在 Lambda 中使用。
- **parameters**：参数列表，与普通函数相同。
- **return_type**：返回类型，可以省略，编译器会根据函数体推断。
- **function body**：函数体，包含具体的操作。

### 捕获列表

捕获列表决定了 Lambda 表达式如何访问外部变量。常见的捕获方式有：

- **值捕获**：`[x]` 捕获变量 `x` 的值。
- **引用捕获**：`[&x]` 捕获变量 `x` 的引用。
- **混合捕获**：`[x, &y]` 捕获 `x` 的值和 `y` 的引用。
- **捕获所有**：`[=]` 捕获所有外部变量的值，`[&]` 捕获所有外部变量的引用。

### 示例

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    int a = 10;
    int b = 20;

    // 定义一个 Lambda 表达式
    auto add = [](int x, int y) -> int {
        return x + y;
    };

    std::cout << "Sum: " << add(a, b) << std::endl;

    // 使用 Lambda 表达式进行排序
    std::vector<int> vec = {5, 3, 8, 1};
    std::sort(vec.begin(), vec.end(), [](int x, int y) {
        return x < y;  // 按升序排序
    });

    // 输出排序结果
    for (int num : vec) {
        std::cout << num << " ";
    }
    std::cout << std::endl;

    // 捕获外部变量
    auto captureExample = [a, &b]() {
        std::cout << "Captured a: " << a << ", b: " << b << std::endl;
        b += 10;  // 修改 b 的值
    };
    captureExample();
    std::cout << "Modified b: " << b << std::endl;

    return 0;
}
```

### 特点

1. **匿名性**：Lambda 表达式不需要名称，适合短小的函数。
2. **灵活性**：可以捕获外部变量，方便在局部环境中使用。
3. **可读性**：可以直接在使用的地方定义，提高代码可读性。
4. **类型推断**：支持自动推断返回类型，使得使用更加简洁。

### 用途

- **回调函数**：用于事件处理和异步操作。
- **算法**：与 STL 算法结合使用，如排序、过滤等。
- **简化代码**：减少了定义函数的冗余代码。

### 总结

Lambda 表达式是 C++ 中一种强大而灵活的工具，使得函数式编程风格得以融入 C++，提高了代码的简洁性和可读性。通过 Lambda 表达式，开发者可以更方便地处理复杂操作和逻辑。
