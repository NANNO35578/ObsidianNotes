# 基于Web与Android双端的智能笔记管理系统

## 摘 要

随着移动互联网的快速演进，用户的信息记录和知识管理需求不再满足于基本的编辑修改等功能，而是向智能化处理及高效检索方向转变，在智能终端技术的普及下这一需求更是与日俱增。但目前市面上主流笔记软件普遍存在局限性问题。一方面，跨平台同步不稳定的问题影响用户体验；另一方面，对于非结构化信息的解析处理能力偏弱的问题导致系统响应迟钝；面对海量笔记数据时，检索速度与查询效率上难以满足用户预期也是一大问题。本文针对上述问题，设计并实现了一套基于Web与Android双端的智能笔记管理系统，为现有应用的不足提供帮助。

系统采用前后端分离架构。系统按模块化划分主要有以下5个模块，涵盖用户管理模块、笔记管理模块、搜索模块、OCR识别模块、推荐模块。在功能层面上，系统双端均支持笔记的CRUD与目录分类等基础功能。在智能处理层面上，首先系统引入了Elastic search来构建全文索引提高查找效率；其次系统通过MinIO实现图片与文件等对象资源的统一管理，增强模态数据管理能力；第三，系统集成OCR识别技术，实现图片与文档高效智能的转化为笔记；第四，系统融合了自然语言处理技术，对笔记文本进行智能标签生成，增强信息的语义结构化程度与可检索性；最后，系统通过记录用户的历史行为与检索记录，据此实现混合推荐算法，完成个性化笔记推荐。

在技术实现上，此系统后端使用Drogon1.9.11配合C++17编写RESTful API，数据库使用MariaDB 10.11，全文检索使用Elastic search8.12，对象存储使用MinIO，并集成PaddleOCR-VL-1.5接口实现图片转笔记。Web前端基于Vue3.5开发，Android端使用Kotlin开发，耗时业务采用异步机制提升系统响应性能。

关键词 智能笔记系统;Web应用;Android开发;全文检索;推荐系统

## Intelligent note-taking System Based on both Web

## and Android platforms

### Abstract

With the rapid evolution of mobile Internet, the user's information recording and knowledge management needs are no longer satisfied with the basic editing and modification functions, but to the direction of intelligent processing and efficient retrieval. With the popularity of intelligent terminal technology, this demand is increasing day by day. However, the current mainstream note-taking software on the market generally has limitations. On the one hand, the problem of unstable cross-platform synchronization affects the user experience; on the other hand, the problem of weak analytical processing ability for unstructured information leads to slow system response; in the face of massive note data, it is also a big problem that the retrieval speed and query efficiency are difficult to meet user expectations. In view of the above problems, this paper designs and implements a set of intelligent note management system based on Web and Android, which provides help for the shortcomings of existing applications.

The system adopts a front-end and back-end separation architecture. The system is divided into the following five modules according to modularization, including user management module, note management module, search module, OCR recognition module and recommendation module. At the functional level, both ends of the system support basic functions such as CRUD and directory classification of notes. At the level of intelligent processing, the system first introduces Elastic search to build full-text index to improve search efficiency. Secondly, the system realizes the unified management of object resources such as pictures and files through MinIO, and enhances the ability of multi-modal.data management. Thirdly, the system integrates OCR recognition technology to realize the efficient and intelligent transformation of pictures and documents into notes; fourthly, the system integrates natural language processing technology to generate intelligent tags for note texts, and enhances the semantic structure and retrieval of information. Finally, the system realizes the hybrid recommendation algorithm by recording the user's historical behavior and retrieval records, and completes the personalized note recommendation.

<!-- -II- -->

In terms of technical implementation, the back-end of this system uses Drogon1.9.11 to write RESTful API with C++17, the database uses MariaDB 10.11, full-text retrieval uses Elastic search8.12, object storage uses MinIO, and integrates PaddleOCR-VL-1.5 interface to realize picture transfer notes. The Web front-end is developed based on Vue3.5, and the Android side is developed using Kotlin. The time-consuming business uses an asynchronous mechanism to improve system response performance.

Keywords Intelligent Note-taking System, Web application, Android development, Full-text Search, Recommendation system

### 第1章 绪论

#### 1.1 课题目的和意义

##### 1.1.1 课题目的

移动互联网的泛在与智能终端的普及，使用户在信息记录与知识管理方面呈现出多设备、多场景、多模态化的需求。然而，当前主流笔记工具多围绕单一平台构建，功能模块彼此隔离，难以支撑跨终端的无缝衔接与高效管理。已有研究指出，现有云笔记产品在可用性上仍存在跨平台同步不稳定、非结构化信息解析能力不足等问题[1]，且多数系统在移动端仅提供轻量级查看功能，缺乏与桌面端对等的智能处理能力[2]。同时，随着个人笔记数据的持续积累，仅依赖人工目录分类与简单关键词匹配的管理方式，已难以满足即时的语义检索与知识复用需求[3]。

针对上述问题，本文旨在设计并实现一套覆盖Web与Android双端的智能笔记管理系统。系统采用前后端分离架构，通过统一的后端服务实现多终端数据的集中管理与状态同步。在功能层面，除支持文本笔记的创建、编辑与多级分类外，系统集成光学字符识别（OCR）技术，利用基于深度学习的版面分析与文本识别方法，将图片及扫描文档自动转化为可编辑的结构化笔记；同时引入预训练语言模型与关键短语预测技术，对笔记文本进行语义标签生成，从而强化信息的结构化程度与可检索性。此外，系统还将部署分布式全文检索引擎并针对检索速度与准确率进行调优，结合用户行为上下文实现混合推荐，以提升海量笔记场景下的查询效率与个性化服务能力。本课题的核心目的在于构建一个融合多模态感知、跨平台协作与智能分析的一体化笔记管理系统，为个人知识管理提供高效、可靠的技术支撑方案。

##### 1.1.2 课题研究意义

本课题的研究意义体现在用户体验优化、工程实践价值与技术方法推广三个维度。

在用户体验层面，多元信息的涌入使用户对笔记系统的诉求从基础记录转向高效的智能整理。现有工具在弱网环境下的同步一致性、非文本数据的结构化转换等方面存在明显短板[8]。本文通过设计多端协同与异步处理机制，并整合OCR与自然语言处理技术，实现对文本、图像等异质模态数据的统一管理与语义标注，有望降低用户的信息整理成本，提升知识获取与回溯效率。

在工程实践层面，本课题横跨Web前端、Android原生开发与高并发后端服务构建等多个技术域，技术集成度高。系统以Drogon框架构建RESTful服务，协同MariaDB、Elasticsearch与MinIO等组件构成分布式存储与计算基座。过程不仅验证了多技术栈融合的可行性，其基于消息队列的异步调度、增量式数据同步与容器化部署等工程决策，也可为同类复杂系统的设计与落地提供可复用的参考经验。

在技术方法推广层面，系统将深度学习驱动的OCR识别、关键短语预测及上下文感知推荐等一系列智能技术，实际嵌入笔记管理流程，形成了从信息采集、语义结构化到主动推送的闭环。相关方案在个人知识管理、在线教育平台及企业级知识库建设中具有直接的移植价值。同时，系统采用模块化设计且核心组件均基于开源生态构建，具备良好的可扩展性与可维护性，为后续功能的演进与性能优化奠定了坚实的基础。

#### 1.2 国内外研究现状分析

##### 1.2.1 国内研究现状分析

随着信息技术的持续迭代，数字化笔记工具已成为个人知识管理与协同办公的重要载体。在国内市场，以有道云笔记、印象笔记、语雀、飞书文档、石墨文档及WPS笔记为代表的产品已形成较为完整的生态格局。其中，有道云笔记与印象笔记侧重于个人知识管理与多端同步，支持网页剪藏、OCR识别及文档扫描等功能，已有研究对其可用性进行了系统评估[1]；语雀定位于结构化知识库构建，强调文档的组织化管理与团队知识沉淀；飞书文档与石墨文档则聚焦在线协同编辑场景，支持多人实时协作。尽管上述产品在功能丰富度方面已取得显著进展，但针对非结构化信息的深度解析与跨端数据一致性保障等问题，工程界与学术界仍在持续探索[10]。

国内学术界在智能笔记系统及相关技术领域的研究,主要集中在多模态信息处理、智能文本分析及系统架构优化等方向。

在多模态信息处理方面，研究重点围绕信息采集效率与识别准确率的提升展开。随着移动设备摄像能力增强，基于OCR技术的图片文本识别逐渐成为笔记系统的核心功能模块。相关研究通过引入图像预处理算法，在一定程度上提升了复杂场景下中文文本识别的准确率，使得图像内容能够有效转化为可编辑文本。然而，在移动端资源受限的条件下，如何兼顾识别精度与响应延迟仍是亟待解决的关键问题[2]。

在自然语言处理应用方面，国内研究多聚焦于关键词提取、自动摘要及文本分类等功能。基于TF-IDF、TextRank及其融合方法的轻量级算法因其实现简单、计算开销较低，被广泛应用于实际系统中，用于提升笔记内容的结构化程度与检索效率。同时，随着预训练语言模型的发展，部分研究开始探索将BERT等深度学习模型应用于语义表示与内容推荐。已有综述指出,预训练语言模型在关键短语预测任务中展现出显著优势[5],但在实际工程部署中仍需在计算资源消耗与接口响应效率之间进行权衡。

在系统架构与数据同步方面，国内笔记系统普遍采用云端集中存储与多端访问的模式。多数应用基于传统的请求-响应机制实现数据同步，并采用时间戳覆盖或“最后写入优先”等策略处理冲突。这类方法实现相对简单，但在复杂使用场景下仍可能出现数据不一致问题。针对非结构化信息的有效组织，有研究从内容节点入手探究在线文档信息组织的灵活性程度[11]，为笔记系统的数据结构设计提供了理论参考。此外，面向特定场景的笔记系统设计也取得了一定进展，例如基于Android平台的手写笔记应用实现了书写轨迹的采集与回放功能[2]，以及基于文本相似度的个人笔记管理方案为语义检索提供了新思路[3]。

总体来看,国内在智能笔记系统的工程实现方面已具备一定基础,但在多模态数据深度融合、跨端数据一致性保障以及智能化处理能力等方面仍有待进一步突破。

##### 1.2.2 国外研究现状分析

相较于国内研究，国外在多模态信息处理与智能笔记系统领域起步较早，相关研究在理论模型、系统架构及商业化产品方面均取得了较为成熟的成果。在商业化应用层面，Notion、Evernote、Microsoft OneNote、Obsidian、Google Keep等产品构成了全球笔记软件市场的核心阵营。

在学术研究层面，国外在多模态数据表示与融合方面提出了将文本、图像及语音等多种数据映射至统一特征空间的方法，为跨模态检索与统一信息管理提供了理论基础。此类方法能够实现不同类型数据之间的语义关联，使得用户可以通过多种模态进行信息检索与组织，从而提升系统的智能化水平。

在智能识别与自然语言处理技术方面,国外普遍采用基于深度学习的端到端模型。尤其是在OCR识别领域，结合卷积神经网络与序列建模方法的模型在复杂版面分析、多语言识别及低质量图像处理中表现出较高的准确率。最新研究展示了基于深度学习的印刷文档版面分析与OCR系统的完整技术路径[4]，为笔记系统中的图像转文本功能提供了前沿方案。同时，NLP技术在文本分析领域已形成涵盖情感分析、主题建模与文本生成的全面方法论体系[15]，为智能笔记系统的语义理解模块提供了坚实的理论支撑。

#### 2.2 系统需求分析

##### 2.2.1 系统功能需求概述

根据系统设计目标，本文设计的智能笔记管理系统主要围绕用户信息管理、笔记管理、文件夹管理、全文搜索、文件管理、OCR识别、标签管理以及推荐服务等核心功能展开。各功能需求简要介绍如下。

用户管理功能主要用于实现用户的注册、登录及身份认证。系统通过账号密码完成用户身份校验，并基于JWT机制维持用户登录状态。在用户登录后，可以获取个人信息并进行基本资料管理，从而保障系统访问的安全性与个性化服务的实现。

笔记管理功能主要包括笔记的创建、编辑、删除及查询操作。用户可以对笔记内容进行实时编辑，并通过系统自动保存等机制避免数据丢失。同时，系统支持笔记的公开与私有设置，以及对公开笔记的浏览、点赞和收藏等交互操作，以增强用户之间的信息共享与交流。

文件夹管理功能用于对笔记进行层次化组织。系统支持多级文件夹结构，用户可以创建、修改及删除文件夹，并将笔记归类至不同目录中，从而实现对大量笔记内容的有效管理，提高信息整理效率。

全文搜索功能基于Elasticsearch实现，支持用户通过关键词对笔记标题、内容、摘要及标签等字段进行检索。系统能够返回相关度较高的搜索结果，并提供高亮显示，从而帮助用户快速定位目标信息。

文件管理功能主要用于支持图片及附件的上传与管理。系统通过MinIO实现文件对象存储，用户可以将文件上传至服务器，并在笔记中引用相关资源。同时，系统提供文件状态查询功能，以便用户了解上传进度与处理结果。

OCR 识别功能用于处理图片或文档中的文本信息。用户可上传图片或PDF 文件，系统通过调用 OCR 服务对内容进行识别，并将识别结果转换为 文本形式生成笔记，从而减少人工输入，提高信息录入效率。

标签管理功能用于对笔记内容进行语义分类。系统支持用户手动管理标签，同时结合自然语言处理技术自动生成标签，实现对笔记内容的结构化组织，提升后续检索与推荐效果。

推荐功能通过分析用户的行为数据及标签信息，构建用户兴趣模型，并向用户推荐相关笔记内容。系统针对新用户与老用户采用不同策略，在保证推荐效果的同时提升系统的智能化水平。

##### 3.2.7 推荐模块设计

推荐模块用于根据用户行为数据提供个性化内容推荐，是系统智能化的重要体现。其接口设计如表3-6所示。该模块通过GET方法请求/api/recommend/notes 这一接口，主要参数为page、page_size，响应为笔记列表，后端接口名为RecommendNotes。

该模块采用基于标签与行为数据的推荐策略。考虑到新用户行为数据不足，因此对于新用户，系统通过热门标签与搜索历史构建推荐内容；对于老用户，则通过分析用户浏览、点赞及收藏行为，建立兴趣模型，并结合时间衰减机制计算用户偏好，从而生成个性化推荐结果。当推荐结果不足时，系统提供兜底策略返回公共笔记数据，以保证推荐功能的稳定性。

#### 4.1 核心算法与机制实现

本系统围绕“智能笔记管理”这一核心目标，在推荐、搜索、OCR处理及认证等关键环节中设计并实现了一系列算法与机制。其中，以基于用户行为与标签的推荐算法为核心，同时辅以全文检索算法优化策略与异步处理机制，共同支撑系统的智能化能力与高性能表现。

##### 4.1.1 基于用户行为与标签的推荐算法

本系统推荐模块采用“分层兴趣建模+标签匹配检索”的策略实现个性化推荐，其核心思想是根据用户行为数据的丰富程度，动态选择不同的推荐策略，从而兼顾冷启动问题与推荐精度问题。

首先, 系统依据用户在最近30天内的行为记录数量(包括浏览、点赞、收藏等)对用户进行分层。当行为数据较少时, 判定为新用户; 反之则为老用户。该划分方式能够有效区分“兴趣信息稀疏”与“兴趣信息充分”两类用户场景。

对于老用户，系统构建基于行为加权与时间衰减的兴趣计算模型。具体而言，将用户行为划分为浏览、点赞与收藏三类，并分别赋予不同权重，其中收藏权重最高、点赞次之、浏览最低。兴趣得分计算公式如式4-1：

<table border="1"><tr><td></td><td>$S c o r e = ( v i e w \times 1 + l i k e \times 3 + c o l l e c \times 7 ) \times e ^ { - \lambda \cdot \Delta t }$</td><td>(4-1)</td></tr></table>

其中, $\Delta t$ 表示用户最近一次行为距当前时间的间隔天数, $\lambda$ 为时间衰减系数。通过引入指数衰减函数,使得近期行为对推荐结果的影响更大,从而增强推荐的时效性。系统根据兴趣得分对标签进行排序,选取前若干个高权重标签作为用户兴趣标签集合。

对于新用户，由于缺乏足够的行为数据，系统采用多源信息融合的冷启动策略，从用户已有笔记标签、最新操作标签、搜索历史以及系统热门标签中提取候选标签，并进行去重合并，构建初始兴趣集合。

在完成兴趣标签建模后，系统基于Elasticsearch执行标签匹配查询，从公开笔记库中检索包含相关标签的内容，并按相关度排序生成推荐列表。为保证系统稳定性，还设计了多级兜底机制：当标签匹配结果为空时，自动降级为返回最新公开笔记，以保证推荐结果的可用性。

在搜索功能实现中，系统采用基于倒排索引的全文检索算法，以提升检索效率与匹配精度。系统在 Elasticsearch 中构建 notes 索引，对笔记的标题、正文及摘要字段进行分词处理，其中中文分词采用 IK 分词器，从而支持中文语义级检索。基于 C++ 自实现了 ES 客户端，通过 HTTP 与 ES 服务端口通信，实现文档处理。

##### 4.1.3 OCR文本识别与自动生成算法

针对图片与PDF内容的处理需求，系统设计并实现了基于OCR的文本提取与自动笔记生成流程。该流程采用“异步任务+状态驱动”的实现方式。

当用户上传文件后，系统首先创建文件记录并标记为“处理中”，随后在后台线程中调用PaddleOCR服务进行文本识别，模型为PaddleOCR-VL-1.5。识别结果返回后，系统对文本进行清洗与格式转换，并自动生成对应的笔记内容。

该过程的核心在于异步执行机制的设计，即通过后台线程处理耗时任务，并通过状态字段与前端轮询机制实现进度反馈，从而避免阻塞主线程，提高系统整体吞吐能力。

##### 4.1.4 异步处理与最终一致性机制

在系统实现过程中,大量涉及I/O密集型操作(如数据库访问、搜索引擎调用、文件上传等)。为提高系统性能,本文采用基于事件循环的异步处理机制。

具体而言,系统基于Drogon框架的非阻塞I/O模型,将数据库操作与HTTP请求处理以回调方式执行;对于OCR识别、文件上传等长耗时任务,则采用独立线程执行,并在完成后通过事件循环回调主线程更新状态。

在数据一致性方面，系统采用“数据库优先，搜索引擎异步同步”策略。即所有核心数据首先写入MariaDB，随后异步更新Elasticsearch索引。该策略在保证主数据强一致性的同时，允许搜索数据存在短暂延迟，从工程角度实现了性能与一致性的平衡。

##### 4.1.5JWT身份认证算法实现

系统采用Svc（JSON Web Token）实现无状态身份认证机制。用户登录成功后，服务端生成包含用户标识与过期时间的令牌，并使用HMAC-SHA256算法进行签名。

后续请求中，客户端只需要通过请求头携带令牌，服务端接收后依次完成令牌解析、签名真伪核验以及有效期校验。验证通过即校验无误后提取用户身份信息并执行相应业务流程；若验证失败服务端会返回未授权响应。

该认证方式避免了传统会话机制对服务器存储的依赖，提高了系统的横向扩展性与高并发处理能力。
