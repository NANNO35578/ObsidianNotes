### 项目概况

这是一个名为 **Calcite Web** 的智能笔记管理系统前端项目，主要特点如下：

- **技术栈**：Vue 3.5.24 + Vite 7.2.4 + Vue Router 4.6.4 + Element Plus 2.13.7 + md-editor-v3 + Axios
- **架构**：单页应用（SPA），主页面采用 `el-splitter` 三栏布局（左侧文件树 20% / 中间编辑区 60% / 右侧标签与文件 20%）
- **状态管理**：**未使用 Pinia/Vuex**，状态集中在 `Home.vue` 中通过 Props/Events 向下传递
- **主题**：Everforest 配色，支持深色/浅色切换，通过 CSS 变量实现
- **构建**：Vite 提供开发服务器，并将 `/api` 代理到后端 `http://localhost:8888`

### 发现的一些值得注意的细节

1. **无测试框架**：项目目前未配置 Jest/Vitest/Cypress 等任何测试工具。
2. **无代码规范工具**：未配置 ESLint/Prettier。
3. **异步上传模式**：文件上传和 OCR 识别均采用“提交后立即返回 `file_id` + 客户端轮询状态”的模式。
4. **中文优先**：代码注释、文档、甚至部分变量命名均以中文为主。
5. **文档与代码存在轻微差异**：`docs/dev_guide.md` 中提到了一些实际已不存在的文件（如 `tag.js`、`TagDialog.vue`），`AGENTS.md` 已按**实际文件结构**进行准确描述。

`AGENTS.md` 已覆盖项目概述、构建命令、目录结构、API 规范、主题系统、路由权限、代码风格、测试说明与安全注意事项等章节，供后续 AI Agent 快速上手。
