### 项目概况
**calcite-server** 是一个 C++ 编写的智能笔记管理后端，使用 [Drogon](https://github.com/drogonframework/drogon) 框架（C++17），面向 Web 与 Android 双端。

### 技术栈
- **Web 框架**：Drogon（异步、高性能）
- **数据库**：MariaDB，通过 Drogon ORM 访问
- **文件存储**：MinIO（S3 兼容对象存储）
- **全文搜索**：Elasticsearch 8.12.2 + IK 中文分词
- **LLM 推荐**：Moonshot (Kimi) API（早期 DeepSeek 已废弃）
- **构建工具**：CMake >= 3.5

### 代码组织
采用经典分层架构：
- `controllers/` — HTTP 路由入口（Auth、Note、File、Folder、OCR、Recommend 等）
- `services/` — 业务逻辑（AuthService、KimiService、OcrService 等）
- `models/` — Drogon ORM 模型（由 `drogon_ctl create model` **自动生成，禁止手动修改**）
- `utils/` — 基础设施客户端（EsClient、MinioClient、JwtUtil、PasswordUtil）
- `test/` — 基于 `drogon_test` 的测试，当前规模较小

### 构建与测试
```bash
cd calcite/build && cmake .. && make -j$(nproc)
./calcite                    # 运行服务
./test/calcite_test          # 运行测试
```

### 关键约定
- **统一 API 响应格式**：`{"code": 0, "message": "...", "data": {}}`
- **认证方式**：`Authorization: Bearer <token>` 或 `?token=`
- **数据同步策略**：先写 MariaDB，再异步同步 ES；ES 失败不阻塞主流程
- **代码风格**：`.clang-format` 基于 LLVM，无列宽限制，短函数允许单行

### 探索结论摘要

本项目 **Calcite** 是一个基于 Web 与 Android 双端的智能笔记管理系统，采用三仓库子模块（Git submodule）架构：

| 子模块 | 核心技术 | 关键职责 |
|--------|---------|---------|
| **`calcite_server/`** | Drogon (C++17/20) + MariaDB + Elasticsearch + MinIO | RESTful API 服务端，提供认证、笔记 CRUD、全文搜索、文件存储、OCR、AI 标签生成与推荐 |
| **`calcite_web/`** | Vue 3 + Vite + Pinia + Element Plus + md-editor-v3 | 三栏式 SPA，支持 Markdown 编辑、主题切换、文件上传、公开笔记浏览 |
| **`calcite_android/`** | Kotlin + Jetpack (Room/Navigation/WorkManager/Retrofit) | Android 客户端，支持离线浏览、后台同步、Markdown 渲染 |

### 关键发现

- **构建系统**：后端用 CMake（`calcite_server/calcite/CMakeLists.txt`），Web 用 Vite（`vite.config.js`），Android 用 Gradle Kotlin DSL（`libs.versions.toml` + `build.gradle.kts`）。
- **代码风格**：项目注释、文档、变量命名**均以中文为主**。
- **状态管理**：Web 端使用 Pinia（已配置 Vitest 单元测试），Android 使用 MVVM + Repository。
- **测试策略**：Web 端有 Vitest + jsdom 测试（`stores/__tests__/`）；后端和 Android 目前为基础测试框架，可扩展。
- **部署依赖**：需预先启动 MariaDB、Elasticsearch（带 IK 分词）、MinIO，后端监听 `8888`，Web 开发代理指向该地址。
- **安全**：JWT Bearer 认证，前端 401 自动清除 token 并跳转登录；密码后端哈希存储。
