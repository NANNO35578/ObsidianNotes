````markdown title:""
推荐算法:

score = 
    标签匹配得分(平滑后)     * 0.4 +
    行为加权得分            * 0.4 +
    时间衰减增益(越新分越高)  * 0.1 +
    全局热度增益            * 0.1

$$
\begin{aligned}
\text{score} = & \ \log(\text{tag\_match} + 1) \times 0.4 \\
& + (\text{like} \times 5 + \text{collect} \times 4 + \text{view} \times 2 + \text{search} \times 1) \times 0.4 \\
& + \exp(-0.1 \times \text{小时差}) \times 0.1 \\
& + \log(\text{全局热度} + 1) \times 0.1
\end{aligned}
$$



```sql title:""
SELECT
    n.id AS note_id,
    n.title,
    n.created_at,

    (
        -- 1. 标签匹配度（平滑）
        LOG(COUNT(DISTINCT nt.tag_id) + 1) * 0.4

        -- 2. 用户行为加权分
        + (
            5 * COUNT(CASE WHEN ub.action = 'like' THEN 1 END)
          + 4 * COUNT(CASE WHEN ub.action = 'collect' THEN 1 END)
          + 2 * COUNT(CASE WHEN ub.action = 'view' THEN 1 END)
          + 1 * COUNT(CASE WHEN ub.action = 'search' THEN 1 END)
        ) * 0.4

        -- 3. 时间衰减（越新分数越高）
        + EXP(-0.1 * TIMESTAMPDIFF(HOUR, n.created_at, NOW())) * 0.1

        -- 4. 笔记全局热度
        + LOG(nb.view_total + 1) * 0.1

    ) AS final_score

FROM note n
JOIN note_tag nt ON n.id = nt.note_id
LEFT JOIN user_behavior ub ON n.id = ub.note_id
LEFT JOIN note_stats nb ON n.id = nb.note_id  -- 笔记统计表

WHERE nt.tag_id IN (?)  -- 感兴趣的标签ID
GROUP BY n.id
ORDER BY final_score DESC
LIMIT 50;
```



对于新用户, 笔记数量为0
用户每新建笔记会生成新的标签, 当*新标签数量*达到5个时, 查找用户笔记中标签出现数量最多的3个标签以及最新的2个标签生成**基础推荐标签集合**.

若用户采用了*搜索*功能, 将搜索结果中最多的2个标签同样加入基础推荐标签集合.

基于基础推荐标签集合, 从公开笔记中为用户推荐50篇笔记


- 每篇推荐的笔记记录用户行为: view like collect. 权重1, 3, 7
- 笔记中包含多个标签`[tag0, tag1, tag2...]` 
- 为此次推荐的笔记相关联的标签计算分数, 计算结果应当考虑到推荐列表中标签多次出现情况, 这时应当将次标签分数计算到尽可能大一些
- 标签分数应当受到时间衰减增益, 也就是越新分数越高
````

一、新用户冷启动推荐算法
$$

\begin{aligned}
\text{基础标签集合 } S_{\text{base}} &= \text{Top3(用户笔记标签频率)} \cup \text{Top2(用户最新标签)} \\
\text{搜索标签集合 } S_{\text{search}} &= \text{Top2(搜索结果标签频率)} \\
\text{最终推荐标签集合 } S_{\text{rec}} &= S_{\text{base}} \cup S_{\text{search}} \\
\text{推荐笔记列表 } N_{\text{rec}} &= \text{Top50}\left( \text{公开笔记}, \text{标签} \in S_{\text{rec}}, \text{创建时间降序} \right)
\end{aligned}
$$

二、老用户标签兴趣评分算法
$$
\begin{aligned}
% 1. 行为加权标签得分（含行为权重、出现次数、时间衰减）
\mathrm{tag\_score}(t)
&= \Big(1\cdot N_{\text{view}}(t) + 3\cdot N_{\text{like}}(t) + 7\cdot N_{\text{collect}}(t)\Big)
\\
&\quad \times C(t)
\times e^{-\lambda \Delta t}, \quad \lambda=0.1
\\
% 2. 按行为得分取Top-K标签
S_{\text{behavior}} &= \mathrm{Top}_K\big(\{t\}, \mathrm{tag\_score}(t)\big)
\\
% 3. 最近搜索高频标签
S_{\text{search}} &= \mathrm{Top}_2(\text{最近搜索结果标签频率})
\\
% 4. 最终用户兴趣标签集合
S_{\text{user}} &= S_{\text{behavior}} \cup S_{\text{search}}
\\
% 5. 推荐笔记
N_{\text{rec}} &= \mathrm{Top}_{50}\big(\text{公开笔记}, \text{tag}\in S_{\text{user}}, \text{时间降序}\big)
\end{aligned}

$$
符号说明
$$
\begin{aligned}
N_{\text{view}}(t)   &: \text{标签 } t \text{ 对应的用户浏览次数} \\
N_{\text{like}}(t)   &: \text{标签 } t \text{ 对应的用户点赞次数} \\
N_{\text{collect}}(t)&: \text{标签 } t \text{ 对应的用户收藏次数} \\
C(t)                 &: \text{标签 } t \text{ 在推荐列表中出现的次数} \\
\Delta t             &: \text{笔记发布距今时间（小时）} \\
S_{\text{behavior}}  &: \text{用户行为计算得到的兴趣标签集合} \\
S_{\text{search}}    &: \text{最近搜索结果中出现最多的2个标签} \\
S_{\text{user}}      &: \text{融合搜索意图后的最终用户兴趣标签集合}
\end{aligned}
$$

````markdown title:"还是GPT好使"
# 四、算法层面需要补充的关键点

## ⚠️ 1. C(t) 定义有问题

你现在写的是：

> 标签在推荐列表中出现次数

👉 这是**循环依赖**（推荐结果还没出）

### 建议改成：

```math
C(t) = 标签在全局热门笔记中的出现频率
```

👉 或直接用：

```math
C(t) = log(1 + note_count(tag))
```

---

## ⚠️ 2. 时间衰减 Δt 用错对象了

你写的是：

> 笔记发布时间

但你在算的是：

👉 **用户兴趣，不是内容热度**

### 应该改为：

```math
Δt = 用户最近一次与该标签交互的时间差
```

👉 否则会出现：

* 老用户兴趣被“新笔记”误导

---

## ⚠️ 3. 冷启动策略可以再补一刀

你现在只有：

* 用户笔记标签
* 搜索标签

👉 问题：

👉 **新用户可能啥都没有**

### 建议加：

```math
S_hot = 全局热门标签 TopK
```

最终：

```math
S_rec = S_base ∪ S_search ∪ S_hot
```
````
