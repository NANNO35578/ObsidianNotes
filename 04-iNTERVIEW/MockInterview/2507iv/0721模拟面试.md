2. 如何在项目中引入智能指针
	- 项目中使用智能指针, 比如在一个类中, 包含多个类的对象, 为了避免可能不不要的拷贝赋值等或为了保证类大小, 通常保留对象的指针形式, 此时会在构造函数进行`new`操作初始化, 一般在析构函数进行`delete`操作. 然而, 当我们类中子对象逐渐变多后, 若再来一个子对象, 我们可能忘记在析构函数中释放内存, 若此时服务器仍有工作在运行, 就会造成内存泄漏, 亦或者在客户端, 若未正确调用析构函数, 可能导致数据丢失或其他问题 
	- 在容器中的成员, 若为指针类型, 可考虑使用智能指针, 避免手动管理内存
	- 可以将智能指针作为信号和槽的参数，确保对象在不再使用时自动释放
```cpp
connect(sender, &Sender::signal, this, [this](std::shared_ptr<MyClass> obj) { /* 使用obj */ });
```
   - 由于Qt的父子对象机制，通常不建议对`QObject`使用`std::unique_ptr`或`std::shared_ptr`。如果需要使用智能指针，通常将非`QObject`的类使用智能指针管理

3. http常见状态码
	- `1xx` : 服务器收到请求, 正在处理
	- `2xx` : 请求处理成功
	- `3xx` : 重定向 需要附加操作
	- `4xx` : 客户端出错 可能是请求语法错误或无法完成请求
	- `5xx` : 服务器出错
