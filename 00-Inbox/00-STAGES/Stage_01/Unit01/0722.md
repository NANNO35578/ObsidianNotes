# `goto`语句
```c
#include <stdio.h>

int main() {
	int a=5;
	lable1:
		for (int i = 0 ; i <= a ; i++)
			printf("%d%c",i,i==a?'\n':' ');
	goto lable1; // 将形成循环
	return 0;
}

```

- `system( "pause" );`阻止命令行关闭
- 同时可用类似`system("code");`启动code
