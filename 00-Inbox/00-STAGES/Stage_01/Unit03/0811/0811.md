# 函数
- 对固定逻辑封装的模块
- 例如交换两数值`void swap(int *a,int *b)`以及数组求元素和`int addArr(int *a,int len)`都是功能的模块

样例代码 :
```c
#include <stdio.h>

void swap(int *a,int *b);//函数声明
int addArr(int *a,int len)

int main(){
	int arrayA[5] = { 25, 14, 56, 98, 73};
	int n = 9, m = 5;
	swap(n,m);        //函数调用
	addArr(arrayA,sizeof(arrayA)/sizeof(arrayA[0]));
	
	return 0;
}

void swap(int *a,int b){//函数定义
	int *a = *a ^ *b;
	int *b = *a ^ *b;
	int *a = *a ^ *b;
}

int addArr(int *a,int len){
	int sum=0;
	for (int i = 0; i < len; ++i)
		sum += a[i];
	return sum;
}

```

- 函数执行原理: 调用时进入堆栈，结束时弹出;
- 函数中`return`使用最好附加判断
- `void`在函数中的使用:
```c
#include <stdio.h>
//返回值位置的void
//参数位置
void f1( void ) {//没有参数 大部分编译器void参数可以省略
	return  ; //此时的return可以省略 如果要写 则不加值
} //f1 的void代表不需要返回值。  f2的void* 必须要返回一个指针 
int f2() {
	return 0;//如果返回值不是void return必须写对应类型的值。可能报编译错误
}
void* f3(void* a ) {
	return NULL;
}

int main() {
	//void :无类型/不确定类型  起到类型名的占位作用
	//应用位置： 
	//明确区分：void与void*在返回类型位置的区别。
	return 0;
}
```
