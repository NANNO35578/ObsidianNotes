# 时间复杂度

> [!tip] 概述
>计算机运行程序需要时间，每秒钟大约能进行108次（1亿次）运算
>Time Limit Exceed (TLE) 代表代码超时，当你的代码超时时，你可能使用了~~错误的算法~~不完善的语法，需要分析一下你的代码需要执行多少条基本语句
>避免使用endl，endl很慢，建议替换为'\n'
>   1+2+3+...+${10}^{14}$    ---- 执行${10}^{14}$次语句
>   ${10}^{14}\times ({10}^{14}+1)/2$  ---- 仅执行几条语句

> [!note] 分析时间复杂度
> 时间复杂度通常用O表示。括号内含有关于输出变量的系数为1的单项式或多项式，表示执行了多少条基本语句。例如 O(n) , O(n<sup>2</sup>)

```cpp
#include <iostream>

int main() {
  int n, m, sum = 0;
  std::cin >> n >> m;
  for (int i = 1; i <= n; i *= 2)
    for (int j = 0; j <= m; i++) {
      sum += i;
      sum += j;
    }
  std::cout << sum;
  return 0;
}
```
A.O($n\times m$)   B. O($n\times \log_2(m)$)   C. O($\log_2(n\times m)$)   D. O($m\times \log_2(n)$)


##### __递归时间复杂度__

$$T\left(n\right)=a\times T\left(\frac{n}{b}\right)+f\left(n\right)$$


a : 子问题个数 
b : 子问题规模
$f\left(n\right)$ : 当前问题处理时间复杂度

$n^{\log_b(a)}$  与 $f_\left(n\right)$ 比大小 取大值
若相等 取 $log_2(n)\times n^{log_b (a)}$ 

例如：二叉树递归遍历
子问题个数分左数右树 两个 a= 2
子问题规模 在理想情况下 左右树节点个数相等() b=n


> [!bug] 不适用于斐波那契数列问题
> 该问题子问题间结果互相影响 (非归并)

# 空间复杂度
> 空间复杂度的概念比时间复杂度的概念要简单很多，只需要计算申请的空间即可
> MB - 兆字节 KB - 千字节 Byte - 字节 Bit - 比特
> bool - 1字节 int - 4字节 long long - 8字节 float - 4字节 double - 8字节
> 1MB=1024KB 1KB=1024Byte 1Byte=8Bit
