# Stack By 2 Queue
> 定义两个队列 q1 q2
> 新元素要*Push*时 选择一个非空队列push(第一个元素可push进任意一个) 
> 当*Pop*时 找到非空队列假设为q1 将其front元素push到q2(空)中 直至剩余一个元素 若此时保存 然后pop 再将保存元素返回 即是*Top* 若直接pop 就是*Pop*

# `char *str1;`与`char str2[]`的区别


|                        | C                         | C++                       |
| ---------------------- | ------------------------- | ------------------------- |
| 头文件                    | `<string.h>`              | `<string>`                |
| 初始化`char*`类<br>型为"ABC" | `const char* pC = "ABC";` | `string str = "ABC";`<br> |
|                        | 不可操作`pC[0] = 'a';`        | 可操作`str[0] = 'a';`        |
| 利用数组初始化                | `char str[] = "ABC";`     |                           |
|                        | 不可操作`str = "abcd;"`       | 可操作`str = "abcd;"`        |
| 比较                     | `strcmp(s1 , s2);`        | 可用`s1 > s2 && s1 == s2`   |
| 复制                     | `strcpy(s1 , s2);`        | `s1 = s2;`                |
| 追加                     | `strcat(s1,s2);`          | `s1 += s2;`               |

# 空格替换
> [!quote] 空格替换为"Haha"
> 一个足够长的字符串 中间有若干空格 将其替换为"Haha" 要求时间空间消耗尽可能小

> 遍历一遍字符串 记下空格个数k 将字符串末尾的单词复制到(4 - 1)* k个字节空间后 在其单词首部插入"Haha" 继续向前遍历 将末尾单词复制到后面 插入"Haha" 重复此步骤
>

# 单词反转
> [!quote] "Here to you" -> "you to Here"
> 将字符串中的单词倒序

> 1. 将整个字符串反转(除'\0') 遍历将单词反转
> 2. 取栈1将字符串中的字符依此存入 若遇到空格 将其栈内元素压入栈2 栈2再压入空格 继续执行此步骤 直至字符串尾 将栈2元素依此弹出
