# Level Order With `\n`

Origin : `queue` 实现


> 分隔开
> 1. 变量滚动
> 2. 分隔标记
> 3. 二维数组
> 4. 多个队列
> 5. 两个队列


#### 计数
1. 双计数器: 当前层数元素个数i 下一层元素个数j 
	- 入根节点 i = 1 j=0
	- 取队首打印时i-- 有孩子节点时 j 记录 
	- 若i为0 则当前层 打印结束 j 赋值给 i
2. `size()` : 入根节点 当前层元素个数 i =size()
	- 取队首打印 i-- 
	- 若i为0 当前层结束 再次赋值 i =size()

#### 标记
1. 间隔 : 标记元素N 入根节点后 入N
	- 取队首 若为N 当前层已结束 队尾插入N
	- 队元素为1 结束
2. 双标记 : 当前层尾元素 $T_1$ 初始为根节点 
	- 打印首元素 若不为$T_1$ 压入孩子 将压入的孩子记为$T_2$ 
	- 若为$T_1$     $T_1$赋值为$T_2$ 当前层结束
3. `bacck()` : 根入队后 记当前层尾元素T 为back()
	- 打印 压入孩子 若打印的节点为T 更新T为back()

#### 二维数组
根入 数组一维
- 打印当前维 孩子入下一维


#### 双队列
根节点入队列1 队列2置空
- 打印非空队列 孩子入空队列


#### 深度队列
类似最小栈 并行申请请一个深度队列 根入打印队列 根深度为1 深度入深度队列
- 打印队首元素 压入孩子 孩子深度为父亲深度加一 入深度队列
- 若打印 深度队列都弹出后 队深度队列首元素与当前打印元素深度不同 换行 

#### Array + 层序
根节点指向数组首元素
- 孩子指向数组下一下标位置

#### 前序遍历(括号) 后序遍历
> 前序遍历 : 前序遍历树 
> 	打印父亲 后 加左括号 打印左孩子 
> 	若无孩子 加左右括号(或不加？) 
> 	打印完右孩子 加右括号 
>> 括号(左加右减)个数即深度

> 后序遍历 : 后序遍历序列last 层序遍历原始序列 level 
> level首元素为根节点 last尾元素为根节点
> 	从后往前遍历last 取得元素T 
> 	从前往后遍历level 打印 若为T 加个换行
> 	last遍历到的T为层尾 从level中打印的元素应当同时从last中去除
