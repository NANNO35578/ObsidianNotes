
# Array To Binary Tree
依据第五条性质 将完全二叉树按照从上到下从左到右顺序 从0开始编号 一直到n 
- 父亲节点编号范围 $1$ ~ $n/2-1$ 
- 第i个节点的孩子节点
	- 若$2\times i +1<=n$ 有左孩子
	- 若$2\times i+2<=n$ 有右孩子
