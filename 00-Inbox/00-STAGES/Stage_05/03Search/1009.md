# Hash Table
> [!note] `createHashTable`
> 1. 构造hash函数
> 	1. 常数型函数 C
> 	2. value % n 或小于等于n的最大素数
> 2. 处理Hash冲突 同一个hash下标已有元素
> 	1. 开放定址法
> 		1. 线性探测 若当前位置非空 尝试放入后一个位置 后面全满放入前面
> 		2. 二次探测 尝试放入±1 ±4 ±9 ±25 
> 	2. 拉链法 相同位置元素组成链表

- 当同一下标元素过多(8+)Java 折叠为红黑树 C++扩容 重新散列
- 开放定址法查找时 若当前哈希表下标存在元素且不匹配 向后遍历 若出现空元素 则不存在 若到尾，向前遍历

> 在一堆无序元素中 需要进行多次查找 时间复杂度尽量在O(1)
> 将元素下标与数据构成*映射* 该映射即为哈希函数

> [!example] 在一个字符数组中查找某个字符下标 数组元素不重复 
> `char arr[] = { 'a', ':', '1', '=' };`
> 由数据与下标可达成常数关系 即哈希表可存储该字符ASCII码为哈希索引 即
> ```cpp
> int hashTable[len] ;
> for( i=0; i<len; ++i) hashTable[arr[i]]= i;
> ```

可存储元素数据 也可存储索引
 * 如果您需要快速查找和操作数据且数据值可能会变化，存储值的方法更为合适。
 * 如果您关心内存使用，并且数据值重复较多，存储索引的方法可能更具优势。



>[!quote] 对`int arr[] = { 61, 78, 120, 9, 57, 34, 89, 233, 145, 104, 23, 2, 42};`要进行若 干次查找某个元素是否存在于该数组，存在返回下标，不存在返回`-1` ，时间复杂度尽量在O(1);
> 首先构造哈希函数 使用`% MOD_N` 此处元素个数为13 为素数 `MOD_N`可取13
> 考虑同一哈希下标会出现多个元素 若出现 采用拉链法 
> 因此 需要构造链表
> ```cpp
> struct List{
> 	int val;
> 	List* next;
> 	List(int v):val(v), next(nullptr){}
> }
> ```
> 而哈希表则为`List*`的数组当使用`new`申请空间时候应当做如下声明
> `List** hashTable = new List*[size]` 此时`size`可取`MOD_N`
> 将元素插入哈希表 
> 0: 61%13= 9 应当放入hashTable[9] :0
> 1: 78%13= 0 应当放入hashTable[0] :1
> 2: 120%13= 3 应当放入hashTable[3] :2
> 3: 9%13= 9 应当放入hashTable[9] :0->3
> ...
> ...
> ...
> 查找时例如数据67
> 67%13= 2 找到hashTable[2] 遍历该链表 进行匹配
