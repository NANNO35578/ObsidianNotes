### [1, 3, 5]钞票面额 求价值为 n 的物品最少多少张钞票
子问题：

决策：选最小
状态转移方程

$$
f(i) = \min{f(i-V\left[j\right])+1 } 
$$

dp数组定义：$dp[i]$: 价值 $i$ 物品最少所需钞票； $i$: 物品价值
初始化：$dp[0] = 0$

推导：
```cpp
dp[0] = 0;                   // 0
dp[1] = dp[1 -1] + 1;        // 1
dp[2] = dp[2 -1] + 1;        // 2
      = dp[1] + 1;
dp[3] = min{ (dp[3 -3] + 1), (dp[3 -1] + 1) }
      = min{ (dp[0] + 1), (dp[2] + 1) }
      = min{ 1, 3 }          //1

dp[4] = min{ (dp[4 -3] + 1), (dp[4 -1] + 1) }  
      = min{ (dp[1] + 1), (dp[3] + 1) }
      = min{ 2, 2 }          //2
      
dp[5] = min{ (dp[5 -3] + 1), (dp[5 -1] + 1), (dp[5 - 5] + 1) }  
      = min{ (dp[2] + 1), (dp[4] + 1), (dp[0] + 1) }
      = min{ 3, 3, 1 }          //1
      
dp[6] =       // 1
dp[7] =       // 1
dp[1] =       // 1
```
