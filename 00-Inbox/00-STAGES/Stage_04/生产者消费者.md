# 条件变量`pthread_cond_t`
- 用于线程间同步的一种机制。它允许线程在某个条件发生时被唤醒，从而实现更高效的线程协作
- 条件变量通常与互斥锁 (`pthread_mutex_t`) 一起使用，以确保对共享数据的安全访问

##### 初始化条件变量
```c
int pthread_cond_init(pthread_cond_t *cond, const pthread_condattr_t *attr);
```
- **参数**：
    - `cond`：指向条件变量的指针。
    - `attr`：条件变量的属性，通常为 `NULL`。
- **返回值**：成功返回0，失败返回错误码。

##### 销毁条件变量
```c
int pthread_cond_destroy(pthread_cond_t *cond);
```
- **参数**：
    - `cond`：指向条件变量的指针。
- **返回值**：成功返回0，失败返回错误码。

##### 等待条件变量
```c
int pthread_cond_wait(pthread_cond_t *cond, pthread_mutex_t *mutex);
```
- **参数**：
    - `cond`：指向条件变量的指针。
    - `mutex`：指向互斥锁的指针（在调用此函数之前，必须先锁定）。
- **返回值**：成功返回0，失败返回错误码。
- **说明**：释放互斥锁并等待条件变量的通知。当条件变量被其他线程广播或信号后，重新获取互斥锁
	- 挂起执行与唤醒执行，第一次解锁并挂起，第二次上锁并唤醒

##### 发送信号
```c
int pthread_cond_signal(pthread_cond_t *cond);
```
- **参数**：
    - `cond`：指向条件变量的指针。
- **返回值**：成功返回0，失败返回错误码。
- **说明**：唤醒一个等待该条件变量的线程。

##### 广播信号
```c
 int pthread_cond_broadcast(pthread_cond_t *cond);
```
 - **参数**：
    - `cond`：指向条件变量的指针。
- **返回值**：成功返回0，失败返回错误码。
- **说明**：唤醒所有等待该条件变量的线程。

# 生产者消费者工作模型
![[CustomerAndProducerWorkModel.png]]

> [!hint] 
> 生产者负责生成数据或任务，并将其放入共享缓冲区；
> 消费者则从缓冲区中取出数据并进行处理
> 有效地解决多线程环境中的资源共享问题，避免资源竞争和数据不一致

生产者: 负责生成数据并将其放入缓冲区

消费者: 从缓冲区中取出数据进行处理

缓冲区: 用于存储生产者生成的数据，通常采用环形链表或队列实现

### 上锁机制

在多线程环境中，为了确保数据的一致性和防止竞争条件，生产者和消费者在特定情况下需要上锁
1. **生产者上锁**：
    - 在生产者准备插入数据之前，需先获取锁，以确保其他线程（消费者）无法在此期间修改缓冲区
    - 生产者在放入数据后，释放锁并通过条件变量通知消费者，有数据可供消费
2. **消费者上锁**：
    - 在消费者准备取出数据之前，同样需要获取锁，以防止生产者在此期间修改缓冲区
    - 消费者在成功取出数据后，释放锁，并通过条件变量通知生产者，可以继续生产


### 具体工作流程
1. **生产者流程**：
    - 检查缓冲区是否已满（`not full`）。
    - 获取锁。
    - 将数据放入缓冲区。
    - 更新 `rear` 指针和 `count`。
    - 释放锁。
    - 通知消费者有新数据可用（使用条件变量）。
2. **消费者流程**：
    - 检查缓冲区是否为空（`not empty`）。
    - 获取锁。
    - 从缓冲区取出数据。
    - 更新 `front` 指针和 `count`。
    - 释放锁。
    - 通知生产者可以继续生产（使用条件变量）。
