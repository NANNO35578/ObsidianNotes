# 1-单例模式
> __单例模式(Singleton Pattern)__: 属于创建型模式。3个要点:
> 1. 当前类最多只能创建一个实例。
> 2. 它必须自己创建这个实例(而不是调用者创建)
> 3. 它必须自己向整个系统提供全局访问点访问这个实例。


##### 懒汉式
> 采用一系列限制限制对象创建 同时构造一系列方法对单例对象回收

__保底回收__ : 使用静态成员自动回收机制 在静态成员的析构函数中调用回收;


> 申请一个静态对象返回 该对象将在程序结束自动回收


优缺点：

|       | 优点             | 缺点           |
| ----- | -------------- | ------------ |
| 懒汉式 1 | 可自行选择何时回收该单例对象 |              |
| 懒汉式 2 | 创建简单           | 只能等到程序结束才能回收 |




##### 饿汉式

> 静态类成员
> 不会因为多线程创建多个实例
