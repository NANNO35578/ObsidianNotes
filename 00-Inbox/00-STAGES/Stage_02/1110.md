# 拷贝构造

##### 隐式类型转换

某个类存在一个基本类型数据作参数传入即可完成初始化的构造函数可作如下初始化
`ClassName varName = BASIC_DATA_TYPE;`
例如
```cpp
class className{
public:
	int m_a;
public:
	className():m_a(0){};
	className(int a):m_a(a) {};     //隐式类型转换构造 int 转换到className
	                                //
	className(int a,int b=9 ):m_a(a+b){};        //同样是隐式类型转换构造
	//! 修饰 explicit 禁止发生隐式类型转换
	explicit className(int a,int b =99):m_a(a+b){};
}

className c0 = 10 ;

```

##### 拷贝构造

```cpp

className newClass_1;
className newClass_Copy(newClass_1);    //拷贝构造 浅拷贝 

	CTest(const CTest& newTest) :m_a(newTest.m_a), m_p(nullptr) {
		newTest.m_p != nullptr ? (m_p = new int(*newTest.m_p)) : (m_p = nullptr);
	};

```

> [!tip] 
> 拷贝构造函数类中除了默认的无参构造函数还会有默认的拷贝构造，参数为: const 当前类对象的引用函数体代码 ，形参对象中的成员依次给this对象成员做初始化
> 默认的拷贝构造，是一个浅拷贝，对于类中指针成员只是简单的将地址做了一个拷贝，指针指向的空间并没有拷贝
> __问题__: 存在指针成员并申请，释放空间。
> _解决_: 深拷贝，需要手动重构拷贝构造函数
> - 应当尽量避免拷贝 采用引用 指针等
> - 默认会提供拷贝构造函数，如果手动重构了，则编译器不会提供默认的了
> - 如果手动重构拷贝构造函数，默认的无参构造函数不会提供了

##### `operator=` 等号运算符重载
> 默认的函数:operator=参数:const 当前类对象的引用 ，返回类型当前类对象的引用_函数体代码_ : 形参对象中的成员依次给this对象中的成员做赋值操作
>  !默认的 operator=  是一个浅拷贝
>  ?解决:深拷贝 ，手动重构 operator=
>  ?如果手动重构了这个函数，编译器则不会提供了
