# 函数默认值`void fun(int a = 1);`

默认值声明 : `void fun(int a=1);`
作用 : 辅助代码开发

> 函数拥有多个参数时 设置默认值的从右向左放置 不设置默认值的放左侧 不得交叉
> 函数的声明与定义分开 以声明处设置的默认值为准 定义处默认值无效
> 多次声明 取最近声明处默认值为准

> [!error] error C2572: “fun3”: 重定义默认参数 : 参数 1
> 定义处默认值无效 且会有重定义默认参数错误
> 函数调用前一定会声明

```c++
#include <iostream>

void fun1(std::string  a = "abcd") {
	std::cout << a << '\n';
}

void fun(int a = 0){
	std::cout << a << '\n';
}

int main(){
	void fun(int a = -1);
	fun();    // -1
	::fun();  // 0 
	return 0;
}

```

# 函数重载

函数重载`Function OverLoading` 在同一个作用域内，允许有多个同名函数，但它们的参数列表必须不同。这样，根据传递的参数类型和数量，编译器会自动选择合适的函数调用。

```c++
#include <iostream>
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

> [!error] error C2084: 函数“void funArr(int [])”已有主体
> `void funArr(int arr[])` 与 `void funArr(int* arr)` 为重定义
> *因数组名作参数会退化为指针*

> [!error] error C2084: 函数“void fun(int)”已有主体
> `void fun(int a)` 与 `void fun(const int a)` 也为重定义 
> *函数传参数时为 “复制” *

- `void fun();` 与有默认值的重载`void fun(int a = -1)` 区分:
	- 取用声明局部化 提高优先级
	- `{ void fun();              fun(); }`
	- `{ void fun(int a = -1);    fun(); }`

> [!warning] `void fun(int* a);` 与`void fun(const int* a);` 是重载

# `nullptr` 与 *NULL*

`int* pInt;` pInt称为野指针 悬空指针: 指向一块申请后使用并已释放的空间

`NULL` C语言宏定义 *#define NULL 0* 会出现含义不明确问题 
> [!tip] 例 : 函数重载
> `void fun(int a);` 与 `void fun(int* a);` 当参数传入*NULL*时
> 实际上调用的是 `void fun(int a);` 

C++提出`nullptr` 明确为一个空指针 是关键字 `void fun(nullptr);` 明确调用第二个

# Reference 引用

对已存在的变量或一段空间取别名 `int a = 9; int& a_ = a;`
指向同一地址 `&a_` 等于 `&a`
可在函数参数处声明 

> [!tip] 区别`void fun(int a);` 与`void fun(int& a);` 以及`void fun(int* a);`


- 均为重载 因为引用实现原理为指针常量 第三个为指针级别 前二者需区分 :
	- 常量传入 调用第一个
	- 声明局部化
		- `{void fun(int a);      fun(a); }`  
		- `{void fun(int& a);     fun(a); }`
	- 函数指针
		- `void (*pOrigin)(int) = &fun;`
		- `void (*pReference)(int&) = &fun;`

如果只是查看实参的情况下, 使用 值传递 引用传递 指针传递 都可以,
如果修改实参 引用传递 指针值传递不推荐 
对于复合类型来说 *额外申请的空间大小* 伴随着实参而变动 不可控大小
