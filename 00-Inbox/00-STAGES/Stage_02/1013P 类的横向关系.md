# 组合 - 依赖 - 关联 - 聚合

1. **组合 (Composition)**：强拥有关系，生命周期由父类管理。
2. **依赖 (Dependency)**：暂时的使用关系，通常出现在方法参数或局部变量中。
3. **关联 (Association)**：弱关系，通常通过指针或引用来表示，但对象之间的生命周期独立。
4. **聚合 (Aggregation)**：比组合弱的拥有关系，整体和部分可以独立存在。

在 C++ 中，类与类之间的关系可以从**横向**和**纵向**两个维度来分析。具体来说，类之间的关系包括**组合 (Composition)**、**依赖 (Dependency)**、**关联 (Association)** 和 **聚合 (Aggregation)** 等，而纵向则涉及**继承 (Inheritance)**。这两种关系模式帮助我们在设计时清晰地表达对象之间的交互与依赖。

### 横向关系（类与类之间的联系）

1. **组合 (Composition)**

   * **定义**：组合是一种强依赖关系，表示一个类“拥有”另一个类，并且这个“拥有”的对象的生命周期与容器类的生命周期相同。即，如果容器对象被销毁，容器中的对象也会被销毁。
   * **特性**：

     * 组合关系是一种“强拥有”关系，通常使用成员对象来实现。
     * 被组合的对象的生命周期由拥有它的对象管理。
     * 一般情况下，被组合的类对象是作为成员变量嵌入到容器类中，而不是单独存在。

   **示例**：

   ```cpp
   class Engine {
   public:
       void start() {
           // 启动引擎
       }
   };

   class Car {
   private:
       Engine engine;  // 引擎是 Car 的组成部分
   public:
       void drive() {
           engine.start();  // 使用引擎
       }
   };
   ```

   **说明**：`Car` 类拥有 `Engine` 类的实例，并且 `Engine` 的生命周期与 `Car` 相同。当 `Car` 对象销毁时，`Engine` 对象也会被销毁。

2. **依赖 (Dependency)**

   * **定义**：依赖关系表示一个类依赖于另一个类的功能。在 C++ 中，通常表现为类通过函数参数、返回值类型或者局部变量来依赖其他类。
   * **特性**：

     * 依赖关系通常是暂时的，依赖类的生命周期通常不会受到影响。
     * 依赖性通常出现在方法参数、局部变量或返回类型中。
     * 可以通过传递对象或指针来实现。

   **示例**：

   ```cpp
   class Engine {
   public:
       void start() {
           // 启动引擎
       }
   };

   class Car {
   public:
       void drive(Engine& engine) {
           engine.start();  // 依赖于 Engine
       }
   };
   ```

   **说明**：`Car` 类通过方法参数 `Engine& engine` 来依赖 `Engine` 类。`Engine` 对象的生命周期不受 `Car` 的影响。

3. **关联 (Association)**

   * **定义**：关联是一种较弱的关系，表示两个类对象之间存在某种“使用”的关系，但它们的生命周期是独立的。通常表现为一个类包含另一个类的指针或引用，但对象之间没有直接的拥有关系。
   * **特性**：

     * 关联关系可以是双向的，也可以是单向的。
     * 关联的对象通常是通过指针或引用传递，但不会由当前对象负责销毁。
     * 对象的生命周期独立于对方。

   **示例**：

   ```cpp
   class Engine {
   public:
       void start() {
           // 启动引擎
       }
   };

   class Car {
   private:
       Engine* engine;  // 关联关系（指针）
   public:
       Car(Engine* eng) : engine(eng) {}
       void drive() {
           engine->start();  // 使用 Engine 对象
       }
   };
   ```

   **说明**：`Car` 和 `Engine` 之间有一个简单的关联关系。`Car` 使用指针来引用 `Engine` 对象，但它并不拥有 `Engine`，`Engine` 的生命周期不由 `Car` 管理。

4. **聚合 (Aggregation)**

   * **定义**：聚合是一种特殊的关联关系，表示一个类是另一个类的一部分，但这种部分关系是较弱的。与组合不同，聚合的对象是相对独立的，生命周期由外部控制。
   * **特性**：

     * 聚合关系通常表示“整体-部分”关系，但整体和部分可以独立存在。
     * 被聚合的对象可能在多个容器中共享。
     * 聚合通常使用指针或引用来表示。

   **示例**：

   ```cpp
   class Engine {
   public:
       void start() {
           // 启动引擎
       }
   };

   class Car {
   private:
       Engine* engine;  // 聚合关系
   public:
       Car(Engine* eng) : engine(eng) {}
       void drive() {
           engine->start();  // 使用 Engine
       }
   };
   ```

   **说明**：`Car` 类有一个聚合关系，它通过指针引用外部传入的 `Engine` 对象，而不拥有该对象的生命周期，`Engine` 可以在其他地方被管理和销毁。

### 纵向关系（类的继承关系）

继承是一种描述类之间**父子**关系的机制，其中一个类（子类）继承自另一个类（父类），继承可以让子类获得父类的属性和方法。

1. **继承 (Inheritance)**

   * **定义**：继承是面向对象编程中的一种机制，允许一个类从另一个类继承成员属性和成员函数。通过继承，子类可以复用父类的代码，并且可以扩展或修改父类的功能。
   * **特性**：

     * 继承是一种"是一个"（Is-A）关系。
     * 子类可以继承父类的公有和保护成员（方法和属性），但无法继承父类的私有成员。
     * 子类可以重写父类的方法，也可以定义自己特有的方法。
     * C++ 中支持单继承和多继承。

   **示例**：

   ```cpp
   class Animal {
   public:
       void eat() {
           // 吃东西
       }
   };

   class Dog : public Animal {
   public:
       void bark() {
           // 吠叫
       }
   };

   class Cat : public Animal {
   public:
       void meow() {
           // 喵喵叫
       }
   };
   ```

   **说明**：`Dog` 和 `Cat` 类都继承自 `Animal` 类，因此它们都拥有 `Animal` 类的 `eat` 方法。`Dog` 和 `Cat` 分别添加了自己的特有方法。

2. **多态 (Polymorphism)**

   多态性是通过继承和重写实现的，使得父类指针或引用可以指向子类对象并调用子类重写的方法。

   ```cpp
   class Animal {
   public:
       virtual void makeSound() {
           std::cout << "Animal sound\n";
       }
   };

   class Dog : public Animal {
   public:
       void makeSound() override {
           std::cout << "Bark\n";
       }
   };

   class Cat : public Animal {
   public:
       void makeSound() override {
           std::cout << "Meow\n";
       }
   };

   int main() {
       Animal* animal = new Dog();
       animal->makeSound();  // 输出 "Bark"
       delete animal;

       animal = new Cat();
       animal->makeSound();  // 输出 "Meow"
       delete animal;
   }
   ```

   **说明**：通过虚函数和重写，`Dog` 和 `Cat` 类可以对 `Animal` 类中的 `makeSound` 方法进行不同的实现，从而实现多态。




#### 纵向关系

1. **继承 (Inheritance)**：表示父类和子类之间的关系，子类继承父类的属性和方法，支持代码复用。
2. **多态 (Polymorphism)**：通过继承和虚函数的机制，使得父类指针或引用可以调用子类重写的方法。

通过这两种关系，C++ 可以清晰地表达类之间的互动和层次结构，帮助我们设计出更具扩展性和可维护性的程序。
