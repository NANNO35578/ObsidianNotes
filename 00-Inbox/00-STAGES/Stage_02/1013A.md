# class expand

> 成员属性:属于对象的，定义对象的时候存在，定义多个对象会存在多份的成员属性，各自维护，彼此独立，互不干扰。
> 成员函数:属于类的，编译期就存在了，他的存在与否和是否定义对象无关，一个类中只会存在一份，被多个对象共享使用。

# class static member


> 静态成员属性:属于类的，编译期存在，在类外定义，格式 static 关键字去掉,类型 类名作用域在一个类中，只会存在一份，被多个对象所共享。
>> 使用:可以通过对象，在没有对象的时候，可以通过类名作用域直接调用。
> 
> 静态成员函数:属于类的，编译期存在，在一个类中，只会存在一份，被多个对象所共享。
>> 使用:可以通过对象，在没有对象的时候，可以通过类名作用域直接调用。
> 
> 调用的区别:
> 1. 本质上的差异:是否 有*this* 指针, 静态函数没有*this*，普通成员函数编译器默认加上的第一个参数。
> 2. 成员使用: 静态函数只能使用类中的其他*静态成员*，一般函数都可以使用。

> this:
>> 非静态成员函数包括 构造、析构函数，都会有隐藏的*this指针参数*，当前类的指针, `类名\*const this`  ，在函数内部使用成员，都是通过this指针使用的。

# const member

> 初始化在构造函数的初始化参数列表中


```cpp
	const int a=2; //函数位于栈区 a同样位于栈区(的常量区)
	const int* pConst = new const int; //位于堆区的常量
	
	//初始化参数列表： 属于构造函数一部分 用于真正的初始化成员 member(value) 或member{value}
	//初始化顺序取决于成员在类中声明的先后顺序 与初始化参数列表中的顺序无关
	ConstTest(int v1, int v2) :m_a(v1), m_const(m_a) {};
```
