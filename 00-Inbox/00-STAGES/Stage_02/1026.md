# 头文件与源文件

> __头文件__:变量的声明，函数的声明，类的声明、定义...
> __源文件__:变量的定义，函数的定义，成员属性定义及初始化，成员函数的定义

编译器 对待的差异 __单个头文件不参与编译__

头文件:		单独的头文件 不参与编译
源文件:		自上而下，独立进行编译

# 头文件重复调用

> 直接和编译器沟通，告诉编译器当前的这个头文件 ，在其他的源文件中，只会包含一次。`#pragma once` : 特点： 代码简单，方便快捷 ，编译效率高，适用范围没那么广，并非C++标准支持的
> 另一方案 ： 基于宏的逻辑判断
> 特点： 麻烦，编译速度慢，C++标准的，所有编译器都支持的 ，可以做到部分代码去重(置于 `#endif` 之后)

```c
#ifndef __A_H__ 
#define __A_H__
```

# 3. 程序生成过程
##### 3.1.预处理`Preprocessing`
将源文件(`.cpp`)初步处理，生成预处理文件(`.i`):
	1.解析 `#include` 头文件展开替换。
	2.宏定义指令:#define 宏的替换，#undef等。
	3.预处理指令:解析 `#if`、`#ifndef`、`#ifdef`、`#else`、`#elif`、`#endif`等
	4. 删除所有注释。

##### 3.2.编译`Compilation`
将预处理后的文件(.i)进行一系列词法分析、语法分析、语义分析及优化，产生相应的汇编代码文件(`.asm`)

##### 3.3.汇编`Assembly`
将编译后的汇编代码文件(`.asm`)汇编指令逐条翻译成目标机器指令，并生成可重定位目标程序的`.obj`文件，该文件为二进制文件，字节编码是机器指令

##### 3.4.链接`Linking`
通过链接器将多个目标文件(`.obj`)和 库文件 链接在一起生成一个完整的可执行程序。

# 4.编译期-运行期

> __编译期__ 是指把源程序交给编译器编译、生成的过程，最终得到可执行文件。
> __运行期__ 是指将可执行文件交给操作系统执行、直到程序退出，把在磁盘中的程序二进制代码放到内存中执行起来，执行的目的是为了实现程序的功能。

# `define`

> 效率比函数高
> 宏参数没有类型,不同于函数参数，不能够自动计算，表达式的求解

函数:	有参数类型的校验 自动计算 表达式的求解

##### 宏定义多行
> [!quote] 只需在行末加上一个`\` 
> eg:
 ```c
 #define Print(container) for(auto& v:container){\
							std::cout<<v<<' ';}\
						std::cout<<'\n';

#undef XXX 	//! 取消宏绑定
```


- 宏名与函数相同 函数名可以加括号

- `#` :	将宏参数转换为 __字符串__,加双引号 `#define D(ARG) #ARG`
- `#@` :	将宏参数转换为 __字符__，加单引号 `#define E(ARG) #@ARG`
- `##` :	单纯拼接的作用相当于字符串自加 `#define F(ARG) int aaa##ARG = 456;`

# 内联函数`inline`
结合宏高效 函数能校验参数 自动计算参数表达式的优点

> [!bug] 修饰： inline
> 适用场景: 适合代码量少，短小精悍的函数，里面避免有复杂的逻辑，复杂的循环 `for`,`while `,`switch`,空间换时间的做法。
> 缺点: 过度的使用 会导致代码量膨胀，内存增加
> 
> inline 建议性关键字: 
>  建议编译器将这个函数作为内联函数，编译器会有自己的检查规则，判断其是否为内联函数。
>  递归函数，实现多态的虚函数，一定不能为 内联函数
>  在类、结构体中 声明且定义的函数，默认为内联函数，在类、结构体中声明，且在类外定义的函数，默认为非内联函数。
