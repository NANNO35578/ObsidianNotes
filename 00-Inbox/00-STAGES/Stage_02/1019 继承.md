# 继承(extend)


> 子类可以使用父类成员 同时会包含父类成员 在父类的基础上 子类可视为其延续和扩展
>

# 继承的优点

> > 继承的优点
> 从*功能相似*的多个子类中，抽离出来*公共成员*，放到一个类中，这个类即是一个父类，提高代码复用性、扩展性，灵活性。

> [!example] `CPeople`
> 人有白种人 黄种人 黑人 
> 都有吃 走路 消费等行为 同时都有money等属性


### 隐藏
> 在继承下 子类定义了父类相同名类成员
> 子类成员函数 与父类之间不是重载

# 父类指针可直接指向子类对象

> *父类指针可直接指向子类对象* 
> 保证子类对象可成功调用父类成员
> 
> 子类指针不可直接指向父类对象
> 子类指针指向空间大 若指向父类对象 会出现越界访问 而父类指针指向空间小 子类对象存在一个父类对象空间可给予指向






---
# 类成员函数指针

定义: 
```cpp
class Test {
public:
	void fun(int a){ std::cout << a << '\n'; };
}

void (Test ::* pFun_class)(int a) = &Test::fun;
```

- 定义指针名前加类名以及`::*` 因与普通函数不同 类成员函数还含有一个this指针
- 赋值加作用域因函数属于该作用域
- `::*` `.*` `->*` 属于一个整体操作符

---
# 解决问题

例如黄种人 白种人 黑种人 三者都有吃的成员函数
但父类People没有该成员函数 可通过类成员函数指针来间接调用吃
