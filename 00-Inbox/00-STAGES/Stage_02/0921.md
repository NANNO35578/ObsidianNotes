## Namespace `::`

全局域 `::`
自定义域 `namespace nameAKA { }`

```c++
#include <iostream>

int var = 0;

namespace nameA {// 命名空间 作用域
	int var = 3;
}

namespace nameB {
	int var = -1;
}

int main() {
	int var = 9;
	std::cout << ::var << var << '\n';
	std::cout << nameA::var << '\n';
	std::cout << nameB::var << '\n';
	return 0;
}
```

## new & delete

> [!abstract] 动态申请空间
> - "动态"指的是*在程序运行期间(非编译器)分配空间* 程序需要时分配空间 更加灵活
> - `new delete`为关键字 `malloc(); free();`为函数
> - `new`分配内存调用构造函数 `delete`释放内存调用析构函数 `malloc free`只是简单调用
> - 
 
|       | malloc                | new                             |
| :---- | :-------------------- | :------------------------------ |
| 传递参数  | 申请空间大小<br>大小为字节       |                                 |
| 返回值   | void*<br>多数情况需要强制类型转换 | 对应类型空间首地址                       |
| 能否初始化 | 不能                    | new int(99);new int[2]{99,999}; |

- 申请一个 `int` : `int* pInt = new int;`
- 申请一个 `int*` : `int** pPI = new int*;`
- 申请一个 `int[5]` : `int* pAI = new int[5];`
- 申请一个*指针数组* `int*[3]` : `int **pPA = new int*[3];` 因`int *[3]`首元素为`int*` 其指针为`int**`
- *数组指针* `int(*)[3]` : `int (**pAP)[3] = new (int(*)[3]);`
- 多维数组 `int (*p2D)[3] = new int[2][3];` 首元素为`int[3]`

## foreach

在C++中， for 循环的标准形式是用分号 ; 来分隔初始化表达式、循环条件和更新表达式三个部分。然而，C++11标准引入了一种新的循环形式，即范围 for 循环（也称 for each 循环），在这种循环中，循环的遍历范围是用冒号 : 来指定的。  
  
范围 for 循环的基本语法如下：  
```c++
for (元素类型 变量名 : 遍历范围) { // 循环体代码  }  
```
 
>元素类型：指定遍历范围中元素的类型。  
>变量名：用于访问遍历范围中的当前元素。  
>遍历范围：可以是一个数组、一个容器（如 std::vector 、 std::list 等）、一个拥有 begin() 和 end() 成员函数的任意序列，或者是使用花括号 {} 包围的初始化列表。  

这种循环形式使得遍历容器或数组变得更加简洁和易读。下面是一个使用范围 for 循环遍历 std::vector 容器的例子：  
```c++
#include <iostream>  
#include <vector>  
  
int main() {  
    std::vector<int> vec = {1, 2, 3, 4, 5};  
    for (int num : vec) {  
        std::cout << num << std::endl;  
    }  
    return 0;  
}  
```

   
在这个例子中， `for (int num : vec)` 表示遍历 `vec` 容器中的每一个元素，将每个元素的值赋给 int num 变量，然后执行循环体代码，这里是打印 num 的值。  
  
范围 for 循环是遍历容器或数组元素的一种非常便捷的方式，可以使代码更加简洁和清晰。

> [!tip] `auto`指针
> `for (auto& i : vec)`
