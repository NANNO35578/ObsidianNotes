# Linux 基础命令

- 终端可在任意目录下打开
- Linux 中一切皆为文件 不分盘符 从根目录 `/` 开始
- 文件夹大小为4096

1. `bin`存储可执行文件(命令)
2. `sbin` 对 `bin` 的补充
3. `boot` 启动文件夹 启动所需配置文件
4. `dev` 设备文件夹 
5. `etc` 配置
6. `home` 用户(非游客)文件夹
7. `lib` 库文件夹
8. `media` 媒体文件夹 
9. `mnt` 挂载文件夹
10. `opt` 第三方软件
11. `tmp` 临时的文件
12. `usr` 用户安装的软件

> [!note] `shell` 命令解释器
> 将命令解释成操作系统能听懂的语言 可用`cat /etc/shells` 查看内容
> 当前版本存储在全局变量 SHELL中 可使用`echo $SHELL` 查看

## 基本命令

1. `cd` 更改目录为 `cd ..` 返回父目录 `cd ./dir1` 进入当前目录下dir1文件夹
2. `pwd` 打印当前工作目录
3. `su <usrName>` 切换用户 `su` `su root` 均可切换为root 用户 提示符由$更换为#
4. `cat` 打印文件内容
5. `echo` 可打印字符串 加`"` 后可输入换行回车 在下一个`"`结束
6. `ls` 列出当前(指定)文件夹下文件 _-l_ 显示详细信息 _-a_ 显示隐藏文件 依次为文件类型及权限 所属用户 用户组 大小 时间 等
- 文件类型有 _-_ 普通文件 _d_ 目录 _l_ 符号链接 _b_ 块设备文件 _c_ 字符设备文件 _s_ socket文件，网络套接字 _p_ 管道
- 权限为三组$rwx$ 若为$-$则为无该权限 依次为文件创建者 同组用户 其他组用户的权限 可用三个八进制数表示
- `-R` 打印包含子目录文件

![[ls_l_a.png]]

7. `>` 重定向符号 将内容写入文件 覆盖
8. `touch` 创建文件 若存在 仅更新时间
9. `man` 查看某个命令作用 参数等
10. `which` 查看命令可执行文件位置
11. `mkdir` 创建文件夹 _-p_ 创建有所属关系的文件夹
12. `rmdir` 仅删除空文件夹
13. `tree` 树状打印文件夹文件
14. `rm` 删除任何文件 _-r_ 删除文件夹以及内容 _-f_ 不询问
15. `mv` 重命名/ 移动
16. `cp` 拷贝文件/文件夹(_-r_)
17. `wc` 计算文件byte数 -c 或 –bytes 或 –chars 只显示bytes数. -l 或 –lines 只显示列数.   -w 或 –words 只显示字数
18. `df` 查看磁盘使用情况
19. `whoami` 打印当前用户名
20. `chmod` 改变当前用户对目标文件的权限 如`chmod 0777 file1`
21. `chown` 改变文件创建用户以及所属组 如`sudo chown colin:colin file1`
22. `find` 查找文件 `find dir -name 'name'` name参数支持模糊查找
23. `grep` 检索文件内容 `grep 'content' dir -R` 循环检索dir路径下 _-i_ 不区分大小写 _-n_ 显示匹配到的行号
24. `zip -r dst.zip srcDir` `unzip src.zip`压缩/解压缩
25. `tar` 压缩包管理
	1. 主选项包括：_c_ 创建新的档案文件 _r_ 把要存档的文件追加到档案文件的末尾 _t_ 列出档案文件的内容，查看已经备份了哪些文件 _u_ 更新文件。用新增的文件取代原备份文件，如果在备份文件中找不到要更新的文件，则把它追加到备份文件的最后 _x_ 从档案文件中释放文件
	2. 辅选项包括：_f_ 使用档案文件或设备，这个选项通常是必选的 _k_ 保存已经存在的文件 _m_ 在还原文件时，把所有文件的修改时间设定为现在 _M_ 创建多卷的档案文件，以便在几个磁盘中存放 _v_ 详细报告tar处理的文件信息。如无此选项，tar不报告文件信息。（信息） _w_ 每一步都要求确认 _z_ 用gzip来压缩/解压缩文件，加上该选项后可以将档案文件进行压缩，但还原时也一定要使用该选项进行解压缩 _j_ 用bzip2来压缩/解压缩文件，加上该选项后可以将档案文件进行压缩，但还原时也一定要使用该选项进行解压缩 
- 要将文件备份到一个特定的设备，只需把设备名作为备份文件名。
- 打包/解包: `tar cvf dir.tar dir` `tar xvf dir.tar dir`
- gz压缩包: `tar zcvf dir.tar.gz dir` `tar zxvf dir.tar.gz`
- bz2压缩包: `tar jcvf dir.tar.bz2 dir` `tar jxvf dir.tar.bz2`
- 指定目录解压缩: `tar zxvf dir.tar.gz –C ~/test`

## __磁盘管理__

- 命令: `mount [-t vfstype] –o options device dir`
- `[-t vfstyle]`磁盘类型有     
	光盘或光盘镜像：iso9660
	DOS fat16文件系统：msdos
	Windows 9x fat32文件系统：vfat
	Windows NT ntfs文件系统：ntfs
	mount windows文件网络共享：smbfs
	UNIX(LINUX) 文件网络共享：nfs
- `-o options` 主要用来描述设备或档案的挂接方式。常用的参数有：
	loop：用来把一个文件当成硬盘分区挂接上系统
	ro：采用只读方式挂接设备
	rw：采用读写方式挂接设备
	 iocharset：指定访问文件系统所用字符集
	 device：要挂接（mount）的设备
	 dir设备在系统上的挂接点（mount point）。
- _挂载U盘_ 
	- 检测存储设备名称`sudo fdisk –l`
	- 挂载存储设备sdbl到挂载点/mnt目录`sudo mount /dev/sdb1 /mnt`
	- 访问/mnt 
	- 卸载/mnt `sudo umount /mnt`
- 卸载`sudo umount 挂载点`

## __进程管理__
1. `who` 查看当前用户
2. `ps` 监控后台进程
	- `ps aux` 
	![[psAux.png]]
	- 标头定义
		1. USER 用户名
		2. UID  用户ID（User ID）
		3. PID  进程ID（Process ID）
		4. PPID 父进程的进程ID（Parent Process ID）
		5. SID  会话ID（Session ID）
		6. %CPU 进程的CPU占用率
		7. %MEM 进程的内存占用率
		8. VSZ 进程所使用的虚存的大小（Virtual Size）
		9. RSS 进程使用的驻留集大小或者是实际内存的大小，kbytes字节
		10. TTY 与进程关联的终端（tty）
		11. STAT 进程的状态：进程状态使用字符表示的（STAT的状态码）
	
	_STAT_ 有

| 字符  | 英文名称                     | 描述                                                            |
| --- | ------------------------ | ------------------------------------------------------------- |
| R   | Runnable                 | 正在运行或在运行队列中等待。                                                |
| S   | Sleeping                 | 休眠中，受阻，在等待某个条件的形成或接受到信号。                                      |
| I   | Idle                     | 空闲                                                            |
| Z   | Zombie                   | 僵死（a defunct process），进程已终止，但进程描述符存在，直到父进程调用`wait4()`系统调用后释放。 |
| D   | Uninterruptible sleep    | 不可中断，收到信号不唤醒和不可运行，进程必须等待直到有中断发生。                              |
| T   | Terminate                | 停止，进程收到`SIGSTOP`、`SIGSTP`、`SIGTIN`、`SIGTOU`信号后停止运行。           |
| P   | Waiting for page swap    | 等待交换页                                                         |
| W   | No resident pages        | 无驻留页，没有足够的记忆体分页可分配。                                           |
| X   | Dead process             | 死掉的进程                                                         |
| <   | High priority process    | 高优先级进程                                                        |
| N   | Low priority process     | 低优先级进程                                                        |
| L   | Locked memory pages      | 内存锁页，有记忆体分页分配并锁在记忆体内。                                         |
| s   | Leader process           | 进程的领导者（在它之下有子进程）。                                             |
| l   | Multi-threaded           | 多进程的（使用 `CLONE_THREAD`，类似 NPTL pthreads）。                     |
| +   | Background process group | 位于后台的进程组                                                      |

## __用户管理__ 
1. 创建用户 
	- `sudo useradd –s /bin/bash –g colin –d /home/colin –m colin`
	  `sudo useradd –s /bin/sh –g group –G adm,root pzh`
	- 新建了一个用户pzh 该用户的登录shell是/bin/sh 属于group用户组 同时又属于adm和root用户组 其中group用户组是其主组 
	    -s 指定新用户登录时shell类型
	    -g 指定所属组，改组必须已经存在
	    -G 指定附属组，改组必须已经存在
	    -g 用户家目录
	    -m 用户家目录不存在时，自动创建该目录
2. `sudo passwd usrName` 设置密码
3. `sudo groupadd usrGroup` 设置用户组
4. `su usrName` 切换用户 `su` 无参数时切换为root用户
5. `sudo usrdel -r usrName` 删除用户以及主目录

`umask`（用户文件创建模式掩码）是一个用于设置默认文件权限的命令。它定义了在创建新文件和目录时，系统默认权限中应当“遮罩”掉的权限。


5. `umask` 查看当前umask值 通常是一个三位或四位的八进制数。
6. `umask <mask>` 设置umask值
- 权限说明
- 默认情况下，创建文件的权限通常是 `666`（rw-rw-rw-），而创建目录的权限是 `777`（rwxrwxrwx）。
>  如果 umask 设置为 `022` 那么新文件的权限将是 `644`(rw-r--r--) 新目录的权限将是 `755`(rwxr-xr-x) 这意味着，用户可以读写文件，组和其他用户只能读取。
- 常见的umask值
	- `000`: 所有用户都可以读、写、执行（不推荐）。
	- `022`: 用户可读写，组和其他用户可读（常用）。
	- `027`: 用户可读写，组可读，其他用户无权限（安全性较高）。
- `umask`只影响新创建的文件和目录，不会改变已有文件的权限。
- 可以在用户的Shell配置文件（如 `.bashrc` 或 `.bash_profile`）中设置umask，以便在每次登录时自动应用。
