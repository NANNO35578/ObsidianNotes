# 静态库/动态库
_静态库_ : 编译时直接拷贝到可执行文件中
_动态库_ : 编译时只拷贝链接库到可执行新文件中
 如有`st.lib`静态库, 有`dy.dll`动态库以及对应`dyLink.lib`动态链接库
现有app.exe 可执行文件两个库都调用了, 调用库`st.lib`是直接拷贝 而动态库`dy.dll`的使用则是拷贝动态链接库`dyLink.lib`, 其类似指针 指向动态库中的函数

##### 静态库/动态库 对比

|     | 优点                                                               | 缺点                                                                                       |
| --- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 静态库 | 1. 调用速度快<br>2. 发布方便                                              | 1. 导致可执行文件变大，<br>2. 若库文件修改了，需要重新编译库文件和整个可执行文件，耗时长<br>3. 当多个应用程序依赖同一个库文件，并且同时运行时，会拷贝多分到内存 |
| 动态库 | 1. 库文件修改，只需重新编译库文件，节省时间<br>2. 当多个应用程序依赖同一个库文件，并且同时运行时，只存在一份，节省内存 | 1. 调用速度慢(相对动态库)<br>2. 拷贝或者发布需要提供可执行文件和链接库                                                |

##### 使用
- 静态库使用：
	1. 包含头文件 
	2. 导入依赖库

- 动态库使用：
	1. 包含头文件
	2. 导入依赖库(动态链接库)
	3. 把dll文件拷贝到可执行文件相同路径下

## 服务器
> 服务器模板
```cpp
int main() {
  // 1.!加载库
  // 2.!创建套接字(UDP)
  // 3.!绑定端口和IP
  while (true) {
    // 4.!接受数据
    // 5.!发送数据
  }
  // 6.!关闭套接字_卸载库
  return 0;
}
```
