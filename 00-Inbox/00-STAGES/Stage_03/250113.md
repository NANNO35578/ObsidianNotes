# ISO/OSI 七层模型
##### ISO/OSI 开放式系统互连 _理论_ 模型
International Organization for Standardization
 / Open System Interconnection

系统： 功能完善，可二次开发
开放式： 开源，免费

![[OSI七层模型.png]]


## 应用层
>> 提供不同设备间相同应用程序间通信

常用协议
- HTTP/HTTPS : 端口80/443 HTTPS含有SSL加密，更安全. 网络是开放的，需要在数据传输之前进行加密
- FTP : 文件传输协议 端口21. 一般网盘会使用该协议
- DNS : Domain Name Server 域名解析协议
- DHCP : 动态主机控制协议 网络配置协议 用于终端设备动态获取IP地址
- Telnet 
- Smtp 
- SSH 

## 表示层
>> 提供数据格式转换服务, 如
- 数据加解密 : 发送端加密，接收端解密
- 数据解压缩 : 文件更小，传输更快
- 图片/视频编解码 : 专门对图片/视频进行压缩以及解压缩
## 会话层
>> 建立和管理维护会话(session)
- session会话管理 : web页面跳转账户信息存储在会话中
- 服务器验证用户登录 
- 断点续传 

## 传输层
>> 到达操作系统

==协议== : TCP/ UDP
__TCP__ 传输控制协议 
提供一种 _面向连接的_、_可靠的_、_基于字节流_ 的传输层通信协议 有流量控制和差错控制 用于数据稳定传输和完整性比较高的场景
__UDP__ 用户数据报协议
提供一种无连接的、高效率、低可靠性的数据传输服务 用于数据时效性比较高的场景

==线程== : 解决"同时"问题 并发*同步处理*
==端口== : 区分数据应传递给哪个应用程序 一程序可使用多个端口号. 网路设备上也有端口，但只是物理意上叫端口 _netstat -ano_ 可查看端口号 PID等 配合 _tasklist_ : Image Name   PID  Session Name  Session#    Mem Usage

==socket== : 通信的基石
包含进行网络通信必须的五种信息:连接协议 源IP 目的IP 源端口 目的端口

## 网络层
>> 并非所有网络设备都具有完整的OSI七层 例如路由器以及防火墙工作在网络层
>> 寻址 路由转发

IP : 网际协议 
查看网络配置 Windows :_ipconfig_  Linux : _ifconfig_ 

## 数据链路层
>> 网路设备:交换机 网卡     提供链路管理 物理寻址 重发

MAC地址 设备物理编号标识
交换机通过MAC地址表交换数据 简单内部转发
![[macAddrTable.png]]

## 物理层
>> 光纤 网线

==光纤== : 传播光信号 传播速度快 远距离消耗小
==网线== : 传播电信号 有损耗



> [!tip]  ha
>  数据到了网络层叫 IP数据报 
>  到了数据链路层叫 数据帧
>  到了物理层 为 01比特流
