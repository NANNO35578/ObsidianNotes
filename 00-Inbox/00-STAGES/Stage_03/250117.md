## 子网掩码
> 又叫网络掩码 地址掩码 子网络遮罩 将子网掩盖 不被窥探

例如: 24位子网掩码 255.255.255.0 ==按位与&(有0为0)==IP地址192.168.10.126 就可以得到 _网络号_ 主机号变0

![[子网掩码.png]]

## 网关
> 网间连接器 协议转换器. 
> 网间连接器 就是连接两个子网之间的 _设备或软件_ 如路由器具有网关功能 都是具有路由功能的IP地址 就是说网关必须要有路由功能 默认的主机号都是0,这样的才是网关。

## 广播地址
> 用于向网络中的所有的设备进行广播。具有正常的网络号部分 而 _主机号部分全为1_ 的IP地址称之为 _(直接)_ 广播地址 ==全0默认为网关==

_有限广播地址_ :指的是32位全位1(即255.255.255.255)的IP地址 用于本网广播
_直接广播地址_ 可在其他指定广播域发广播 而有限广播地址只能在自己的广播域发广播


## 非默认子网掩码
> 网络号比该类默认子网掩码长 从主机号借几位过来作为网络号 _(子网号)_

![[非默认子网掩码.png]]

> [!bug] 子网划分常见问题

1. _选定的子网掩码将创建多少个子网?_
	$2^X$个，其中$X$是子网掩码借用的主机位数
	如:192.168.10.32/28，28:网络 号 C类IP的默认子网掩码为: 25x5.255.255.0 24位网络号，借用了主机位4位来充当子网号 实际子网掩码:255.255.255.240，可创建的子网个数就是$2^4=16$
2. _每个子网可包含多少台主机?_
	$2^Y-2$台，其中$Y$是剩余主机位的位数。-2 主机位全为0默认作为网关，全为1作为子网的广播地址
3. _有哪些子网?_
	一个例子是算出子网的步长(增量)。$256-248=8$，即子网掩码为248时，步长为8从0开始不断增加中间的结果就是子网，直到到达子网掩码值，即0、8、16、32...

# IP首部格式
IP工作在网络层

[IPv4 Header](https://networklessons.com/cisco/ccna-routing-switching-icnd1-100-105/ipv4-packet-header)

![[IPv4首部.png]]

_每行4字节(32位)_
首部长度20~60字节 : 固定部分20字节 可选部分0~40字节 且必须为4字节倍数

- _版本_ : v4 v6
- _首部长度_ : IP首部长度大小 配合总长度可计算出数据长度
- _区分服务_ : 
- _片偏移_ : 标记当前包的编号
- _标识_ : 标记当前包属于哪一个大包
- _标志_ : 区分当前是否为最后一个包(后续是否有包) 
- _生存时间_ : 最大生存跳数
- _协议_ : TCP/IP
- _首部校验和_ : 基本都有(ARP无) 检验当前IP数据报是否出错(有篡改) 

> 可变部分
> TVL Type-Value-Length 有些设备无传输层等 但是需要传数据

# 以太网Ⅱ帧结构

![[以太网帧结构.png]]
目标MAC(6) 源MAC(6) 类型(2)  数据(46~1500) 帧校验(4) 
数据(46~1500)MTU = IP首部(20~60) + TCP首部(20~60) + 用户数据MSS
以太网帧大小范围 64~1518

_MTU_ : 一个网络包最大长度 _以太网_ 中一般为1500字节
_MSS_ : 出去IP首部以及TCP首部 一个网络包所能容纳的最大TCP数据长度
