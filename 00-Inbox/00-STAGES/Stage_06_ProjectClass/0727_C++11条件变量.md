## `wait()`
1. `void wait(unique_lock<mutex>& __lock);` : 参数为已上锁的unique_lock, 函数执行时,阻塞调用线程, 释放锁, 等待条件变量通知. 通知到来(不保证先后), 先获取互斥锁, 然后解放阻塞, 开始往下执行
2. `void wait(unique_lock<mutex>& __lock, _Predicate __p)` : 第二参数为虚假唤醒时判断的可调用对象. 例如线程池中判断线程池是否关闭, 作为消费者, 任务队列是否为空可作为判断.
```cpp
    template<typename _Predicate>
    void wait(unique_lock<mutex>& __lock, _Predicate __p) {
		while (!__p())
		  wait(__lock);
    }
```


*虚假唤醒* : 由于系统调度或系统中断, 可能导致线程状态异常, 从而虚假唤醒(条件变量未发送, wait返回)
## `notify`
1. `notify_one()` : 相当于`pthread_cond_signal(pthread_cond_t*)`
2. `notify_all()` : 相当于`pthread_cond_broadcast(pthread_cond_t*)`

# `lambda` 表达式

允许在函数内部定义*匿名函数*，可以在需要时直接传递或调用，适用于临时的函数对象，简化代码，尤其在STL算法中非常常见

##### 1. 基本语法：
```cpp
[捕获列表](参数列表) -> 返回类型 {
    // 函数体
}
```
* **捕获列表**：指定lambda函数如何访问外部变量
* **参数列表**：定义lambda函数的参数（可选）
* **返回类型**：可选，指定返回值的类型，如果推断不了，可以手动指定
* **函数体**：lambda表达式的主体部分，定义了执行的内容

##### 2. 捕获列表：
捕获列表用于指定lambda函数如何访问外部作用域中的变量。它有几种写法：
* **`[]`**：不捕获任何变量
* **`[=]`**：按值捕获所有外部变量
* **`[&]`**：按引用捕获所有外部变量
* **`[var]`**：按值捕获指定的`var`变量
* **`[=, &var]`**：按值捕获所有变量，但按引用捕获`var`
* **`[this]`**：捕获当前对象的`this`指针

##### 3. `mutable`关键字：

`mutable` 关键字是lambda表达式的一个特性，表示即使lambda按值捕获了外部变量，lambda函数体内仍然可以修改这些变量

通常，lambda表达式按值捕获外部变量时，这些变量的值会被复制到lambda中，并且默认情况下，lambda无法修改这些复制的变量。然而，如果在lambda的定义中使用了`mutable`关键字，就可以修改这些按值捕获的外部变量。

* **关键点**：虽然`x`被按值捕获，但由于`mutable`关键字，它在lambda内部被允许修改。修改只会影响lambda函数内部的`x`，外部的`x`值保持不变。
主要用于:
* 需要修改lambda内部捕获的外部变量，但又希望捕获时不通过引用
* 在需要为lambda定义一些状态时，且该状态是临时的、仅供lambda函数内部使用

##### 4. 返回类型推导：
- 在C++14及以后的版本中，lambda表达式的返回类型可以自动推导，无需手动指定

# `std::bind`& `std::function` 

可调用对象有:
1. 函数指针
2. 重载`()`的类对象*仿函数*
3. lambda表达式
4. 可被转换为函数指针的类对象
5. 类成员函数指针
6. bind表达式或其他function对象

`std::function` 就是对可调用对象的封装器


## `std::bind`

- 将可调用对象与`std::function`绑定
- 对于lambda表达式, 绑定时不能带`&`
- 可提前绑定部分参数, 简化函数调用
- 可将对象的与类成员函数绑定

1. 全部绑定, 此时返回值为`std::function<void()>`
2. 部分绑定, 缺省的参数使用`std::placeholder::_1`替代, 再次调用时加入参数, 例:
```cpp
int add(int a, int b) { return a + b; }

int main(int argc, char const *argv[]) {
  auto lambdaFunc = [](int a, int b) { return a + b; };
  std::function<int(int, int)> lambdaFunc = [](int a, int b) { return a + b; };

  std::function<int(int)>      labf       = std::bind(lambdaFunc, 2, std::placeholders::_1);
  std::function<int(int)>      funcAdd    = std::bind(&add, 2, std::placeholders::_1);

  return 0;
}
```
