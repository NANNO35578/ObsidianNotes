##### 腾讯云为例

1. 购买配置, 开机. 默认为root用户, 密码为购买时设置的


##### visual studio code 使用SSH连接:
1. Remote-SSH: Add New SSH Host
2. 输入连接字符串，格式为：`{bash}ssh root@43.140.216.192` 
3. 选择 SSH 配置文件, 一般是 `~/.ssh/config`. 然后就可以连接
4. 选Linux, 输入root用户密码

5. 设置普通用户
```bash title:"添加普通用户, 添加到 sudoers"
adduser usr25 # 按照提示输入新用户的密码和其他信息, 如全名、电话等. 按 `Enter` 跳过不需要的信息
usermod -aG sudo usr25 # 将 `usr25` 添加到 `sudo` 组
```



##### 上传文件到服务器
**SFTP**
1. **连接到服务器**: `{bash}sftp usr25@43.140.216.192` 
2. 输入usr25 的密码
3. **使用 `put` 命令上传文件夹**: `{bash}put -r ./directory /home/usr25/directory`



##### 安装MySQL 同 [[WSL 安装 MySql]] 
##### 安装uwf
- 设置3306端口开发`{bash}sudo ufw allow 3306` 同理开放其他端口. 启动MySQL服务即可本地使用MySQL workbench连接. 可参考[[workbench连接到WSL中的MySQL数据库]] 
##### 在腾讯云的安全组中编辑出站入站规则
- 开放TCP:3306入站, 若有其他端口需要连接, 同理开放入站. 出栈默认全部通过.
- 查看端口哪个程序在使用某端口: `{bash}sudo netstat -tulnp | grep 33060`
