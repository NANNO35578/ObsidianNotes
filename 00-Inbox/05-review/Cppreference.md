##### [cppreference.com](https://en.cppreference.com/index.html)


`cppreference.com` 不是 C++ 官方网站，但它是 C++ 社区中最受欢迎、最权威的参考网站之一，尤其在开发者中广泛使用。它提供了详细的 C++ 标准库文档、语言特性解释以及 C++17、C++20 等版本的变化。`cppreference` 是由志愿者社区维护的，确保了其内容的更新和准确性。

##### 权威的 C/C++ 参考网站有哪些？

1. **C++ 官方网站**
   [C++ 官方网站 (isocpp.org)](https://isocpp.org/)
   这个网站由 C++ 标准委员会维护，提供有关 C++ 语言的各种资源。它包含 C++ 的标准文档、新闻、文章、教程等。

2. **C++ 标准文档**
   [ISO C++ 标准文档](https://www.iso.org/standard/68564.html)
   这是 C++ 语言和库的官方标准。虽然这个网站本身并不提供免费的标准文档，但你可以购买完整的 ISO C++ 标准文档。

3. **cppreference.com**
   [cppreference.com](https://cppreference.com/)
   这是 C++ 开发者常用的一个参考网站，提供 C++ 语言和库的全面文档。它的优点是快速、全面，且更新及时。

4. **cplusplus.com**
   [cplusplus.com](http://www.cplusplus.com/)
   这是另一个受欢迎的 C/C++ 参考网站，提供 C++ 标准库、教程和示例代码。不过，它的更新频率相对较低，某些新版本的特性可能没有及时更新。

5. **GNU C++ 文档**
   [GNU C++ Library Documentation](https://gcc.gnu.org/onlinedocs/libstdc++)
   这是 GNU 编译器工具链（GCC）的官方标准库文档。如果你使用 GCC 编译器，它是一个很有用的参考。

6. **C++ Core Guidelines**
   [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines)
   由 C++ 标准委员会成员（如 Bjarne Stroustrup）和 C++ 社区的其他专家编写，涵盖了 C++ 编程的最佳实践、代码风格和性能优化建议。

### 总结

* **官方标准**：ISO C++ 的标准文档（需要购买）。
* **社区推荐**：`cppreference.com` 是开发者最常使用的参考网站，内容全面且更新及时。
* **其他参考**：`cplusplus.com` 提供了 C++ 的基础教程和库，但更新不如 `cppreference` 及时。

在实际开发中，`cppreference.com` 是最为权威和方便的文档之一，适合开发者查阅细节。如果你希望深入了解标准或获取最新的版本信息，可以参考 C++ 官方网站和 C++ Core Guidelines。
