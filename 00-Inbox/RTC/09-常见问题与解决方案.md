# 第九章：常见问题与解决方案

## 9.1 延迟问题

### 9.1.1 问题表现

- 说话后延迟很久才听到回音
- 视频动作延迟
- 交互不流畅

### 9.1.2 原因分析

#### 网络延迟

- **物理距离**：距离远导致延迟高
- **网络拥塞**：网络拥堵导致延迟增加
- **路由问题**：路由路径不优

#### 处理延迟

- **编码延迟**：编码处理时间长
- **解码延迟**：解码处理时间长
- **缓冲延迟**：播放缓冲过大

### 9.1.3 解决方案

#### 网络优化

```javascript
// 1. 选择就近服务器
const servers = [
  { region: 'us-east', latency: 50 },
  { region: 'us-west', latency: 80 },
  { region: 'asia', latency: 120 }
];
const bestServer = servers.reduce((a, b) => 
  a.latency < b.latency ? a : b
);

// 2. 使用低延迟传输
const transport = {
  protocol: 'udp',        // 使用UDP
  tcpCandidate: false,    // 不使用TCP
  iceTransportPolicy: 'relay' // 优先使用中继
};
```

#### 编码优化

```javascript
// 低延迟编码配置
const lowLatencyConfig = {
  // 减少B帧
  bFrames: 0,
  
  // 降低GOP
  keyFrameInterval: 30,  // 1秒一个关键帧
  
  // 使用低延迟模式

```

#### 播放优化

```javascript

  if (networkQuality === 'good') {
    // 网络好，减少缓冲
    setBufferSize(100);  // 100ms
  } else {
    // 网络差，增加缓冲
    setBufferSize(300);  // 300ms
  }
}
```

## 9.2 卡顿问题

### 9.2.1 问题表现

- 视频播放不流畅
- 画面停顿
- 音频断断续续

### 9.2.2 原因分析

#### 网络问题

- **带宽不足**：带宽不够导致数据接收慢
- **丢包率高**：丢包导致需要重传
- **网络抖动**：网络不稳定

#### 设备问题

- **CPU不足**：解码处理不过来
- **内存不足**：内存不够用
- **GPU不足**：渲染处理不过来

#### 编码问题

- **码率过高**：超出网络能力
- **分辨率过高**：超出设备能力
- **帧率过高**：超出处理能力

### 9.2.3 解决方案

#### 自适应调整

```javascript
// 检测卡顿并调整
class StutterDetector {
  constructor() {
    this.frameDrops = 0;
    this.lastFrameTime = 0;
  }
  
  detectStutter(currentFrameTime) {
    const frameInterval = currentFrameTime - this.lastFrameTime;
    const expectedInterval = 1000 / 30; // 30fps
    
    if (frameInterval > expectedInterval * 2) {
      this.frameDrops++;
      return true;
    }
    
    this.lastFrameTime = currentFrameTime;
    return false;
  }
  
  handleStutter() {
    if (this.frameDrops > 5) {
      // 降低质量
      decreaseQuality();
      this.frameDrops = 0;
    }
  }
}
```

#### 码率自适应

```javascript
// 根据卡顿情况调整码率
function adjustBitrateForStutter(stutterCount) {
  if (stutterCount > 10) {
    // 严重卡顿，大幅降低码率
    currentBitrate *= 0.7;
  } else if (stutterCount > 5) {
    // 中等卡顿，适度降低码率
    currentBitrate *= 0.85;
  } else if (stutterCount === 0) {
    // 无卡顿，可以尝试提高码率
    currentBitrate *= 1.1;
  }
  
  // 限制码率范围
  currentBitrate = Math.max(minBitrate, 
    Math.min(maxBitrate, currentBitrate));
}
```

#### 帧率自适应

```javascript
// 根据性能调整帧率
function adjustFrameRate(cpuUsage, gpuUsage) {
  if (cpuUsage > 80 || gpuUsage > 80) {
    // 性能不足，降低帧率
    targetFrameRate = Math.max(15, targetFrameRate - 5);
  } else if (cpuUsage < 50 && gpuUsage < 50) {
    // 性能充足，可以提高帧率
    targetFrameRate = Math.min(60, targetFrameRate + 5);
  }
}
```

## 9.3 音画不同步

### 9.3.1 问题表现

- 说话和口型不匹配
- 音频和视频时间差明显
- 同步问题逐渐累积

### 9.3.2 原因分析

#### 处理延迟不同

- **编码延迟**：音频和视频编码延迟不同
- **解码延迟**：音频和视频解码延迟不同
- **网络延迟**：音频和视频网络延迟不同

#### 播放速度不同

- **播放速度**：音频和视频播放速度不一致
- **缓冲不同**：音频和视频缓冲不同
- **时钟不同**：音频和视频时钟不同步

### 9.3.3 解决方案

#### 时间戳同步

```javascript
// 音视频同步
class AVSynchronizer {
  constructor() {
    this.audioTime = 0;
    this.videoTime = 0;
    this.syncThreshold = 40; // 40ms
  }
  
  updateAudioTime(timestamp) {
    this.audioTime = timestamp;
    this.sync();
  }
  
  updateVideoTime(timestamp) {
    this.videoTime = timestamp;
    this.sync();
  }
  
  sync() {
    const diff = this.audioTime - this.videoTime;
    
    if (Math.abs(diff) > this.syncThreshold) {
      if (diff > 0) {
        // 音频快，加快视频或减慢音频
        this.speedUpVideo();
      } else {
        // 视频快，加快音频或减慢视频
        this.speedUpAudio();
      }
    }
  }
  
  speedUpVideo() {
    videoElement.playbackRate = 1.01; // 稍微加快
  }
  
  speedUpAudio() {
    audioElement.playbackRate = 1.01; // 稍微加快
  }
}
```

#### 统一时钟

```javascript
// 使用统一时钟基准
class UnifiedClock {
  constructor() {
    this.baseTime = Date.now();
    this.audioOffset = 0;
    this.videoOffset = 0;
  }
  
  getCurrentTime() {
    return Date.now() - this.baseTime;
  }
  
  syncAudio(timestamp) {
    const currentTime = this.getCurrentTime();
    this.audioOffset = timestamp - currentTime;
  }
  
  syncVideo(timestamp) {
    const currentTime = this.getCurrentTime();
    this.videoOffset = timestamp - currentTime;
  }
  
  getSyncedAudioTime() {
    return this.getCurrentTime() + this.audioOffset;
  }
  
  getSyncedVideoTime() {
    return this.getCurrentTime() + this.videoOffset;
  }
}
```

## 9.4 网络抖动处理

### 9.4.1 问题表现

- 延迟不稳定
- 数据包到达时间不一致
- 播放不流畅

### 9.4.2 原因分析

- **网络拥塞**：网络流量大
- **路由变化**：路由路径变化
- **无线网络**：WiFi信号不稳定

### 9.4.3 解决方案

#### 抖动缓冲（Jitter Buffer）

```javascript
// 抖动缓冲
class JitterBuffer {
  constructor() {
    this.buffer = [];
    this.targetDelay = 100; // 100ms目标延迟
    this.maxDelay = 300;   // 300ms最大延迟
  }
  
  addPacket(packet) {
    this.buffer.push({
      data: packet,
      arrivalTime: Date.now(),
      timestamp: packet.timestamp
    });
    
    // 按时间戳排序
    this.buffer.sort((a, b) => a.timestamp - b.timestamp);
  }
  
  getPacket() {
    if (this.buffer.length === 0) return null;
    
    const now = Date.now();
    const firstPacket = this.buffer[0];
    const delay = now - firstPacket.arrivalTime;
    
    if (delay >= this.targetDelay) {
      // 达到目标延迟，可以播放
      return this.buffer.shift().data;
    }
    
    // 延迟过大，丢弃旧包
    if (delay > this.maxDelay) {
      this.buffer.shift();
      return this.getPacket();
    }
    
    return null; // 还需要等待
  }
  
  adjustTargetDelay(networkJitter) {
    // 根据网络抖动调整目标延迟
    if (networkJitter > 50) {
      this.targetDelay = Math.min(200, this.targetDelay + 10);
    } else if (networkJitter < 20) {
      this.targetDelay = Math.max(50, this.targetDelay - 10);
    }
  }
}
```

#### 网络平滑

```javascript
// 网络延迟平滑
class NetworkSmoother {
  constructor() {
    this.delays = [];
    this.windowSize = 10;
  }
  
  addDelay(delay) {
    this.delays.push(delay);
    if (this.delays.length > this.windowSize) {
      this.delays.shift();
    }
  }
  
  getSmoothedDelay() {
    if (this.delays.length === 0) return 0;
    
    // 计算平均值
    const sum = this.delays.reduce((a, b) => a + b, 0);
    return sum / this.delays.length;
  }
  
  getJitter() {
    if (this.delays.length < 2) return 0;
    
    // 计算延迟方差
    const mean = this.getSmoothedDelay();
    const variance = this.delays.reduce((sum, delay) => {
      return sum + Math.pow(delay - mean, 2);
    }, 0) / this.delays.length;
    
    return Math.sqrt(variance);
  }
}
```

## 9.5 回声问题

### 9.5.1 问题表现

- 听到自己的声音
- 声音循环
- 通话质量差

### 9.5.2 原因分析

- **扬声器声音被麦克风采集**：免提通话常见
- **AEC未启用或配置不当**：回声消除未工作
- **设备问题**：设备硬件问题

### 9.5.3 解决方案

#### 启用AEC

```javascript
// 启用回声消除
const constraints = {
  audio: {
    echoCancellation: true,    // 启用AEC
    noiseSuppression: true,    // 启用降噪
    autoGainControl: true     // 启用自动增益
  }
};

navigator.mediaDevices.getUserMedia(constraints)
  .then(stream => {
    // 使用stream
  });
```

#### 音量控制

```javascript
// 控制音量，避免回声
function adjustVolumeForEcho(echoLevel) {
  if (echoLevel > threshold) {
    // 回声大，降低播放音量
    audioElement.volume = Math.max(0.3, audioElement.volume - 0.1);
  } else {
    // 回声小，可以恢复音量
    audioElement.volume = Math.min(1.0, audioElement.volume + 0.05);
  }
}
```

## 9.6 黑屏/花屏问题

### 9.6.1 问题表现

- 视频画面黑屏
- 画面花屏
- 画面显示异常

### 9.6.2 原因分析

- **关键帧丢失**：I帧丢失导致无法解码
- **解码错误**：数据损坏导致解码失败
- **格式不匹配**：编码格式不支持

### 9.6.3 解决方案

#### 关键帧保护

```javascript
// 关键帧快速重传
class KeyFrameProtection {
  constructor() {
    this.lastKeyFrameTime = 0;
    this.keyFrameInterval = 30000; // 30秒
  }
  
  requestKeyFrame() {
    // 请求关键帧
    sendKeyFrameRequest();
    this.lastKeyFrameTime = Date.now();
  }
  
  checkKeyFrame() {
    const timeSinceLastKeyFrame = Date.now() - this.lastKeyFrameTime;
    if (timeSinceLastKeyFrame > this.keyFrameInterval) {
      // 超过间隔，请求关键帧
      this.requestKeyFrame();
    }
  }
}
```

#### 错误恢复

```javascript
// 解码错误恢复
```
