## 📋 接口说明

### POST /api/ocr/recognize
- **功能**：上传图片/PDF进行OCR识别
- **请求**：multipart/form-data，`file`字段
- **响应**：立即返回 `file_id` 和 `processing` 状态
- **支持格式**：jpg, jpeg, png, bmp, webp, pdf

### GET /api/ocr/status?file_id={id}
- **功能**：查询OCR处理状态
- **响应**：包含处理状态，若完成则包含 `note_id`

---

## 🔄 业务流程

```
上传文件 → 创建记录(processing) → OCR识别 → 创建笔记 → MinIO上传 → 更新状态(done)
```

1. 接收 multipart 文件上传
2. 插入 `file_resource` 表，`status = processing`
3. 调用第三方OCR API（Base64编码）
4. 根据识别结果创建笔记（标题=文件名，内容=markdown）
5. 异步上传原始文件到 MinIO
6. 更新 `file_resource`：`note_id`, `url`, `status = done`
