# vi     
Vi有三种基本工作模式
- 命令模式
- 文本输入模式
- 末行模式
![[vimKeyMap.jpg]]
##### 部分命令
1. `Ctr-d` : 向下翻半屏
2. `Ctr-u` : 向上翻半屏
3. `Ctr-f` : 向下翻一屏
4. `Ctr-b` : 向上翻一屏
5. `d0` : 删除光标前本行所有内容,不包含光标所在字符
6. `.` : 重复上一次操作的命令
7. `>>` : 文本行右移
8. `<<` : 文本行左移
9. `:%s/abc/123/g` 字符串替换
10. 查看 Man Page: 光标移动到函数上 `Shift+k` 光标移动到函数上 `3 Shift+k` 查看第三章的 Man Page
11. `[-d` : 可以查看宏定义,必须先包含此宏所在的头文件
12. _vim里执行 shell 下命令_: `:!command`
##### 分屏操作
`sp`: 上下分屏,后可跟文件名
`vsp`: 左右分屏,后可跟文件名
`Ctr+w+w`: 在多个窗口切换

启动分屏:
1. `$ vim -On file1 file2 ... ` 使用大写O参数进行垂直分n屏
2. `$ vim -on file1 file2 ...` 使用小写o参数进行水平分n屏

关闭分屏
1. `ctrl+w c` 关闭当前窗口
2. `ctrl+w q` 关闭当前窗口，如果只剩最后一个，则退出vim

编辑中分屏
1. `ctrl+w s` 上下分割当前打开的文件
2. `:sp filename` _上下分割，并打开一个新的文件_
3. `ctrl+w v` 左右分割当前打开的文件
4. `:vsp filename` _左右分割，并打开一个新的文件_

分屏编辑中光标的移动
vi中的光标键是h,j,k,l,要在各个屏之间切换，只需要先按一下`ctrl+w`
1. `ctrl+w h/j/k/l` 把光标移动到左/下/上/右边的屏
2. `ctrl+w w` 把光标移动到下一个的屏
3. `ctrl+w H/J/K/L` 向左/下/上/右移动分屏

屏幕尺寸
1. `ctrl+w +` 增加高度
2. `ctrl+w` 减少高度
3. `ctrl+w =` 让所有屏的高度一致
4. `ctrl+w >` 左加宽度
5. `ctrl+w <` 右加宽度
6. `ctrl+w n <` 右增加n宽 (如：n=30)

# `gcc` 编译c代码
1. `gcc main.c -o mainOut` 编译生成可执行文件mainOut
2. 其他参数 :
	- `-v` / –v / –version 查看gcc版本号
	- `-I` _指定头文件目录_，注意-I和参数之间 _没有_ 空格
	- `-c` _只编译，生成.o文件_，不进行链接
	- `-g` 包含调试信息 
	- `-On` n=0∼3 编译优化，n越大优化得越多
	- `-Wall` 提示更多警告信息
	- `-D` 编译时定义宏，注意-D和之间没有空格
	- `-E` 生成预处理文件
	- `-M` 生成.c文件与头文件依赖关系以用于Makefile，包括系统库的头文件
	- `-MM` 生成.c文件与头文件依赖关系以用于Makefile，不包括系统库的头 

> 对以下简单文件编译 使用 
> `g++ main.cpp add.cpp dec.cpp mul.cpp sub.cpp -o mainOut -I../include`

# `gdb` 调试
- 在编译源代码时加入调试参数`-g` 使用`gdb`启动可执行文件 即可开始调试
![[gdb.png]]
- `l` 显示10行 参数n 为显示的中间行号
- `start` 开始调试 若未加断点 自动停在main函数开始处
- `next` 1 逐过程 不进入函数 enter可重复操作
- `step` 逐语句 可进入函数
- `p` 打印变量值
- `display` 固定变量 `display` 取消固定加变量编号
- `run` 继续 到下一个断点或直到结尾
- `b` 参数加函数名 或者行号
- `info breakpoints` 显示断点 触发次数
- `disable num` 暂时禁用断点num `enable` 
- `q` 退出

# `make` 自动化构建过程
`makefile` 一种用于自动化构建过程的文件，通常与 `make` 工具一起使用 定义了一系列的规则和依赖关系 指导如何编译和链接程序

优点:
1. 便捷的管理代码,不需要每次都书写复杂的编译命令
2. 复用性极强,可以反复使用管理不同的工程
3. 节省编译时间

- 编译时间=(预处理+编译+汇编)
编译期: 每个源文件对应生成一个.o文件 
链接期: 把所有.o文件和依赖的库文件链接生成可执行文件

- makefile是才用 _空间换时间_ 的方式节省编译时间。
第一次编译的时候不会节省时间,但是会保存所有生成的.o文件;
下一次编译的时候,编译器只重新编译 _修改的源文件_
其他没有修改的源文件不重新编译 使用保存的.o链接生成可执行文件

- 编译器怎么识别哪个源文件被修改的?
比较源文件的修改时间和.o文件的生成时间

> [!bug] 注意
> 1. 文件名必须以makefile或者Makefile命名
> 2. 注释使用 # 
> 3. make命令执行当前路径下的makefile文件
> 4. 向下建立依赖关系
> 5. 只有一个目标 若有多个则目标之间需要主从关系

##### makefile三要素:
1. 目标:makefile的目标是完成编译,生成可执行文件,目标就是可执行文件的名字
2. 依赖:编译依赖的源文件或者资源文件
3. 命令:生成最终目标需要执行的命令

##### 变量
1. 自定义变量: 无需指定类型默认是字符串类型 变量名可以由大小写字母、数字、下划线构成,但是不能以数字开头,为了与高级语言区分,一般使用全大写命名 _使用变量_:`$(变量名)`
2. 特殊变量(内置变量): 
	- `$@` :代表目标的名字
	- `$^` :代表所有依赖项
	- `$<` : 代表依赖项中的第一项

##### 内置函数和内建语法:
1. 文件名获取函数:`wildcard`
	`SRCFILE=$ (wildcard \*.c)`
	使用wildcard获取当前路径下所有.c文件的名字,赋值给变量SRCFILE
2. 字符串处理函数:`patsubst`
	`DSTFILE=$(patsubst %.c, %.o, $ (SRCFILE))`
	使用patsubst把变量SRCFILE中保存的文件的名字后缀.c替换成.o 赋值给DSTFILE
3. 内建语法
```makefile
%.o:%.c
	命令
```

##### 功能命令
无依赖
```makefile
output:
    echo "hahaha"

clean:
    rm -rf $(TARGET) $(DSTFILE)

install:
    sudo cp $(TARGET) $(INSTALL_PATH)

disclean:
    sudo rm -rf $(INSTALL_PATH)/$(TARGET)
```
##### 格式:
```makefile
目标:依赖
(Tab)命令
```
