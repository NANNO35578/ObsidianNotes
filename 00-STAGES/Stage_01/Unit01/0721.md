# `scanf`格式化输入

> [!bug] `scanf`不安全
> ```c
> #define _CRT_SECURE_NO_WARNINGS  //或者关闭安全警告
> #include <stdio.h>
> 
> int main(){
> 	int a; int b;
> 	scanf("%d",&a);// VS 2019 提示不安全
> 	scanf_s("%d",&b);// 或者使用安全的函数
> 	
> 	return 0;
> }
> ```

- `scanf`返回值为正确读取的数据个数
- `scanf`格式化对于`flout`以及`double`类型分别使用`%f`以及`%lf`
- `scanf`对于整型读取 空格以及enter作合法间隔
