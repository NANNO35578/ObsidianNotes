# 滑动窗口

> [!quote] 239滑动窗口
> 给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。返回 _滑动窗口中的最大值_ 。
> 

> 构造一个max双向队列 首先取队列首元素入队列 
> 接下来k个元素 与队首比较 若大于队首 清空队列 压入该元素
> 若小于等于该队首 与队尾比较 若队尾小于该元素 弹出队尾 再比较直到队尾大于等于该元素 压入该元素

> 当遍历了k个元素 再来元素时 与队首比较 
> 若小于队首

 2. `maxOfVec` 方法

```cpp
std::vector<int> maxOfVec(const std::vector<int>& vec) {
    auto max = std::max_element(vec.begin(), vec.end());
    return {*max};  // 返回最大值
}
```

- **功能**：这个辅助方法用于找出给定向量 `vec` 的最大值，并返回一个包含该最大值的向量。
- **实现**：
  - 使用 `std::max_element` 找到 `vec` 中的最大元素。
  - 返回一个包含最大值的向量（如 `{max}`）。

## 3. `maxSlidingWindow` 方法

```cpp
std::vector<int> maxSlidingWindow(std::vector<int>& nums, int k) {
    if (k >= nums.size()) return maxOfVec(nums);
    if (k == 1) return nums;
```

- **功能**：计算在长度为 `k` 的滑动窗口中，每个窗口的最大值。
- **边界条件**：
  - 如果 `k` 大于等于 `nums` 的长度，返回整个数组的最大值。
  - 如果 `k` 等于 1，直接返回 `nums` 因为每个窗口只有一个元素，最大值就是这个元素本身。

 4. 初始化数据结构

```cpp

```

- **`maxDeque`**：双端队列，用于存储当前窗口中可能的最大值的索引。保持索引的顺序有助于快速访问最大值。
- **`res`**：结果向量，用于存储每个窗口的最大值。

- 遍历 `nums` 数组的每个元素。

## 5.1 移除过期的元素

```cpp
if (!maxDeque.empty() && maxDeque.front() == i - k) {
    maxDeque.pop_front();
}
```

- 检查队列的前端是否存储的索引已经超出了当前窗口的范围（`i - k` 是当前窗口的最左边元素的索引）。
- 如果是，则移除该索引。

## 5.2 维护 `maxDeque`

```cpp
while (!maxDeque.empty() && nums[maxDeque.back()] < nums[i]) {
    maxDeque.pop_back();
}
```

- 移除队列中所有小于当前元素 `nums[i]` 的索引，确保 `maxDeque` 始终保存当前窗口内的最大值索引。

## 5.3 添加当前元素的索引

```cpp
maxDeque.push_back(i);
```

- 将当前元素的索引添加到 `maxDeque` 中。

 5.4 记录当前窗口的最大值

```cpp
if (i >= k - 1) {
    res.push_back(nums[maxDeque.front()]);
}
```

- 当 `i` 达到 `k - 1` 及以上时，说明当前窗口已经形成，记录窗口的最大值（即 `maxDeque` 的前端最大值的对应元素）。

 6. 返回结果

```cpp
return res;
```

- 返回所有窗口的最大值组成的结果向量。

# 总结

这段代码利用双端队列有效地维护滑动窗口的最大值，确保每次窗口滑动时都能快速更新最大值。时间复杂度为 O(n)，因为每个元素最多进入和离开双端队列一次。
