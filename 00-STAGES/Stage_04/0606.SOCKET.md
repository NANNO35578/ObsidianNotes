- 一般用于网络应用开发,系统提供的一套API函数接口,成为套接字函数,网络应用开发是软件开发工程师必备技能
- Linux中everything is file, 将所有的设备访问方式抽象为文件,可以通过文件描述符访问大多数Linux设备。socket也为文件

`socket_fd` 含有IP地址 端口(Port)
	IP v4 `AF_INET`
	IP v6 `AF_INET6`
常见端口80(http) 443(https) 53(dns) 20,21(ftp) 
自定义端口大于5000(1024)

##### 结构体
```cpp
struct sockaddr_in addr; //网络信息结构体类型

addr.sin_family = AF_INET;
addr.sin_port= 大端(8080);
addr.sin_addr.s_addr= 大端(ip);

htons(); //小端转大端端口
htonl(); //小端转大端IP
ntohs(); //大端转小端端口
ntohl(); //大端转小端IP

inet_pton(AF_INET, char * ip, void * addr); // "192.168.10.1" -> addr 
inet_ntop(AF_INET, void * addr, char * ip ,16); // addr -> "192.168.10.1"
```


##### 常用函数
`int sockfd = socet(AF_INET, SOCK_STREAM, 0); //IP版本, 流/数据报, 协议号 成功返回sock_fd,失败返回-1,errno被设置`

`bind(sock_fd, struct sockaddr* addr, socklen_t addrlen); //成功返回0失败返回-1`
- 绑定可以对socket设置自定义的ip和端口号
- 其次当绑定某端口的进程退出,可以临时禁用端口号,时长为2MSL

`listen(int sockfd , int backlog);` 成功返回0， 失败返回-1
	`backlog` : 监听序列数 默认128 

`connect(int sockfd, struct sockaddr*dest,socklen_t addrlen);`
	请求连接到dest函数,成功返回0失败返回-1 

`int Csockfd = accept(int Ssockfd, struct sockaddr*addr, socklen_t*addrlen)`
	成功返回sockfd, 失败返回-1, 通过Ssockfd获取通信Csockfd
* adrrlen 传入传出参数,传入可接收的拓构体大小,成功后传出实际大小

`ssize_t recv(int sockfd,void*buf,size_t size,int flag)`
	MSG_DONTWAIT,非阻塞接收 成功返回读取的数据量,失败返回-1

`ssize_t send(int sockfd,void*buf,size_t size,int flag)`
	MSG_NOSIGNAL(避免信号杀死) 成功返回发送数据量，失败返回-1
