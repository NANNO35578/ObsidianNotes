# `extern "C"`介绍一下
`extern "C"` 是 C++ 中的一个关键字，用于指示编译器以 C 语言的方式来处理函数名。这在 C++ 中调用 C 函数时尤为重要，因为 C++ 使用名称改编（name mangling）来支持函数重载，而 C 则没有这种机制。
##### 作用 
1. **防止名称改编**：C++ 编译器会对函数名进行改编，以支持重载和其他 C++ 特性。使用 `extern "C"` 可以避免这种改编，使得 C 函数的名称保持不变，便于链接。
2. **兼容性**：允许 C++ 代码调用 C 语言编写的库和函数，确保不同语言之间的兼容性。
##### 使用方式
1. **函数声明**：
```cpp
    extern "C" {
        void c_function();
    }
```
1. **包含 C 头文件**：
```cpp
    extern "C" {
        #include "c_header.h"
    }
```
3. **在函数定义时**：
```cpp
    extern "C" void c_function() {
        // C 函数的实现
    }
```

##### 注意事项

- `extern "C"` 只能用于函数声明和定义，不能用于变量声明。
- 通常在头文件中使用 `extern "C"`，以确保 C++ 和 C 代码之间的正确链接。
##### 示例

以下是一个示例，演示如何在 C++ 中调用 C 函数：

```cpp
// c_functions.h
#ifdef __cplusplus
extern "C" {
#endif

void c_function();

#ifdef __cplusplus
}
#endif

// c_functions.c
#include <stdio.h>

void c_function() {
    printf("Hello from C function!\n");
}

// main.cpp
#include <iostream>
#include "c_functions.h"

int main() {
    c_function(); // 调用 C 函数
    return 0;
}
```

# 实现范围for循环需要实现什么
范围 `for` 循环（也称为范围基 `for` 循环）是 C++11 引入的一种简洁的循环方式，主要用于遍历容器（如数组、`std::vector`、`std::list` 等）中的元素。要实现范围 `for` 循环，必须满足以下条件：

##### 1. **可迭代性**
容器或对象必须支持迭代，通常需要提供以下成员：
- **begin()**：返回指向容器开头的迭代器。
- **end()**：返回指向容器末尾（不包含该位置）的迭代器。
##### 2. **适用的类型**
范围 `for` 循环可以用于以下类型：
- STL 容器（如 `std::vector`、`std::list`、`std::map` 等）。
- 原始数组。
- 任何自定义类，只要实现了上述的 `begin()` 和 `end()` 方法。
##### 示例
```cpp
class MyContainer {
public:
    std::vector<int> data;
    // 构造函数
    MyContainer(std::initializer_list<int> init) : data(init) {}

    // begin() 方法
    std::vector<int>::iterator begin() { return data.begin(); }
    // end() 方法
    std::vector<int>::iterator end() { return data.end(); }
};
```

# STL中`sort()` 如何实现的

- 在C++ STL里， std::sort  定义于  `<algorithm>`  头文件，默认用内省排序（Introsort）实现，结合了快速排序、堆排序和插入排序的优势
##### 实现原理
- 快速排序（Quicksort） ：平均时间复杂度 O(n log n)，最坏为 O(n^2)。 std::sort  先采用快速排序，每次选基准元素将序列划分成两部分，递归排序。
- 堆排序（Heapsort） ：时间复杂度稳定在 O(n log n)，但常数项大。当递归深度超过一定阈值（2 log n），为避免快速排序最坏情况， std::sort  会切换到堆排序。
- 插入排序（Insertion sort） ：小规模数据（元素数量少于16）排序效率高，时间复杂度接近 O(n)。在数据量较小时， std::sort  采用插入排序。
