[1963. 使字符串平衡的最小交换次数](https://leetcode.cn/problems/minimum-number-of-swaps-to-make-the-string-balanced/)

### 代码思路
1. **初始化变量**
    - 创建两个计数器：`openCount`（记录开括号 `[` 的数量）和 `closeCount`（记录闭括号 `]` 的数量）。
    - 创建一个变量 `swaps`，用于统计需要的交换次数。
2. **遍历字符串**
    - 对输入字符串中的每个字符进行遍历：
        - 如果字符是 `[`，则增加 `openCount`。
        - 如果字符是 `]`，则增加 `closeCount`。
3. **检查平衡条件**
    - 每当 `closeCount` 大于 `openCount` 时，表示当前闭括号数量超出了开括号数量，需要进行交换以恢复平衡。
        - 增加 `swaps` 计数（表示需要一次交换）。
        - 调整 `openCount` 和 `closeCount`，视为已成功交换一个闭括号为开括号。
4. **返回结果**
    - 遍历完成后，返回 `swaps` 的值，表示将字符串变为平衡字符串所需的最小交换次数。

### 复杂度分析
- **时间复杂度**：O(n)，其中 n 是字符串的长度，因为需要遍历字符串一次。
- **空间复杂度**：O(1)，只使用了固定数量的额外变量。

```cpp
int minSwapsToBalance(string s) {
    int openCount = 0, closeCount = 0;
    int swaps = 0;

    for (char c : s) {
        if (c == '[') {
            openCount++;
        } else {
            closeCount++;
        }

        // 如果闭括号数量大于开括号数量，进行交换
        if (closeCount > openCount) {
            swaps++;
            closeCount--; // 视为交换一个闭括号
            openCount++;  // 相应地增加一个开括号
        }
    }

    return swaps;
}
```
