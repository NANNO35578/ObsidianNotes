[2716. 最小化字符串长度](https://leetcode.cn/problems/minimize-string-length/)

- 直接统计出现了26个字符中的哪几个就行

```cpp
int minimizeStringLength(const std::string& s) {
    std::vector<bool> appeared(26, false);
    // 统计出现的字符
    for (char c : s) appeared[c - 'a'] = true;
    // 计算不同字符的数量
    int minimizedLength = 0;
    for (bool exists : appeared) {
        if (exists) {
            minimizedLength++;
        }
    }
    return minimizedLength;
}
```
---
- 由于一共只有 26 个字母，而一个 int 变量有 32 个二进制位，我们可以用一个整数作为哈希表来存储每个字母是否出现。
```cpp
class Solution {
public:
    int minimizedStringLength(string s) {
        int mask = 0;
        for (char c : s) {
            mask |= 1 << (c - 'a');
        }
        return __builtin_popcount(mask);
	    }
};
```
- 同时可以使用 `std::bitset<26>{}` 记录

1. **掩码（mask）**:
    - `int mask = 0;`：初始化一个整数 `mask`，用来记录字符的出现情况。这个整数的每个位代表一个字母（从 'a' 到 'z'）。
    - `1 << (c - 'a')`：对于每个字符 `c`，计算其在掩码中的位置。`c - 'a'` 得到字符相对于 'a' 的偏移量。例如，'a' 对应 0 位，'b' 对应 1 位，依此类推。
2. **位操作**:
    - `mask |= 1 << (c - 'a');`：使用按位或操作将相应的位设为 1。这意味着如果字符 `c` 出现过，掩码中相应的位就会被设置为 1。
3. **计算不同字符数量**:
    - `__builtin_popcount(mask)`：这是 GCC 提供的内置函数，返回整数中二进制位为 1 的个数，也就是掩码中不同字母的数量。

##### 整体逻辑

1. 遍历字符串 `s`，对每个字符进行位运算，更新 `mask`。
2. 最后通过 `__builtin_popcount` 计算并返回掩码中 1 的数量，即字符串中不同字符的数量。
