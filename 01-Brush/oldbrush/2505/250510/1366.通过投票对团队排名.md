[1366. 通过投票对团队排名](https://leetcode.cn/problems/rank-teams-by-votes/)
### 代码思路
1. **数据结构选择**：
    - 使用 `unordered_map<char, vector<int>>` 来存储每个团队的得分情况。每个团队的得分数组记录该团队在每个排名上的票数。
2. **初始化得分**：
    - 遍历每个投票字符串，对于每个团队的每个排名位置，将其对应的票数加一。
3. **收集团队名称**：
    - 将所有团队的字符存入一个 `vector<char>` 中，以便后续排序。
4. **自定义排序**：
    - 使用 `std::sort` 对团队进行排序。排序时，首先比较得分数组中各个排名的票数，如果存在不同的得分，则按得分排序；如果得分相同，则按字母顺序排序。
5. **生成结果**：
    - 将排序后的团队字符合并为一个字符串并返回。

```cpp
    string rankTeams(vector<string>& votes) {
	    int n = votes.size();
	    int m = votes[0].size();
	    std::unordered_map<char, std::vector<int>> scores;
	
	    // 初始化每个团队的得分数组
	    for (const auto& vote : votes) {
	        for (int i = 0; i < m; ++i) {
	            scores[vote[i]].resize(m, 0);
	            scores[vote[i]][i]++;
	        }
	    }
	
	    // 进行排序
	    std::vector<char> teams;
	    for (const auto& pair : scores) {
	        teams.push_back(pair.first);
	    }
	
	    std::sort(teams.begin(), teams.end(), [&scores](char a, char b) {
	        for (int i = 0; i < scores[a].size(); ++i) {
	            if (scores[a][i] != scores[b][i]) {
	                return scores[a][i] > scores[b][i]; // 按得分排序
	            }
	        }
	        return a < b; // 如果依然平局，按字母顺序
	    });
	
	    return std::string(teams.begin(), teams.end());
    }
```
