
[31. 下一个排列](https://leetcode.cn/problems/next-permutation/)

1. **从后向前查找**： 找到第一个不符合升序的元素 `nums[i]`，即 `nums[i] < nums[i + 1]`。这个位置 `i` 是需要处理的关键点
2. **特殊情况**： 如果整个数组是降序的（即未找到这样的 `i`），则直接将数组反转，变为升序排列
3. **找到合适的交换元素**： 从后向前再次查找，找到第一个大于 `nums[i]` 的元素 `nums[j]`，然后交换 `nums[i]` 和 `nums[j]`
4. **反转后面的部分**： 将 `nums[i + 1]` 到 `nums[end]` 的部分反转，使得其成为最小的排列

```cpp
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();
        int i = n - 2;

        // 找到从末尾开始的第一个递减元素
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }

        if (i >= 0) {
            // 找到刚好大于nums[i]的元素
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }
            std::swap(nums[i], nums[j]);
        }

        std::reverse(nums.begin() + i + 1, nums.end());
    }
```
- `i` 用于找到最后一个升序对的前一个元素
- 如果找到了这样的 `i`，则再找出 `j`，这个 `j` 是 `nums[i]` 右边第一个比 `nums[i]` 大的元素，进行交换
- 最后，反转 `i` 之后的部分，形成下一个字典序排列
