[1472. 设计浏览器历史记录](https://leetcode.cn/problems/design-browser-history/)


**数据成员**：    
    - `vector<string> interface`：用来存储浏览历史的网页地址
    - `int pr`：指示当前历史记录的位置（指针）

1. **访问新网页** `void visit(string url)`：
    - 首先，调整指针`pr`，将其位置向前（即指向当前网页之后的位置），然后将新网址`url`加入到历史记录中
    - `resize`方法用于调整`interface`的大小，确保之前的历史记录被清除（即，访问新网页后，不能再向后浏览之前的历史）
2. **返回历史** `string back(int steps)`：
    - 通过减少`pr`的值来实现返回历史记录，确保不小于0
    - 返回`interface`中`pr`位置的网页
3. **前进历史** `string forward(int steps)`：
    - 通过增加`pr`的值来实现向前浏览，确保不超过历史记录的最后一项
     - 返回`interface`中`pr`位置的网页

```cpp
class BrowserHistory {
private:
    vector<string> interface;
    int pr = 0;

public:
    BrowserHistory(string homepage) { interface.push_back(homepage); }

    void visit(string url) {
        interface.resize(++pr);
        interface.push_back(url);
    }

    string back(int steps) {
        pr = max(pr - steps, 0);
        return interface[pr];
    }

    string forward(int steps) {
        pr = min(pr + steps, (int)interface.size() - 1);
        return interface[pr];
    }
};
```
