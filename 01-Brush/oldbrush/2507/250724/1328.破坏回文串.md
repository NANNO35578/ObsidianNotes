[1328. 破坏回文串](https://leetcode.cn/problems/break-a-palindrome/)

##### 贪心
- 令 palindrome 的长度为 n，如果 n=1，那么无论怎么替换，它都是回文串，返回空字符串
- 对于 n>1，将 palindrome 分成两段，遍历前半段，如果某个字符不等于 ‘a’，那么将它替换成 ‘a’，得到的就是结果字符串
- 如果前半段的所有字符都等于 ‘a’，根据回文串的特性，后半段的所有字符都等于 ‘a’，将最后一个字符替换成 ‘b’，得到的就是结果字符串


```cpp
    string breakPalindrome(string palindrome) {
        int n = palindrome.size();

        // 特殊情况
        if (n == 1)
            return "";

        // 尝试替换字符
        for (int i = 0; i < n / 2; ++i) {
            if (palindrome[i] != 'a') {
                palindrome[i] = 'a'; // 替换为 'a'
                return palindrome;   // 返回结果
            }
        }

        // 如果所有前半部分字符都是 'a'
        // 替换最后一个字符
        palindrome[n - 1] = 'b';
        return palindrome;
    }
```
