[2502. 设计内存分配器](https://leetcode.cn/problems/design-memory-allocator/)

##### 双向链表
- 链表节点存储程序id、当前块大小、当前块起始位置
- 分配时，从头遍历，找到合适位置
	- 若大小相等，直接更改程序id即可
	- 若空闲块更大，拆分为小块
	- 若无合适位置返回-1
- 删除时，遍历链表，若id相同，进行删除
	- 即设置id为空闲0
	- 若`next`块为空闲，合并
	- 若`prev`块为空闲，合并
	- 若没找到id，返回0

```cpp
/*
 * @lc app=leetcode.cn id=2502 lang=cpp
 *
 * [2502] 设计内存分配器
 */
 
// @lc code=start
class Allocator {
 private:
  struct ListMem {
    int      available;
    int      begin;
    int      callid;
    ListMem* next;
    ListMem* prev;

    ListMem(int a, int b, int id, ListMem* nxt, ListMem* pre)
        : available(a), begin(b), callid(id), next(nxt), prev(pre) {}
  };

  ListMem* dummy;

 public:
  Allocator(int n) {
    dummy             = new ListMem(-1, -1, -1, new ListMem(n, 0, 0, nullptr, nullptr), nullptr);
    dummy->next->prev = dummy;
  }

  int allocate(int size, int mID) {
    ListMem* point = dummy;
    while (point->next->available < size || point->next->callid != 0) {
      point = point->next;
      if (point->next == nullptr) return -1;
    }
    ListMem* nxt = point->next;
    ListMem* cur = nullptr;

    if (nxt->available == size) {
      cur         = nxt;
      cur->callid = mID;
    } else {
      cur = new ListMem(size, nxt->begin, mID, nxt, point);
      nxt->available -= size;
      nxt->begin += size;
      point->next = cur;
      nxt->prev   = cur;
    }

    return cur->begin;
  }

  int freeMemory(int mID) {
    int      total = 0;
    ListMem* point = dummy->next;
    ListMem* nxt   = nullptr;
    ListMem* pre   = nullptr;

    while (point != nullptr) {
      if (point->callid == mID) {
        nxt           = point->next;
        pre           = point->prev;
        point->callid = 0;

        total += point->available;

        if (nxt != nullptr && nxt->callid == 0) {
          point->available += nxt->available;
          point->next = nxt->next;
          if (nxt->next != nullptr)
            point->next->prev = point;

          delete nxt;
          nxt = nullptr;
        }

        if (pre != nullptr && pre->callid == 0) {
          point->available += pre->available;
          point->prev = pre->prev;
          if (pre->prev != nullptr)
            point->prev->next = point;

          point->begin = pre->begin;

          delete pre;
          pre = nullptr;
        }

      } else
        point = point->next;
    }
    return total;
  }
};
```

##### 单链表
- 删除时先将id匹配的块设置为空闲，并求出`total`
- 再次遍历，合并空闲块

```cpp
class Allocator {
    struct Block {
        int begin, size, mID;
        Block* next;
        Block(int b, int s, int id) : begin(b), size(s), mID(id), next(nullptr) {}
    };
    Block* head;

public:
    Allocator(int n) {
        head = new Block(0, n, 0); // 整块空闲
    }

    int allocate(int size, int mID) {
        Block* prev = nullptr;
        Block* curr = head;
        while (curr) {
            if (curr->mID == 0 && curr->size >= size) {
                int allocBegin = curr->begin;
                if (curr->size == size) {
                    curr->mID = mID;
                } else {
                    // 拆分
                    Block* allocBlock = new Block(curr->begin, size, mID);
                    allocBlock->next = curr;
                    if (prev) prev->next = allocBlock;
                    else head = allocBlock;
                    curr->begin += size;
                    curr->size -= size;
                    return allocBegin;
                }
                return allocBegin;
            }
            prev = curr;
            curr = curr->next;
        }
        return -1;
    }

    int freeMemory(int mID) {
        int freed = 0;
        Block* curr = head;
        while (curr) {
            if (curr->mID == mID) {
                freed += curr->size;
                curr->mID = 0;
            }
            curr = curr->next;
        }
        // 合并相邻空闲块
        curr = head;
        while (curr && curr->next) {
            if (curr->mID == 0 && curr->next->mID == 0) {
                Block* toDelete = curr->next;
                curr->size += toDelete->size;
                curr->next = toDelete->next;
                delete toDelete;
            } else {
                curr = curr->next;
            }
        }
        return freed;
    }

    ~Allocator() {
        while (head) {
            Block* tmp = head;
            head = head->next;
            delete tmp;
        }
    }
};
```

##### 线段树

- 线段树高效支持区间查询和区间修改，适合本题的“区间分配/释放+区间查找”场景
- 通过维护区间最长连续 0 信息，实现了快速分配
- 通过懒惰标记和区间合并，保证了高效的区间修改
- 哈希表辅助记录分配，便于释放

1. *问题本质*
- 有一块长度为 n 的内存，支持分配和释放操作
- 分配时要找到**最左边的、长度不少于 size 的连续空闲区间**，并分配给 mID
- 释放时要将所有属于 mID 的区间释放

2. *为什么用线段树？*
- 需要**高效地查询**“最左边的、长度不少于 size 的连续空闲区间”
- 需要**高效地批量修改**某个区间的状态（分配/释放）
- 线段树可以在 O(log n) 时间内完成区间查询和区间修改，非常适合本题

3. *线段树节点信息设计*
每个节点维护以下信息（以 0 表示空闲，1 表示已分配）：
- `pre0`：区间前缀连续 0 的最大长度
- `suf0`：区间后缀连续 0 的最大长度
- `max0`：区间内最长连续 0 的长度
- `todo`：懒惰标记，表示该区间是否需要被整体赋值（-1 表示无操作，0 表示全空闲，1 表示全分配）

4. 主要操作流程
 - 初始化:构建一棵线段树，初始所有区间都是 0（空闲）。
 - 分配 allocate(size, mID)
	1. **查找区间**  用线段树的 `findFirstFreeBlock` 方法，二分查找最左边的、长度不少于 size 的连续 0 区间，返回其起点 i
	2. **分配区间**  如果找到了，调用 `update` 方法，把区间 [i, i+size-1] 赋值为 1（已分配）
	3. **记录分配**  用哈希表 `blocks[mID]` 记录该 mID 分配的所有区间，便于释放
	4. **返回结果**  返回分配区间的起点；如果找不到，返回 -1
 - 释放 freeMemory(mID)
	1. **查找分配记录**  查找 mID 分配的所有区间
	2. **释放区间**  对每个区间，调用 `update` 方法，把区间赋值为 0（空闲）
	3. **删除分配记录**  删除 mID 的分配记录
	4. **返回释放单元数**  返回释放的总单元数



5. 线段树的核心方法
*区间赋值* apply/update: 
- 如果一个区间被整体赋值（全 0 或全 1），直接更新节点信息和懒惰标记。
- 如果只部分赋值，递归到子区间，并合并左右子树的信息。
*懒惰标记* pushdown :如果父节点有未下传的赋值操作，先把操作下传到左右子节点，保证信息正确。
*区间合并* : 合并左右子树时，更新 pre0、suf0、max0，保证每个节点都能反映其区间的最长连续 0 信息。
*区间查询* findFirstFreeBlock : 
- 递归查找最左边的、长度不少于 size 的连续 0 区间。
- 先查左子树，再查跨越左右子树的区间（左子树后缀 0 + 右子树前缀 0），最后查右子树

6. 哈希表 blocks 的作用
- 记录每个 mID 分配的所有区间，便于释放时快速找到并释放所有相关区间。

```cpp
class SegTree {
    struct Node {
        int pre0, suf0, max0, todo;
    };

    std::vector<Node> t;

    // 区间赋值操作
    void apply(int i, int l, int r, int v) {
        auto& o = t[i];
        int size = v <= 0 ? r - l + 1 : 0;
        o.pre0 = o.suf0 = o.max0 = size;
        o.todo = v;
    }

    // 下传懒标记
    void pushdown(int o, int l, int r) {
        int& v = t[o].todo;
        if (v != -1) {
            int m = (l + r) / 2;
            apply(o * 2, l, m, v);
            apply(o * 2 + 1, m + 1, r, v);
            v = -1;
        }
    }

    // 初始化线段树
    void build(int o, int l, int r) {
        apply(o, l, r, -1);
        if (l == r) {
            return;
        }
        int m = (l + r) / 2;
        build(o * 2, l, m);
        build(o * 2 + 1, m + 1, r);
    }

public:
    SegTree(int n) {
        int sz = 1;
        while (sz < n) sz <<= 1;
        t.resize(sz << 1);
        build(1, 0, n - 1);
    }

    // 把 [ql, qr] 都置为 v
    void update(int o, int l, int r, int ql, int qr, int v) {
        if (ql <= l && r <= qr) {
            apply(o, l, r, v);
            return;
        }
        pushdown(o, l, r);
        int m = (l + r) / 2;
        if (ql <= m) {
            update(o * 2, l, m, ql, qr, v);
        }
        if (m < qr) {
            update(o * 2 + 1, m + 1, r, ql, qr, v);
        }

        // 合并左右子树的信息
        Node& lo = t[o * 2];
        Node& ro = t[o * 2 + 1];
        // 区间前缀连续 0 的个数
        t[o].pre0 = lo.pre0;
        if (lo.pre0 == m - l + 1) {
            t[o].pre0 += ro.pre0; // 和右子树的 pre0 拼起来
        }
        // 区间后缀连续 0 的个数
        t[o].suf0 = ro.suf0;
        if (ro.suf0 == r - m) {
            t[o].suf0 += lo.suf0; // 和左子树的 suf0 拼起来
        }
        // 区间最长连续 0 的个数
        t[o].max0 = std::max({lo.max0, ro.max0, lo.suf0 + ro.pre0});
    }

    // 线段树二分，找最左边的区间左端点，满足区间全为 0 且长度 >= size
    // 如果不存在这样的区间，返回 -1
    int findFirstFreeBlock(int o, int l, int r, int size) {
        if (t[o].max0 < size) {
            return -1;
        }
        if (l == r) {
            return l;
        }
        pushdown(o, l, r);
        int m = (l + r) / 2;
        int idx = findFirstFreeBlock(o * 2, l, m, size); // 递归左子树
        if (idx < 0) {
            // 左子树的后缀 0 个数 + 右子树的前缀 0 个数 >= size
            if (t[o * 2].suf0 + t[o * 2 + 1].pre0 >= size) {
                return m - t[o * 2].suf0 + 1;
            }
            idx = findFirstFreeBlock(o * 2 + 1, m + 1, r, size); // 递归右子树
        }
        return idx;
    }
};

class Allocator {
    int n;
    SegTree tree;
    std::unordered_map<int, std::vector<std::pair<int, int>>> blocks;

public:
    Allocator(int n) : n(n), tree(n) {}

    // 分配 size 大小的内存块给 mID
    int allocate(int size, int mID) {
        if (size > n) return -1; // 边界处理
        int i = tree.findFirstFreeBlock(1, 0, n - 1, size);
        if (i < 0) { // 无法分配内存
            return -1;
        }
        blocks[mID].emplace_back(i, i + size - 1);
        tree.update(1, 0, n - 1, i, i + size - 1, 1); // 分配内存 [i, i+size-1]
        return i;
    }

    // 释放 mID 占用的所有内存块
    int freeMemory(int mID) {
        auto it = blocks.find(mID);
        if (it == blocks.end()) return 0; // mID 不存在
        int ans = 0;
        for (auto& [l, r] : it->second) {
            ans += r - l + 1;
            tree.update(1, 0, n - 1, l, r, 0); // 释放内存
        }
        blocks.erase(it);
        return ans;
    }
};

 * int param_2 = obj->freeMemory(mID);
 */
```

#线段树 
## 1. 线段树是什么？
- 线段树是一种高效的区间数据结构，支持 O(log n) 的区间统计、查询和修改
- 适合处理大规模、动态的区间问题
- 代码实现有一定复杂度，但功能强大，灵活性高

## 2. 线段树的结构
- 线段树是一棵二叉树，每个节点表示一个区间（区间可以是数组的某一段）
- 根节点表示整个区间 `[0, n-1]`
- 每个非叶子节点的左右子节点分别表示其区间的左右两半
- 叶子节点表示单个元素
举例：假设有数组 `A[0..7]`，线段树的根节点表示 `[0,7]`，左子树表示 `[0,3]`，右子树表示 `[4,7]`，依此类推，直到叶子节点表示单个元素

## 3. 线段树的用途
- 区间求和：查询某一段区间的和
- 区间最大/最小值：查询某一段区间的最大/最小值
- 区间更新：将某一段区间的值全部加上/赋值为某个数
- 其他区间统计：如区间乘积、区间gcd等

## 4. 线段树的操作
*4.1 建树Build*
- 递归地将区间分成两半，分别建立左右子树
- 时间复杂度 O(n)
*4.2 区间查询Query*
- 查询某个区间 `[l, r]` 的统计信息
- 如果当前节点区间完全包含在 `[l, r]` 内，直接返回
- 否则递归查询左右子树，合并结果
- 时间复杂度 O(log n)
*4.3 区间修改Update*
- 修改某个区间 `[l, r]` 的值（如加上某个数、赋值为某个数）
- 如果当前节点区间完全包含在 `[l, r]` 内，直接修改
- 否则递归修改左右子树，并更新当前节点的统计信息
- 时间复杂度 O(log n)
*4.4 懒惰标记Lazy Propagation*
- 用于区间修改时的优化，避免重复递归
- 当一个区间需要修改时，先打上“懒惰标记”，等到需要用到子区间时再下传

## 5. 线段树的空间复杂度
- 线段树的节点数大约是 4n（实际为 2n~4n），所以空间复杂度为 O(n)

## 6. 线段树的代码示例（区间和）
```cpp
class SegmentTree {
    vector<int> tree, lazy;
    int n;
    void build(vector<int>& nums, int node, int l, int r) {
        if (l == r) {
            tree[node] = nums[l];
            return;
        }
        int mid = (l + r) / 2;
        build(nums, node*2, l, mid);
        build(nums, node*2+1, mid+1, r);
        tree[node] = tree[node*2] + tree[node*2+1];
    }
    // 省略 query, update, pushdown 等函数
public:
    SegmentTree(vector<int>& nums) {
        n = nums.size();
        tree.resize(4*n);
        lazy.resize(4*n);
        build(nums, 1, 0, n-1);
    }
};
```

## 7. 线段树的应用场景
- 动态区间和、区间最大/最小值、区间统计
- 区间覆盖、区间加法、区间赋值
- 解决“区间修改+区间查询”类问题
