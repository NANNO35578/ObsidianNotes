[39. 组合总和](https://leetcode.cn/problems/combination-sum/) 


##### DFS 回溯
1. **递归函数**： 创建一个递归函数 `backtrack`，它接受当前的组合 `current`、当前的和 `current_sum`、以及当前的起始索引 `start` 作为参数
2. **结束条件**：
    - 如果 `current_sum` 等于 `target`，则将 `current` 添加到结果列表中
    - 如果 `current_sum` 大于 `target`，则返回（剪枝）
3. **循环选择**：
    - 从 `start` 索引开始，遍历 `candidates` 数组。由于数字可以重复选择，在循环中可以从当前索引继续选择
    - 将当前数字添加到 `current` 中，并更新 `current_sum`
    - 递归调用 `backtrack`
    - 完成后，将当前数字从 `current` 中移除（回溯）

```cpp
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        vector<vector<int>> result;
        vector<int> current;
        backtrack(candidates, target, 0, current, result);
        return result;
    }

    void backtrack(vector<int>& candidates, int target, int start, vector<int>& current, vector<vector<int>>& result) {
        if (target == 0) {
            result.push_back(current);
            return;
        }
        if (target < 0) return; // 剪枝
        
        for (int i = start; i < candidates.size(); i++) {
            current.push_back(candidates[i]);
            backtrack(candidates, target - candidates[i], i, current, result); // 允许重复选择
            current.pop_back(); // 回溯
        }
    }
```

---

##### 动态规划

1. **定义状态**： 使用一个数组 `dp`，其中 `dp[i]` 表示和为 `i` 的所有组合的列表
2. **初始化**： `dp[0]` 初始化为一个包含空列表的列表，表示和为 0 的组合
3. **状态转移**： 对于每个候选数字 `num`，遍历从 `num` 到 `target` 的所有值 `i`，将 `num` 添加到 `dp[i - num]` 中的每个组合中，形成新的组合
4. **返回结果**： 最终，`dp[target]` 将包含所有和为 `target` 的组合

```cpp
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        vector<vector<vector<int>>> dp(target + 1);
        dp[0] = {{}};

        for (int num : candidates) {
            for (int i = num; i <= target; i++) {
                for (auto& combination : dp[i - num]) {
                    auto new_combination = combination; // 复制
                    new_combination.push_back(num);
                    dp[i].push_back(new_combination);
                }
            }
        }

        return dp[target];
    }
```
