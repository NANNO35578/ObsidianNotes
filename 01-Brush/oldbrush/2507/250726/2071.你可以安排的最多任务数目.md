[2071. 你可以安排的最多任务数目](https://leetcode.cn/problems/maximum-number-of-tasks-you-can-assign/)
#### 方法一：二分 + 贪心校验

1. 对 `tasks` 和 `workers` 升序排序
2. 对答案 `k` 二分（区间 $0, min(n,m)$）
    - 判断能否「**恰好** 完成最简单的前 `k` 个任务」
3. **可行性校验 `check(k)`**（复杂度 $O(k log k)$）：
    1. 在排序好的 `workers` 中取最强的 `k` 人，放入 `multiset<int> S`
    2. 从最难的任务往前依次分配：
        - 若 `*prev(S.end()) >= need`，直接 pop 最强工人
        - 否则若剩余药丸 > 0，找 `S.lower_bound(need − strength)`：  
            · 若存在，将此工人 pop，药丸数– 1；  
            · 否则失败
    3. 全部分配成功则返回 `true`
4. 二分过程中更新答案，最终即为最大可完成任务数

```cpp
int maxTaskAssign(vector<int>& tasks, vector<int>& workers, int pills, int strength) {
    int n = tasks.size(), m = workers.size();
    sort(tasks.begin(), tasks.end());
    sort(workers.begin(), workers.end());

    auto can = [&](int k) {
        if (k > m) return false;
        multiset<int> S(workers.end()-k, workers.end());
        int p = pills;
        for (int i = k-1; i >= 0; --i) {
            int need = tasks[i];
            auto it = prev(S.end());
            if (*it >= need) {
                S.erase(it);
            } else {
                if (p == 0) return false;
                auto jt = S.lower_bound(need - strength);
                if (jt == S.end()) return false;
                S.erase(jt);
                --p;
            }
        }
        return true;
    };

    int lo = 0, hi = min(n, m), ans = 0;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (can(mid)) {
            ans = mid;
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    return ans;
}
```

#### 方法二：一次遍历的贪心在线匹配

- 同样先对 `tasks`、`workers` 升序排序
- 用指针 `cur` 标记已完成的任务数，初始 `cur=0`
- 用两个容器暂存「待分配」工人：
    1. `queue<int> pill_q`：已经使用药丸、但**未**匹配任务的工人下标
    2. `stack<int> nopill_s`：未使用药丸、已**能**直接匹配当前最简单任务的工人下标
- 另外维护两个计数器：
    - `pill_left`：剩余药丸数，初始 `pills`
    - `used_pills`：已实际用来完成任务的药丸数，初始 0

遍历每个工人 `i=0..m-1`：

1. **优先处理 `pill_q`**，看队首工人 `j=pill_q.front()`：
    - 如果当前工人 `workers[i] >= workers[j] + strength`，  
        则把这位「曾被预判用药」的工人 `j` 最终匹配到下一个任务上：
        - 若 `workers[j]+strength >= tasks[cur]`，任务数 `cur++`，`used_pills++`
        - 否则尝试用栈顶的 `nopill_s`（即将一次“本可无药完成”的匹配改为吃药补强）；  
            若 `nopill_s` 也空，则退回一粒药丸给 `pill_left`
    - 处理完后将 `pill_q.pop()`，并继续尝试下一个 `pill_q.front()`
2. **再看当前工人 `i`：**
    - 若 `workers[i] >= tasks[cur]`，直接匹配不吃药：`cur++`，`nopill_s.push(i)`
    - 否则若 `pill_left>0`，预判吃药：`pill_left--`，`pill_q.push(i)`
    - 否则无法分配——尝试回退一个已用药完成的任务（若 `used_pills>0`），或者丢弃一个较弱的「待用药」工人，用当前工人代替
循环结束后，`pill_q` 中若还有元素，也用它们 **吃药** 去匹配剩余最简单任务

整段逻辑是一种**在线贪心+局部回溯**策略：
- 新工人来了，先看看能否「替补」掉之前预判的吃药工人，使他们完成任务；
- 再决定当前工人到底是「直接用」还是「先预判吃药」；
- 并通过 `nopill_s` 把一些原本能无药完成的工人「改造」为用药完成，以腾出药丸给更迫切的任务

```cpp
int maxTaskAssign(vector<int>& tasks, vector<int>& workers, int pills, int strength) {
    ranges::sort(tasks);
    ranges::sort(workers);
    int n = tasks.size(), m = workers.size();
    int cur = 0, pill_left = pills, used_pills = 0;
    queue<int> pill_q;
    stack<int> nopill_s;

    for (int i = 0; i < m && cur < n; ++i) {
        // 先试着让队首的“预判吃药”工人完成任务
        while (!pill_q.empty() &&
               workers[i] >= workers[pill_q.front()] + strength) {
            int j = pill_q.front(); pill_q.pop();
            if (workers[j] + strength >= tasks[cur]) {
                ++cur; ++used_pills;
            }
            else if (!nopill_s.empty()) {
                // 回退一次本可无药完成的匹配，用药腾药
                ++used_pills;
                pill_q.push(nopill_s.top());
                nopill_s.pop();
            }
            else {
                // 真无法用这粒药，退还
                ++pill_left;
            }
            if (cur >= n) return n;
        }

        // 决定当前工人 i 的去向
        if (workers[i] >= tasks[cur]) {
            // 直接匹配，不吃药
            ++cur;
            nopill_s.push(i);
        }
        else if (pill_left > 0) {
            // 预判吃药、但暂不匹配
            --pill_left;
            pill_q.push(i);
        }
        else {
            // 无法立刻匹配也没药——尝试回退一次
            if (used_pills > 0) {
                --used_pills;
                --cur;
                pill_q.push(i);
            }
            else if (!pill_q.empty()) {
                pill_q.pop();
                pill_q.push(i);
            }
        }
    }

    // 剩余“预判吃药”工人补足尾部任务
    while (cur < n && !pill_q.empty()) {
        int j = pill_q.front(); pill_q.pop();
        if (workers[j] + strength >= tasks[cur]) {
            ++cur;
        }
    }
    return cur;
}
```
