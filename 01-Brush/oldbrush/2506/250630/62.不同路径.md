[62. 不同路径](https://leetcode.cn/problems/unique-paths/)

##### 动态规划
- 从起始点开始，起始点ans为1，向右所有位置ans均为1
- 从起始点开始，向下所有位置ans均为1
- 考虑(1,1)位置ans，即正上方与左侧ans之和
- 可推出动态转移方程
$$
dp[row,col]= \begin{cases}
 dp[row-1][col] + dp[row][col-1]& row>0,col>0\\
1& row=0,col=0
\end{cases}
$$

- 空间复杂度为O($n^2$)

```cpp
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m, vector(n, 0));

        for (int row = 0; row < m; ++row) {
            for (int col = 0; col < n; ++col) {
                if (col == 0 || row == 0)
                    dp[row][col] = 1;
                else
                    dp[row][col] = dp[row - 1][col] + dp[row][col - 1];
            }
        }
        return dp[m-1][n-1];
    }
```

---

*考虑到除最近一列以外，dp数组中其他列对`ans` 无贡献，且不影响*
- 剪枝 空间复杂度O($n$) 
```cpp
    int uniquePaths(int m, int n) {
        vector<int> upDp(n, 0);
        int leftDp = 0;
        int cur = 0;
        for (int row = 0; row < m; ++row) {
            for (int col = 0; col < n; ++col) {
                if (col == 0) {
                    cur = leftDp = 1;
                } else if (row == 0) {
                    cur = upDp[col] = 1;
                } else {
                    cur = upDp[col] + leftDp;
                    leftDp = cur;
                    upDp[col] = cur;
                }
            }
        }
        return cur;
    }
```

# 方法二：组合数学

在从左上角到右下角的路径中，一共需要移动 `m+n−2` 次，其中包含 `m−1` 次向下移动和 `n−1` 次向右移动。因此，路径的总数可以表示为从 `m+n−2` 次移动中选择 `m−1` 次向下移动的组合数，即：
$$ C_{m+n-2}^{m-1} = \frac{(m+n-2)!}{(m-1)!(n-1)!} $$

```cpp
    int uniquePaths(int m, int n) {
        long long ans = 1;
        for (int x = n, y = 1; y < m; ++x, ++y) {
            ans = ans * x / y;
        }
        return ans;
    }
```
