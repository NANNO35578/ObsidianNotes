[152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)

1. **处理负数**：由于负数可以将最大乘积变为最小乘积，因此每次遇到负数时，交换 `maxProduct` 和 `minProduct`
2. **更新逻辑**：
    - 使用 `max` 和 `min` 来分别更新当前的最大和最小乘积
    - 在每一步中，考虑当前元素和当前乘积的乘积，确保能得到最大的结果
3. **初始值**：初始化 `maxProduct` 和 `minProduct` 为 `nums[0]`，同时 `ans` 也初始化为 `nums[0]`



```cpp
    int maxProduct(vector<int>& nums) {
        if (nums.empty()) return 0; // 处理空数组的情况

        int maxProduct = nums[0];
        int minProduct = nums[0];
        int ans = nums[0];
        for (int i = 1; i < nums.size(); ++i) {
            if (nums[i] < 0) {
                swap(maxProduct, minProduct); // 负数会交换最大和最小
            }
            maxProduct = max(nums[i], maxProduct * nums[i]); // 更新最大乘积
            minProduct = min(nums[i], minProduct * nums[i]); // 更新最小乘积
            ans = max(ans, maxProduct); // 更新最终答案
        }
        return ans;
    }
```


---

1. **初始化**：
    - `product`: 用于计算当前子数组的乘积，初始值为 1。
    - `max`: 用于记录找到的最大乘积，初始值为数组的第一个元素。
2. **正向遍历**：
    - 遍历数组，从左到右计算每个连续子数组的乘积。
    - 每次将当前元素乘入 `product`，并更新 `max` 为当前乘积与 `max` 的较大值。
    - 如果遇到 0，重置 `product` 为 1，因为 0 会使得乘积为 0，因此需要从下一个元素重新开始计算。
3. **反向遍历**：
    - 由于负数的存在，可能会影响乘积，因此需要从右到左再次遍历数组。
    - 同样地，计算当前子数组的乘积，更新 `max`，并在遇到 0 时重置 `product`。
4. **返回结果**：最终返回 `max`，即找到的最大乘积。

```cpp
    int maxProduct(vector<int>& nums) {
       int product = 1;
        int n = nums.size();
        int maxProduct = nums[0]; // 初始化最大乘积

        // 正向遍历
        for (int i = 0; i < n; i++) {
            product *= nums[i];
            maxProduct = max(maxProduct, product);
            if (nums[i] == 0) {
                product = 1; // 遇到 0 重置乘积
            }
        }

        // 从后往前遍历
        product = 1;
        for (int i = n - 1; i >= 0; i--) {
            product *= nums[i];
            maxProduct = max(maxProduct, product);
            if (nums[i] == 0) {
                product = 1; // 遇到 0 重置乘积
            }
        }
        return maxProduct; // 返回最大乘积
    }
```
