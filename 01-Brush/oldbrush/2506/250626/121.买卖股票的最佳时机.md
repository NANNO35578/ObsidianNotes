[121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)


1. **初始化变量**:
    - `maxProfit`: 用于存储当前最大利润，初始值为 0。
    - `minPrice`: 用于存储迄今为止的最低价格，初始值设为一个很大的数（`INT_MAX`），以确保任何价格都能更新它。
2. **遍历价格数组**:
    - 对于每一天的股票价格：
        - **更新最低价格**: 如果当前价格低于 `minPrice`，则更新 `minPrice`。
        - **计算当前利润**: 通过当前价格减去 `minPrice` 得到当前的利润。
        - **更新最大利润**: 如果当前利润大于 `maxProfit`，则更新 `maxProfit`。

```cpp
    int maxProfit(vector<int>& prices) {
        int maxProfit = 0; // 初始化最大利润为 0
        int minPrice = INT_MAX; // 初始化最低价格为最大整数

        for (int price : prices) {
            // 更新最低价格
            if (price < minPrice) {
                minPrice = price;
            }
            // 计算当前利润并更新最大利润
            int profit = price - minPrice;
            if (profit > maxProfit) {
                maxProfit = profit;
            }
        }
        return maxProfit; // 返回最大利润
    }
```
