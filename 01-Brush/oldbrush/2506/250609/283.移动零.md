[283. 移动零](https://leetcode.cn/problems/move-zeroes/)

##### 双指针
- zeroCheck 下标用于检测当前数字是否为0
- 是 则利用nearVal 下标从此处开始往后寻找到第一个非0 交换
```cpp
    void moveZeroes(vector<int>& nums) {
        int zeroCheck = 0;
        int nearVal = 0;

        while (zeroCheck != nums.size() - 1) {
            if (nums[zeroCheck] == 0) {
                while (nums[nearVal] == 0) {
                    if (nearVal == nums.size() - 1)
                        return;
                    ++nearVal;
                }
                swap(nums[zeroCheck], nums[nearVal]);
            }
            ++zeroCheck;
            if(zeroCheck>nearVal)nearVal=zeroCheck;
        }
    }
```
---
##### 优化
- 左指针指向当前已经处理好的序列的尾部，右指针指向待处理序列的头部
- 右指针不断向右移动，每次右指针指向非零数，则将左右指针对应的数交换，同时左指针右移。

```cpp
    void moveZeroes(vector<int>& nums) {
        int n = nums.size(), left = 0, right = 0;
        while (right < n) {
            if (nums[right]) {
                swap(nums[left], nums[right]);
                left++;
            }
            right++;
        }
    }
```
