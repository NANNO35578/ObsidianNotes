[108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

##### 递归
- 由于中序遍历二叉搜索树为有序数组，因此，可反过来，由数组中间数作为根节点递归寻找左右根节点即可构造

```cpp

    TreeNode* get(const std::vector<int>& nums, int left, int right) {
        if (left > right) {
            return nullptr;
        }

        int mid = left + (right - left) / 2; // 找到中间元素
        TreeNode* root = new TreeNode(nums[mid]);

        root->left = get(nums, left, mid - 1);   // 递归构建左子树
        root->right = get(nums, mid + 1, right); // 递归构建右子树

        return root;
    }

    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return get(nums, 0, nums.size() - 1);
    }
```
