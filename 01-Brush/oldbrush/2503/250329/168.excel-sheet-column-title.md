[Excel表格名称](https://leetcode.cn/problems/excel-sheet-column-title/description/)
> 给你一个整数 `columnNumber` ，返回它在 Excel 表中相对应的列名称。
	例如：
	A -> 1
	B -> 2
	C -> 3
	...
	Z -> 26
	AA -> 27
	AB -> 28 
	...

- 对于整数 n，若 n 能被 26 整除，则有：![[168_1.png]] 其中 $0≤r≤25$。
- 因此有：![[168_2.png]] 这里我们用到了 $0≤a_0​ −1≤25$ 这一性质。
```cpp
    string convertToTitle(int columnNumber) {
        string ans = "";
        while (columnNumber > 0) {
            columnNumber--;  // Adjust for 0-based index
            char col = 'A' + (columnNumber % 26);
            ans += col;
            columnNumber /= 26;
        }
        reverse(ans.begin(), ans.end());
        return ans;
    }
```
