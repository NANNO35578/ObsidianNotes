[统计公平数对的数目](https://leetcode.cn/problems/count-the-number-of-fair-pairs/description/?envType=daily-question&envId=2025-04-19)
1. **排序数组**：
    - 首先对输入数组 `nums` 进行排序。这将帮助我们更高效地查找满足条件的数对。
2. **使用双指针或二分查找**：
    - 对于每个元素 `nums[i]`，需要找到所有满足条件的 `nums[j]`（其中 `j > i`）：
        - **下界**：找到 `nums[j]` 使得 `nums[i] + nums[j] >= lower`。
        - **上界**：找到 `nums[j]` 使得 `nums[i] + nums[j] <= upper`。
3. **计算有效对数**：
    - 使用 `lower_bound` 和 `upper_bound` 来快速找到满足条件的 `j` 的范围。
    - 计算该范围内的有效索引，并累加到结果中。
4. **避免重复计数**：
    - 在计算时，需要确保不重复计算 `(i, i)` 这样的对。
5. **结果处理**：
    - 由于每对 `(i, j)` 会被计算两次（`(i, j)` 和 `(j, i)`），最后将结果除以 2。
```cpp
    long long countFairPairs(vector<int>& nums, int lower, int upper) {
        sort(nums.begin(), nums.end());
        long long count = 0;
        int n = nums.size();

        for (int i = 0; i < n; ++i) {
            int j_start =
                lower_bound(nums.begin(), nums.end(), lower - nums[i]) -
                nums.begin();
            int j_end = upper_bound(nums.begin(), nums.end(), upper - nums[i]) -
                        nums.begin();

            count += j_end - j_start;  // Count valid j indices

            if (j_start <= i && i < j_end) {
                count--;  // Exclude the pair (i, i)
            }
        }

        return count / 2;  // Each pair is counted twice
    }
```

##### 方法二：三指针
思路与算法

在给数组 `nums` 排序后，随着枚举的 `nums[j]` 变大，`upper−nums[j]` 和 `lower−nums[j]` 都变小，于是我们可以用三指针来代替二分查找的搜索过程。

具体来说，使用两个指针 `left` 和 `right` 分别表示` ≤upper−nums[j]` 的最大元素位置，和` <lower−nums[j]` 的最大元素位置，那么满足条件的 `nums[i]` 就被夹在三个指针当中，作差从而得到答案的数量。
```cpp
    long long countFairPairs(vector<int>& nums, int lower, int upper) {
        sort(nums.begin(), nums.end());
        long long ans = 0;
        int left = nums.size(), right = nums.size();
        for (int j = 0; j < nums.size(); ++j) {
            while (right && nums[right - 1] > upper - nums[j]) {
                right--;
            }
            while (left && nums[left - 1] >= lower - nums[j]) {
                left--;
            }
            ans += min(right, j) - min(left, j);
        }
        return ans;
    }

```
