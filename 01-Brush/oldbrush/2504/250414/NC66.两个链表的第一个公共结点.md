[两个链表的第一个公共结点](https://www.nowcoder.com/profile/386104436/codeBookDetail?submissionId=457438401)
- **检查空链表**：首先，如果任意一个链表的头节点为空，直接返回 `nullptr`。
- **计算链表长度**：
    - 使用两个指针 `p1` 和 `p2` 分别遍历 `pHead1` 和 `pHead2`，计算两个链表的长度 `llong` 和 `lshort`。
- **对齐起始位置**：
    - 根据两个链表的长度差，移动较长链表的指针，使得两个指针的起始位置相同。具体来说，如果 `pHead1` 较长，则先移动 `p1`，否则移动 `p2`。
- **寻找公共节点**：
    - 使用 `while` 循环同时遍历两个链表，比较两个指针 `p1` 和 `p2` 是否相同。如果相同，则返回该节点，即为第一个公共节点。
- **返回结果**：如果遍历结束仍未找到公共节点，返回 `nullptr`。

```cpp
    ListNode* FindFirstCommonNode(ListNode* pHead1, ListNode* pHead2) {
        if (pHead1 == nullptr || pHead2 == nullptr) return nullptr;
 
        int llong = 0;
        int lshort = 0;
 
        ListNode* p1 = pHead1;
        ListNode* p2 = pHead2;
        while (p1 != nullptr) {
            p1 = p1->next;
            ++llong;
        }
        while (p2 != nullptr) {
            p2 = p2->next;
            ++lshort;
        }
        p1 = pHead1;
        p2 = pHead2;
        if (llong > lshort) {  //* p1 longger
            llong -= lshort;
            for (int i = 0; i < llong; ++i) {
                p1 = p1->next;
            }
        } else {
            lshort -= llong;
            for (int i = 0; i < lshort; ++i) {
                p2 = p2->next;
            }
        }
        while (p1 != nullptr) {
            if (p1 == p2) return p1;
            p1 = p1->next;
            p2 = p2->next;
        }
        return nullptr;
    }
```
