
[189. 轮转数组](https://leetcode.cn/problems/rotate-array/)


---


##### 方法一：借助额外数组

- 数字交换后的位置应当为$(i+k)\%n$
- 可利用额外空间, 将将每个数字先放入辅助数组, 然后拷贝回原数组

时间复杂度 O(n)，空间复杂度 O(n)

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        if (n == 0) return;
        k %= n;
        vector<int> tmp(n);
        for (int i = 0; i < n; i++) {
            tmp[(i + k) % n] = nums[i];
        }
        // 拷贝回原数组
        for (int i = 0; i < n; i++) {
            nums[i] = tmp[i];
        }
    }
};
```

##### 方法二：三次反转（原地算法）
时间复杂度 O(n)，空间复杂度 O(1)

思路：  
1. 整体反转  
2. 反转前 k 个元素  
3. 反转剩下的 n−k 个元素

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        if (n == 0) return;
        k %= n;
        // 1. 整体反转
        reverse(nums.begin(), nums.end());
        // 2. 反转前 k 个元素
        reverse(nums.begin(), nums.begin() + k);
        // 3. 反转剩余的 n-k 个元素
        reverse(nums.begin() + k, nums.end());
    }
};
```

##### 「环状替换」

- 计数已经替换的元素个数，空间 O(1)）
- 数组中的元素在轮转后，会形成 **一个个环**

从某个起点出发，顺着 “当前位置 + k” 的规则，一直往下替换，直到回到起点，这样完成一个环
- 然后再从下一个未处理的下标继续，直到所有元素都被移动过

```cpp
#include <vector>
using namespace std;

class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        if (n == 0) return;
        k %= n;
        int count = 0;    // 已经替换的元素个数
        for (int start = 0; count < n; ++start) {
            int cur = start;
            int prev = nums[cur];
            do {
                int next = (cur + k) % n;
                int tmp = nums[next];
                nums[next] = prev;
                prev = tmp;
                cur = next;
                ++count;
            } while (cur != start);
        }
    }
};
```
