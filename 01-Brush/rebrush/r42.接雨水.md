#### 动态规划（预计算左右最大值）

*解题思路*:

1. 先一次遍历，计算并存储每个位置 i 左侧（含 i）的最高高度 `leftMax[i]`
2. 再一次从右向左遍历，计算每个位置 i 右侧（含 i）的最高高度 `rightMax[i]`
3. 最后对于每个 i，`water[i] = min(leftMax[i], rightMax[i]) - height[i]`，累加即可
- 时间复杂度：O(n)
- 空间复杂度：O(n) （用于 `leftMax` 和 `rightMax` 两个数组）

```cpp
int trap(vector<int>& height) {
    int n = height.size();
    if (n <= 2) return 0;

    vector<int> leftMax(n), rightMax(n);
    leftMax[0] = height[0];
    for (int i = 1; i < n; ++i)
        leftMax[i] = max(leftMax[i - 1], height[i]);

    rightMax[n - 1] = height[n - 1];
    for (int i = n - 2; i >= 0; --i)
        rightMax[i] = max(rightMax[i + 1], height[i]);

    int water = 0;
    for (int i = 0; i < n; ++i)
        water += min(leftMax[i], rightMax[i]) - height[i];

    return water;
}
```

#### 双指针

*解题思路*:
1. 维护两个指针 `l`、`r`，初始分别指向数组左右端；以及两个变量 `leftMax`、`rightMax` 表示当前遍历过的左右最高柱子高度。
2. 在每一步比较 `height[l]` 和 `height[r]`：
    - 若 `height[l] < height[r]`，则左侧决定水位：
        - 如果 `height[l] >= leftMax`，更新 `leftMax = height[l]`；
        - 否则可接水 `leftMax - height[l]`，累加到结果，再 `l++`。
    - 否则右侧决定水位（对称操作），再 `r--`。
3. 由于每次都向内移动一个指针，遍历一次完成。

- 时间复杂度：O(n)
- 空间复杂度：O(1)

```cpp
int trap(vector<int>& height) {
    int n = height.size();
    int l = 0, r = n - 1;
    int leftMax = 0, rightMax = 0;
    int water = 0;

    while (l < r) {
        if (height[l] < height[r]) {
            if (height[l] >= leftMax) {
                leftMax = height[l];
            } else {
                water += leftMax - height[l];
            }
            ++l;
        } else {
            if (height[r] >= rightMax) {
                rightMax = height[r];
            } else {
                water += rightMax - height[r];
            }
            --r;
        }
    }

    return water;
}
```

##### 枚举 **O(n²)会超时**

1. 对于每个下标 i，能够接的水量取决于其左侧最高柱子和右侧最高柱子的较小值减去自身高度：  
    $water[i] = min(max_left[i], max_right[i]) − height[i]$
2. 因为没有预处理，直接在每个 $i$ 处向左向右扫描来找 `max_left` 和 `max_right`。
3. 对所有 $i$ 累加即可。

- 时间复杂度：O(n²)，n 为数组长度 **超时**
- 空间复杂度：O(1)

```cpp
int trap(vector<int>& height) {
    int n = height.size();
    int water = 0;
    for (int i = 0; i < n; ++i) {
        int maxL = 0, maxR = 0;
        // 找 i 左侧最高
        for (int j = 0; j <= i; ++j)
            maxL = max(maxL, height[j]);
        // 找 i 右侧最高
        for (int j = i; j < n; ++j)
            maxR = max(maxR, height[j]);
        water += min(maxL, maxR) - height[i];
    }
    return water;
}
```
