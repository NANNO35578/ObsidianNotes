
[1027. 最长等差数列](https://leetcode.cn/problems/longest-arithmetic-subsequence/)

- *掌阅科技2025笔试算法第三题*

----

##### 基于哈希表的动态规划

- 用 `dp[i]` 存一个哈希表，`dp[i][d]` 表示「以 `nums[i]` 结尾，公差为 `d` 的最长等差子序列长度」；
- 枚举每一对 `(j,i)`（`j<i`），计算差值 `d = nums[i] - nums[j]`，
    - 如果 `dp[j]` 中已有 `d`，则 `dp[i][d] = dp[j][d] + 1`，否则从长度 2 开始；
    - 更新全局最大值。

时间复杂度 O(n²)，空间复杂度 O(n²)（最坏情况下每个 `dp[i]` 都存 O(i) 个差值）。

```cpp
int longestArithSeqLength(vector<int>& nums) {
    int n = nums.size();
    if (n < 2) return n;
    int ans = 2;
    // dp[i]: map from 差值 d 到长度
    vector<unordered_map<int,int>> dp(n);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            int d = nums[i] - nums[j];
            int len = 2;
            auto it = dp[j].find(d);
            if (it != dp[j].end()) {
                len = it->second + 1;
            }
            dp[i][d] = max(dp[i][d], len);
            ans = max(ans, dp[i][d]);
        }
    }
    return ans;
}
```

##### 固定差值范围的二维数组

- 适用于数值范围较小的场景

如果已知 `nums[i]` 的取值范围较小, 例如此题中 $0≤nums[i]≤500$，那么公差 $d ∈ [−500,500]$，可以用一个定长二维数组代替哈希表。这样常数略小，速度更快。

- 令 `OFFSET = 500`，把真实差值 `d` 映射到数组下标 `d+OFFSET`；
- 用 `dp[i][d+OFFSET]` 存「以 i 结尾，公差为 d」的最大长度。

时间复杂度同样 O(n²)，空间复杂度 O(n·D)，其中 D=1001。

```cpp
int longestArithSeqLength(vector<int>& nums) {
    int n = nums.size();
    if (n < 2) return n;
    const int OFFSET = 500;
    const int D = 2 * OFFSET + 1;  // 差值映射区间大小
    int ans = 2;
    // dp[i][k]: 以 nums[i] 结尾，差值为 (k-OFFSET) 的最长等差子序列长度
    vector<vector<int>> dp(n, vector<int>(D, 0));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            int diff = nums[i] - nums[j] + OFFSET;  // 映射到 [0..D)
            // 如果之前没有，至少能组成长度为 2 的 (nums[j], nums[i])
            dp[i][diff] = max(dp[i][diff], dp[j][diff] ? dp[j][diff] + 1 : 2);
            ans = max(ans, dp[i][diff]);
        }
    }
    return ans;
}
```

#### 若为最长等差子数组, 可使用滑动窗口

```cpp title:"最长等差子数组（连续）长度"
int longestArithSubarrayLength(const vector<int>& nums) {
    int n = nums.size();
    if (n < 2) return n;
    int best = 2;
    int cur = 2;
    int d = nums[1] - nums[0];
    for (int i = 2; i < n; i++) {
        int di = nums[i] - nums[i - 1];
        if (di == d) {
            cur++;
        } else {
            d = di;
            cur = 2;
        }
        best = max(best, cur);
    }
    return best;
}
```
